# Math — Grade 6 — Unit 1, Lesson 4

## Topic
Ratio Tables

## Learning Objectives
- Organize equivalent ratios in a ratio table.
- Use multiplication and division patterns to find missing values in a ratio table.
- Apply ratio tables to solve real-world problems involving equivalent ratios.

## Prerequisites
- Understanding of equivalent ratios (Lesson 3).
- Ability to multiply and divide both terms of a ratio by the same number.
- Familiarity with reading and completing simple tables.
- Multiplication fluency through 12 x 12.

## Materials Needed
- Whiteboard and markers (or projector).
- Graph paper (optional, for drawing tables neatly).
- Student worksheet (Guided Practice and Independent Practice problems).
- Index cards or half-sheets for Exit Ticket.

**Standards:** 6.RP.3a — Make tables of equivalent ratios relating quantities with whole-number measurements, find missing values in the tables, and plot the pairs of values on the coordinate plane.

## Warm-Up (5 minutes)

**Purpose:** Review generating equivalent ratios and set up the need for an organized tool to track them.

1. Ask: "List four equivalent ratios for 3:4." Give the student 90 seconds.
2. Ask: "How did you keep track of them? Did you write them in a list? Did you have a system?"
3. Say: "Today we are going to learn a tool called a ratio table that helps us organize equivalent ratios in a clear, systematic way. It makes finding patterns — and missing values — much easier."

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Ratio table** — A table that lists pairs of numbers that are all equivalent ratios of each other.
- **Scale factor** — The number you multiply (or divide) both terms by to move from one row of a ratio table to another.

### Instruction Notes

**Step 1 — Connect to a concrete model.**

Say: "Suppose a smoothie recipe uses 2 bananas for every 5 strawberries. Let's figure out how many of each we need for different batch sizes."

Build the first row with counters: 2 bananas (yellow counters), 5 strawberries (red counters). Then double: 4 bananas, 10 strawberries. Triple: 6 bananas, 15 strawberries.

Now organize this in a table on the board:

| Bananas | Strawberries |
|---------|-------------|
| 2       | 5           |
| 4       | 10          |
| 6       | 15          |
| 8       | 20          |
| 10      | 25          |

Say: "This is a ratio table. Each row shows an equivalent ratio. The ratio of bananas to strawberries is always 2:5."

**Step 2 — Show the multiplication pattern.**

Point to the table. "Notice the pattern going down: bananas go up by 2, strawberries go up by 5. That is the additive pattern — you are adding another batch each time."

"But there is also a multiplicative pattern. From the first row to the third row: 2 x 3 = 6, and 5 x 3 = 15. We multiplied both by 3. From the first row to the fifth row: 2 x 5 = 10, and 5 x 5 = 25. We multiplied both by 5."

"You can use either pattern to extend a ratio table, but multiplication is more powerful because it lets you jump to any row, not just the next one."

**Step 3 — Find missing values in a ratio table.**

Present this table with a missing value:

| Laps | Minutes |
|------|---------|
| 3    | 12      |
| 6    | 24      |
| 9    | ?       |

"How do we find the missing value? Strategy 1: Notice the additive pattern — laps go up by 3, minutes go up by 12. So the missing value is 24 + 12 = 36."

"Strategy 2: From the first row, multiply both by 3. 3 x 3 = 9 (check), 12 x 3 = 36. Same answer."

Now show a table where the jump is not sequential:

| Apples | Cost ($) |
|--------|----------|
| 4      | 3        |
| ?      | 15       |

"Here, the additive pattern does not help as easily because we skipped rows. Use multiplication: 3 x ? = 15, so ? = 5. We multiplied the cost by 5, so multiply apples by 5 too: 4 x 5 = 20 apples."

**Step 4 — Show how to use division to go backward.**

| Students | Textbooks |
|----------|-----------|
| 30       | 5         |
| 6        | ?         |

"From 30 to 6, we divided by 5 (30 / 5 = 6). So divide textbooks by 5 too: 5 / 5 = 1. The missing value is 1."

### Worked Examples

**Example A — Complete a ratio table.**

The ratio of red paint cans to blue paint cans is 3:7. Fill in the ratio table.

| Red | Blue |
|-----|------|
| 3   | 7    |
| 6   | 14   |
| 9   | 21   |
| 12  | 28   |
| 15  | 35   |

Method: Each row multiplies the original 3:7 by 1, 2, 3, 4, 5. Alternatively, each row adds 3 to red and 7 to blue.

**Example B — Find a missing value using multiplication.**

| Hours | Miles |
|-------|-------|
| 2     | 90    |
| 6     | ?     |

From 2 to 6, we multiply by 3 (2 x 3 = 6). So multiply miles by 3: 90 x 3 = 270. The missing value is 270 miles.

**Example C — Find a missing value using division.**

| Cups of Flour | Cups of Sugar |
|--------------|---------------|
| 18           | 12            |
| 3            | ?             |

From 18 to 3, we divide by 6 (18 / 6 = 3). So divide sugar by 6: 12 / 6 = 2. The missing value is 2 cups of sugar.

## Guided Practice (10 minutes)

1. Complete the ratio table for the ratio 5:2.

   | Column A | Column B |
   |----------|----------|
   | 5        | 2        |
   | 10       | ?        |
   | 15       | ?        |
   | 20       | ?        |

   - *Facilitator prompt:* "What do you multiply 5 by to get 10? Apply the same multiplier to 2."

2. Find the missing value.

   | Dogs | Cats |
   |------|------|
   | 4    | 7    |
   | 12   | ?    |

   - *Facilitator prompt:* "What did you multiply 4 by to get 12? Now do the same to 7."

3. Find the missing value.

   | Hours | Pages Read |
   |-------|-----------|
   | 8     | 120       |
   | 2     | ?         |

   - *Facilitator prompt:* "We are going from a bigger number to a smaller number. Should we multiply or divide?"

4. A cookie recipe uses 3 eggs for every 5 cups of flour. Complete the ratio table.

   | Eggs | Flour (cups) |
   |------|-------------|
   | 3    | 5           |
   | 6    | ?           |
   | ?    | 20          |
   | 15   | ?           |

   - *Facilitator prompt:* "Work row by row. For each, figure out what you multiplied the known value by compared to the first row."

5. Is the pair (8, 14) in the ratio table for 4:7? Explain how you know.
   - *Facilitator prompt:* "If the base ratio is 4:7, what do you multiply both by to check if you get 8 and 14?"

## Check for Understanding (5 minutes)

### Exit Ticket

1. Complete the ratio table.

   | Cats | Dogs |
   |------|------|
   | 3    | 8    |
   | 9    | ?    |

2. Find the missing value.

   | Miles | Hours |
   |-------|-------|
   | 40    | 8     |
   | ?     | 2     |

**Scoring:**
- 2 out of 2 correct = Mastery demonstrated.
- 1 out of 2 correct = Partial understanding; review errors.
- 0 out of 2 correct = Reteach needed.

### If Mastery Is Not Met
Return to building with counters. Have the student physically build 3 red and 8 blue, then make two more copies and count. Record results in a table. Emphasize: "Every row is just more copies of the same group." Then practice the multiplication strategy: "What did you multiply by to get from here to here?"

### If Mastery Is Met
Give the student this challenge: "Create a ratio table where the first row is 7:4. Fill in five rows. Then cover up two values in different rows and give it to me as a puzzle to solve."

## Extension (Optional)

1. **Build a Ratio Table Story:** Write a short story about a real-world situation (like a recipe, a sports season, or a road trip). Create a ratio table with at least five rows that goes with your story, and include two missing values for someone else to find.

2. **Coordinate Connection:** Plot the pairs from a ratio table on a coordinate grid (the first column is x, the second column is y). What do you notice about the points? (They should form a straight line through the origin.)

## Teacher/Facilitator Notes

### Common Errors
- **Adding a constant to only one column.** Students may see the additive pattern in one column (e.g., +3) but forget to apply the corresponding pattern to the other column. Emphasize that both columns must follow the same multiplicative scaling.
- **Using different multipliers for each column.** A student might multiply the first column by 3 and the second by 2, creating a row that is NOT an equivalent ratio. Always check: "Did you multiply both by the same number?"
- **Struggling with division to go backward.** If a student is comfortable multiplying forward but cannot divide to go from a larger row to a smaller one, practice finding the scale factor explicitly: "What number do I divide 12 by to get 4? That is 3. Now divide the other side by 3 too."

### Pacing Advice
Most students find ratio tables intuitive because the table structure provides a visual scaffold. Spend the most time on problems where the jump between rows is not sequential (e.g., going from row 1 directly to row 4) because these require multiplicative rather than additive thinking. If the student is quick, push into the Stretch problem 6, which requires reasoning about a non-standard scale factor.
