# Math — Grade 6 — Unit 3, Lesson 5

## Topic
Equivalent Expressions

## Learning Objectives
- Identify like terms in an algebraic expression and combine them.
- Apply the distributive property to expand expressions of the form a(b + c).
- Use the distributive property and combining like terms to simplify expressions.
- Verify that two expressions are equivalent by substituting values.

## Prerequisites
- Writing and identifying parts of algebraic expressions (Lesson 3).
- Evaluating algebraic expressions by substituting values (Lesson 4).
- Understanding of the commutative and associative properties from earlier grades.

## Materials Needed
- Whiteboard and markers (or projector).
- Algebra tiles (or paper cut-outs: large squares for x, small unit squares for 1).
- Student worksheet (Guided Practice and Independent Practice problems).
- Colored pencils (for distinguishing variable terms and constant terms).
- Paper and pencil.

**Standards:** 6.EE.3 — Apply the properties of operations to generate equivalent expressions. 6.EE.4 — Identify when two expressions are equivalent.

## Warm-Up (5 minutes)

**Purpose:** Introduce the idea that two different-looking expressions can have the same value.

1. Write on the board: Expression A = 3 + 3 + 3 + 3. Expression B = 4 x 3. Ask: "Are these the same?" (Yes, both equal 12.)
2. Write: Expression C = 2(5 + 1). Expression D = 2 x 5 + 2 x 1. Ask: "Evaluate both." (C = 2 x 6 = 12. D = 10 + 2 = 12.)
3. Say: "Two expressions that always give the same value, no matter what numbers you use, are called equivalent expressions. Today we learn two powerful tools for creating equivalent expressions: combining like terms and the distributive property."

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Equivalent expressions** — Expressions that have the same value for every possible value of the variable(s).
- **Like terms** — Terms that have the same variable raised to the same power. For example, 3x and 5x are like terms; 3x and 3y are not; 3x and 3x^2 are not.
- **Combining like terms** — Adding or subtracting the coefficients of like terms. For example, 3x + 5x = 8x.
- **Distributive property** — A property that states a(b + c) = ab + ac. Multiplying a number by a sum is the same as multiplying the number by each addend and then adding the products.

### Instruction Notes

**Step 1 — Like terms and combining them.**

Write on the board: 3x + 5x.

Say: "These are like terms because they both have the variable x. Think of it this way: if x represents apples, then 3 apples + 5 apples = 8 apples. So 3x + 5x = 8x."

Write: 4y + 2y - y.

Say: "All three terms are like terms (they all have y). Remember, y means 1y. So: 4y + 2y - 1y = 5y."

Write: 3x + 7 + 2x + 5.

Say: "Here we have two types of terms: variable terms (3x and 2x) and constants (7 and 5). We can only combine like terms. So: 3x + 2x = 5x, and 7 + 5 = 12. The simplified expression is 5x + 12."

Write: 6a + 3b + 2a.

Say: "6a and 2a are like terms (both have a), but 3b is different. So: 6a + 2a = 8a, and 3b stays. The result is 8a + 3b."

**Important warning:** Write 3x + 5 on the board. Say: "Can we simplify this? No! 3x and 5 are NOT like terms. 3x means 3 groups of x and 5 is just the number 5. We cannot combine them into 8x or 8. The expression 3x + 5 is already as simple as it gets."

**Step 2 — The distributive property.**

Draw a rectangle on the board divided into two sections. Label the width as 3 and the two length sections as x and 4.

Say: "The area of this rectangle can be written two ways: as 3(x + 4) — width times total length — or as 3x + 12 — the sum of the two smaller rectangle areas. These are equivalent expressions."

Write the property: a(b + c) = ab + ac.

Say: "The distributive property says: multiply the number outside the parentheses by EVERY term inside. Watch out — a common mistake is to multiply only the first term."

Demonstrate:
- 2(x + 3) = 2 x x + 2 x 3 = 2x + 6
- 5(2n - 4) = 5 x 2n - 5 x 4 = 10n - 20
- 4(3x + 2y + 1) = 12x + 8y + 4

**Step 3 — Combining both skills.**

Write: 3(x + 2) + 4x.

Say: "First, distribute: 3(x + 2) = 3x + 6. Now the expression is 3x + 6 + 4x. Combine like terms: 3x + 4x = 7x. Result: 7x + 6."

**Step 4 — Verifying equivalence by substitution.**

Say: "How can we check that 3(x + 2) + 4x and 7x + 6 are really equivalent? We substitute a value — say x = 5 — into both and check."

- 3(5 + 2) + 4(5) = 3(7) + 20 = 21 + 20 = 41.
- 7(5) + 6 = 35 + 6 = 41.

Say: "Both give 41. That gives us confidence they are equivalent. To be even more sure, you could try another value."

### Worked Examples

**Example A: Combining like terms.**

Simplify: 7m + 3 + 2m - 1.

- Group like terms: (7m + 2m) + (3 - 1).
- Combine: 9m + 2.
- Answer: **9m + 2**.

**Example B: Distributive property.**

Expand: 6(2x + 5).

- Distribute 6 to each term: 6 x 2x + 6 x 5.
- Compute: 12x + 30.
- Answer: **12x + 30**.

**Example C: Distribute and combine.**

Simplify: 2(3n + 4) + 5n - 1.

- Distribute: 2(3n + 4) = 6n + 8.
- Rewrite: 6n + 8 + 5n - 1.
- Combine like terms: (6n + 5n) + (8 - 1) = 11n + 7.
- Answer: **11n + 7**.

## Guided Practice (10 minutes)

Simplify each expression. Show your steps.

1. 5x + 3x
   - Answer: **8x**

2. 4a + 7 + 2a + 3
   - Answer: (4a + 2a) + (7 + 3) = **6a + 10**

3. Expand: 3(y + 6)
   - Answer: 3y + 18

4. Expand: 4(2x - 3)
   - Answer: 8x - 12

5. Simplify: 2(x + 5) + 3x
   - Answer: 2x + 10 + 3x = **5x + 10**

6. Are the expressions 4(n + 2) and 4n + 8 equivalent? Verify by substituting n = 3.
   - Answer: 4(3 + 2) = 4(5) = 20. And 4(3) + 8 = 12 + 8 = 20. Yes, they are equivalent.

**Facilitator tip:** For problem 4, if the student writes 4(2x - 3) = 8x - 3, they forgot to distribute to the second term. Draw the rectangle model: width 4, lengths 2x and -3. Both parts get multiplied by 4.

## Independent Practice (10-15 minutes)

### Part A: Combining Like Terms

Simplify each expression.

1. 6y + 4y
2. 8n - 3n + 2
3. 3x + 5 + 7x - 2
4. 2a + 9b + 5a - 3b
5. 12 + 4p - 7 + p

### Part B: Distributive Property

Expand each expression.

6. 5(x + 4)
7. 3(2n - 7)
8. 8(3y + 1)
9. 2(4a + 3b)
10. 7(x - 2) + 3

### Part C: Word Problems

11. Destiny says 5x + 3 can be simplified to 8x. Is she correct? Explain why or why not.

12. Write two different expressions that are both equivalent to 6x + 12. Verify your answer by substituting x = 2 into all three expressions.

13. A school is ordering supplies for n classrooms. Each classroom needs 4 boxes of markers and 3 boxes of crayons. Write two equivalent expressions for the total number of boxes needed: one using the distributive property form and one in expanded form.

### Answer Key

**Part A**

1. **10y**
2. 8n - 3n + 2 = **5n + 2**
3. (3x + 7x) + (5 - 2) = **10x + 3**
4. (2a + 5a) + (9b - 3b) = **7a + 6b**
5. (4p + p) + (12 - 7) = **5p + 5**

**Part B**

6. **5x + 20**
7. **6n - 21**
8. **24y + 8**
9. **8a + 6b**
10. 7x - 14 + 3 = **7x - 11**

**Part C**

11. Destiny is incorrect. 5x and 3 are not like terms — 5x has a variable and 3 is a constant. They cannot be combined. The expression 5x + 3 is already simplified.

12. Answers will vary. Two equivalent expressions: 3(2x + 4) and 2(3x + 6). Check with x = 2: 6(2) + 12 = 24; 3(2(2) + 4) = 3(8) = 24; 2(3(2) + 6) = 2(12) = 24. All three equal 24.

13. Distributive property form: n(4 + 3) = n(7) = 7n. Expanded form: 4n + 3n. Both simplify to 7n total boxes. Verification: if n = 5 classrooms, then 7(5) = 35 boxes. Also: 4(5) + 3(5) = 20 + 15 = 35 boxes.

## Assessment Check

Simplify: 4(2x + 3) + 5x - 6.

**Target response:** 4(2x + 3) = 8x + 12. Then 8x + 12 + 5x - 6. Combine like terms: (8x + 5x) + (12 - 6) = **13x + 6**. If the student gets a different answer, check their distribution step and their combining of like terms separately.

## Extension

- **Algebra Tile Models:** Use algebra tiles (or draw them) to model and simplify the following: (a) 2(x + 3) — show 2 groups of (1 x-tile and 3 unit-tiles). (b) 3(2x + 1) + x — show 3 groups of (2 x-tiles and 1 unit-tile), then add 1 more x-tile. Draw the final result and write the simplified expression.

- **Reverse Engineering:** The simplified expression is 8x + 5. Write three different unsimplified expressions that are equivalent to 8x + 5. For example: 3x + 5x + 5, or 2(4x + 2) + 1, or 8x + 10 - 5. Verify each by substituting x = 1.
