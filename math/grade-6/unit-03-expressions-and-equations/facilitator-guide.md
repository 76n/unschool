# Facilitator Guide — Grade 6 Math, Unit 3: Expressions and Equations

**Grade:** 6
**Subject:** Mathematics
**Unit:** 3 — Expressions and Equations
**Recommended Duration:** 10 lessons (approximately 3-4 weeks at 3 sessions/week)
**Facilitation Mode:** Guided (facilitator leads instruction; student works independently for practice)

---

## Unit Overview

This unit introduces the foundational concepts of algebra. Students learn to write, evaluate, and simplify numerical and algebraic expressions. They build understanding of variables as representations of unknown or changing quantities. The unit then transitions into equations — what they mean, how they differ from expressions, and how to solve one-step equations using inverse operations. Finally, students explore inequalities and their representations on the number line. This unit is a critical bridge from arithmetic thinking to algebraic reasoning and sets the stage for multi-step equations in Grade 7.

By the end of this unit, the student will be able to:

- Write numerical expressions using exponents and evaluate them using the order of operations
- Use variables to represent unknowns and changing quantities in algebraic expressions
- Evaluate algebraic expressions by substituting given values for variables
- Apply the distributive property and combine like terms to generate equivalent expressions
- Distinguish between expressions and equations
- Solve one-step equations involving addition, subtraction, multiplication, and division using inverse operations
- Translate real-world situations into equations and solve them
- Write, interpret, and graph simple inequalities on a number line

**Why this matters:** Algebra is the language of mathematics. The ability to represent relationships with variables, write equations to model real-world problems, and reason about unknowns is essential for every subsequent math course. This unit gives students their first formal tools for algebraic thinking — skills they will use throughout middle school, high school, and beyond.

## Lesson Summaries and Facilitation Notes

### Lesson 1: Writing Numerical Expressions
**Goal:** Translate word phrases into numerical expressions and introduce exponent notation.
**Key moves:** Start with familiar operations ("the sum of 8 and 3" = 8 + 3) and build to multi-operation phrases. Introduce exponents as repeated multiplication: 2^3 means 2 x 2 x 2, not 2 x 3. Have students practice both directions: phrase-to-expression and expression-to-phrase.
**Watch for:** Students confusing exponents with multiplication (e.g., thinking 3^4 = 12 instead of 81). Spend extra time on the distinction with physical demonstrations (e.g., stacking groups).

### Lesson 2: Order of Operations
**Goal:** Evaluate multi-step numerical expressions using the correct order of operations (PEMDAS/GEMDAS).
**Key moves:** Present a problem like 3 + 4 x 2 and let students argue about the answer before revealing the convention. Introduce the order: Grouping symbols, Exponents, Multiplication/Division (left to right), Addition/Subtraction (left to right). Emphasize that multiplication and division are equal rank (process left to right), as are addition and subtraction.
**Watch for:** Students who always multiply before dividing or always add before subtracting regardless of left-to-right order. Also watch for students who apply PEMDAS too rigidly (e.g., thinking multiplication always comes before division).

### Lesson 3: Variables and Algebraic Expressions
**Goal:** Understand that a variable represents an unknown or changing value, and translate word phrases into algebraic expressions.
**Key moves:** Introduce the variable as a letter standing for a number. Use real-world contexts: "Let n = the number of students in a class." Build expressions from situations: "5 more than a number" = n + 5. Emphasize that "3 times a number" is written as 3n (not 3 x n or 3*n in algebra).
**Watch for:** Students thinking a variable always has one fixed value. Clarify: sometimes it represents an unknown we want to find, and sometimes it represents a quantity that can change.

### Lesson 4: Evaluating Algebraic Expressions
**Goal:** Substitute given values into algebraic expressions and evaluate using order of operations.
**Key moves:** Start with single-variable expressions (evaluate 3x + 7 when x = 4). Show the substitution step explicitly: 3(4) + 7 = 12 + 7 = 19. Use parentheses around the substituted value to avoid errors. Progress to multi-variable expressions (evaluate 2a - b when a = 5, b = 3).
**Watch for:** Students who forget to apply order of operations after substitution, or who substitute incorrectly (e.g., putting the value in the wrong place). Also watch for students who write 3x = 34 (concatenation) instead of 3(4) = 12.

### Lesson 5: Equivalent Expressions
**Goal:** Use the distributive property and combine like terms to create equivalent expressions.
**Key moves:** Introduce like terms (same variable part: 3x and 5x are like terms; 3x and 3y are not). Demonstrate combining: 3x + 5x = 8x. Introduce the distributive property: 2(x + 3) = 2x + 6. Verify equivalence by substituting a value into both forms. Use area models to make the distributive property visual.
**Watch for:** Students combining unlike terms (e.g., 3x + 5 = 8x). Reinforce: only terms with the same variable part (including the same exponent) can be combined.

### Lesson 6: Introduction to Equations
**Goal:** Understand what an equation is, distinguish it from an expression, and determine whether a value is a solution.
**Key moves:** An equation has an equal sign; an expression does not. Use the balance scale metaphor: the equal sign means both sides weigh the same. Test whether a given value is a solution by substituting it in and checking both sides. Example: Is x = 5 a solution to 2x + 1 = 11? Check: 2(5) + 1 = 11, 11 = 11. Yes!
**Watch for:** Students confusing expressions and equations. A clear anchor chart helps: "Expression = phrase (no equal sign), Equation = sentence (has an equal sign)."

### Lesson 7: Solving One-Step Equations: Addition and Subtraction
**Goal:** Solve equations of the form x + a = b and x - a = b using inverse operations.
**Key moves:** Use the balance scale metaphor heavily. Whatever you do to one side, you must do to the other side. For x + 5 = 12, subtract 5 from both sides. For x - 3 = 8, add 3 to both sides. Always check by substituting the answer back into the original equation. Include examples with fractions and decimals.
**Watch for:** Students who guess-and-check instead of using inverse operations. While guess-and-check works for simple problems, students need to learn the algebraic method for harder problems ahead.

### Lesson 8: Solving One-Step Equations: Multiplication and Division
**Goal:** Solve equations of the form ax = b and x/a = b using inverse operations.
**Key moves:** Continue the balance metaphor. For 3x = 15, divide both sides by 3. For x/4 = 6, multiply both sides by 4. Show the connection: multiplication and division are inverse operations, just as addition and subtraction are. Include examples with fractions (e.g., x/2 = 3.5, 1/3 x = 9).
**Watch for:** Students who confuse which operation to "undo." Reinforce: look at what operation is happening to the variable and do the opposite. Also watch for students dividing in the wrong direction (e.g., dividing 15 by x instead of dividing both sides by 3).

### Lesson 9: Writing and Solving Equations from Word Problems
**Goal:** Translate real-world situations into one-step equations and solve them.
**Key moves:** Use a structured approach: (1) Identify what is unknown and assign a variable, (2) Identify the relationship and write an equation, (3) Solve, (4) Check in the context of the problem. Practice with money, measurement, and age problems. Emphasize that the answer must make sense in context (no negative ages, no half-people).
**Watch for:** Students who struggle to identify which operation the situation describes. Use key-word lists cautiously (key words can mislead), but do help students recognize common structures: "total" often means addition, "each" or "per" often means multiplication.

### Lesson 10: Inequalities
**Goal:** Write, interpret, and graph simple inequalities on a number line; solve simple one-step inequalities.
**Key moves:** Introduce inequality symbols (<, >, <=, >=) and their meanings. Translate situations to inequalities: "You must be at least 48 inches tall" = h >= 48. Graph on number line with open/closed circles. Solve simple one-step inequalities using the same inverse operations as equations. Introduce the rule: when multiplying/dividing by a negative, flip the inequality sign (briefly, with explanation).
**Watch for:** Students confusing the direction of inequality symbols. The mnemonic "the alligator eats the bigger number" or "the arrow points to the smaller number" can help. Also watch for confusion about open vs. closed circles on the number line.

## Differentiation Strategies

### Struggling Learners
- Provide a "key phrase to operation" reference card for translating words to expressions
- Use physical algebra tiles or cut-out manipulatives for combining like terms and solving equations
- For equation solving, draw the balance scale for every problem until the concept is automatic
- Allow a PEMDAS reference card during practice (fade out over time)
- Reduce the number of practice problems but increase scaffolding on each one

### Advanced Learners
- Introduce two-step equations informally (e.g., 2x + 3 = 11)
- Explore writing expressions with multiple variables for real-world formulas (distance = rate x time)
- Challenge: find multiple equivalent forms for the same expression
- Extend inequalities: solve and graph compound inequalities (e.g., 2 < x < 7) informally
- Create their own word problems that translate to given equations

## Common Errors and How to Address Them

| Error | Likely Cause | Remediation |
|-------|-------------|-------------|
| 3^4 = 12 instead of 81 | Confusing exponents with multiplication | Return to definition: 3^4 = 3 x 3 x 3 x 3. Write out expanded form every time. |
| 3 + 4 x 2 = 14 instead of 11 | Evaluating left to right, ignoring order of operations | Review the PEMDAS hierarchy. Circle the operation to do first before computing. |
| Combining 3x + 5 = 8x | Treating unlike terms as like terms | Use color coding: highlight variable terms in one color, constants in another. Only same-color terms combine. |
| 2(x + 3) = 2x + 3 | Distributing to only one term | Use the area model: draw a rectangle with width 2 and length (x + 3). Both parts of the length get multiplied. |
| x + 5 = 12, so x = 17 | Adding instead of subtracting to solve | Return to balance scale: "If x + 5 = 12, and you add 5 more, is it still balanced?" Show that undoing means using the opposite operation. |
| 3x = 15, so x = 5 but then writes 3(5) = 35 | Concatenation error during check | Always use parentheses for substitution: 3(5) means 3 times 5 = 15. |

## Assessment Guidance

The **Unit Assessment** covers all major skills. Administer after Lesson 10.

**Mastery criteria (80% or above = 40 of 50 points):**
- Writes and evaluates numerical and algebraic expressions correctly
- Applies order of operations with grouping symbols, exponents, and all four operations
- Uses the distributive property and combines like terms to create equivalent expressions
- Solves one-step equations using inverse operations and checks solutions
- Writes and graphs inequalities on a number line

**If below mastery:** Reteach based on error patterns — expression writing and evaluation (Lessons 1-4), equivalent expressions (Lesson 5), equation concepts and solving (Lessons 6-8), word problems (Lesson 9), or inequalities (Lesson 10).
