# Math — Grade 6 — Unit 3, Lesson 3

## Topic
Variables and Algebraic Expressions

## Learning Objectives
- Define a variable and explain how it differs from a specific number.
- Translate word phrases into algebraic expressions using variables.
- Use correct algebraic notation (e.g., 3n instead of 3 x n).
- Identify the parts of an algebraic expression: terms, coefficients, and constants.

## Prerequisites
- Writing numerical expressions from word phrases (Lesson 1).
- Evaluating numerical expressions using order of operations (Lesson 2).
- Familiarity with using letters to represent unknowns from simple missing-number problems (e.g., ___ + 5 = 12).

## Materials Needed
- Whiteboard and markers (or projector).
- Index cards for vocabulary matching.
- Student worksheet (Guided Practice and Independent Practice problems).
- Paper and pencil.

**Standards:** 6.EE.2a — Write expressions that record operations with numbers and with letters standing for numbers. 6.EE.6 — Use variables to represent numbers and write expressions when solving a real-world or mathematical problem.

## Warm-Up (5 minutes)

**Purpose:** Bridge from numerical expressions to the idea that sometimes we do not know one of the numbers.

1. Write on the board: "A bag has some marbles. You add 5 more marbles. Write an expression for the total number of marbles."
2. Ask: "What is the problem here?" Guide the student to see: we do not know how many marbles are in the bag to start with.
3. Say: "In Lesson 1, we turned word phrases into numerical expressions where every number was given. But what if a number is unknown or could change? Today we learn how to use a letter — called a variable — to stand in for that unknown number."
4. Write: n + 5. Say: "We let n = the number of marbles already in the bag. Then 'add 5 more' gives us n + 5. This is called an algebraic expression."

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Variable** — A letter or symbol used to represent a number that is unknown or that can change.
- **Algebraic expression** — A mathematical phrase that contains numbers, variables, and operation symbols, but no equal sign.
- **Term** — A single number, a variable, or a number multiplied by a variable. In the expression 3x + 7, the terms are 3x and 7.
- **Coefficient** — The number multiplied by a variable. In 3x, the coefficient is 3. If a variable has no visible coefficient (e.g., x), the coefficient is 1.
- **Constant** — A term with no variable. In 3x + 7, the constant is 7.

### Instruction Notes

**Step 1 — What is a variable?**

Say: "A variable is a letter that stands for a number. We often use letters like x, y, n, or a, but any letter works. Sometimes the variable represents one specific unknown number that we want to find. Other times it represents a quantity that can take on many different values."

Give examples:
- "Let n = the number of students in a class." (n could be 20, 25, 30 — it varies.)
- "A shirt costs d dollars." (d could be any price.)
- "You are x years old." (x is a specific number — your actual age — but we just do not know it yet.)

**Step 2 — Translating word phrases to algebraic expressions.**

Say: "The same translation skills you used in Lesson 1 work here, but now one or more numbers are replaced by variables."

Work through these translations together:

| Word Phrase | Algebraic Expression |
|-------------|---------------------|
| A number plus 8 | n + 8 |
| 5 less than a number | n - 5 |
| Twice a number | 2n |
| A number divided by 4 | n ÷ 4 or n/4 |
| 3 more than twice a number | 2n + 3 |
| The product of a number and itself | n x n or n^2 |

Say: "Notice that 'twice a number' is written as 2n, not 2 x n. In algebra, when a number is multiplied by a variable, we write them side by side. The multiplication symbol is dropped to avoid confusion with the letter x. So 3 times a number is 3n, not 3 x n."

Say: "Also notice that 'a number divided by 4' can be written as n ÷ 4 or as a fraction: n/4. Both mean the same thing."

**Step 3 — Identifying parts of an expression.**

Write the expression: 4x + 3y - 7.

Say: "This expression has three terms: 4x, 3y, and 7."

- "In 4x, the coefficient is 4 and the variable is x."
- "In 3y, the coefficient is 3 and the variable is y."
- "The number 7 is a constant — it has no variable attached."

Write: x + 9.

Say: "This has two terms: x and 9. The coefficient of x is 1, because x means 1 times x. We just do not write the 1."

### Worked Examples

**Example A: Simple translation.**

Write an algebraic expression for: "a number decreased by 12."

- "Decreased by" means subtraction.
- Let n = the number.
- Expression: n - 12.
- Answer: **n - 12**.

**Example B: Two-operation translation.**

Write an algebraic expression for: "6 more than 4 times a number."

- "4 times a number" = 4n.
- "6 more than" = add 6.
- Expression: 4n + 6.
- Answer: **4n + 6**.

**Example C: Real-world context.**

A movie ticket costs $9. You also buy a popcorn that costs p dollars. Write an expression for the total cost.

- The ticket is $9 (a constant).
- The popcorn is p dollars (a variable because the price could vary).
- Total cost: 9 + p.
- Answer: **9 + p** (or equivalently, **p + 9**).

## Guided Practice (10 minutes)

Write an algebraic expression for each situation. Use the variable suggested.

1. A number (n) increased by 15.
   - Answer: n + 15

2. The product of 7 and a number (x).
   - Answer: 7x

3. 10 less than a number (y).
   - Answer: y - 10

4. A number (m) divided by 3, then plus 4.
   - Answer: m/3 + 4

5. You have d dollars. You spend $8 on lunch. Write an expression for how much money you have left.
   - Answer: d - 8

6. A rectangle has a length of 12 inches and a width of w inches. Write an expression for its perimeter.
   - Answer: 2(12) + 2w = 24 + 2w (accept either form)

**Facilitator tip:** For problem 6, remind the student that perimeter = 2 x length + 2 x width. This connects algebra to geometry and shows that algebraic expressions model real situations.

## Independent Practice (10-15 minutes)

### Part A: Translating Phrases

Write an algebraic expression for each phrase. Use the variable n for "a number."

1. A number plus 20
2. A number minus 6
3. Triple a number
4. A number divided by 5
5. 8 less than twice a number
6. The sum of a number and 15, divided by 3
7. 4 times the quantity of a number plus 9
8. A number squared, minus 10

### Part B: Identifying Parts

For each expression, identify (a) the terms, (b) the coefficients, and (c) any constants.

9. 5x + 2
10. 3a - 7b + 12
11. y + 4

### Part C: Word Problems

12. Jasmine earns $12 per hour babysitting. She worked h hours last week. Write an expression for the total amount she earned.

13. A class has b boys and g girls. Write an expression for the total number of students in the class.

14. Liam is y years old. His sister is 3 years younger. Write an expression for his sister's age.

### Answer Key

**Part A**

1. n + 20
2. n - 6
3. 3n
4. n/5
5. 2n - 8
6. (n + 15)/3 or (n + 15) ÷ 3
7. 4(n + 9)
8. n^2 - 10

**Part B**

9. Terms: 5x and 2. Coefficient of x: 5. Constant: 2.
10. Terms: 3a, 7b, and 12. Coefficient of a: 3. Coefficient of b: 7. Constant: 12.
11. Terms: y and 4. Coefficient of y: 1. Constant: 4.

**Part C**

12. 12h (or 12 x h). Jasmine earns $12 for each hour, so total earnings = 12 times the number of hours.
13. b + g. The total number of students is the number of boys plus the number of girls.
14. y - 3. His sister is 3 years younger, so subtract 3 from Liam's age.

## Assessment Check

A pizza costs $14 and each extra topping costs t dollars. You order 3 extra toppings. Write an expression for the total cost of the pizza.

**Target response:** 14 + 3t. (The base pizza is $14, and each of the 3 toppings costs t dollars, so the topping cost is 3t. The total is 14 + 3t.) If the student writes 14 + t + t + t, acknowledge that it is correct but guide them to the simplified form 14 + 3t.

## Extension

- **Expression Scavenger Hunt:** Find three real-world situations around your home or school that could be modeled with an algebraic expression. For example: "The number of pages left to read if a book has 200 pages and you have read p pages: 200 - p." Write the situation and the expression for each.

- **Two-Variable Expressions:** Write algebraic expressions for these situations that involve two different variables: (a) You buy x notebooks at $3 each and y pens at $1 each. Write an expression for the total cost. (b) A rectangle has length l and width w. Write an expression for its area.
