# Math — Grade 6 — Unit 3, Lesson 4

## Topic
Evaluating Algebraic Expressions

## Learning Objectives
- Substitute given values for variables in algebraic expressions.
- Use parentheses around substituted values to maintain clarity and avoid errors.
- Apply the order of operations after substitution to evaluate expressions correctly.
- Evaluate expressions with more than one variable.

## Prerequisites
- Writing algebraic expressions with variables (Lesson 3).
- Understanding of terms, coefficients, and constants (Lesson 3).
- Evaluating numerical expressions using order of operations (Lesson 2).

## Materials Needed
- Whiteboard and markers (or projector).
- Student worksheet (Guided Practice and Independent Practice problems).
- Paper and pencil.

**Standards:** 6.EE.2c — Evaluate expressions at specific values of their variables. Include expressions that arise from formulas used in real-world problems. Perform arithmetic operations, including those involving whole-number exponents, in the conventional order when there are no parentheses to specify a particular order.

## Warm-Up (5 minutes)

**Purpose:** Review the idea that a variable represents a number, and build toward replacing it with a specific value.

1. Write on the board: n + 5. Say: "If n = 3, what is the value of n + 5?" (3 + 5 = 8.)
2. Write: n + 5. Say: "Now, if n = 10, what is the value?" (10 + 5 = 15.)
3. Write: n + 5. Say: "And if n = 0?" (0 + 5 = 5.)
4. Say: "The expression n + 5 gives us a different answer depending on what value n takes. Today we are going to practice this skill — called evaluating an algebraic expression — with more complex expressions. The key is to be organized and careful, especially when there are multiple operations."

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Evaluate** — To find the numerical value of an expression by replacing variables with given numbers and computing.
- **Substitute** — To replace a variable with a specific number.
- **Substitution** — The process of replacing a variable with a given value.

### Instruction Notes

**Step 1 — The substitution process.**

Say: "Evaluating an expression has three steps: (1) Write the expression. (2) Replace each variable with the given value, putting parentheses around it. (3) Compute using order of operations."

Write on the board: Evaluate 3x + 7 when x = 4.

Say: "Step 1: Write the expression: 3x + 7."
Say: "Step 2: Substitute — replace x with 4, using parentheses: 3(4) + 7."
Say: "Step 3: Compute using order of operations. Multiplication first: 3(4) = 12. Then addition: 12 + 7 = 19."

Say: "Why do I use parentheses? Because without them, 3x when x = 4 might look like 34 instead of 3 times 4. Parentheses make the multiplication clear."

**Step 2 — Expressions with multiple operations.**

Write: Evaluate 2x^2 - 5 when x = 3.

Say: "Replace x with (3): 2(3)^2 - 5."
Say: "Now use order of operations. Exponent first: (3)^2 = 9. Then multiply: 2 x 9 = 18. Then subtract: 18 - 5 = 13."

Ask: "What if someone did 2(3) = 6 first, then squared to get 36, then subtracted 5 to get 31? Would that be correct?" (No. The exponent applies only to x, not to 2x. That is why order of operations matters: exponents before multiplication.)

**Step 3 — Expressions with two variables.**

Write: Evaluate 5a - 2b when a = 4 and b = 3.

Say: "Replace a with (4) and b with (3): 5(4) - 2(3)."
Say: "Multiply: 5(4) = 20 and 2(3) = 6. Subtract: 20 - 6 = 14."

**Step 4 — Expressions from real-world formulas.**

Write: The area of a triangle is A = (1/2)bh, where b is the base and h is the height. Find the area when b = 10 and h = 6.

Say: "Substitute: A = (1/2)(10)(6). Multiply: (1/2)(10) = 5, then 5 x 6 = 30. The area is 30 square units."

### Worked Examples

**Example A: Single variable, one operation.**

Evaluate 8n - 3 when n = 5.

- Substitute: 8(5) - 3.
- Multiply: 8(5) = 40.
- Subtract: 40 - 3 = 37.
- Answer: **37**.

**Example B: Single variable, exponent involved.**

Evaluate x^2 + 4x when x = 6.

- Substitute: (6)^2 + 4(6).
- Exponent: (6)^2 = 36.
- Multiply: 4(6) = 24.
- Add: 36 + 24 = 60.
- Answer: **60**.

**Example C: Two variables with division.**

Evaluate (a + b) / 2 when a = 7 and b = 13.

- Substitute: (7 + 13) / 2.
- Grouping: 7 + 13 = 20.
- Divide: 20 / 2 = 10.
- Answer: **10**.

## Guided Practice (10 minutes)

Evaluate each expression for the given value(s). Show the substitution step and all work.

1. Evaluate 4x + 1 when x = 3.
   - Answer: 4(3) + 1 = 12 + 1 = **13**

2. Evaluate 20 - 2n when n = 7.
   - Answer: 20 - 2(7) = 20 - 14 = **6**

3. Evaluate n^2 + 5 when n = 4.
   - Answer: (4)^2 + 5 = 16 + 5 = **21**

4. Evaluate 3a + 2b when a = 5 and b = 4.
   - Answer: 3(5) + 2(4) = 15 + 8 = **23**

5. Evaluate (x + y) / 3 when x = 8 and y = 7.
   - Answer: (8 + 7) / 3 = 15 / 3 = **5**

6. Evaluate 2(n + 3) when n = 6.
   - Answer: 2(6 + 3) = 2(9) = **18**

**Facilitator tip:** On problem 3, make sure the student computes n^2 = 16 before adding 5. If they compute n^2 + 5 = 4^2 + 5 = 4 x 7 = 28, they are not following order of operations. Remind them: exponents come before addition.

## Independent Practice (10-15 minutes)

### Part A: Single Variable

Evaluate each expression for the given value of the variable.

1. 6x - 4 when x = 5
2. 3n + 12 when n = 8
3. 15 - 2y when y = 3
4. x^2 - 1 when x = 7
5. 4n^2 when n = 3
6. (x + 8) / 2 when x = 6
7. 5(n - 2) + 1 when n = 10
8. n^3 - 10 when n = 3

### Part B: Two Variables

Evaluate each expression for the given values.

9. a + 3b when a = 10, b = 4
10. 4x - y when x = 6, y = 9
11. xy + 2 when x = 5, y = 7
12. (m - n)^2 when m = 9, n = 4

### Part C: Word Problems

13. A gym membership costs $25 per month plus a one-time fee of $50. The expression 25m + 50 gives the total cost for m months of membership. How much does a 6-month membership cost?

14. The formula for the perimeter of a rectangle is P = 2l + 2w, where l is the length and w is the width. Find the perimeter of a rectangle with length 15 cm and width 8 cm.

### Answer Key

**Part A**

1. 6(5) - 4 = 30 - 4 = **26**
2. 3(8) + 12 = 24 + 12 = **36**
3. 15 - 2(3) = 15 - 6 = **9**
4. (7)^2 - 1 = 49 - 1 = **48**
5. 4(3)^2 = 4(9) = **36**
6. (6 + 8) / 2 = 14 / 2 = **7**
7. 5(10 - 2) + 1 = 5(8) + 1 = 40 + 1 = **41**
8. (3)^3 - 10 = 27 - 10 = **17**

**Part B**

9. 10 + 3(4) = 10 + 12 = **22**
10. 4(6) - 9 = 24 - 9 = **15**
11. (5)(7) + 2 = 35 + 2 = **37**
12. (9 - 4)^2 = (5)^2 = **25**

**Part C**

13. 25(6) + 50 = 150 + 50 = **$200**. A 6-month membership costs $200.
14. P = 2(15) + 2(8) = 30 + 16 = **46 cm**.

## Assessment Check

Evaluate 3x^2 + 2x - 5 when x = 4.

**Target response:** 3(4)^2 + 2(4) - 5 = 3(16) + 8 - 5 = 48 + 8 - 5 = **51**. If the student makes an error, identify which step went wrong (substitution, exponent, multiplication, or addition/subtraction) and address that specific skill.
