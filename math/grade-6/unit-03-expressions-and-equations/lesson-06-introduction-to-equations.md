# Math — Grade 6 — Unit 3, Lesson 6

## Topic
Introduction to Equations

## Learning Objectives
- Distinguish between an expression and an equation.
- Understand that an equation states two expressions are equal.
- Determine whether a given value is a solution to an equation by substituting and checking.
- Use the balance scale metaphor to understand what it means to keep an equation "balanced."

## Prerequisites
- Writing and evaluating algebraic expressions (Lessons 3-4).
- Combining like terms and applying the distributive property (Lesson 5).
- Understanding of the equal sign as "the same value as" (not just "the answer is").

## Materials Needed
- Whiteboard and markers (or projector).
- Balance scale image or diagram (drawn on board or printed).
- Student worksheet (Guided Practice and Independent Practice problems).
- Index cards (for expression vs. equation sorting activity).
- Paper and pencil.

**Standards:** 6.EE.5 — Understand solving an equation or inequality as a process of answering a question: which values from a specified set, if any, make the equation or inequality true? Use substitution to determine whether a given number in a specified set is a solution of an equation or inequality.

## Warm-Up (5 minutes)

**Purpose:** Deepen understanding of the equal sign and set up the distinction between expressions and equations.

1. Write on the board: 3 + 5 = 8. Ask: "Is this true or false?" (True.)
2. Write: 3 + 5 = 10. Ask: "True or false?" (False.)
3. Write: 3 + 5 = 2 + 6. Ask: "True or false?" (True — both sides equal 8.)
4. Say: "The equal sign does not mean 'the answer is.' It means 'the value on the left is the same as the value on the right.' An equation is like a balanced scale — both sides must weigh the same. Today we are going to explore equations with variables and figure out which values make them true."

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Equation** — A mathematical sentence that states two expressions are equal. It always has an equal sign (=). Example: 2x + 3 = 11.
- **Expression** — A mathematical phrase with numbers, variables, and operations but NO equal sign. Example: 2x + 3.
- **Solution** — A value for the variable that makes the equation true. Example: x = 4 is a solution to 2x + 3 = 11 because 2(4) + 3 = 11.
- **Balance scale model** — A way to think about equations: the left side and right side of the equation are like the two sides of a balance scale, and they must remain balanced (equal).

### Instruction Notes

**Step 1 — Expressions vs. equations.**

Write on the board:
- 4x + 7 (expression)
- 4x + 7 = 23 (equation)

Say: "An expression is like a phrase — it describes a quantity but does not make a claim. An equation is like a complete sentence — it says two things are equal. The difference is the equal sign."

Say: "Think of it this way: '4 times a number plus 7' is an expression. '4 times a number plus 7 is 23' is an equation. The equation makes a statement that can be true or false."

Write a sorting activity on the board:
- 3n - 5 (expression)
- y + 8 = 20 (equation)
- 2(x + 3) (expression)
- 15 = 3x (equation)
- 9 - 2m + 4 (expression)
- 7 = 7 (equation)

**Step 2 — The balance scale metaphor.**

Draw a simple balance scale on the board. On the left pan, write "2x + 3." On the right pan, write "11."

Say: "Imagine a balance scale with the left side holding 2x + 3 and the right side holding 11. The equation 2x + 3 = 11 means these two sides are balanced — they are equal. Our job is to find the value of x that makes this balance work."

Say: "This balance idea is the most important concept for solving equations. Anything you do to one side, you must also do to the other side to keep the scale balanced. We will use this idea in the next lesson when we learn to solve equations."

**Step 3 — Testing whether a value is a solution.**

Say: "To check if a value is a solution, substitute it into the equation and see if both sides are equal."

Write: Is x = 4 a solution to 2x + 3 = 11?

- Left side: 2(4) + 3 = 8 + 3 = 11.
- Right side: 11.
- 11 = 11. Yes, it is a solution.

Write: Is x = 5 a solution to 2x + 3 = 11?

- Left side: 2(5) + 3 = 10 + 3 = 13.
- Right side: 11.
- 13 does not equal 11. No, x = 5 is not a solution.

Say: "Notice that we check both sides independently and then compare. A value is a solution ONLY if it makes both sides equal."

### Worked Examples

**Example A: Testing a solution.**

Is y = 6 a solution to 3y - 4 = 14?

- Left side: 3(6) - 4 = 18 - 4 = 14.
- Right side: 14.
- 14 = 14. Yes, y = 6 is a solution.
- Answer: **Yes**.

**Example B: Finding the solution from a set.**

Which value from the set {2, 4, 6, 8} is the solution to x + 9 = 15?

- Try x = 2: 2 + 9 = 11. Not 15.
- Try x = 4: 4 + 9 = 13. Not 15.
- Try x = 6: 6 + 9 = 15. Yes!
- Answer: **x = 6**.

**Example C: Checking a two-step expression.**

Is n = 3 a solution to 5n + 2 = 18?

- Left side: 5(3) + 2 = 15 + 2 = 17.
- Right side: 18.
- 17 does not equal 18. No, n = 3 is not a solution.
- Answer: **No**. (The solution is actually n = 3.2, but students will learn to find non-integer solutions later.)

## Guided Practice (10 minutes)

1. Classify each as an expression or an equation.
   (a) 5x - 3 (b) 5x - 3 = 12 (c) 2(y + 4) (d) 7 = n + 1
   - Answer: (a) expression (b) equation (c) expression (d) equation

2. Is x = 7 a solution to x + 5 = 12?
   - Answer: 7 + 5 = 12. 12 = 12. **Yes**.

3. Is n = 4 a solution to 3n = 15?
   - Answer: 3(4) = 12. 12 does not equal 15. **No**.

4. Is y = 8 a solution to 20 - y = 12?
   - Answer: 20 - 8 = 12. 12 = 12. **Yes**.

5. Which value from {3, 5, 7, 9} is the solution to 4x = 20?
   - Answer: Try 3: 12. Try 5: 20. **x = 5**.

6. Is m = 10 a solution to m/2 + 3 = 8?
   - Answer: 10/2 + 3 = 5 + 3 = 8. 8 = 8. **Yes**.

**Facilitator tip:** For problem 5, ask the student: "Before testing each value, can you estimate which one might work? 4 times what is close to 20?" Building estimation skills alongside algebraic skills is important.

## Independent Practice (10-15 minutes)

### Part A: Expression or Equation?

Classify each as an expression or an equation.

1. 8n + 2
2. 8n + 2 = 26
3. 15 = y - 3
4. 6(x + 1) - 4
5. 2a + b

### Part B: Testing Solutions

Determine whether the given value is a solution. Show your substitution work.

6. Is x = 9 a solution to x - 4 = 5?
7. Is n = 6 a solution to 2n + 1 = 11?
8. Is y = 3 a solution to 4y - 5 = 10?
9. Is m = 12 a solution to m/4 = 3?
10. Is x = 7 a solution to 3x - 2 = 20?

### Part C: Finding Solutions from a Set

Find the solution from the given set.

11. Which value from {1, 2, 3, 4, 5} is the solution to x + 8 = 11?
12. Which value from {4, 6, 8, 10, 12} is the solution to 5n = 40?
13. Which value from {2, 4, 6, 8} is the solution to 3x + 1 = 13?

### Part D: Word Problems

14. Marcus has some stickers. After his friend gives him 7 more, he has 19 stickers total. Write an equation to represent this situation. Then determine: is the answer 12 or 26?

15. Explain in your own words: what is the difference between an expression and an equation? Give one example of each.

### Answer Key

**Part A**

1. Expression
2. Equation
3. Equation
4. Expression
5. Expression

**Part B**

6. 9 - 4 = 5. 5 = 5. **Yes**.
7. 2(6) + 1 = 12 + 1 = 13. 13 does not equal 11. **No**.
8. 4(3) - 5 = 12 - 5 = 7. 7 does not equal 10. **No**.
9. 12/4 = 3. 3 = 3. **Yes**.
10. 3(7) - 2 = 21 - 2 = 19. 19 does not equal 20. **No**.

**Part C**

11. Try x = 3: 3 + 8 = 11. **x = 3**.
12. Try n = 8: 5(8) = 40. **n = 8**.
13. Try x = 4: 3(4) + 1 = 13. **x = 4**.

**Part D**

14. Let s = the number of stickers Marcus started with. Equation: s + 7 = 19. Check s = 12: 12 + 7 = 19. Yes! Check s = 26: 26 + 7 = 33. No. The answer is **s = 12**.

15. An expression is a mathematical phrase with numbers, variables, and operations but no equal sign (e.g., 3x + 5). An equation is a mathematical sentence that says two expressions are equal, and it always has an equal sign (e.g., 3x + 5 = 20). An equation can be true or false; an expression is just a quantity.

## Assessment Check

Is x = 5 a solution to 4x - 3 = 17?

**Target response:** 4(5) - 3 = 20 - 3 = 17. 17 = 17. **Yes, x = 5 is a solution.** If the student says "no" or makes a computation error, work through the substitution step by step.

## Extension

- **Equation Creation:** Write three different equations that each have x = 6 as the solution. For example: x + 4 = 10, 2x = 12, x - 1 = 5. Verify each by substitution.

- **True, False, or Open:** Classify each statement as true, false, or open (cannot be determined without knowing the variable's value): (a) 3 + 5 = 8 (true), (b) 4 + 1 = 6 (false), (c) x + 3 = 10 (open — depends on x), (d) 2(3) = 7 (false), (e) 2n = 14 (open). Explain the difference between the three types.
