# Math -- Grade 7 -- Unit 2, Lesson 7

## Topic
Multiplying and Dividing Rational Numbers

## Learning Objectives
- Apply the sign rules for multiplication and division to fractions and decimals.
- Multiply and divide negative fractions, including mixed numbers.
- Multiply and divide negative decimals.
- Evaluate expressions that combine multiplication and division with signed rational numbers.

## Prerequisites
- Mastery of sign rules for multiplying and dividing integers (Lessons 4-5).
- Fluency with multiplying and dividing fractions (multiply numerators and denominators; multiply by the reciprocal to divide).
- Fluency with multiplying and dividing decimals.

## Materials Needed
- Whiteboard and markers (or projector).
- Student worksheet (Guided Practice and Independent Practice problems).
- Index cards or half-sheets for Exit Ticket.
- Calculator (optional, for decimal verification).

**Standards:** 7.NS.2 -- Apply and extend previous understandings of multiplication and division and of fractions to multiply and divide rational numbers. 7.NS.2c -- Apply properties of operations as strategies to multiply and divide rational numbers.

## Warm-Up (5 minutes)

**Purpose:** Review fraction multiplication and division mechanics and connect to sign rules.

1. Compute: 2/3 x 4/5. (Answer: 8/15)
2. Compute: 3/4 / 2/7. (Answer: 3/4 x 7/2 = 21/8 = 2 5/8)
3. Compute: (-6) x (-4). (Answer: 24)
4. Ask: "If (-6) x (-4) = 24, what do you think (-2/3) x (-3/4) equals? How would you approach it?"

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Reciprocal** -- the multiplicative inverse of a number. The reciprocal of a/b is b/a. A number times its reciprocal equals 1.
- **Simplify** -- reduce a fraction to lowest terms by dividing the numerator and denominator by their greatest common factor.

### Instruction Notes

**Step 1 -- The sign rules are the same.**
"The sign rules for multiplication and division of rational numbers are IDENTICAL to the rules for integers."
- Same signs = positive result.
- Different signs = negative result.

Strategy: (1) Determine the sign. (2) Multiply or divide the absolute values. (3) Attach the sign.

**Step 2 -- Multiplying fractions with signs.**
Example: -2/3 x 3/4

Step 1: Different signs (negative x positive) = negative result.
Step 2: |2/3| x |3/4| = 2/3 x 3/4 = 6/12 = 1/2.
Step 3: Attach the sign: -1/2.

Result: -2/3 x 3/4 = **-1/2**.

Example: (-3/5) x (-5/9)

Step 1: Same signs (negative x negative) = positive result.
Step 2: |3/5| x |5/9| = 3/5 x 5/9 = 15/45 = 1/3.
Step 3: Positive.

Result: (-3/5) x (-5/9) = **1/3**.

**Step 3 -- Dividing fractions with signs.**
"To divide fractions, multiply by the reciprocal. Then apply the sign rule."

Example: -3/4 / 2/5

Step 1: Different signs = negative result.
Step 2: |3/4| / |2/5| = 3/4 x 5/2 = 15/8 = 1 7/8.
Step 3: Attach the sign: -1 7/8.

Result: -3/4 / 2/5 = **-15/8** or **-1 7/8**.

**Step 4 -- Multiplying decimals with signs.**
Example: -4.5 x 1.2

Step 1: Different signs = negative result.
Step 2: |4.5| x |1.2| = 5.4.
Step 3: Attach the sign: -5.4.

Result: -4.5 x 1.2 = **-5.4**.

**Step 5 -- Dividing decimals with signs.**
Example: -4.5 / 1.5

Step 1: Different signs = negative result.
Step 2: |4.5| / |1.5| = 3.
Step 3: Attach the sign: -3.

Result: -4.5 / 1.5 = **-3**.

Example: -7.2 / (-0.8)

Step 1: Same signs = positive result.
Step 2: |7.2| / |0.8| = 9.
Step 3: Positive.

Result: -7.2 / (-0.8) = **9**.

### Worked Examples

**Example A -- Multiplying negative fractions**
Compute: (-5/6) x (3/10)

Different signs = negative.
|5/6| x |3/10| = 15/60 = 1/4.
Answer: (-5/6) x (3/10) = **-1/4**.

**Example B -- Dividing negative fractions**
Compute: (-7/8) / (-1/4)

Same signs = positive.
|7/8| / |1/4| = 7/8 x 4/1 = 28/8 = 7/2 = 3 1/2.
Answer: (-7/8) / (-1/4) = **7/2** or **3 1/2**.

**Example C -- Multiplying negative decimals**
Compute: (-2.5) x (-0.4)

Same signs = positive.
|2.5| x |0.4| = 1.0.
Answer: (-2.5) x (-0.4) = **1**.

**Example D -- Mixed number multiplication**
Compute: (-1 1/2) x (2/3)

Convert: -1 1/2 = -3/2.
Different signs = negative.
|3/2| x |2/3| = 6/6 = 1.
Answer: (-1 1/2) x (2/3) = **-1**.

## Guided Practice (10 minutes)

1. Compute: (-3/4) x (2/9)
   - *Facilitator tip:* "Different signs. Multiply the absolute values, then simplify."

2. Compute: (5/6) / (-5/12)
   - *Facilitator tip:* "Different signs = negative. Multiply by the reciprocal of 5/12."

3. Compute: (-3.6) x (-2.5)
   - *Facilitator tip:* "Same signs = positive. Now multiply the absolute values."

4. Compute: 6.3 / (-0.9)
   - *Facilitator tip:* "Different signs. Divide the absolute values."

5. Compute: (-2 1/4) x (-4/3)
   - *Facilitator tip:* "Convert -2 1/4 to an improper fraction first: -9/4."

## Independent Practice (10-15 minutes)

### Part A -- Multiplying Fractions and Decimals
1. (-4/5) x (5/8)
2. (-2/3) x (-9/4)
3. (-1.5) x 4
4. (-0.6) x (-0.3)

### Part B -- Dividing Fractions and Decimals
5. (-3/5) / (6/7)
6. (4/9) / (-2/3)
7. -8.4 / 2.1
8. -6.5 / (-1.3)

### Part C -- Applied and Extended
9. A stock loses $2.50 per share per day for 3 days. What is the total change in value per share? Write a multiplication expression.
10. A submarine descends at a rate of -2.4 feet per second. How far has it descended after 5.5 seconds? Write a multiplication expression.
11. A recipe needs to be cut to 2/3 of its original size. If the original recipe calls for -1/2 cup adjustment (reducing sugar), what is the new adjustment? (Compute 2/3 x (-1/2).)
12. Compute: (-1/2) x (-2/3) / (-3/4). Work left to right.

### Answer Key

**Part A**
1. (-4/5) x (5/8): Different signs = negative. 4/5 x 5/8 = 20/40 = 1/2. Answer: -1/2.
2. (-2/3) x (-9/4): Same signs = positive. 2/3 x 9/4 = 18/12 = 3/2 = 1 1/2. Answer: 3/2.
3. (-1.5) x 4: Different signs = negative. 1.5 x 4 = 6. Answer: -6.
4. (-0.6) x (-0.3): Same signs = positive. 0.6 x 0.3 = 0.18. Answer: 0.18.

**Part B**
5. (-3/5) / (6/7): Different signs = negative. 3/5 x 7/6 = 21/30 = 7/10. Answer: -7/10.
6. (4/9) / (-2/3): Different signs = negative. 4/9 x 3/2 = 12/18 = 2/3. Answer: -2/3.
7. -8.4 / 2.1: Different signs = negative. 8.4 / 2.1 = 4. Answer: -4.
8. -6.5 / (-1.3): Same signs = positive. 6.5 / 1.3 = 5. Answer: 5.

**Part C**
9. (-2.50) x 3 = -7.50. The stock lost $7.50 per share.
10. (-2.4) x 5.5 = -13.2. The submarine has descended 13.2 feet (at -13.2 feet).
11. (2/3) x (-1/2) = -2/6 = -1/3 cup. The new adjustment is -1/3 cup.
12. (-1/2) x (-2/3) = 1/3 (same signs, positive). Then 1/3 / (-3/4) = 1/3 x (-4/3) = -4/9 (different signs, negative). Answer: -4/9.

## Assessment Check

### Exit Ticket
**Problem 1:** Compute (-5/8) x (4/15).

**Problem 2:** Compute -9.6 / (-1.6).

**Scoring:**
- 2 out of 2 correct = Mastery demonstrated.
- 1 out of 2 correct = Partial understanding; review errors.
- 0 out of 2 correct = Reteach needed.

### If Mastery Is Not Met
- Separate sign determination from computation. Have the student write "positive" or "negative" for 10 expressions before computing any of them. Then go back and compute.
- If the issue is fraction arithmetic (not signs), review multiplying and dividing fractions with positive values. Use 5 practice problems with positive fractions before reintroducing signs.
- Provide a worked-example template: (1) Sign: same or different? (2) Absolute values of the numbers. (3) Compute. (4) Attach the sign.

### If Mastery Is Met
- Assign Part C problems if not yet completed.
- Preview: "In the next lesson, we combine all four operations using order of operations. You will see expressions like -3^2 + 4 x (-2). Can you predict the answer?"

## Extension
- **Reciprocal Exploration:** "What is the reciprocal of -3/4? Verify by multiplying: (-3/4) x (-4/3). Does the product equal 1?" (Yes: same signs = positive, 12/12 = 1.)
- **Chain Challenge:** Compute: (-1/2) x (-2/3) x (-3/4) x (-4/5). (Four negative factors = even = positive. Product: 24/120 = 1/5.)

## Teacher/Facilitator Notes

### Common Errors
- **Forgetting to flip the second fraction when dividing.** The student computes (-3/4) / (2/5) as (-3/4) x (2/5) instead of (-3/4) x (5/2). Reinforce: "Division means multiply by the RECIPROCAL. Flip the second fraction."
- **Sign errors with mixed numbers.** The student converts -1 1/2 to -1/2 instead of -3/2. Remind: "Convert the mixed number first, keeping the negative sign with the whole improper fraction."
- **Decimal multiplication place value errors.** The student writes (-1.5) x 4 = -0.6 instead of -6. Encourage estimation: "1.5 x 4 should be about 6, not about 0.6."

### Pacing Advice
- If the student's fraction arithmetic is strong, this lesson can move quickly (30-35 minutes). If not, plan for two sessions: one for fractions, one for decimals.
- The conceptual load in this lesson is low (same sign rules as Lessons 4-5), so the main challenge is computational fluency. Assign plenty of practice.
- Problem 12 (three-operation chain) previews the order of operations work in Lesson 8. Use it as a bridge if the student is ready.
