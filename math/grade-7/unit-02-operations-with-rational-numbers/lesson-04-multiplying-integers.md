# Math -- Grade 7 -- Unit 2, Lesson 4

## Topic
Multiplying Integers

## Learning Objectives
- State and apply the sign rules for multiplying integers: positive x positive = positive, positive x negative = negative, negative x positive = negative, negative x negative = positive.
- Use pattern-based reasoning to explain why a negative times a negative equals a positive.
- Multiply any two integers, including cases involving zero.

## Prerequisites
- Fluency with multiplication of whole numbers.
- Understanding of integers and their positions on a number line (Lessons 1-3).
- Understanding of the commutative property of multiplication (a x b = b x a).

## Materials Needed
- Whiteboard and markers (or projector).
- Student worksheet (Guided Practice and Independent Practice problems).
- Index cards or half-sheets for Exit Ticket.
- Number line (optional, for verification).

**Standards:** 7.NS.2 -- Apply and extend previous understandings of multiplication and division and of fractions to multiply and divide rational numbers. 7.NS.2a -- Understand that multiplication is extended from fractions to rational numbers by requiring that operations continue to satisfy the properties of operations, particularly the distributive property, leading to products such as (-1)(-1) = 1 and the rules for multiplying signed numbers.

## Warm-Up (5 minutes)

**Purpose:** Activate prior knowledge of multiplication and begin to notice patterns with signs.

1. Compute: 4 x 3. (Answer: 12)
2. Compute: 4 x 2. (Answer: 8)
3. Compute: 4 x 1. (Answer: 4)
4. Compute: 4 x 0. (Answer: 0)
5. Ask: "What is happening to the product each time we decrease the second factor by 1?" (The product decreases by 4 each time.)
6. Ask: "Following this pattern, what should 4 x (-1) be?" (0 - 4 = -4.)

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Factor** -- a number being multiplied.
- **Product** -- the result of multiplication.
- **Sign rules** -- the rules that determine the sign of a product based on the signs of the factors.

### Instruction Notes

**Step 1 -- Positive x Positive = Positive.**
"We already know this from elementary school."
3 x 5 = 15. Two positive factors give a positive product.

**Step 2 -- Positive x Negative = Negative (using the pattern).**
Continue the warm-up pattern:
- 4 x 3 = 12
- 4 x 2 = 8
- 4 x 1 = 4
- 4 x 0 = 0
- 4 x (-1) = -4 (pattern: subtract 4)
- 4 x (-2) = -8
- 4 x (-3) = -12

"Each time the second factor decreases by 1, the product decreases by 4. The pattern forces us to conclude that a positive times a negative is negative."

State the rule: **Positive x Negative = Negative.**

Reasoning: "Multiplying 4 x (-3) means adding -3 four times: (-3) + (-3) + (-3) + (-3) = -12."

**Step 3 -- Negative x Positive = Negative.**
By the commutative property: (-3) x 4 = 4 x (-3) = -12.

State the rule: **Negative x Positive = Negative.**

"In summary, when the signs are DIFFERENT, the product is NEGATIVE."

**Step 4 -- Negative x Negative = Positive (using the pattern).**
Now build a pattern starting with a negative first factor:
- (-3) x 3 = -9
- (-3) x 2 = -6
- (-3) x 1 = -3
- (-3) x 0 = 0
- (-3) x (-1) = ?

"Each time the second factor decreases by 1, the product INCREASES by 3. So (-3) x (-1) = 0 + 3 = 3."
- (-3) x (-2) = 6
- (-3) x (-3) = 9

State the rule: **Negative x Negative = Positive.**

"When the signs are the SAME, the product is POSITIVE."

**Step 5 -- Summarize the sign rules.**

| Factor 1 | Factor 2 | Product |
|---|---|---|
| + | + | + |
| + | - | - |
| - | + | - |
| - | - | + |

> **Shortcut: Same signs give a POSITIVE product. Different signs give a NEGATIVE product.**

**Step 6 -- Multiplying by zero.**
"Any number times zero is zero. This is the Zero Property of Multiplication."
- 5 x 0 = 0
- -8 x 0 = 0
- 0 x (-12) = 0

### Worked Examples

**Example A -- Positive x Negative**
Compute: 7 x (-6)

Different signs, so the product is negative.
|7| x |6| = 42.
Answer: 7 x (-6) = **-42**.

**Example B -- Negative x Negative**
Compute: (-8) x (-5)

Same signs, so the product is positive.
|8| x |5| = 40.
Answer: (-8) x (-5) = **40**.

**Example C -- Three factors**
Compute: (-2) x 3 x (-4)

Work left to right:
(-2) x 3 = -6 (different signs, negative).
(-6) x (-4) = 24 (same signs, positive).
Answer: (-2) x 3 x (-4) = **24**.

Shortcut: Count the negative factors. Two negatives = even number of negatives = positive product.

**Example D -- Involving zero**
Compute: (-9) x 0 x 5

Any factor of 0 makes the entire product 0.
Answer: (-9) x 0 x 5 = **0**.

## Guided Practice (10 minutes)

1. Compute: 5 x (-9)
   - *Facilitator tip:* "Different signs. What sign will the product be?"

2. Compute: (-7) x (-8)
   - *Facilitator tip:* "Same signs. The product is..."

3. Compute: (-4) x 6
   - *Facilitator tip:* "Determine the sign first, then multiply the absolute values."

4. Compute: (-3) x (-2) x (-5)
   - *Facilitator tip:* "Work left to right, or count the negative factors. Three negatives = odd = negative product."

5. Without computing, determine the sign of the product: (-2) x (-4) x 3 x (-1) x (-5). Explain.
   - *Facilitator tip:* "Count the negative factors. Is the count even or odd?"

## Independent Practice (10-15 minutes)

### Part A -- Basic Computation
1. 8 x (-3)
2. (-6) x (-9)
3. (-12) x 4
4. (-1) x (-1)

### Part B -- Multiple Factors
5. (-2) x 5 x (-3)
6. 4 x (-1) x (-2) x (-3)
7. (-1) x (-1) x (-1) x (-1) x (-1)

### Part C -- Applied and Extended
8. A stock drops $3 per day for 5 consecutive days. Write a multiplication expression for the total change in value and compute the result.
9. The temperature drops 2 degrees per hour for 6 hours. Write a multiplication expression and find the total temperature change.
10. Explain, using the pattern approach, why (-5) x (-4) = 20. Start your pattern with 5 x (-4), 4 x (-4), 3 x (-4), ... and continue through (-5) x (-4).
11. True or false: "If the product of three integers is negative, then all three integers are negative." Explain.

### Answer Key

**Part A**
1. 8 x (-3) = -24
2. (-6) x (-9) = 54
3. (-12) x 4 = -48
4. (-1) x (-1) = 1

**Part B**
5. (-2) x 5 x (-3): (-2) x 5 = -10, then (-10) x (-3) = 30.
6. 4 x (-1) x (-2) x (-3): 4 x (-1) = -4, (-4) x (-2) = 8, 8 x (-3) = -24. Three negatives (odd) = negative.
7. (-1) x (-1) x (-1) x (-1) x (-1): Five negatives (odd) = -1.

**Part C**
8. (-3) x 5 = -15. The stock lost $15 total.
9. (-2) x 6 = -12. The total temperature change was -12 degrees (a drop of 12 degrees).
10. Pattern: 5 x (-4) = -20, 4 x (-4) = -16, 3 x (-4) = -12, 2 x (-4) = -8, 1 x (-4) = -4, 0 x (-4) = 0, (-1) x (-4) = 4, (-2) x (-4) = 8, (-3) x (-4) = 12, (-4) x (-4) = 16, (-5) x (-4) = 20. Each step, the product increases by 4, confirming (-5) x (-4) = 20.
11. False. Only an odd number of the three factors need to be negative. For example, 2 x 3 x (-1) = -6. Only one factor is negative, but the product is still negative.

## Assessment Check

### Exit Ticket
**Problem 1:** Compute (-7) x (-9).

**Problem 2:** Compute (-3) x 4 x (-2).

**Scoring:**
- 2 out of 2 correct = Mastery demonstrated.
- 1 out of 2 correct = Partial understanding; review errors.
- 0 out of 2 correct = Reteach needed.

### If Mastery Is Not Met
- Rebuild the pattern table from Step 4. Have the student fill in each row, explicitly computing the change from one row to the next.
- Provide a sign-rule reference card: "Same signs = positive product. Different signs = negative product." The student should use this card for every problem until the rules are internalized.
- Give 5 additional problems with just two factors, focusing on sign determination before computation.

### If Mastery Is Met
- Assign Part C problems if not yet completed.
- Preview: "Division follows the same sign rules as multiplication. Why do you think that is? We will explore this in the next lesson."

## Extension
- **Sign Pattern Exploration:** "Compute (-1)^1, (-1)^2, (-1)^3, (-1)^4, ..., (-1)^10. What pattern do you see? Predict (-1)^99 and (-1)^100."
  (Odd exponents give -1, even exponents give +1. (-1)^99 = -1, (-1)^100 = 1.)
- **Distributive Property Preview:** "Use the distributive property to show that (-1)(a + b) = -a + (-b). What does multiplying by -1 do to an expression?"

## Teacher/Facilitator Notes

### Common Errors
- **Stating that negative x negative = negative.** This is the most common misconception. Return to the pattern every time. The student must see the product INCREASING through the pattern and must arrive at the positive result themselves.
- **Forgetting the sign when multiplying absolute values.** The student computes |-6| x |-9| = 54 but writes -54. Encourage a two-step process: (1) Determine the sign. (2) Multiply the absolute values. (3) Attach the sign.
- **Errors with multiple factors.** The student incorrectly tracks the sign through a chain of multiplications. Teach the shortcut: count the number of negative factors. Even count = positive, odd count = negative.

### Pacing Advice
- The pattern-based reasoning in Steps 2 and 4 is the conceptual core of this lesson. Do not rush it. The student should complete the pattern themselves, not simply watch the facilitator write it.
- If the student grasps the sign rules quickly, this lesson can be condensed, allowing time to begin Lesson 5 (division) in the same session.
- Problem 10 (explaining why neg x neg = pos using the pattern) is the most important conceptual problem in the set. Prioritize it even if other problems are skipped.
