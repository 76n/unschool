# Math -- Grade 7 -- Unit 2, Lesson 2

## Topic
Adding Integers with Different Signs

## Learning Objectives
- Add a positive integer and a negative integer using a number line model.
- State and apply the rule: when adding integers with different signs, subtract the smaller absolute value from the larger absolute value and keep the sign of the number with the greater absolute value.
- Determine the sign of a sum by comparing absolute values.

## Prerequisites
- Ability to add integers with the same sign (Lesson 1).
- Understanding of absolute value as distance from zero on the number line.
- Fluency with subtraction of whole numbers.

## Materials Needed
- Whiteboard and markers (or projector).
- Number line (printed or drawn, from -20 to 20).
- Student worksheet (Guided Practice and Independent Practice problems).
- Index cards or half-sheets for Exit Ticket.
- Two-color counters (optional, for zero-pair modeling).

**Standards:** 7.NS.1 -- Apply and extend previous understandings of addition and subtraction to add and subtract rational numbers; represent addition and subtraction on a horizontal or vertical number line diagram.

## Warm-Up (5 minutes)

**Purpose:** Review same-sign addition (Lesson 1) and set up the contrast with different-sign addition.

1. Compute: -6 + (-4). (Answer: -10. Same-sign rule: add absolute values, keep the negative sign.)
2. Compute: 8 + 5. (Answer: 13. Same-sign rule: add absolute values, keep the positive sign.)
3. Ask: "What do you think happens when we add -6 + 4? The signs are different. Will the answer be positive or negative? Make a prediction."

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Different signs** -- one number is positive and the other is negative.
- **Zero pair** -- a pair consisting of +1 and -1 that combine to make 0. (Used in the counter model.)
- **Net result** -- the amount remaining after positive and negative quantities partially cancel.

### Instruction Notes

**Step 1 -- Model different-sign addition on the number line.**
"Let's compute -6 + 4."
- Start at 0. Move 6 units to the left (land on -6).
- From -6, move 4 units to the right (land on -2).
- Result: -6 + 4 = -2.

Draw this on the board. Ask: "We moved left, then right. The left move was bigger, so we ended up on the negative side."

**Step 2 -- Try another example where the positive number is larger.**
"Now let's compute -3 + 7."
- Start at 0. Move 3 units to the left (land on -3).
- From -3, move 7 units to the right (land on 4).
- Result: -3 + 7 = 4.

Ask: "This time the right move was bigger, so we ended up on the positive side."

**Step 3 -- Develop the rule using absolute values.**
Write the examples side by side:
- -6 + 4 = -2. Absolute values: 6 and 4. Difference: 6 - 4 = 2. The number with the larger absolute value is -6 (negative), so the answer is -2.
- -3 + 7 = 4. Absolute values: 3 and 7. Difference: 7 - 3 = 4. The number with the larger absolute value is 7 (positive), so the answer is +4.

State the rule:

> **Rule: When adding integers with different signs, subtract the smaller absolute value from the larger absolute value. The sum takes the sign of the number with the greater absolute value.**

**Step 4 -- Address the special case: adding opposites.**
"What happens when we add a number and its opposite?"
- 5 + (-5): |5| = |−5| = 5. Difference: 5 - 5 = 0. Result: 0.
- -8 + 8: |−8| = |8| = 8. Difference: 8 - 8 = 0. Result: 0.

> **Special case: A number plus its opposite always equals zero.**

This is called the **Additive Inverse Property**: a + (-a) = 0.

### Worked Examples

**Example A -- Negative has larger absolute value**
Compute: -10 + 6

Different signs. Subtract absolute values: |−10| - |6| = 10 - 6 = 4.
The number with the larger absolute value is -10 (negative).
Answer: -10 + 6 = **-4**.

**Example B -- Positive has larger absolute value**
Compute: -5 + 12

Different signs. Subtract absolute values: |12| - |−5| = 12 - 5 = 7.
The number with the larger absolute value is 12 (positive).
Answer: -5 + 12 = **7**.

**Example C -- Adding opposites**
Compute: -15 + 15

These are opposites. a + (-a) = 0.
Answer: -15 + 15 = **0**.

**Example D -- Positive first, then negative**
Compute: 9 + (-14)

Different signs. Subtract absolute values: |−14| - |9| = 14 - 9 = 5.
The number with the larger absolute value is -14 (negative).
Answer: 9 + (-14) = **-5**.

## Guided Practice (10 minutes)

1. Compute: -8 + 3
   - *Facilitator tip:* "Which absolute value is larger? What sign will the answer have?"

2. Compute: 11 + (-4)
   - *Facilitator tip:* "Different signs -- subtract the absolute values. Which number has the larger absolute value?"

3. Compute: -7 + 7
   - *Facilitator tip:* "These are opposites. What do you know about a number plus its opposite?"

4. Show -5 + 9 on a number line. Write the result.
   - *Facilitator tip:* "Start at 0. Move 5 left, then 9 right. Where do you land?"

5. Compute: 6 + (-13)
   - *Facilitator tip:* "The negative number has the larger absolute value, so the answer will be..."

## Independent Practice (10-15 minutes)

### Part A -- Basic Computation
1. -9 + 5
2. 7 + (-3)
3. -12 + 18
4. 14 + (-14)

### Part B -- Determining the Sign
5. Without computing the exact answer, determine whether each sum is positive, negative, or zero. Explain your reasoning.
   - (a) -20 + 15
   - (b) -8 + 13
   - (c) 25 + (-25)
   - (d) -100 + 47

### Part C -- Applied and Extended
6. At noon, the temperature was -4 degrees Celsius. By 3:00 PM, it had risen 9 degrees. What was the temperature at 3:00 PM? Write an addition expression.
7. A football team gains 8 yards on one play and loses 11 yards on the next play. Write an addition expression for the net yardage and compute the result.
8. Evaluate: -15 + 8 + (-3). (Hint: Add from left to right.)
9. Find a value of n so that -7 + n is positive. Find a different value of n so that -7 + n is negative. Explain your reasoning.
10. True or false: "When you add a positive number and a negative number, the answer is always negative." Explain.

### Answer Key

**Part A**
1. -9 + 5 = -4 (|9| - |5| = 4, negative has larger absolute value)
2. 7 + (-3) = 4 (|7| - |3| = 4, positive has larger absolute value)
3. -12 + 18 = 6 (|18| - |12| = 6, positive has larger absolute value)
4. 14 + (-14) = 0 (opposites sum to zero)

**Part B**
5. (a) Negative. |-20| = 20 > |15| = 15, so the negative number dominates.
   (b) Positive. |13| = 13 > |-8| = 8, so the positive number dominates.
   (c) Zero. These are opposites.
   (d) Negative. |-100| = 100 > |47| = 47, so the negative number dominates.

**Part C**
6. -4 + 9 = 5. The temperature at 3:00 PM was 5 degrees Celsius.
7. 8 + (-11) = -3. The net yardage is -3 yards (a loss of 3 yards).
8. -15 + 8 = -7. Then -7 + (-3) = -10. (Same sign at the second step.)
9. Any n > 7 makes the sum positive (e.g., n = 10: -7 + 10 = 3). Any n < 7 and n positive, or any negative n, makes the sum negative (e.g., n = 3: -7 + 3 = -4; or n = -2: -7 + (-2) = -9). Accept any correct examples with valid reasoning.
10. False. The answer depends on which number has the greater absolute value. For example, -3 + 10 = 7 (positive). The answer is negative only when the negative number has the greater absolute value.

## Assessment Check

### Exit Ticket
**Problem 1:** Compute -11 + 7.

**Problem 2:** A hiker is at an elevation of -30 feet (below sea level). She climbs up 45 feet. Write an addition expression and find her new elevation.

**Scoring:**
- 2 out of 2 correct = Mastery demonstrated.
- 1 out of 2 correct = Partial understanding; review errors.
- 0 out of 2 correct = Reteach needed.

### If Mastery Is Not Met
- Return to the number line model. Have the student physically trace the movements: left for negative, right for positive. Count the units aloud.
- Use zero pairs with two-color counters: lay out 11 red chips and 7 yellow chips. Pair them up (7 zero pairs). Count the remaining chips (4 red = -4).
- Practice 5 additional problems: -3 + 8, -10 + 4, 6 + (-9), -1 + 1, 5 + (-12).

### If Mastery Is Met
- Assign Part C problems if not yet completed.
- Preview: "In the next lesson, we tackle subtraction. Here is a sneak peek: 5 - 8 and 5 + (-8) give the same answer. Why do you think that might be true?"

## Extension
- **Three-Addend Chains:** Compute -8 + 5 + (-3) + 10 + (-7). Challenge the student to find an efficient strategy (e.g., group positives and negatives separately, then combine).
- **Real-World Exploration:** "A bank account has a balance of -$45 (overdrawn). Deposits of $30 and $50 are made. What is the new balance? Write the addition expression."

## Teacher/Facilitator Notes

### Common Errors
- **Keeping the wrong sign.** The student computes the correct absolute value difference but assigns the wrong sign. For example, -8 + 3 = 5 instead of -5. Always redirect to: "Which number has the LARGER absolute value? The answer takes THAT number's sign."
- **Adding absolute values instead of subtracting.** The student writes -8 + 3 = -11, applying the same-sign rule. Ask: "Are the signs the same or different?" This single question forces the student to choose the correct rule.
- **Treating all addition as positive.** The student ignores the negative sign entirely and writes -6 + 4 = 10. Return to the number line model to show that moving left then right does not reach 10.

### Pacing Advice
- Lessons 1 and 2 form a natural pair. If the student demonstrated quick mastery of Lesson 1, begin Lesson 2 in the same session.
- The Part B problems (determining the sign without computing) are excellent for building number sense. Prioritize these -- they develop the student's ability to estimate and reason about signed numbers without mechanical computation.
- Problem 8 (three-addend chain) previews the skill of combining multiple signed numbers, which is essential for Lessons 6 and 8. Assign it if time allows.
