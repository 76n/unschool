# Math -- Grade 7 -- Unit 2, Lesson 6

## Topic
Adding and Subtracting Rational Numbers

## Learning Objectives
- Extend the integer addition and subtraction rules to fractions and decimals with different signs.
- Add and subtract negative fractions by finding common denominators and applying sign rules.
- Add and subtract negative decimals by aligning place values and applying sign rules.
- Solve problems that mix fractions, decimals, and negative signs.

## Prerequisites
- Mastery of integer addition and subtraction rules (Lessons 1-3).
- Fluency with adding and subtracting fractions (finding common denominators).
- Fluency with adding and subtracting decimals (aligning place values).
- Understanding of absolute value.

## Materials Needed
- Whiteboard and markers (or projector).
- Student worksheet (Guided Practice and Independent Practice problems).
- Index cards or half-sheets for Exit Ticket.
- Calculator (optional, for decimal verification).

**Standards:** 7.NS.1 -- Apply and extend previous understandings of addition and subtraction to add and subtract rational numbers. 7.NS.1d -- Apply properties of operations as strategies to add and subtract rational numbers.

## Warm-Up (5 minutes)

**Purpose:** Review fraction and decimal addition skills and connect to integer sign rules.

1. Compute: 2/5 + 1/3. (Answer: 6/15 + 5/15 = 11/15)
2. Compute: 4.6 + 2.8. (Answer: 7.4)
3. Compute: -5 + 8. (Answer: 3)
4. Ask: "If you know how to add fractions and you know the sign rules for integers, what do you think -2/5 + 1/3 equals? How would you approach it?"

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Rational number** -- any number that can be written as a fraction a/b where a and b are integers and b is not 0. Includes integers, fractions, terminating decimals, and repeating decimals.
- **Common denominator** -- a shared multiple of two denominators, needed to add or subtract fractions.
- **Additive inverse** -- the opposite of a number. For any rational number r, the additive inverse is -r, and r + (-r) = 0.

### Instruction Notes

**Step 1 -- The sign rules do not change.**
"Everything we learned in Lessons 1-3 still applies. The only difference is that now the numbers are fractions or decimals instead of whole numbers."

Strategy: (1) Determine the sign of the result using the integer rules. (2) Perform the arithmetic with absolute values. (3) Attach the correct sign.

**Step 2 -- Adding fractions with the same sign.**
Example: -1/4 + (-3/8)

Same signs (both negative). Add absolute values:
|−1/4| + |−3/8| = 1/4 + 3/8.
Common denominator: 8. So 2/8 + 3/8 = 5/8.
Both negative, so the answer is -5/8.

Result: -1/4 + (-3/8) = **-5/8**.

**Step 3 -- Adding fractions with different signs.**
Example: -1/3 + 2/5

Different signs. Subtract the smaller absolute value from the larger:
|−1/3| = 1/3 = 5/15. |2/5| = 2/5 = 6/15.
6/15 - 5/15 = 1/15.
2/5 has the larger absolute value and is positive, so the answer is positive.

Result: -1/3 + 2/5 = **1/15**.

**Step 4 -- Subtracting fractions (add the opposite).**
Example: 3/4 - 5/6

Rewrite: 3/4 + (-5/6).
Different signs. Absolute values: |3/4| = 3/4 = 9/12. |−5/6| = 5/6 = 10/12.
10/12 - 9/12 = 1/12.
-5/6 has the larger absolute value and is negative, so the answer is negative.

Result: 3/4 - 5/6 = **-1/12**.

**Step 5 -- Adding and subtracting decimals with signs.**
Example: -2.7 - 1.8

Rewrite: -2.7 + (-1.8).
Same signs (both negative). Add absolute values: 2.7 + 1.8 = 4.5.
Both negative, so the answer is -4.5.

Result: -2.7 - 1.8 = **-4.5**.

Example: -3.5 + 5.2

Different signs. Subtract: 5.2 - 3.5 = 1.7.
5.2 has the larger absolute value and is positive.

Result: -3.5 + 5.2 = **1.7**.

### Worked Examples

**Example A -- Adding fractions, different signs**
Compute: -2/3 + 1/4

Different signs. Common denominator: 12.
|−2/3| = 8/12. |1/4| = 3/12.
8/12 - 3/12 = 5/12.
-2/3 has the larger absolute value (negative), so the answer is negative.
Answer: -2/3 + 1/4 = **-5/12**.

**Example B -- Subtracting fractions**
Compute: -1/6 - 2/3

Rewrite: -1/6 + (-2/3).
Same signs (both negative). Common denominator: 6.
|−1/6| + |−2/3| = 1/6 + 4/6 = 5/6.
Both negative.
Answer: -1/6 - 2/3 = **-5/6**.

**Example C -- Adding decimals, different signs**
Compute: 4.3 + (-7.1)

Different signs. Subtract: 7.1 - 4.3 = 2.8.
-7.1 has the larger absolute value (negative).
Answer: 4.3 + (-7.1) = **-2.8**.

**Example D -- Subtracting decimals**
Compute: -0.75 - (-1.25)

Rewrite: -0.75 + 1.25.
Different signs. Subtract: 1.25 - 0.75 = 0.50.
1.25 has the larger absolute value (positive).
Answer: -0.75 - (-1.25) = **0.5**.

## Guided Practice (10 minutes)

1. Compute: -3/5 + 1/10
   - *Facilitator tip:* "Find a common denominator first. Then apply the different-sign rule."

2. Compute: 1/2 - 5/6
   - *Facilitator tip:* "Rewrite as addition: 1/2 + (-5/6). Common denominator is 6."

3. Compute: -4.2 + (-3.5)
   - *Facilitator tip:* "Same signs. Add the absolute values and keep the negative sign."

4. Compute: 6.1 - 8.4
   - *Facilitator tip:* "Rewrite as 6.1 + (-8.4). Which has the larger absolute value?"

5. Compute: -3/4 - (-1/2)
   - *Facilitator tip:* "Subtracting a negative means adding a positive: -3/4 + 1/2."

## Independent Practice (10-15 minutes)

### Part A -- Fractions
1. -2/5 + 3/10
2. -5/8 + (-1/4)
3. 3/7 - 5/7
4. -1/3 - (-2/9)

### Part B -- Decimals
5. -6.4 + 2.9
6. 3.75 + (-5.25)
7. -1.8 - 3.6
8. -4.05 - (-2.3)

### Part C -- Applied and Extended
9. A recipe calls for 2/3 cup of flour, but you only have 1/4 cup. How much more flour do you need? Write a subtraction expression.
10. The temperature at dawn was -3.5 degrees Celsius. By noon, it had risen 8.2 degrees. By midnight, it had fallen 6.9 degrees from the noon temperature. What was the midnight temperature? Show each step.
11. Simplify: -1/2 + 3/4 - 1/8. Show your work with common denominators.
12. Is it true that -a/b = a/(-b) = -(a/b)? Test with a = 3 and b = 5. Explain.

### Answer Key

**Part A**
1. -2/5 + 3/10: Common denominator 10. -4/10 + 3/10 = -1/10.
2. -5/8 + (-1/4): Common denominator 8. -5/8 + (-2/8) = -7/8.
3. 3/7 - 5/7 = 3/7 + (-5/7) = -2/7.
4. -1/3 - (-2/9) = -1/3 + 2/9. Common denominator 9. -3/9 + 2/9 = -1/9.

**Part B**
5. -6.4 + 2.9: Different signs. 6.4 - 2.9 = 3.5. Negative has larger absolute value. Answer: -3.5.
6. 3.75 + (-5.25): Different signs. 5.25 - 3.75 = 1.50. Negative has larger absolute value. Answer: -1.5.
7. -1.8 - 3.6 = -1.8 + (-3.6): Same signs. 1.8 + 3.6 = 5.4. Answer: -5.4.
8. -4.05 - (-2.3) = -4.05 + 2.3: Different signs. 4.05 - 2.3 = 1.75. Negative has larger absolute value. Answer: -1.75.

**Part C**
9. 2/3 - 1/4 = 8/12 - 3/12 = 5/12 cup more flour is needed.
10. Dawn: -3.5. Noon: -3.5 + 8.2 = 4.7. Midnight: 4.7 - 6.9 = 4.7 + (-6.9) = -2.2 degrees Celsius.
11. -1/2 + 3/4 - 1/8. Common denominator 8: -4/8 + 6/8 - 1/8 = (-4 + 6 - 1)/8 = 1/8.
12. -3/5 = -0.6. 3/(-5) = -0.6. -(3/5) = -0.6. All three are equal. Yes, a negative sign can be placed in the numerator, the denominator, or in front of the fraction -- all three forms are equivalent.

## Assessment Check

### Exit Ticket
**Problem 1:** Compute -5/6 + 1/3.

**Problem 2:** Compute -2.4 - (-5.1).

**Scoring:**
- 2 out of 2 correct = Mastery demonstrated.
- 1 out of 2 correct = Partial understanding; review errors.
- 0 out of 2 correct = Reteach needed.

### If Mastery Is Not Met
- Separate the two skills: (1) sign determination (using integer rules) and (2) fraction/decimal arithmetic. If the student gets the sign correct but makes arithmetic errors, focus on fraction/decimal review. If the student makes sign errors, return to Lessons 1-3 with simpler numbers.
- Provide a step-by-step template: (1) Determine: are the signs the same or different? (2) If same, add absolute values, keep the sign. If different, subtract absolute values, take the sign of the larger absolute value. (3) For fractions, find common denominators before adding/subtracting.
- Give 4 additional problems with fractions and 4 with decimals.

### If Mastery Is Met
- Assign Part C problems if not yet completed.
- Preview: "In the next lesson, we apply sign rules to multiplication and division of fractions and decimals."

## Extension
- **Mixed Number Challenge:** Compute -2 1/3 + 1 3/4. (Convert to improper fractions: -7/3 + 7/4. Common denominator 12: -28/12 + 21/12 = -7/12.)
- **Real-World Exploration:** "Track the high and low temperatures for three days. Compute the difference (high - low) for each day. Which day had the greatest temperature swing?"

## Teacher/Facilitator Notes

### Common Errors
- **Finding the common denominator but forgetting the sign.** The student correctly computes 1/4 + 3/8 = 5/8 but forgets to make it negative when the original problem was -1/4 + (-3/8). Encourage the two-step process: determine the sign FIRST, then compute with absolute values.
- **Subtracting fractions in the wrong order.** In -1/3 + 2/5, the student computes 1/3 - 2/5 and gets a negative fraction, then is confused about the sign. Teach: always subtract the smaller absolute value from the larger.
- **Decimal alignment errors.** When subtracting 4.05 - 2.3, the student may write 4.05 - 2.3 = 1.75 incorrectly. Remind: "Write 2.3 as 2.30 so both numbers have the same number of decimal places."

### Pacing Advice
- This lesson may require two sessions if the student's fraction and decimal arithmetic is not fluent. If this is the case, spend the first session on fractions and the second on decimals.
- Problem 11 (three-term expression with fractions) previews the multi-step work in Lesson 8. Assign it if the student is ready.
- Problem 12 (equivalent forms of negative fractions) is an important conceptual point for algebra readiness. Prioritize it even if other problems are skipped.
