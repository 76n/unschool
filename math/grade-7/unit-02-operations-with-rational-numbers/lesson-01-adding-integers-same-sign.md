# Math -- Grade 7 -- Unit 2, Lesson 1

## Topic
Adding Integers with the Same Sign

## Learning Objectives
- Represent integer addition on a number line.
- Add two positive integers and two negative integers using the number line model.
- State and apply the rule: when adding integers with the same sign, add the absolute values and keep the common sign.

## Prerequisites
- Understanding of positive and negative integers and their positions on a number line.
- Ability to find the absolute value of an integer.
- Fluency with addition of whole numbers.
- Understanding of the concept of opposites (e.g., the opposite of 5 is -5).

## Materials Needed
- Whiteboard and markers (or projector).
- Number line (printed or drawn, from -20 to 20).
- Student worksheet (Guided Practice and Independent Practice problems).
- Index cards or half-sheets for Exit Ticket.
- Two-color counters (optional, for concrete modeling).

**Standards:** 7.NS.1 -- Apply and extend previous understandings of addition and subtraction to add and subtract rational numbers; represent addition and subtraction on a horizontal or vertical number line diagram.

## Warm-Up (5 minutes)

**Purpose:** Activate prior knowledge of integers and absolute value.

1. Display: "Place the following integers on a number line: -7, -3, 0, 2, 5."
2. Ask: "Which integer is farthest from zero?" (-7, because |-7| = 7 is the greatest absolute value.)
3. Ask: "What is the absolute value of -4? Of 4? What do you notice?" (Both are 4. Absolute value is the distance from zero, always positive.)
4. Ask: "If you start at 0 on a number line and move 3 units to the right, where do you land? What if you move 3 units to the left?" (3; -3. Moving right is positive, moving left is negative.)

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Integer** -- any whole number and its opposite: ..., -3, -2, -1, 0, 1, 2, 3, ...
- **Absolute value** -- the distance of a number from zero on the number line, always non-negative. Written |n|.
- **Same sign** -- two numbers that are both positive or both negative.
- **Sum** -- the result of addition.

### Instruction Notes

**Step 1 -- Model addition of two positive integers on the number line.**
"Let's compute 3 + 5 on the number line."
- Start at 0. Move 3 units to the right (land on 3).
- From 3, move 5 more units to the right (land on 8).
- Result: 3 + 5 = 8.

Draw this on the board with arrows. Ask: "Both numbers are positive, so we moved to the right both times. The result is positive."

**Step 2 -- Model addition of two negative integers on the number line.**
"Now let's compute -3 + (-5)."
- Start at 0. Move 3 units to the left (land on -3).
- From -3, move 5 more units to the left (land on -8).
- Result: -3 + (-5) = -8.

Draw this on the board with arrows. Ask: "Both numbers are negative, so we moved to the left both times. The result is negative."

**Step 3 -- Identify the pattern and state the rule.**
Write on the board:
- 3 + 5 = 8 (both positive, result positive)
- -3 + (-5) = -8 (both negative, result negative)

"What pattern do you see?" Guide the student to articulate:

> **Rule: When adding integers with the same sign, add the absolute values and keep the common sign.**

Show with absolute values:
- |3| + |5| = 3 + 5 = 8. Both positive, so the answer is +8.
- |-3| + |-5| = 3 + 5 = 8. Both negative, so the answer is -8.

**Step 4 -- Practice the rule with additional examples.**
- -7 + (-4): |7| + |4| = 11. Both negative, so the answer is -11.
- -12 + (-8): |12| + |8| = 20. Both negative, so the answer is -20.
- 15 + 9: |15| + |9| = 24. Both positive, so the answer is +24.

For each, verify on the number line.

### Worked Examples

**Example A -- Adding two positive integers**
Compute: 6 + 11

Both numbers are positive (same sign).
Add absolute values: |6| + |11| = 6 + 11 = 17.
Keep the positive sign: 6 + 11 = **17**.

**Example B -- Adding two negative integers**
Compute: -9 + (-6)

Both numbers are negative (same sign).
Add absolute values: |-9| + |-6| = 9 + 6 = 15.
Keep the negative sign: -9 + (-6) = **-15**.

**Example C -- Adding two negative integers (larger values)**
Compute: -25 + (-18)

Both numbers are negative (same sign).
Add absolute values: |-25| + |-18| = 25 + 18 = 43.
Keep the negative sign: -25 + (-18) = **-43**.

## Guided Practice (10 minutes)

1. Compute: 8 + 13
   - *Facilitator tip:* "Are the signs the same? What do you do with the absolute values?"

2. Compute: -4 + (-9)
   - *Facilitator tip:* "Both are negative. Add the absolute values first, then attach the sign."

3. Compute: -15 + (-7)
   - *Facilitator tip:* "Use the number line if needed. Start at -15 and move 7 units left."

4. Compute: -20 + (-30)
   - *Facilitator tip:* "Large numbers work the same way. Focus on the absolute values."

5. Show -6 + (-3) on a number line. Write the result.
   - *Facilitator tip:* "Start at 0, move 6 left, then 3 more left. Where do you land?"

## Independent Practice (10-15 minutes)

### Part A -- Basic Computation
1. 7 + 14
2. -5 + (-8)
3. -11 + (-6)
4. 23 + 19

### Part B -- Number Line Problems
5. Draw a number line to model -4 + (-7). What is the sum?
6. Draw a number line to model -10 + (-3). What is the sum?

### Part C -- Applied and Extended
7. The temperature at midnight was -3 degrees Fahrenheit. By 4:00 AM, it had dropped another 8 degrees. Write an addition expression and find the new temperature.
8. A submarine is at a depth of -150 feet. It descends another 75 feet. Write an addition expression and find its new depth.
9. True or false: "The sum of two negative integers is always negative." Explain your reasoning.
10. Find the value of n: -12 + n = -20, where n is a negative integer. Explain how you found your answer.

### Answer Key

**Part A**
1. 7 + 14 = 21
2. -5 + (-8) = -13
3. -11 + (-6) = -17
4. 23 + 19 = 42

**Part B**
5. Number line: start at 0, move 4 left to -4, then 7 more left to -11. Sum = -11.
6. Number line: start at 0, move 10 left to -10, then 3 more left to -13. Sum = -13.

**Part C**
7. -3 + (-8) = -11. The new temperature is -11 degrees Fahrenheit.
8. -150 + (-75) = -225. The submarine is now at -225 feet.
9. True. When both integers are negative, you add the absolute values (which gives a positive number) and keep the negative sign. The result is always negative. On the number line, you are always moving farther left from zero.
10. n = -8. Since -12 + n = -20, we need a negative number that, when added to -12, gives -20. The absolute values: 12 + |n| = 20, so |n| = 8. Since n is negative, n = -8.

## Assessment Check

### Exit Ticket
**Problem 1:** Compute -14 + (-9).

**Problem 2:** A diver is at -40 feet. She descends another 25 feet. Write an addition expression and find her new depth.

**Scoring:**
- 2 out of 2 correct = Mastery demonstrated.
- 1 out of 2 correct = Partial understanding; review errors.
- 0 out of 2 correct = Reteach needed.

### If Mastery Is Not Met
- Return to the number line model. Have the student physically point and count units as they move left for each negative addend.
- Use two-color counters: red for negative, yellow for positive. Adding negatives means adding more red counters.
- Provide 5 additional same-sign addition problems with smaller numbers (-2 + (-3), -1 + (-4), etc.) before re-attempting.

### If Mastery Is Met
- Assign the Applied and Extended problems if not yet completed.
- Preview: "In the next lesson, we will add integers with different signs -- like -5 + 8. What do you think happens when you mix a negative and a positive?"

## Extension
- **Pattern Exploration:** Have the student compute -1 + (-1), -2 + (-2), -3 + (-3), ..., -10 + (-10). Ask: "What pattern do you notice? Can you write a general rule for -n + (-n)?" (The result is -2n.)
- **Real-World Connection:** "Research the lowest temperatures recorded in three different cities. Write an addition expression that shows a 15-degree drop from each starting temperature."

## Teacher/Facilitator Notes

### Common Errors
- **Writing -5 + (-3) = -2 instead of -8.** The student is subtracting absolute values instead of adding them. This is the most common error. The student is prematurely applying the different-sign rule (Lesson 2). Redirect: "Are the signs the same or different? Same signs mean we ADD the absolute values."
- **Dropping the negative sign.** The student computes |-5| + |-3| = 8 and writes the answer as 8 instead of -8. Remind: "After adding the absolute values, you must attach the common sign. Both were negative, so the answer is negative."
- **Confusion about notation.** The student is unsure what -5 + (-3) means because of the two signs. Clarify: "The first minus sign tells us 5 is negative. The plus sign is the operation (addition). The second minus sign in the parentheses tells us 3 is negative."

### Pacing Advice
- This lesson introduces the foundational model for all integer addition. Spend ample time on the number line in Steps 1-2 before moving to the abstract rule in Step 3.
- If the student quickly grasps same-sign addition, this lesson can be condensed to 25-30 minutes, allowing time to begin Lesson 2 in the same session.
- The Applied and Extended problems (Part C) are critical for building conceptual understanding. Prioritize Problem 9 (true/false with explanation) -- it reveals whether the student understands WHY the rule works, not just HOW to use it.
