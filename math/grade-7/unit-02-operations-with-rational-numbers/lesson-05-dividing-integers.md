# Math -- Grade 7 -- Unit 2, Lesson 5

## Topic
Dividing Integers

## Learning Objectives
- State and apply the sign rules for dividing integers: same signs give a positive quotient, different signs give a negative quotient.
- Explain the connection between multiplication and division (division as the inverse of multiplication).
- Evaluate expressions involving division by zero and zero divided by a number.
- Apply integer division in real-world contexts.

## Prerequisites
- Fluency with division of whole numbers.
- Mastery of the sign rules for multiplication (Lesson 4).
- Understanding of multiplication and division as inverse operations.

## Materials Needed
- Whiteboard and markers (or projector).
- Student worksheet (Guided Practice and Independent Practice problems).
- Index cards or half-sheets for Exit Ticket.

**Standards:** 7.NS.2 -- Apply and extend previous understandings of multiplication and division and of fractions to multiply and divide rational numbers. 7.NS.2b -- Understand that integers can be divided, provided that the divisor is not zero, and every quotient of integers (with non-zero divisor) is a rational number.

## Warm-Up (5 minutes)

**Purpose:** Activate prior knowledge of the multiplication-division connection and review sign rules for multiplication.

1. Compute: (-6) x (-4). (Answer: 24)
2. Ask: "If (-6) x (-4) = 24, what does 24 / (-4) equal?" (Answer: -6)
3. Ask: "What does 24 / (-6) equal?" (Answer: -4)
4. Compute: 5 x (-3). (Answer: -15)
5. Ask: "If 5 x (-3) = -15, what does -15 / 5 equal? What does -15 / (-3) equal?" (-3; 5)

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Quotient** -- the result of division.
- **Dividend** -- the number being divided (the numerator in a fraction).
- **Divisor** -- the number you divide by (the denominator in a fraction).
- **Inverse operations** -- operations that undo each other (multiplication and division are inverses).
- **Undefined** -- a mathematical expression that has no valid result (such as division by zero).

### Instruction Notes

**Step 1 -- Connect division to multiplication.**
"Every division problem has a related multiplication fact."
- 24 / 6 = 4 because 6 x 4 = 24.
- -24 / 6 = -4 because 6 x (-4) = -24.
- -24 / (-6) = 4 because (-6) x 4 = -24.
- 24 / (-6) = -4 because (-6) x (-4) = 24.

"Division follows the SAME sign rules as multiplication because division is the inverse of multiplication."

**Step 2 -- State the sign rules for division.**

| Dividend | Divisor | Quotient |
|---|---|---|
| + | + | + |
| + | - | - |
| - | + | - |
| - | - | + |

> **Rule: Same signs give a POSITIVE quotient. Different signs give a NEGATIVE quotient.**

This is identical to the multiplication sign rules.

**Step 3 -- Division involving zero.**

Case 1: **Zero divided by any non-zero number equals zero.**
- 0 / 5 = 0 (because 5 x 0 = 0)
- 0 / (-8) = 0 (because -8 x 0 = 0)

"Zero divided by anything (except zero) is zero. You are sharing nothing among groups."

Case 2: **Any number divided by zero is undefined.**
- 5 / 0 = undefined
- -3 / 0 = undefined

"You cannot divide by zero. There is no number that, when multiplied by 0, gives 5."

Case 3: **0 / 0 is also undefined** (technically "indeterminate," but for Grade 7, "undefined" is sufficient).

**Step 4 -- Apply sign rules to larger problems.**
- -48 / 8: Different signs, negative. |48| / |8| = 6. Answer: -6.
- -72 / (-9): Same signs, positive. |72| / |9| = 8. Answer: 8.
- 56 / (-7): Different signs, negative. |56| / |7| = 8. Answer: -8.

### Worked Examples

**Example A -- Different signs**
Compute: -36 / 4

Different signs, so the quotient is negative.
|36| / |4| = 9.
Answer: -36 / 4 = **-9**.

**Example B -- Same signs (both negative)**
Compute: -54 / (-6)

Same signs, so the quotient is positive.
|54| / |6| = 9.
Answer: -54 / (-6) = **9**.

**Example C -- Zero as the dividend**
Compute: 0 / (-12)

Zero divided by any non-zero number is 0.
Answer: 0 / (-12) = **0**.

**Example D -- Zero as the divisor**
Evaluate: -7 / 0

Division by zero is **undefined**. There is no number that, when multiplied by 0, gives -7.

## Guided Practice (10 minutes)

1. Compute: 42 / (-7)
   - *Facilitator tip:* "Different signs -- the quotient is negative. Now divide the absolute values."

2. Compute: -63 / (-9)
   - *Facilitator tip:* "Same signs -- the quotient is positive."

3. Compute: -45 / 5
   - *Facilitator tip:* "Determine the sign first, then divide."

4. Evaluate: 0 / (-20)
   - *Facilitator tip:* "What happens when zero is divided by any number?"

5. Evaluate: 15 / 0
   - *Facilitator tip:* "Can you find a number that, when multiplied by 0, gives 15?"

## Independent Practice (10-15 minutes)

### Part A -- Basic Computation
1. -56 / 8
2. 81 / (-9)
3. -100 / (-25)
4. -32 / (-4)

### Part B -- Division and Multiplication Connection
5. Write the related multiplication fact for each division: (a) -48 / 6 = -8. (b) 72 / (-8) = -9.
6. If a x (-7) = 35, find a.

### Part C -- Applied and Extended
7. A parking garage charges a flat rate. Over 4 days, Marcus paid a total of $-52 from his bank account (the negative indicates money spent). How much did he pay per day?
8. The temperature dropped a total of 18 degrees over 6 hours at a constant rate. Write a division expression and find the rate of temperature change per hour.
9. Classify each as 0 or undefined:
   - (a) 0 / (-5)
   - (b) -8 / 0
   - (c) 0 / 100
   - (d) (-15) / 0
10. True or false: "Division of integers is commutative (a / b = b / a for all integers)." Give a counterexample if false.

### Answer Key

**Part A**
1. -56 / 8 = -7
2. 81 / (-9) = -9
3. -100 / (-25) = 4
4. -32 / (-4) = 8

**Part B**
5. (a) 6 x (-8) = -48. (b) (-8) x (-9) = 72.
6. a x (-7) = 35. a = 35 / (-7) = -5.

**Part C**
7. -52 / 4 = -13. Marcus paid $13 per day.
8. -18 / 6 = -3. The temperature dropped 3 degrees per hour (rate of change: -3 degrees per hour).
9. (a) 0. (b) Undefined. (c) 0. (d) Undefined.
10. False. Counterexample: 12 / 4 = 3, but 4 / 12 = 1/3. Since 3 is not equal to 1/3, division is not commutative.

## Assessment Check

### Exit Ticket
**Problem 1:** Compute -72 / (-8).

**Problem 2:** A scuba diver descends a total of 90 feet in 6 minutes at a constant rate. Write a division expression using a negative number for the descent, and find the rate of descent per minute.

**Scoring:**
- 2 out of 2 correct = Mastery demonstrated.
- 1 out of 2 correct = Partial understanding; review errors.
- 0 out of 2 correct = Reteach needed.

### If Mastery Is Not Met
- Reconnect every division problem to its multiplication fact. For example: "If you do not know -72 / (-8), ask yourself: What number times -8 gives -72?"
- Provide a sign-rule reference card identical to the one used for multiplication, reinforcing that the rules are the same.
- Give 5 additional division problems with two factors, focusing on sign determination.

### If Mastery Is Met
- Assign Part C problems if not yet completed.
- Preview: "In the next two lessons, we extend these rules to fractions and decimals. The sign rules do not change -- only the arithmetic gets more detailed."

## Extension
- **Chain Operations:** Compute (-120) / (-10) / 3 / (-2). Work left to right. ((-120) / (-10) = 12, 12 / 3 = 4, 4 / (-2) = -2.)
- **Exploration:** "Is there any integer that, when divided by itself, does not equal 1? What about 0 / 0?" (Every non-zero integer divided by itself equals 1. 0 / 0 is undefined.)

## Teacher/Facilitator Notes

### Common Errors
- **Confusing 0 / n and n / 0.** Many students believe both are zero, or both are undefined. Use a concrete analogy: "0 / 5 means sharing 0 cookies among 5 people -- each gets 0. 5 / 0 means sharing 5 cookies among 0 people -- that is impossible."
- **Applying the wrong sign rule.** The student writes -54 / (-6) = -9 (keeping a negative sign because both inputs were negative). Remind: "Same signs = positive quotient. Check with multiplication: (-6) x 9 = -54. That is correct -- the quotient is positive 9."
- **Forgetting that division is not commutative.** The student may assume a / b = b / a. Problem 10 addresses this directly.

### Pacing Advice
- Because the sign rules are identical to multiplication, this lesson often moves faster than Lesson 4. If the student demonstrates quick mastery, condense to 25-30 minutes and assign the Extension problems.
- The zero-division cases (Step 3) are important for mathematical precision. Spend at least 3-4 minutes ensuring the student can distinguish 0 / n from n / 0.
- Lessons 4 and 5 form a natural pair. They can be taught in a single session for students who grasp the sign rules quickly.
