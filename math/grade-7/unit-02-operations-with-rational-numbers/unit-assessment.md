## Answer Key

### Section A: Adding and Subtracting Integers

**A1.** -9 + (-14) = **-23**
Same signs: |9| + |14| = 23. Both negative.

**A2.** -17 + 8 = **-9**
Different signs: |17| - |8| = 9. -17 has greater absolute value, so negative.

**A3.** 5 + (-13) = **-8**
Different signs: |13| - |5| = 8. -13 has greater absolute value, so negative.

**A4.** -6 - 9 = -6 + (-9) = **-15**
Rewrite as addition of the opposite. Same signs: |6| + |9| = 15. Both negative.

**A5.** 4 - (-11) = 4 + 11 = **15**
Subtracting a negative is adding a positive.

**A6.** -8 - (-5) = -8 + 5 = **-3**
Different signs: |8| - |5| = 3. -8 has greater absolute value, so negative.

**A7.** -15 + 7 - (-3) + (-10)
= -15 + 7 + 3 + (-10)
= (-15 + 7) + 3 + (-10)
= -8 + 3 + (-10)
= -5 + (-10)
= **-15**

| Correct answer with work shown | 2 points |
| Correct final answer but no work | 1 point |
| Incorrect answer but valid intermediate steps shown | 1 point |

### Section B: Multiplying and Dividing Integers

**B1.** 7 x (-8) = **-56**
Different signs = negative.

**B2.** (-9) x (-6) = **54**
Same signs = positive.

**B3.** -48 / 6 = **-8**
Different signs = negative.

**B4.** -72 / (-9) = **8**
Same signs = positive.

**B5.** (-3) x (-4) x (-2) = 12 x (-2) = **-24**
Three negative factors (odd count) = negative.

**B6.** 0 / (-15) = **0**
Zero divided by any non-zero number is zero.

**B7.** -12 / 0 is undefined because **there is no number that, when multiplied by 0, gives -12.** Division by zero has no valid result.

### Section D: Order of Operations and Properties

**D1.** -5^2 = -(5^2) = **-25**.
The exponent applies only to 5, not the negative sign.

**D2.** (-5)^2 = (-5)(-5) = **25**.
The parentheses make -5 the base.

**D3.** 8 - 3 x (-4)
Multiplication first: 3 x (-4) = -12.
Then: 8 - (-12) = 8 + 12 = **20**.

| Response | Score |
|----------|-------|
| Correct order of operations AND correct answer | 2 points |
| Computes (8 - 3) x (-4) = -20 (incorrect order) | 0 points |
| Correct multiplication step but sign error in final step | 1 point |

**D4.** (-2)^3 + 12 / (-4)
Exponent: (-2)^3 = -8. Division: 12 / (-4) = -3.
Addition: -8 + (-3) = **-11**.

|----------|-------|

| Level | Score Range | Meaning | Next Steps |

### Section-Specific Reteaching Guide

| If struggling in... | Focus on... |
|---|---|
| Section A | Return to Lessons 1-3. Use number line models for every problem. Focus on the "add the opposite" rule for subtraction. Have the student verbalize whether signs are same or different before computing. |
| Section B | Return to Lessons 4-5. Rebuild the pattern tables from Lesson 4 to re-derive the sign rules. Practice the two-step process: (1) determine the sign, (2) compute with absolute values. Review zero-division cases. |
| Section C | Return to Lessons 6-7. If sign rules are correct but fraction/decimal arithmetic is weak, review fraction operations separately (common denominators, reciprocals). If sign rules are the issue, return to Lessons 1-5 with integers first. |
| Section D | Return to Lessons 8-9. Focus on the -a^2 vs. (-a)^2 distinction with repeated examples. Provide a PEMDAS checklist for multi-step problems. For properties, practice the distributive property with 5 additional examples. |
| Section E | Return to Lesson 10. If translation is the issue (cannot set up expressions), practice identifying key words (dropped = negative, gained = positive, per hour = multiply). If computation is the issue, return to the relevant operation lessons. |

## Error Analysis Guide

| Error Pattern | Example | Likely Cause | Intervention |
|--------------|---------|-------------|-------------|
| Subtracts absolute values for same-sign addition | -9 + (-14) = -5 instead of -23 | Applies different-sign rule to same-sign problem | Ask: "Are the signs the same or different?" Practice sorting problems by sign pattern before computing. |
| Does not convert subtraction to addition | -6 - 9 = 3 instead of -15 | Skips the "add the opposite" step | Require rewriting every subtraction as addition until the step is automatic. |
| Subtracting a negative: keeps it negative | 4 - (-11) = -7 instead of 15 | Does not apply "subtracting a negative = adding a positive" | Use the debt analogy: "Removing a debt increases your balance." |
| Wrong sign for neg x neg | (-9) x (-6) = -54 instead of 54 | Has not internalized the same-sign rule | Return to the pattern table in Lesson 4. |
| Confuses -a^2 and (-a)^2 | Writes -5^2 = 25 | Does not understand that the exponent applies only to the base | Circle the base in each expression. -5^2: base is 5. (-5)^2: base is -5. Drill 5 pairs. |
| Does addition before multiplication | 8 - 3 x (-4) = 8 - (-12) but gets 5 x (-4) = -20 | Does not follow PEMDAS | Use a checklist: P, E, M/D, A/S. Underline the operation to perform at each step. |
| Fraction division: forgets to flip | (-5/6) / (-2/3) computed as (-5/6) x (-2/3) | Confuses multiplication and division of fractions | Write a big arrow: "DIVISION = FLIP and MULTIPLY." Practice 5 fraction division problems with positive numbers first. |
| Word problem: forgets starting value | Computes only the change, not the final value | Does not include the initial condition | Highlight the starting value in every problem. Use a template: Start + Change = Result. |

## Facilitator Observations

- Can the student reliably determine the sign of a result before computing? (This is the most important indicator of conceptual understanding.)
- Does the student convert subtraction to addition automatically, or does this step still require prompting?
- When multiplying or dividing, does the student use the two-step process (sign first, then absolute values)?
- Can the student distinguish -a^2 from (-a)^2 without hesitation?
- In word problems, does the student translate the context into a mathematical expression independently, or does the student need help identifying the operations?
- Does the student check the reasonableness of answers? (For example, does the student notice if a temperature "rises" but the answer is lower than the starting value?)
