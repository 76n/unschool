# Math -- Grade 7 -- Unit 2, Lesson 9

## Topic
Properties of Operations with Rational Numbers

## Learning Objectives
- Identify and apply the commutative, associative, and distributive properties with rational numbers (including negatives).
- Use properties of operations to simplify and evaluate expressions.
- Recognize which operations are commutative and associative (addition and multiplication) and which are not (subtraction and division).

## Prerequisites
- Mastery of all four operations with rational numbers (Lessons 1-7).
- Ability to evaluate multi-step expressions using order of operations (Lesson 8).
- Informal familiarity with properties of operations from earlier grades.

## Materials Needed
- Whiteboard and markers (or projector).
- Student worksheet (Guided Practice and Independent Practice problems).
- Index cards or half-sheets for Exit Ticket.

**Standards:** 7.NS.1d -- Apply properties of operations as strategies to add and subtract rational numbers. 7.NS.2c -- Apply properties of operations as strategies to multiply and divide rational numbers.

## Warm-Up (5 minutes)

**Purpose:** Activate prior knowledge of properties and test whether they hold for negative numbers.

1. Compute: 3 + (-5) and (-5) + 3. (Both equal -2.)
2. Compute: 4 x (-7) and (-7) x 4. (Both equal -28.)
3. Compute: 8 - 3 and 3 - 8. (5 and -5. Different.)
4. Ask: "Addition and multiplication gave the same result when we switched the order. Subtraction did not. Do you remember the name of this property?" (Commutative property.)

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Commutative Property** -- changing the order does not change the result. a + b = b + a (addition). a x b = b x a (multiplication).
- **Associative Property** -- changing the grouping does not change the result. (a + b) + c = a + (b + c) (addition). (a x b) x c = a x (b x c) (multiplication).
- **Distributive Property** -- multiplication distributes over addition and subtraction. a(b + c) = ab + ac. a(b - c) = ab - ac.
- **Identity Property** -- adding 0 or multiplying by 1 leaves a number unchanged. a + 0 = a. a x 1 = a.
- **Inverse Property** -- a + (-a) = 0 (additive inverse). a x (1/a) = 1 (multiplicative inverse, a is not 0).

### Instruction Notes

**Step 1 -- Commutative Property with rational numbers.**
"The commutative property holds for addition and multiplication, even with negative numbers."

Addition: -3 + 7 = 4 and 7 + (-3) = 4. Same result.
Multiplication: (-2) x 5 = -10 and 5 x (-2) = -10. Same result.

"But subtraction and division are NOT commutative."
Subtraction: 5 - (-3) = 8 but (-3) - 5 = -8. Different.
Division: (-12) / 4 = -3 but 4 / (-12) = -1/3. Different.

**Step 2 -- Associative Property with rational numbers.**
"The associative property holds for addition and multiplication."

Addition: [(-2) + 3] + (-5) = 1 + (-5) = -4. And (-2) + [3 + (-5)] = (-2) + (-2) = -4. Same.
Multiplication: [(-2) x 3] x (-4) = (-6) x (-4) = 24. And (-2) x [3 x (-4)] = (-2) x (-12) = 24. Same.

"Subtraction and division are NOT associative."
Subtraction: (10 - 4) - 3 = 6 - 3 = 3. But 10 - (4 - 3) = 10 - 1 = 9. Different.

**Step 3 -- Distributive Property with rational numbers.**
"The distributive property is one of the most powerful tools in algebra."

Example: -3(4 + (-7))

Method 1 -- Inside first: -3(4 + (-7)) = -3(-3) = 9.
Method 2 -- Distribute: -3(4) + (-3)(-7) = -12 + 21 = 9. Same result.

Example: 5(-2 - 3)

Method 1 -- Inside first: 5(-2 - 3) = 5(-5) = -25.
Method 2 -- Distribute: 5(-2) - 5(3) = -10 - 15 = -25. Same.

Example with fractions: -1/2(4/5 + 2/3)

Distribute: (-1/2)(4/5) + (-1/2)(2/3) = -4/10 + (-2/6) = -2/5 + (-1/3).
Common denominator 15: -6/15 + (-5/15) = -11/15.

**Step 4 -- Using properties to simplify expressions.**
Example: Simplify -8 + 15 + 8.

Using the commutative property, rearrange: -8 + 8 + 15 = 0 + 15 = 15.
(Combining opposites makes the computation much easier.)

Example: Simplify 4 x (-3) x 25.

Using the commutative and associative properties: 4 x 25 x (-3) = 100 x (-3) = -300.
(Grouping 4 and 25 first is more efficient.)

Example: Simplify -2(x + 5) using the distributive property.

-2(x + 5) = -2 x x + (-2) x 5 = -2x + (-10) = -2x - 10.

### Worked Examples

**Example A -- Commutative property to simplify**
Simplify: -14 + 23 + 14

Rearrange: -14 + 14 + 23 = 0 + 23 = **23**.

**Example B -- Associative property to simplify**
Simplify: (-5) x 7 x (-2)

Rearrange: (-5) x (-2) x 7 = 10 x 7 = **70**.

**Example C -- Distributive property**
Simplify: -4(3 + (-8))

Distribute: (-4)(3) + (-4)(-8) = -12 + 32 = **20**.
Check: 3 + (-8) = -5. (-4)(-5) = 20. Confirmed.

**Example D -- Distributive property with a variable**
Expand: -3(2x - 7)

-3(2x) - (-3)(7) = -6x - (-21) = -6x + 21.
Answer: **-6x + 21**.

## Guided Practice (10 minutes)

1. Use the commutative property to simplify: -9 + 4 + 9 + (-6).
   - *Facilitator tip:* "Look for additive inverses (numbers that sum to 0)."

2. Use the associative property to simplify: (-4) x (-5) x 3.
   - *Facilitator tip:* "Which pair would you compute first to make it easier?"

3. Use the distributive property to evaluate: 6(-3 + 5).
   - *Facilitator tip:* "Distribute the 6, or simplify inside the parentheses first. Try both ways."

4. Expand using the distributive property: -5(2x + 3).
   - *Facilitator tip:* "Multiply -5 by each term inside the parentheses."

5. Determine whether the following is true or false: (-12) / 4 = 4 / (-12). What does this tell you about division?
   - *Facilitator tip:* "Compute both sides. Division is not commutative."

## Independent Practice (10-15 minutes)

### Part A -- Identifying Properties
1. Name the property illustrated: -7 + 7 = 0.
2. Name the property illustrated: (-3) x (5 x (-4)) = ((-3) x 5) x (-4).
3. Name the property illustrated: 8 x (-1/2 + 3) = 8 x (-1/2) + 8 x 3.

### Part B -- Simplifying with Properties
4. Use properties to simplify: 25 + (-13) + (-25) + 13.
5. Use properties to simplify: (-2) x 9 x (-5).
6. Use the distributive property to evaluate: -7(8 - 11).
7. Expand: -2/3(9x - 6).

### Part C -- Applied and Extended
8. Evaluate -3(x - 4) + 2x when x = -5.
9. Prove with a specific example that subtraction is NOT associative. Use three rational numbers of your choice.
10. Use the distributive property to compute 15 x (-98) mentally. (Hint: rewrite -98 as -100 + 2.)
11. Simplify: -1/4(8a + 12) - 3a. Combine like terms.

### Answer Key

**Part A**
1. Additive Inverse Property (also called the Inverse Property of Addition).
2. Associative Property of Multiplication.
3. Distributive Property.

**Part B**
4. 25 + (-25) + (-13) + 13 = 0 + 0 = **0**.
5. (-2) x (-5) x 9 = 10 x 9 = **90**.
6. -7(8 - 11) = -7(-3) = **21**. Or distribute: -7(8) - (-7)(11) = -56 + 77 = 21.
7. -2/3(9x - 6) = (-2/3)(9x) - (-2/3)(6) = -6x - (-4) = **-6x + 4**.

**Part C**
8. -3(x - 4) + 2x = -3x + 12 + 2x = -x + 12. When x = -5: -(-5) + 12 = 5 + 12 = **17**.
9. Example: (8 - 3) - 2 = 5 - 2 = 3. But 8 - (3 - 2) = 8 - 1 = 7. Since 3 is not 7, subtraction is not associative. (Accept any correct example with rational numbers.)
10. 15 x (-98) = 15 x (-100 + 2) = 15 x (-100) + 15 x 2 = -1500 + 30 = **-1470**.
11. -1/4(8a + 12) - 3a = -2a + (-3) - 3a = -2a - 3 - 3a = **-5a - 3**.

## Assessment Check

### Exit Ticket
**Problem 1:** Use the distributive property to evaluate: -4(5 + (-9)).

**Problem 2:** Use properties to simplify: -18 + 7 + 18 + (-3).

**Scoring:**
- 2 out of 2 correct = Mastery demonstrated.
- 1 out of 2 correct = Partial understanding; review errors.
- 0 out of 2 correct = Reteach needed.

**Exit Ticket Answers:**
1. -4(5 + (-9)) = -4(-4) = **16**. Or distributed: -4(5) + (-4)(-9) = -20 + 36 = 16.
2. -18 + 18 + 7 + (-3) = 0 + 4 = **4**.

### If Mastery Is Not Met
- Focus on the distributive property, as it is the most important property for algebra readiness. Provide 5 additional problems of the form a(b + c) with negative values.
- Have the student verify properties with numerical examples first (choose specific numbers, compute both sides, confirm they are equal) before applying them to simplify.
- If the student struggles to identify opportunities to use properties, provide structured problems: "Rearrange these numbers to find zero pairs: -5 + 8 + 5 + (-3)."

### If Mastery Is Met
- Assign Part C problems if not yet completed.
- Preview: "In the next lesson, we put everything together with real-world problems that require multiple operations with rational numbers."

## Extension
- **Mental Math Challenge:** Use the distributive property to compute these mentally: (a) 12 x (-49) [= 12(-50 + 1) = -600 + 12 = -588]. (b) -8 x 102 [= -8(100 + 2) = -800 + (-16) = -816].
- **Property Proof:** "Can you show that the distributive property works for a = -2, b = 3/4, and c = -1/2? Compute a(b + c) and ab + ac separately and show they are equal."

## Teacher/Facilitator Notes

### Common Errors
- **Distributing only to the first term.** The student writes -3(4 + 5) = -12 + 5 instead of -12 + (-15). Remind: "The -3 multiplies EVERY term inside the parentheses."
- **Sign errors when distributing a negative.** The student writes -2(x - 3) = -2x - 6 instead of -2x + 6. Remind: "A negative times a negative is positive. -2 times -3 is +6."
- **Applying commutative property to subtraction.** The student assumes a - b = b - a. Use a concrete counterexample: 5 - 3 = 2 but 3 - 5 = -2.

### Pacing Advice
- This lesson can often be completed in one session. The properties themselves are not new -- what is new is applying them to negative numbers.
- Prioritize the distributive property above the other properties. It is used far more frequently in algebra and is the one most likely to cause sign errors.
- Problem 10 (mental math with the distributive property) is excellent for showing the practical value of properties. Use it to demonstrate that properties are not just abstract rules but tools for efficient computation.
