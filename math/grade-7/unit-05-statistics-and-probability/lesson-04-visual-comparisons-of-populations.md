# Math -- Grade 7 -- Unit 5, Lesson 4

## Topic
Visual Comparisons of Populations

## Learning Objectives
- Create side-by-side dot plots and double box plots on the same number line scale.
- Describe the overlap and separation of two data distributions visually.
- Use visual displays to support or challenge comparative inferences from Lesson 3.
- Interpret what the degree of overlap between two distributions means about the populations.

## Prerequisites
- Creating and reading dot plots (Grade 6).
- Creating and reading box plots (Grade 6).
- Computing IQR, median, and range (Grade 6; reviewed in Lesson 3).
- Comparing two populations using numerical summaries (Lesson 3).

## Materials Needed
- Graph paper (for drawing dot plots and box plots)
- Ruler (for box plot construction)
- Pencil, plus a colored pencil or pen for the second data set
- Student worksheet (Guided Practice and Independent Practice)
- Index cards for Exit Ticket

**Standards:** 7.SP.3 and 7.SP.4 -- Informally assess the degree of visual overlap of two numerical data distributions; measure the difference between the centers by expressing it as a multiple of a measure of variability.

## Warm-Up (5 minutes)

**Purpose:** Refresh box plot construction from Grade 6.

Give the student the following data set: 12, 18, 22, 15, 25, 20, 17, 30, 14, 28

Ask: "Without computing -- just by looking at this data -- approximately where do you think the median is? Now order the data and find the actual median, Q1, and Q3."

Ordered: 12, 14, 15, 17, 18, 20, 22, 25, 28, 30
- Median = (18+20)/2 = 19
- Q1 = (14+15)/2 = 14.5
- Q3 = (25+28)/2 = 26.5
- Min = 12, Max = 30

Say: "Now we can build a box plot. Today we'll build two box plots on the same number line to compare two groups visually."

## Direct Instruction (12 minutes)

### Key Vocabulary

- **Dot plot** -- a display that places one dot per data value above a number line. Good for small data sets.
- **Box plot (box-and-whisker plot)** -- a display showing the five-number summary: minimum, Q1, median, Q3, maximum. The box spans Q1 to Q3; the median is a line inside the box; the whiskers extend to the minimum and maximum.
- **Overlap** -- the region where the two data distributions share the same range of values. High overlap means the groups are hard to distinguish; low overlap means the groups are clearly different.
- **Separation** -- the degree to which the two distributions' centers or ranges are apart from each other.

### Instruction Notes

**Step 1 -- Why visual displays matter.**

Say: "In Lesson 3, we compared two groups using numbers: mean, median, IQR, MAD. Numbers are precise but can be hard to interpret at a glance. Visual displays give us the whole picture at once -- we can see not just where the centers are, but how the entire spread of data from Group A compares to Group B."

**Step 2 -- Double dot plots.**

Say: "The simplest visual comparison is a double dot plot. We use the same horizontal number line for both groups, but place one group's dots above the line and the other group's below -- or use different symbols or colors for each group."

Draw an example on the board:

Group A scores: 5, 6, 7, 7, 8, 8, 9
Group B scores: 2, 3, 4, 5, 6, 7, 8

Both on a number line from 1 to 10.

Say: "We can immediately see that Group A clusters higher on the number line. Group B's values mostly fall in the 2-7 range, while Group A's values mostly fall in the 5-9 range. There is some overlap in the middle (5-8), but the centers are clearly different."

**Step 3 -- Double box plots.**

Say: "For larger data sets or when we want to emphasize the five-number summary, we use two box plots on the same scale."

Explain the reading:
- Which box is positioned higher (or further right) on the number line? That group has higher values.
- Which box is longer? That group has greater IQR (more spread in the middle 50%).
- Which box overlaps more with the other box? Greater overlap means the groups are harder to distinguish.
- Overlapping boxes mean: "Many values in both groups fall in the same range."
- Separated boxes (no overlap between the boxes) mean: "The groups are clearly different."

**Step 4 -- Interpreting overlap (7.SP.3).**

Say: "The standard asks us to informally assess the degree of visual overlap. We do this by looking at how much the two boxes share the same stretch of the number line."

Describe three scenarios:
1. **No overlap:** Box A ends at 50, Box B begins at 60. Clearly different populations.
2. **Partial overlap:** Box A spans 40-70, Box B spans 60-90. Overlap in the 60-70 region.
3. **Complete overlap:** Box A spans 40-80, Box B spans 35-85. Nearly identical distributions.

### Worked Example

**Comparing test scores for two classes:**

Class 1 five-number summary: Min=58, Q1=68, Med=75, Q3=83, Max=92
Class 2 five-number summary: Min=40, Q1=52, Med=62, Q3=74, Max=88

Draw two box plots on the same scale (30 to 100).

Observations:
- Class 1's median (75) is higher than Class 2's median (62). Difference = 13 points.
- Class 1's box (68-83) and Class 2's box (52-74) overlap in the range 68-74. The overlap is relatively small -- about 6 points of the approximately 30 points each box spans.
- Class 1's box is positioned clearly above Class 2's box for most of its range.
- Conclusion: "Class 1 tends to score higher than Class 2. There is limited overlap between the two groups, and the difference in medians (13 points) is meaningful relative to the spread."

## Guided Practice (10 minutes)

**Scenario:** A researcher compared reaction times (in milliseconds) for two groups: teens who regularly play video games and teens who do not.

Gamers data: 190, 210, 225, 200, 215, 195, 230, 220, 205, 210

Non-gamers data: 240, 265, 280, 255, 270, 245, 290, 260, 250, 275

Work through together:

1. Find the five-number summary for each group.
   - Gamers ordered: 190, 195, 200, 205, 210, 210, 215, 220, 225, 230. Min=190, Q1=(200+205)/2=202.5, Median=(210+210)/2=210, Q3=(215+220)/2=217.5, Max=230.
   - Non-gamers ordered: 240, 245, 250, 255, 260, 265, 270, 275, 280, 290. Min=240, Q1=(250+255)/2=252.5, Median=(260+265)/2=262.5, Q3=(270+275)/2=272.5, Max=290.
   - **Facilitator tip:** "Order each data set before finding the five-number summary."

2. Draw two box plots on the same number line (scale: 180 to 300).
   - The student draws both box plots on the same scale, labeled "Gamers" and "Non-gamers."
   - **Facilitator tip:** "Make sure both plots use exactly the same scale so the visual comparison is fair."

3. Describe the overlap.
   - The highest gamer value is 230; the lowest non-gamer value is 240. The boxes do NOT overlap at all. There is a gap of 10 ms between the top of the gamer distribution and the bottom of the non-gamer distribution.
   - **Facilitator tip:** "Where does the gamer box end? Where does the non-gamer box begin?"

4. Write a comparative inference.
   - "Gamers have consistently faster reaction times than non-gamers (median 210 ms vs. 263 ms). The two groups do not overlap at all -- every gamer in the sample had a faster reaction time than every non-gamer in the sample. This is a strong difference."

## Independent Practice (12 minutes)

### Tier 1 (On-level)

A school tracked the number of hours of sleep per night for 10 students on two sports teams.

Team Basketball: 6, 7, 8, 7, 6, 9, 7, 8, 6, 8

Team Swimming: 8, 9, 8, 7, 10, 9, 8, 9, 8, 10

1. Find the five-number summary for each team.

2. On graph paper, draw two box plots on the same number line. Label each clearly.

3. Describe the overlap between the two distributions. Do the boxes overlap? By how much?

4. Write two sentences comparing the sleep habits of basketball and swimming team members based on your box plots.

### Tier 2 (Stretch)

5. Use the sleep data from Problems 1-4.
   - (a) Calculate the IQR for each team.
   - (b) By how many IQR units does Team Swimming's median exceed Team Basketball's median? (Hint: Difference in medians / IQR of basketball.)
   - (c) Does the visual overlap agree with your calculation in part (b)? Explain.

6. Create a dot plot for the following two data sets on the same number line. Then describe which plot is more spread out and which has a higher center.

   Data Set X: 10, 12, 11, 13, 12, 14, 13, 11, 12, 13
   Data Set Y: 7, 15, 9, 17, 12, 14, 8, 16, 11, 13

### Tier 3 (Challenge)

7. Interleaved review (Unit 4 -- Geometry): The median score in a geometry test for Class A is 78. The IQR is 14 (Q1=71, Q3=85). A student earns a score that is on the edge of the upper whisker of the box plot (at the maximum), which is 20 points above Q3. What is the student's score? If a circle has a circumference of C = 3.14 * 20, what is its radius? (Combines geometry review with box plot interpretation.)

8. A researcher says: "Because Team Swimming's dot plot is entirely above Team Basketball's dot plot with no overlap, I can be absolutely certain that all swimmers sleep more than all basketball players in the whole school." Evaluate this statement. What is correct about it? What is wrong about it?

## Exit Ticket

Two groups of students reported how many texts they send per day.

Group A (7th graders): Min=10, Q1=18, Median=25, Q3=32, Max=45

Group B (8th graders): Min=22, Q1=28, Median=35, Q3=42, Max=50

**Problem 1:** Sketch two box plots on the same number line (scale 0 to 55) for these data.

**Problem 2:** Do the two boxes overlap? What range do they share?

**Problem 3:** Write one sentence comparing texting habits between 7th and 8th graders based on the box plots.

**Mastery:** Accurate box plots with correct overlap identified and a complete comparative statement = Mastery. Box plots drawn but overlap not identified or comparison too vague = Review overlap interpretation before next lesson.

## Answer Key

### Independent Practice

1. Basketball ordered: 6, 6, 6, 7, 7, 7, 8, 8, 8, 9. Five-number summary: Min=6, Q1=(6+7)/2=6.5, Median=(7+7)/2=7, Q3=(8+8)/2=8, Max=9. Swimming ordered: 7, 8, 8, 8, 8, 9, 9, 9, 10, 10. Five-number summary: Min=7, Q1=(8+8)/2=8, Median=(8+9)/2=8.5, Q3=(9+9)/2=9, Max=10.

2. Box plots drawn on the same scale. Basketball box runs from 6.5 to 8 with median line at 7. Swimming box runs from 8 to 9 with median line at 8.5. Whiskers extend to the min and max.

3. Basketball box spans 6.5-8 (Q1 to Q3); Swimming box spans 8-9. The boxes barely touch at Q1 of swimming (8) = Q3 of basketball (8) -- minimal overlap at a single point. The distributions are almost non-overlapping.

4. Sample: "Swimming team members tend to sleep more per night than basketball team members -- the swimming team's median sleep (8.5 hours) is higher than basketball's (7 hours). The two distributions barely overlap, suggesting the difference in sleep habits is consistent across both teams."

5. (a) Basketball IQR = 8-6.5 = **1.5 hours**. Swimming IQR = 9-8 = **1 hour**. (b) Difference in medians = 8.5-7 = 1.5 hours. 1.5/1.5 = **1 IQR unit** above. (c) Yes -- visually, the swimming box starts roughly where the basketball box ends, confirming a difference of about 1 IQR and nearly no overlap.

6. X ordered: 10, 11, 11, 12, 12, 12, 13, 13, 13, 14. Range = 4. Center (mean) = 121/10 = 12.1. Y ordered: 7, 8, 9, 11, 12, 13, 14, 15, 16, 17. Range = 10. Center (mean) = 122/10 = 12.2. The dot plots should show X clustered tightly around 12, while Y spreads from 7 to 17. Data Set Y is more spread out; both sets have nearly the same center (mean ≈ 12).

7. Q3 = 85. The maximum is 20 points above Q3: 85 + 20 = **105**. (Note: This is an unusual situation -- the maximum is 20 above Q3, which would be an outlier in most contexts. Accept as stated.) Circle circumference: C = 3.14 * 20. C = 2 * pi * r, so 2 * 3.14 * r = 3.14 * 20. Divide both sides by 3.14: 2r = 20. r = **10**.

8. What is correct: In the sample, every swimmer did sleep more than every basketball player. The data supports this for the 10 students studied. What is wrong: The researcher cannot be "absolutely certain" for the whole school based on a sample. This is an inference about a population based on sample data, subject to sampling variability. A different sample might show some overlap. Also, the word "certain" overstates what samples can tell us.

### Exit Ticket

1. Box plots drawn on 0-55 scale. 7th grade: whisker at 10, box from 18 to 32, median line at 25, whisker at 45. 8th grade: whisker at 22, box from 28 to 42, median line at 35, whisker at 50.

2. Yes, the boxes overlap. 7th grade box spans 18-32; 8th grade box spans 28-42. They share the range **28-32**.

3. Sample: "8th graders tend to send more texts per day than 7th graders (median 35 vs. 25), and the boxes partially overlap (28-32), meaning some 7th and 8th graders have similar texting habits, but on the whole 8th graders text more."

## Teacher Notes

- Double box plots and dot plots are the primary visual tools for this standard. Having graph paper and a ruler is essential -- poorly scaled box plots are hard to compare.
- Emphasize that both plots must use the SAME number line scale. A common error is drawing each plot on its own scale, which makes comparison meaningless.
- The concept of "overlap" in 7.SP.3 is intentionally informal. The standard does not require precise calculation of overlap area. Focus on: (1) do the boxes share any range? (2) does the overlap cover most of the boxes or only a little? (3) which group is clearly higher?
- If the student has graph paper, the dot plot in Tier 2, Problem 6 can be constructed quite easily. Encourage the student to use different symbols (x vs. dot) or different colors for the two data sets.
