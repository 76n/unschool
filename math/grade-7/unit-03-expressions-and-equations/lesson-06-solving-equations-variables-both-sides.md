# Math -- Grade 7 -- Unit 3, Lesson 6

## Topic
Solving Equations with Variables on Both Sides

## Learning Objectives
- Recognize equations that have variable terms on both sides.
- Solve equations with variables on both sides by collecting variable terms on one side using inverse operations.
- Identify equations that have no solution (contradiction) or infinitely many solutions (identity).
- Verify solutions by substituting back into the original equation.

## Prerequisites
- Ability to solve two-step equations (Lesson 5).
- Ability to combine like terms (Lesson 2).
- Fluency with integer operations, including subtraction of negative numbers (Unit 2).

## Materials Needed
- Whiteboard and markers (or projector).
- Balance scale diagram (for conceptual model).
- Student worksheet (Guided Practice and Independent Practice problems).
- Index cards or half-sheets for Exit Ticket.

**Standards:** 7.EE.4a -- Solve word problems leading to equations of the form px + q = r and p(x + q) = r, where p, q, and r are specific rational numbers. (Extension: variables on both sides introduces Grade 8 content informally.)

## Warm-Up (5 minutes)

**Purpose:** Review two-step equations and introduce the new challenge.

1. Solve: 5x + 3 = 18. (5x = 15, x = 3)
2. Solve: 2x - 7 = 1. (2x = 8, x = 4)
3. Ask: "What if the equation is 5x + 3 = 2x + 18? Now there are x-terms on BOTH sides. How do we handle that?"

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Variables on both sides** -- an equation where the variable appears in terms on both the left side and the right side. Example: 3x + 5 = x + 13.
- **Collect variable terms** -- use inverse operations to move all variable terms to one side of the equation.
- **No solution** -- an equation that is never true, no matter what value the variable takes. Example: 2x + 1 = 2x + 5 simplifies to 1 = 5, which is false.
- **Infinitely many solutions (identity)** -- an equation that is true for every value of the variable. Example: 3x + 6 = 3(x + 2) simplifies to 3x + 6 = 3x + 6, which is always true.

### Instruction Notes

**Step 1 -- Move variable terms to one side.**

Say: "When we see variables on both sides, our goal is to get all the variable terms on one side and all the constant terms on the other side. We do this by adding or subtracting variable terms from both sides."

Write: 5x + 3 = 2x + 18

Say: "I see x-terms on both sides: 5x on the left and 2x on the right. I will subtract 2x from both sides to move the variable terms to the left."

- 5x - 2x + 3 = 2x - 2x + 18
- 3x + 3 = 18

Say: "Now this is a regular two-step equation. Subtract 3, then divide by 3."

- 3x = 15
- x = 5

Say: "Check: Left side: 5(5) + 3 = 25 + 3 = 28. Right side: 2(5) + 18 = 10 + 18 = 28. Both sides equal 28."

**Step 2 -- Another example, moving to the right.**

Write: 2x + 9 = 6x - 7

Say: "I can move the variable terms to either side. Let me subtract 2x from both sides so the coefficient stays positive."

- 2x - 2x + 9 = 6x - 2x - 7
- 9 = 4x - 7

Say: "Now add 7 to both sides."
- 16 = 4x

Say: "Divide both sides by 4."
- 4 = x, so x = 4

Say: "Check: Left: 2(4) + 9 = 8 + 9 = 17. Right: 6(4) - 7 = 24 - 7 = 17. Correct."

**Step 3 -- Introduce no solution and identity (briefly).**

Say: "Sometimes when we collect variable terms, something unusual happens."

Write: 2x + 1 = 2x + 5

Say: "Subtract 2x from both sides."
- 1 = 5

Say: "This is a false statement. No value of x can make 1 equal to 5. This equation has NO SOLUTION."

Write: 3(x + 2) = 3x + 6

Say: "Expand the left side: 3x + 6 = 3x + 6. Subtract 3x from both sides: 6 = 6. This is always true. EVERY value of x is a solution. We call this an identity."

### Worked Examples

**Example A: Standard variables on both sides**
Solve: 4x + 7 = x + 22

Subtract x from both sides: 3x + 7 = 22
Subtract 7: 3x = 15
Divide by 3: x = **5**
Check: 4(5) + 7 = 27. And 5 + 22 = 27.

**Example B: Larger coefficient on the right**
Solve: 3x - 4 = 7x + 8

Subtract 3x from both sides: -4 = 4x + 8
Subtract 8: -12 = 4x
Divide by 4: -3 = x, so x = **-3**
Check: 3(-3) - 4 = -9 - 4 = -13. And 7(-3) + 8 = -21 + 8 = -13.

**Example C: No solution**
Solve: 5x + 10 = 5x - 3

Subtract 5x: 10 = -3
This is false. **No solution.**

## Guided Practice (10 minutes)

1. Solve: 6x + 2 = 4x + 10
   - 2x + 2 = 10, 2x = 8, x = **4**. Check: 6(4) + 2 = 26, 4(4) + 10 = 26.
   - **Facilitator tip:** "Subtract 4x from both sides to start."

2. Solve: 3x + 15 = 8x - 5
   - 15 = 5x - 5, 20 = 5x, x = **4**. Check: 3(4) + 15 = 27, 8(4) - 5 = 27.
   - **Facilitator tip:** "Move the smaller x-term to get a positive coefficient."

3. Solve: 7x - 1 = 3x + 11
   - 4x - 1 = 11, 4x = 12, x = **3**. Check: 7(3) - 1 = 20, 3(3) + 11 = 20.
   - **Facilitator tip:** "Subtract 3x from both sides."

4. Solve: 2x + 8 = 2x + 8
   - 8 = 8. **Infinitely many solutions (identity).**
   - **Facilitator tip:** "What happened when the variable terms cancelled? Is the remaining statement true or false?"

5. Solve: 9x - 6 = 4x + 14
   - 5x - 6 = 14, 5x = 20, x = **4**. Check: 9(4) - 6 = 30, 4(4) + 14 = 30.
   - **Facilitator tip:** "Standard process -- subtract 4x, add 6, divide by 5."

## Independent Practice (10-15 minutes)

### Part A: Equations with Variables on Both Sides

1. 8x + 3 = 5x + 15
2. 2x + 20 = 6x - 4
3. 10x - 8 = 3x + 13
4. 4x + 9 = x - 6
5. -x + 7 = 2x - 8

### Part B: Special Cases

6. 3x + 12 = 3x + 12
7. 5x - 4 = 5x + 7
8. 2(x + 3) = 2x + 6

### Part C: Word Problems

9. Two cell phone plans: Plan A costs $30 per month plus $0.10 per minute. Plan B costs $20 per month plus $0.15 per minute. After how many minutes of use do both plans cost the same? (Write the equation and solve.)
10. A rectangle has a length of (3x + 1) and a width of (x + 5). If the length equals twice the width, find x. (Write the equation 3x + 1 = 2(x + 5) and solve.)

### Answer Key

**Part A**
1. 8x + 3 = 5x + 15 → 3x + 3 = 15 → 3x = 12 → x = **4**. Check: 8(4) + 3 = 35, 5(4) + 15 = 35.
2. 2x + 20 = 6x - 4 → 20 = 4x - 4 → 24 = 4x → x = **6**. Check: 2(6) + 20 = 32, 6(6) - 4 = 32.
3. 10x - 8 = 3x + 13 → 7x - 8 = 13 → 7x = 21 → x = **3**. Check: 10(3) - 8 = 22, 3(3) + 13 = 22.
4. 4x + 9 = x - 6 → 3x + 9 = -6 → 3x = -15 → x = **-5**. Check: 4(-5) + 9 = -11, (-5) - 6 = -11.
5. -x + 7 = 2x - 8 → 7 = 3x - 8 → 15 = 3x → x = **5**. Check: -(5) + 7 = 2, 2(5) - 8 = 2.

**Part B**
6. 3x + 12 = 3x + 12 → 12 = 12. **Infinitely many solutions (identity).**
7. 5x - 4 = 5x + 7 → -4 = 7. **No solution.**
8. 2(x + 3) = 2x + 6 → 2x + 6 = 2x + 6 → 6 = 6. **Infinitely many solutions (identity).**

**Part C**
9. Equation: 30 + 0.10m = 20 + 0.15m. Solve: 30 - 20 = 0.15m - 0.10m → 10 = 0.05m → m = **200 minutes**. Check: Plan A: 30 + 0.10(200) = 30 + 20 = $50. Plan B: 20 + 0.15(200) = 20 + 30 = $50.
10. Equation: 3x + 1 = 2(x + 5) = 2x + 10. Solve: 3x + 1 = 2x + 10 → x + 1 = 10 → x = **9**. Check: Length = 3(9) + 1 = 28, Width = 9 + 5 = 14, and 2(14) = 28 = Length.

## Assessment Check

### Exit Ticket
**Problem:** Solve: 5x + 4 = 2x + 19

**Target response:** 3x + 4 = 19, 3x = 15, x = **5**. Check: 5(5) + 4 = 29, 2(5) + 19 = 29.

**Scoring:**
- Correct solution with check = Mastery demonstrated.
- Correct approach but arithmetic error = Partial understanding; review integer operations.
- Does not know how to handle variables on both sides = Reteach; demonstrate the process of subtracting the smaller variable term from both sides.

## Extension
- **Multi-Step:** Solve 3(x + 2) = 2(x + 5) + x. Expand: 3x + 6 = 2x + 10 + x = 3x + 10. Then: 3x + 6 = 3x + 10, so 6 = 10. **No solution.**
- **Challenge:** Solve 4(2x - 1) = 3(x + 2) + 5x. Expand: 8x - 4 = 3x + 6 + 5x = 8x + 6. Then: 8x - 4 = 8x + 6, so -4 = 6. **No solution.** Ask: "Can you create an equation with variables on both sides that HAS a solution?"
