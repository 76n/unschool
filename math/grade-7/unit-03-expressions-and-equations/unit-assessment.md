## Answer Key

### Section 1: Simplifying Expressions

**1.1.** 7x + 3 - 2x + 9
Combine x-terms: 7x - 2x = 5x. Combine constants: 3 + 9 = 12.
Answer: **5x + 12**

**1.2.** -4a + 6b - a + 2b
Combine a-terms: -4a - a = -5a. Combine b-terms: 6b + 2b = 8b.
Answer: **-5a + 8b**

**1.3.** 5(2y - 3) = 5(2y) - 5(3) = **10y - 15**

**1.4.** -3(4x + 7) = (-3)(4x) + (-3)(7) = **-12x - 21**

**1.5.** GCF of 12 and 18 is 6. 12x + 18 = **6(2x + 3)**

**1.6.** 3(x + 4) + 2x - 5
= 3x + 12 + 2x - 5
= (3x + 2x) + (12 - 5)
= **5x + 7**

| Response | Score |
|----------|-------|
| Correct answer with distribution shown | 2 points |
| Correct distribution but error combining like terms | 1 point |
| Incorrect distribution | 0 points |

**1.7.** 4(2a - 1) - 3(a + 5)
= 8a - 4 - 3a - 15
= (8a - 3a) + (-4 - 15)
= **5a - 19**

| Response | Score |
|----------|-------|
| Correct answer with both distributions shown | 2 points |
| One distribution correct but error in the other or in combining | 1 point |
| Both distributions incorrect | 0 points |

**1.8.** -2(3x + 4) + 5(x - 2)
= -6x - 8 + 5x - 10
= (-6x + 5x) + (-8 - 10)
= **-x - 18** (or equivalently -1x - 18)

| Response | Score |
|----------|-------|
| Correct answer with all work shown | 3 points |
| Both distributions correct but error combining | 2 points |
| One distribution correct, other has sign error | 1 point |
| Both distributions incorrect | 0 points |

### Section 3: Equations from Word Problems

**3.1.** Streaming service.

Let m = number of months.
Equation: 9m + 15 = 69
Solve: 9m = 54, m = **6 months**.
Check: 9(6) + 15 = 54 + 15 = 69.

| Response | Score |

| Correct equation and solution but variable not defined | 2 points |

**3.2.** Rectangular garden.

Let w = width (in feet).
Then length = 2w + 3.
Perimeter: 2(2w + 3) + 2w = 54
4w + 6 + 2w = 54
6w + 6 = 54
6w = 48
w = **8 feet**
Length = 2(8) + 3 = **19 feet**

Check: Perimeter = 2(19) + 2(8) = 38 + 16 = 54. Correct.

| Response | Score |
|----------|-------|
| Variable defined, correct equation, correct width and length | 4 points |
| Correct equation and correct width but does not find length (or finds it incorrectly) | 3 points |
| Correct equation but arithmetic error in solving | 2 points |
| Defines the variable and sets up a reasonable equation but cannot solve | 1 point |
| Cannot set up the equation | 0 points |

**3.3.** Sticker collection.

Let n = number of Noah's stickers.
Then Emma has 3n - 8 stickers.
Together: n + (3n - 8) = 52
4n - 8 = 52
4n = 60
n = **15 stickers** (Noah)
Emma: 3(15) - 8 = 45 - 8 = **37 stickers**

Check: 15 + 37 = 52. And 3(15) - 8 = 37. Correct.

| Correct equation and Noah's stickers but does not find Emma's (or error in Emma's) | 2 points |
| Correct setup but arithmetic error | 1 point |

### Section 5: Mixed Reasoning

**5.1.** Error analysis.

The student wrote 4(x + 3) = 4x + 3. The error is that the student **only distributed the 4 to the x and did not multiply 4 by 3**. The distributive property requires multiplying the outside factor by EVERY term inside the parentheses.

Correct work: 4(x + 3) + 2x = 4x + 12 + 2x = **6x + 12**.

| Response | Score |
|----------|-------|
| Identifies the distribution error AND provides correct answer | 2 points |
| Identifies the error but gives incorrect corrected answer, OR gives correct answer but does not clearly explain the error | 1 point |
| Does not identify the error | 0 points |

**5.2.** Solving 5x - 3 = 5x + 7.

Subtract 5x from both sides: -3 = 7.
This is a **false statement**. The equation has **no solution**. There is no value of x that makes 5x - 3 equal to 5x + 7, because subtracting 3 from a quantity and adding 7 to the same quantity can never give the same result.

| Response | Score |
|----------|-------|
| Arrives at -3 = 7 (or equivalent) and correctly states "no solution" with explanation | 2 points |
| States no solution but does not show work or explain | 1 point |
| Attempts to solve but does not recognize the contradiction | 0 points |

**5.3.** Sign-flip explanation.

Example answer: "Consider the true inequality 4 < 8. If we divide both sides by -2, we get -2 and -4. But -2 is greater than -4 (it is to the right on the number line), so -2 > -4. The direction of the inequality reversed. This happens because multiplying or dividing by a negative number changes the positions of the numbers relative to each other on the number line. A larger positive number becomes a more negative number (farther left), so the order reverses."

| Response | Score |
|----------|-------|
| Provides a correct numerical example showing the flip AND explains why it happens | 2 points |
| Provides a correct numerical example but explanation is incomplete or unclear | 1 point |
| No example or incorrect example | 0 points |

## Rubric and Mastery Determination

| Level | Score Range | Meaning | Next Steps |
|-------|-----------|---------|------------|
| **Mastered** | 40-50 (80-100%) with at least 50% per section | Solid understanding of expressions, equations, and inequalities | Advance to Unit 4 (Geometry). |
| **Approaching** | 30-39 (60-79%) | Partial understanding; specific gaps exist | Identify weak sections. Use the Section-Specific Reteaching Guide below. Reassess weak sections after reteaching. |
| **Developing** | Below 30 (<60%) | Significant gaps remain | Check prerequisites: Can the student combine like terms? Solve one-step equations? Operate with negative numbers? Address foundational gaps before reteaching unit content. |

### Section-Specific Reteaching Guide

| If struggling in... | Focus on... |
|---|---|
| Section 1 (Expressions) | Return to Lessons 2-4. Use algebra tiles for combining like terms. Practice distributing with negative factors using the "arrows from the outside" method. Require checking by substitution. |
| Section 2 (Equations) | Return to Lesson 5. Rebuild the "undo" strategy with one-step equations first, then layer on two-step. For variables-on-both-sides errors (2.5-2.6), reteach Lesson 6 with balance-scale models. |
| Section 3 (Word Problems) | Return to Lesson 7. Practice the 4-step process (Define, Translate, Solve, Interpret) with simpler contexts first. Focus on identifying the repeated quantity (coefficient) vs. the one-time quantity (constant). |
| Section 4 (Inequalities) | Return to Lesson 8. If the student solves correctly but forgets the sign flip, provide 5 numeric examples of the sign-flip rule. If graphing is the issue, review open vs. closed circles with the "included or not?" question. |
| Section 5 (Reasoning) | Return to the specific topic that the student missed. Error analysis skills improve with practice -- give the student 3-4 "find the error" problems per session. |

## Error Analysis Guide

| Error Pattern | Example | Likely Cause | Intervention |
|--------------|---------|-------------|-------------|
| Combines unlike terms | 3x + 5y = 8xy | Does not understand "like terms" | Return to Lesson 2. Use color-coding: highlight all x-terms in one color, y-terms in another. Verify with substitution. |
| Distributes to only one term | 4(x + 3) = 4x + 3 | Incomplete application of distributive property | Draw arrows from the outside factor to EACH inside term. Require the student to write each multiplication separately. |
| Wrong order in equation solving | For 2x + 5 = 13, divides by 2 first | Does not understand "undo in reverse order" | Use the building/unbuilding diagram: "x was multiplied by 2, then 5 was added. Undo the adding first." |
| Forgets sign flip for inequalities | Writes -2x > 8 as x > -4 instead of x < -4 | Does not remember or understand the sign-flip rule | Provide 5 numeric examples: start with 2 < 6, multiply both sides by -1. Show that -2 > -6. Repeat until the pattern is clear. |
| Cannot translate word problems | Writes random operations | Does not connect verbal phrases to operations | Practice with a phrase-to-symbol reference card. Start with one-step translations before combining into equations. |
| Does not check solutions | Accepts incorrect answers | Skips the verification step | Require checking for every problem until it becomes habitual. Circle the check step in each solution. |
| Sign errors with negative coefficients | Solves -4x + 6 = -10 as -4x = -4, then x = 1 | Subtraction error: 6 - (-10) computed incorrectly | Review integer subtraction: -10 - 6 = -16, not -4. Return to Unit 2 Lesson 3 if subtraction of negatives is a persistent issue. |

## Facilitator Observations

- Can the student simplify expressions fluently, or does each step require prompting?
- When solving equations, does the student automatically check by substitution?
- Can the student set up word problems independently, or does the student need help identifying the variable and relationship?
- Does the student remember to flip the inequality sign when dividing by a negative, or is this still a frequent error?
- Can the student explain WHY a step works (conceptual understanding), or only perform the steps mechanically (procedural knowledge)?
- How does the student handle negative numbers throughout the unit? Are sign errors isolated or pervasive?
