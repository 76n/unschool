# Math -- Grade 7 -- Unit 3, Lesson 1

## Topic
Review: Algebraic Expressions and Properties

## Learning Objectives
- Identify the parts of an algebraic expression: terms, coefficients, constants, and variables.
- Evaluate algebraic expressions by substituting given values for variables.
- Apply the commutative, associative, and distributive properties to numerical and algebraic expressions.
- Explain why properties of operations are useful for simplifying expressions.

## Prerequisites
- Understanding of variables as letters that represent unknown quantities (Grade 6).
- Ability to evaluate expressions using order of operations (Unit 2, Lesson 8).
- Familiarity with the commutative, associative, and distributive properties (Unit 2, Lesson 9).

## Materials Needed
- Whiteboard and markers (or projector).
- Student worksheet (Guided Practice and Independent Practice problems).
- Index cards or half-sheets for Exit Ticket.

**Standards:** 7.EE.1 -- Apply properties of operations as strategies to add, subtract, factor, and expand linear expressions with rational coefficients.

## Warm-Up (5 minutes)

**Purpose:** Activate prior knowledge of expression vocabulary and evaluation.

1. Write on the board: 4x + 7
2. Ask: "What is the variable in this expression?" (x)
3. Ask: "What is the coefficient of x?" (4)
4. Ask: "What is the constant?" (7)
5. Ask: "If x = 3, what is the value of 4x + 7?" (4(3) + 7 = 12 + 7 = 19)

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Variable** -- a letter that represents an unknown or changing quantity.
- **Term** -- a single number, a variable, or a number multiplied by a variable. Terms are separated by addition or subtraction signs. In 3x + 2y - 5, the terms are 3x, 2y, and -5.
- **Coefficient** -- the numerical factor multiplied by a variable. In 3x, the coefficient is 3. In -7y, the coefficient is -7. In x (which means 1x), the coefficient is 1.
- **Constant** -- a term with no variable. In 3x + 8, the constant is 8.
- **Expression** -- a mathematical phrase that contains numbers, variables, and operations but no equals sign.

### Instruction Notes

**Step 1 -- Identify parts of expressions.**

Say: "Today we are going to review the building blocks of algebraic expressions. This review will set the stage for everything we do in this unit -- combining like terms, using the distributive property, and solving equations."

Write on the board: 5x - 3y + 12 - x

Say: "Let me identify each part of this expression."
- Terms: 5x, -3y, 12, -x
- Coefficients: 5 (for x in the first term), -3 (for y), -1 (for x in the last term)
- Constants: 12
- Variables: x and y

Say: "Notice that -x means -1 times x. The coefficient is -1, not 0. Every variable has a coefficient, even if it is not written."

**Step 2 -- Review the commutative property.**

Say: "The commutative property tells us that order does not matter for addition and multiplication."

- Addition: a + b = b + a. Example: 3 + 7 = 7 + 3 = 10.
- Multiplication: a x b = b x a. Example: 4 x 5 = 5 x 4 = 20.
- This does NOT apply to subtraction or division: 10 - 3 = 7, but 3 - 10 = -7.

**Step 3 -- Review the associative property.**

Say: "The associative property tells us that grouping does not matter for addition and multiplication."

- Addition: (a + b) + c = a + (b + c). Example: (2 + 3) + 4 = 5 + 4 = 9, and 2 + (3 + 4) = 2 + 7 = 9.
- Multiplication: (a x b) x c = a x (b x c). Example: (2 x 3) x 4 = 6 x 4 = 24, and 2 x (3 x 4) = 2 x 12 = 24.

**Step 4 -- Review the distributive property.**

Say: "The distributive property connects multiplication and addition. It says that multiplying a sum by a number is the same as multiplying each addend by that number and then adding."

- a(b + c) = ab + ac
- Example: 3(4 + 5) = 3(4) + 3(5) = 12 + 15 = 27. Check: 3(9) = 27.
- With subtraction: a(b - c) = ab - ac
- Example: 5(10 - 2) = 5(10) - 5(2) = 50 - 10 = 40. Check: 5(8) = 40.

Say: "In the next few lessons, we will use the distributive property with variables, not just numbers. The rule works exactly the same way."

### Worked Examples

**Example A: Identify parts of an expression**
Expression: -2a + 7b - 4 + a

- Terms: -2a, 7b, -4, a
- Coefficients: -2 (first a term), 7 (b term), 1 (second a term)
- Constants: -4
- Variables: a and b

**Example B: Evaluate an expression**
Evaluate 3x - 2y + 5 when x = -4 and y = 3.

3(-4) - 2(3) + 5
= -12 - 6 + 5
= -18 + 5
= **-13**

**Example C: Apply the distributive property**
Expand: 6(x + 3)

6(x + 3) = 6(x) + 6(3) = 6x + 18

Check with x = 2: 6(2 + 3) = 6(5) = 30, and 6(2) + 18 = 12 + 18 = 30.

## Guided Practice (10 minutes)

1. Identify the terms, coefficients, and constants in: 9m - 4n + 1 - 3m
   - Terms: 9m, -4n, 1, -3m. Coefficients: 9, -4, -3. Constant: 1. Variables: m, n.
   - **Facilitator tip:** "Remember that -3m counts as a separate term with coefficient -3."

2. Evaluate 5a + 2b - 7 when a = -2 and b = 4.
   - 5(-2) + 2(4) - 7 = -10 + 8 - 7 = -2 - 7 = **-9**
   - **Facilitator tip:** "Substitute carefully, especially with negative values. Use parentheses."

3. Use the commutative property to rewrite: 8 + 3x
   - 3x + 8 (same value, different order)
   - **Facilitator tip:** "We are just rearranging the terms. The value does not change."

4. Use the distributive property to expand: 4(y + 5)
   - 4(y) + 4(5) = 4y + 20
   - **Facilitator tip:** "Multiply the 4 by every term inside the parentheses."

5. Use the distributive property to expand: -3(x - 2)
   - -3(x) + (-3)(-2) = -3x + 6
   - **Facilitator tip:** "Be careful with the signs. Negative times negative gives positive."

## Independent Practice (10-15 minutes)

### Part A: Identifying Parts of Expressions

1. List the terms, coefficients, and constants in: 7x - 3 + 2y - x
2. List the terms, coefficients, and constants in: -5p + 8 - q + 6p
3. What is the coefficient of y in the expression 12 - y + 4x? (Remember: -y = -1y)

### Part B: Evaluating Expressions

4. Evaluate 6x - 3 when x = -5.
5. Evaluate -2a + 4b when a = 3 and b = -1.
6. Evaluate x^2 - 3x + 2 when x = -2.

### Part C: Properties

7. Expand using the distributive property: 5(2x + 3)
8. Expand using the distributive property: -2(4y - 7)
9. Expand using the distributive property: 8(a + b - 3)
10. Which property justifies: 3 + (x + 5) = (3 + x) + 5?
11. Which property justifies: 7 x 4 = 4 x 7?
12. Use the distributive property to compute mentally: 6 x 53. (Hint: 53 = 50 + 3)

### Answer Key

**Part A**
1. Terms: 7x, -3, 2y, -x. Coefficients: 7 (first x term), 2 (y term), -1 (second x term). Constant: -3. Variables: x, y.
2. Terms: -5p, 8, -q, 6p. Coefficients: -5 (first p term), -1 (q term), 6 (second p term). Constant: 8. Variables: p, q.
3. The coefficient of y is -1.

**Part B**
4. 6(-5) - 3 = -30 - 3 = **-33**
5. -2(3) + 4(-1) = -6 + (-4) = **-10**
6. (-2)^2 - 3(-2) + 2 = 4 + 6 + 2 = **12**

**Part C**
7. 5(2x + 3) = 10x + 15
8. -2(4y - 7) = -8y + 14
9. 8(a + b - 3) = 8a + 8b - 24
10. Associative Property of Addition.
11. Commutative Property of Multiplication.
12. 6 x 53 = 6(50 + 3) = 6(50) + 6(3) = 300 + 18 = **318**

## Assessment Check

### Exit Ticket
**Problem 1:** List the terms and coefficients in: -4x + 9 - 2y + x

**Problem 2:** Expand using the distributive property: -5(3a - 4)

**Target response:**
1. Terms: -4x, 9, -2y, x. Coefficients: -4, -2, 1.
2. -5(3a - 4) = -15a + 20

**Scoring:**
- 2 out of 2 correct = Mastery demonstrated.
- 1 out of 2 correct = Partial understanding; review errors.
- 0 out of 2 correct = Reteach needed; review vocabulary and the distributive property before proceeding.
