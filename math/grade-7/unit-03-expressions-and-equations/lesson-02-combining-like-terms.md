# Math -- Grade 7 -- Unit 3, Lesson 2

## Topic
Combining Like Terms

## Learning Objectives
- Define "like terms" as terms with the same variable(s) raised to the same power(s).
- Identify like terms within an expression, including terms with negative coefficients.
- Simplify expressions by combining like terms.
- Verify simplification by substituting a value for the variable.

## Prerequisites
- Ability to identify terms, coefficients, and constants in an expression (Lesson 1).
- Fluency with addition and subtraction of integers and rational numbers (Unit 2).
- Understanding that a variable with no written coefficient has a coefficient of 1 (e.g., x = 1x).

## Materials Needed
- Whiteboard and markers (or projector).
- Colored pencils or highlighters (optional, for color-coding like terms).
- Algebra tiles (optional but recommended for concrete modeling).
- Student worksheet (Guided Practice and Independent Practice problems).
- Index cards or half-sheets for Exit Ticket.

**Standards:** 7.EE.1 -- Apply properties of operations as strategies to add, subtract, factor, and expand linear expressions with rational coefficients.

## Warm-Up (5 minutes)

**Purpose:** Build intuition for combining like quantities before formalizing the concept.

1. Ask: "If you have 3 apples and someone gives you 5 more apples, how many apples do you have?" (8 apples)
2. Ask: "If you have 3 apples and 5 bananas, can you say you have 8 of something?" (No -- they are different fruits.)
3. Ask: "If you have 4x and someone gives you 2x, how many x's do you have?" (6x)
4. Ask: "If you have 4x and 2y, can you combine them into one term?" (No -- they are different variables.)

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Like terms** -- terms that have exactly the same variable(s) raised to the same power(s). The coefficients can be different. Examples: 3x and -7x are like terms; 5y^2 and 2y^2 are like terms; 3x and 3y are NOT like terms.
- **Combining like terms** -- adding or subtracting the coefficients of like terms to create a single term. Example: 3x + 5x = 8x.
- **Simplify** -- rewrite an expression in a shorter or more efficient form without changing its value.

### Instruction Notes

**Step 1 -- Define like terms.**

Say: "Like terms are terms that have the same variable part. The coefficients do not have to match -- only the variable part must be identical."

Write on the board and sort:

| Like Terms | NOT Like Terms |
|---|---|
| 5x and -2x (both have x) | 5x and 5y (different variables) |
| 3a and a (both have a) | 4x and 4x^2 (different exponents) |
| -7 and 12 (both are constants) | 2xy and 3x (different variable parts) |

Say: "Constants are like terms with each other because they have no variable part -- they are all 'plain numbers.'"

**Step 2 -- Combine like terms by adding coefficients.**

Say: "To combine like terms, add their coefficients and keep the variable part the same. Think of it like adding apples to apples."

- 3x + 5x = (3 + 5)x = 8x
- 7y - 2y = (7 - 2)y = 5y
- -4a + 9a = (-4 + 9)a = 5a
- 6m - 6m = (6 - 6)m = 0m = 0

Say: "When we combine like terms, we are really using the distributive property in reverse: 3x + 5x = (3 + 5)x = 8x."

**Step 3 -- Simplify expressions with multiple types of terms.**

Write: 4x + 3 + 2x - 7

Say: "First, identify the like terms. The x-terms are 4x and 2x. The constants are 3 and -7."

- Combine x-terms: 4x + 2x = 6x
- Combine constants: 3 + (-7) = -4
- Simplified expression: 6x - 4

Say: "Let me check by substituting x = 5 into both the original and simplified expressions."
- Original: 4(5) + 3 + 2(5) - 7 = 20 + 3 + 10 - 7 = 26
- Simplified: 6(5) - 4 = 30 - 4 = 26. They match.

**Step 4 -- Handle negative coefficients carefully.**

Write: 8y - 3y + 2 - 5y + 9

Say: "The y-terms are 8y, -3y, and -5y. The constants are 2 and 9."

- Combine y-terms: 8y + (-3y) + (-5y) = (8 - 3 - 5)y = 0y = 0
- Combine constants: 2 + 9 = 11
- Simplified expression: **11**

Say: "All the variable terms cancelled out. The simplified expression is just the number 11."

### Worked Examples

**Example A: Two like terms**
Simplify: 9x + 4x

Add the coefficients: 9 + 4 = 13. Keep the variable.
9x + 4x = **13x**

**Example B: Multiple terms with two variable types**
Simplify: 5a - 2b + 3a + 7b

Group like terms: (5a + 3a) + (-2b + 7b)
Combine: 8a + 5b
Answer: **8a + 5b**

Check with a = 1, b = 2: Original: 5(1) - 2(2) + 3(1) + 7(2) = 5 - 4 + 3 + 14 = 18. Simplified: 8(1) + 5(2) = 8 + 10 = 18.

**Example C: Expression with negative coefficients and constants**
Simplify: -3x + 8 + 5x - 12 + x

Group like terms: (-3x + 5x + x) + (8 - 12)
Combine x-terms: -3 + 5 + 1 = 3, so 3x
Combine constants: 8 - 12 = -4
Answer: **3x - 4**

Check with x = 2: Original: -3(2) + 8 + 5(2) - 12 + 2 = -6 + 8 + 10 - 12 + 2 = 2. Simplified: 3(2) - 4 = 6 - 4 = 2.

## Guided Practice (10 minutes)

1. Simplify: 6x + 2x
   - 6x + 2x = **8x**
   - **Facilitator tip:** "Just add the coefficients: 6 + 2 = 8."

2. Simplify: 10y - 4y
   - 10y - 4y = **6y**
   - **Facilitator tip:** "Subtract the coefficients: 10 - 4 = 6."

3. Simplify: 3a + 7 - a + 2
   - Group: (3a - a) + (7 + 2) = 2a + 9
   - Answer: **2a + 9**
   - **Facilitator tip:** "Remember, -a means -1a, so 3 - 1 = 2."

4. Simplify: -2m + 5n + 8m - 3n
   - Group: (-2m + 8m) + (5n - 3n) = 6m + 2n
   - Answer: **6m + 2n**
   - **Facilitator tip:** "Sort the m-terms together and the n-terms together."

5. Simplify: 7x - 3 + 2x - 5 - 4x
   - Group: (7x + 2x - 4x) + (-3 - 5) = 5x + (-8) = 5x - 8
   - Answer: **5x - 8**
   - **Facilitator tip:** "Combine the x-terms first: 7 + 2 - 4 = 5. Then the constants: -3 - 5 = -8."

6. Simplify: -6p + 4 + 6p - 4
   - Group: (-6p + 6p) + (4 - 4) = 0 + 0 = 0
   - Answer: **0**
   - **Facilitator tip:** "Everything cancels. The expression equals 0 for any value of p."

## Independent Practice (10-15 minutes)

### Part A: Basic Combining

1. 5x + 3x
2. 12y - 7y
3. -4a + 10a
4. 8b + b (remember: b = 1b)
5. -3x - 5x
6. 9m - 9m

### Part B: Multi-Term Expressions

7. 4x + 6 + 3x - 2
8. -5y + 3 + 2y + 8
9. 7a - 2b + 3a + 5b
10. -6p + 4q - 2p - q
11. 3x - 8 + x + 5 - 2x + 1
12. -4n + 7 + 9n - 3 - 5n + 2

### Part C: Word Problems

13. Maria has 5x dollars in her savings account and 3x dollars in her checking account. She spends 2x dollars on books. Write and simplify an expression for how much money she has left.
14. A rectangle has a length of (3x + 2) and a width of (x + 5). Write and simplify an expression for the perimeter. (Hint: Perimeter = 2 x length + 2 x width.)

### Answer Key

**Part A**
1. 5x + 3x = **8x**
2. 12y - 7y = **5y**
3. -4a + 10a = **6a**
4. 8b + b = 8b + 1b = **9b**
5. -3x - 5x = **-8x**
6. 9m - 9m = **0**

**Part B**
7. (4x + 3x) + (6 - 2) = **7x + 4**
8. (-5y + 2y) + (3 + 8) = **-3y + 11**
9. (7a + 3a) + (-2b + 5b) = **10a + 3b**
10. (-6p - 2p) + (4q - q) = **-8p + 3q**
11. (3x + x - 2x) + (-8 + 5 + 1) = **2x - 2**
12. (-4n + 9n - 5n) + (7 - 3 + 2) = **0n + 6 = 6**

**Part C**
13. 5x + 3x - 2x = **6x** dollars
14. Perimeter = 2(3x + 2) + 2(x + 5) = 6x + 4 + 2x + 10 = **8x + 14** (Note: Students may also write this as 2(3x + 2 + x + 5) = 2(4x + 7) = 8x + 14.)

## Assessment Check

### Exit Ticket
**Problem:** Simplify: -2x + 9 + 7x - 3 - x

**Target response:** (-2x + 7x - x) + (9 - 3) = 4x + 6

**Scoring:**
- Correct simplified expression = Mastery demonstrated.
- Correct grouping but arithmetic error = Partial understanding; review integer addition.
- Cannot identify like terms = Reteach needed; return to the definition and use color-coding.

## Extension
- **Challenge Problem:** Simplify: 2.5x - 1.8y + 3.5x + 0.8y - 4. (Answer: 6x - y - 4)
- **Error Analysis:** A student simplified 3x + 5y as 8xy. Explain the error and give the correct answer. (Like terms must have the same variable part. 3x and 5y are not like terms and cannot be combined. The expression 3x + 5y is already simplified.)
