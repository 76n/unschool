# Math — Grade 3 — Unit 4, Lesson 8

## Topic
Equivalent Fractions

## Learning Objectives
By the end of this lesson, the student will be able to:
- Understand that equivalent fractions are different fractions that name the same amount
- Use fraction strips to discover that 1/2 = 2/4 = 3/6 = 4/8
- Use area models to show and verify equivalent fractions
- Generate simple equivalent fractions by subdividing parts

## Prerequisites
- Comparing fractions with the same denominator and same numerator (Lessons 6-7)
- Representing fractions with area models and fraction strips (Lessons 2-4)
- Understanding that the denominator tells how many equal parts the whole has (Lesson 2)

## Materials Needed
- Fraction strips (halves, thirds, fourths, sixths, eighths)
- Grid paper (for drawing area models)
- Colored pencils or crayons
- Scissors
- Paper and pencil
- Dry-erase board and marker

---

## Warm-Up (5 minutes)
**Purpose:** Review comparisons and activate thinking about fractions that might be the same size.

1. "Compare 1/2 and 1/4. Which is greater?" (1/2 > 1/4) "Compare 1/2 and 1/8." (1/2 > 1/8)
2. "Look at your fraction strips. Lay the 1/2 strip on the table. Now try to find another strip — not halves — that is exactly the same length." (2/4 matches, so does 3/6 and 4/8)
3. "Interesting! Different fractions, but the same amount. Today we will explore fractions that are equal to each other."

---

## Direct Instruction (10-15 minutes)
**Purpose:** Introduce equivalent fractions using concrete and representational models.

### Key Vocabulary
- **Equivalent fractions:** Different fractions that name the same amount (e.g., 1/2 and 2/4)
- **Subdivide:** Cut each piece into smaller equal parts to create a new fraction that covers the same amount

### Instruction Notes

**Step 1: Discover equivalences with fraction strips.**

Lay the 1/2 strip on the table. Line up other fraction strips underneath it, starting at the same left edge.

"Let's find every fraction strip that lines up exactly with 1/2."
- 2/4 lines up perfectly. "Two fourths is the same length as one half. So 1/2 = 2/4."
- 3/6 lines up perfectly. "Three sixths equals one half too. 1/2 = 3/6."
- 4/8 lines up perfectly. "Four eighths also equals one half. 1/2 = 4/8."

"Write all of these: 1/2 = 2/4 = 3/6 = 4/8. These are called equivalent fractions."

**Step 2: Use area models to see why this works.**

Draw a rectangle and divide it in half. Shade the left half.

"This shows 1/2. Now I am going to draw a line down the middle of EACH half, cutting each piece into 2 smaller pieces. How many total pieces now?" (4) "How many are shaded?" (2) "So the shaded part is now 2/4. I did not add or remove any shading — I just made more cuts. 1/2 = 2/4."

Repeat: start with the same 1/2 rectangle. Draw two extra lines to cut each half into 3 equal parts. "Now there are 6 pieces total, and 3 are shaded. 1/2 = 3/6."

"The key idea: when you subdivide (cut each piece into the same number of smaller pieces), the amount of shading does not change. You just describe it with a different fraction."

**Step 3: Try another set of equivalences.**

Start with 1/3 shaded on a strip. Find matches:
- 2/6 lines up. "1/3 = 2/6."
- "Does any eighths strip match 1/3?" (No — thirds and eighths do not line up evenly.)

"Not every fraction has an equivalent in every denominator. But when it does, we can find it by subdividing."

### Worked Examples

**Example A:** Show that 2/4 = 4/8 using an area model.

Draw a rectangle divided into 4 equal columns. Shade 2 columns. "This is 2/4." Now draw a horizontal line through the middle, cutting each column in half. "Now there are 8 pieces total. How many are shaded? 4. So 2/4 = 4/8."

**Example B:** Show that 2/3 = 4/6 using fraction strips.

"Lay out 2 thirds. Now lay out sixths underneath. How many sixths does it take to match the same length? 4. So 2/3 = 4/6."

"Notice the pattern: 2/3 — I doubled both the numerator and the denominator — 4/6. When you cut each third into 2 pieces, you get twice as many pieces, and twice as many are shaded."

## Guided Practice (10 minutes)
**Purpose:** Practice finding and verifying equivalent fractions.

**Activity 1: Fraction strip matching.**

For each fraction, use strips to find an equivalent fraction.

- "Find a fraction equivalent to 1/2 using eighths." (4/8) "How many eighths match the length of 1/2?"
- "Find a fraction equivalent to 1/4 using eighths." (2/8)
- "Find a fraction equivalent to 2/3 using sixths." (4/6)

"If the student struggles, have them physically place the strips side by side, sliding pieces until they find the match."

**Activity 2: Area model verification.**

Draw a rectangle divided into 4 columns with 3 columns shaded (3/4). Now subdivide each column in half (draw a horizontal line).

"How many total pieces now?" (8) "How many are shaded?" (6) "So 3/4 = ___." (6/8)

"Ask the student: Did the amount of shading change? (No.) Then why is the fraction name different? (Because the pieces are smaller, so it takes more of them to cover the same space.)"

## Independent Practice

### Tier 1 (Approaching)
Use fraction strips or drawings to find equivalent fractions.

1. 1/2 = ___/4 (2/4)
2. 1/3 = ___/6 (2/6)
3. 2/4 = ___/8 (4/8)
4. Draw a rectangle. Shade 1/2. Then divide each piece in half and write the new fraction. (2/4)

### Tier 2 (On Level)
Find the equivalent fraction. You may draw an area model to help.

1. 1/2 = ___/6 (3/6)
2. 1/4 = ___/8 (2/8)
3. 2/3 = ___/6 (4/6)
4. 3/4 = ___/8 (6/8)
5. True or false: 1/2 = 4/8. Explain. (True. Four eighths is the same length as one half on the fraction strips.)

### Tier 3 (Advanced)
Find equivalent fractions and reason about patterns.

1. Fill in the chain: 1/2 = 2/___ = 3/___ = 4/___ (1/2 = 2/4 = 3/6 = 4/8)
2. Fill in the chain: 1/3 = ___/6 = ___/9 (1/3 = 2/6 = 3/9)
3. "Lily says 1/3 = 3/6. Is she correct? Prove it with a drawing." (No. 1/3 = 2/6, not 3/6. 3/6 = 1/2. A drawing will show that 1/3 does not line up with 3/6.)
4. "What pattern do you notice in the numerator and denominator when you create equivalent fractions?" (Both the numerator and denominator are multiplied by the same number.)
5. "Can you find a fraction with a denominator of 8 that is equivalent to 1/3? Why or why not?" (No. Thirds do not divide evenly into eighths. 8 is not a multiple of 3.)

---

## Exit Ticket (2-3 minutes)

1. Fill in the blank: 1/2 = ___/8 (4/8)
2. Are 2/4 and 3/6 equivalent? How do you know? (Yes. Both equal 1/2. On fraction strips, 2/4 and 3/6 are the same length.)

**Mastery = Both correct with reasoning for question 2.**

## Teacher Notes

**Equivalent fractions can feel "magical" to students.** The idea that two different-looking fractions can be the same amount is a big conceptual leap. Anchor every claim in something the student can see and touch — fraction strips laid side by side, or shaded area models where the shading clearly covers the same space.

**Do not introduce the multiplication rule too early.** The pattern "multiply top and bottom by the same number" is useful, but if students learn it as a trick without understanding WHY it works, they will struggle in Grade 4 when they need to find equivalent fractions with larger denominators. Let the concrete models lead. The rule should emerge from the student's own observations.

**Common misconception — adding instead of multiplying:** A student might think 1/3 = 2/4 (adding 1 to both numerator and denominator). Fraction strips will quickly disprove this. Show that 1/3 and 2/4 do NOT line up.

**Another common error:** Confusing 1/3 = 3/6 (tripling the numerator but only doubling the denominator). Again, strips correct this immediately.

**Standards:** 3.NF.3a — Understand two fractions as equivalent if they are the same size or the same point on a number line. 3.NF.3b — Recognize and generate simple equivalent fractions and explain why they are equivalent.
