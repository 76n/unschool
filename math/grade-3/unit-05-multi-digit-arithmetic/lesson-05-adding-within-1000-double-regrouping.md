# Math — Grade 3 — Unit 5, Lesson 5

## Topic
Adding Within 1,000 — Regrouping Tens; Double Regrouping

## Learning Objectives
By the end of this lesson, the student will be able to:
- Add three-digit numbers that require regrouping in the tens place (but not the ones place).
- Add three-digit numbers that require regrouping in both the ones and tens places (double regrouping).
- Use the standard algorithm with correct notation for each regrouping step.
- Estimate and verify that a sum is reasonable.

## Prerequisites
- Adding with regrouping in the ones place (Lesson 4)
- Place value understanding: hundreds, tens, ones
- Rounding and estimation (Lessons 1–3)

## Materials Needed
- Base-ten blocks: ones, tens, hundreds
- Place value mat (Hundreds | Tens | Ones)
- Grid paper or lined paper
- Whiteboard and markers

---

## Warm-Up (5 minutes)
**Purpose:** Review single regrouping and activate prior knowledge.

**Quick-fire review:** Solve on whiteboards.
1. 246 + 137 = ____ (383 — regrouping ones)
2. 153 + 219 = ____ (372 — regrouping ones)
3. 328 + 245 = ____ (573 — regrouping ones)

After #3, ask: "Did you regroup? Where?" (Ones: 8+5=13.)
"What if the tens column added up to more than 9? That's what we're exploring today."

Pose this warm-up scenario without solving: "362 + 174 — Estimate first." (400+200=600.) "What do you think will happen in the ones column? Tens column?"

---

## Direct Instruction (10-15 minutes)
**Purpose:** Extend regrouping to the tens place and then to both places simultaneously.

### Key Vocabulary
- **Regroup tens:** Exchange 10 tens for 1 hundred. This happens when the tens column sum equals or exceeds 10 (i.e., ≥ 10 tens).
- **Double regrouping:** When both the ones column AND the tens column require regrouping in the same addition problem.

### Instruction Notes

**CRA Phase: Concrete → Representational → Abstract**

**Part 1: Regrouping tens only**
Use blocks to model 362 + 174.
- Ones: 2 + 4 = 6. Place 6 ones. No regrouping.
- Tens: 6 + 7 = 13 tens. Show 13 ten-rods. Ask: "Can we have 13 in the tens column?" No — we regroup 10 tens into 1 hundred flat.
- Trade 10 ten-rods for 1 hundred flat. Now we have 3 tens remaining and 1 extra hundred.
- Hundreds: 3 + 1 + 1 (regrouped) = 5.
- Total: 536.

Write the algorithm:
```
  1           ← regrouped hundred
  362
+ 174
-----
  536
```
Ones: 2+4=6. Tens: 6+7=13, write 3, regroup 1 (write small 1 above hundreds). Hundreds: 3+1+1=5.

**Part 2: Double regrouping**
Use blocks to model 475 + 368.
- Ones: 5 + 8 = 13 ones. Regroup 10 ones for 1 ten. Write 3 in ones place; note extra ten.
- Tens: 7 + 6 + 1 (regrouped) = 14 tens. Regroup 10 tens for 1 hundred. Write 4 in tens place; note extra hundred.
- Hundreds: 4 + 3 + 1 (regrouped) = 8.
- Total: 843.

Write the algorithm:
```
  1 1         ← regrouped hundreds above hundreds, regrouped tens above tens
  475
+ 368
-----
  843
```

### Worked Examples

**Example 1: Regrouping tens only — 364 + 282**
Estimate: 400 + 300 = 700.
```
  1
  364
+ 282
-----
  646
```
Ones: 4+2=6 (no regroup). Tens: 6+8=14, write 4, regroup 1 to hundreds. Hundreds: 3+2+1=6. Answer: **646**. Reasonable? (Yes, close to 700.)

**Example 2: Double regrouping — 587 + 246**
Estimate: 600 + 200 = 800.
```
1 1
  587
+ 246
-----
  833
```
Ones: 7+6=13, write 3, regroup 1 to tens. Tens: 8+4+1=13, write 3, regroup 1 to hundreds. Hundreds: 5+2+1=8. Answer: **833**. Reasonable? (Yes, close to 800.)

**Example 3: Double regrouping — 673 + 458**
Estimate: 700 + 500 = 1,200. Wait — can our sum exceed 1,000? Yes! But our focus is within 1,000; let's choose 453 + 378 instead.
Estimate: 500 + 400 = 900.
```
1 1
  453
+ 378
-----
  831
```
Ones: 3+8=11, write 1, regroup 1. Tens: 5+7+1=13, write 3, regroup 1. Hundreds: 4+3+1=8. Answer: **831**. Reasonable? (Yes, close to 900.)

## Guided Practice (10 minutes)
Use base-ten blocks for the first problem, drawings for the second, and the standard algorithm alone for the third.

1. 451 + 293 = ____ (tens regroup: 5+9=14 → regroup; ones: 1+3=4)
2. 356 + 477 = ____ (double regroup: ones 6+7=13; tens 5+7+1=13)
3. 684 + 247 = ____ (double regroup: ones 4+7=11; tens 8+4+1=13)

For each:
- Estimate first (nearest 100).
- Work through with blocks or drawing.
- Write the standard algorithm with small regrouping marks.
- Check reasonableness.

**Facilitator prompts:**
- "After the ones column, look at your tens column. What's the sum? Is it 10 or more?"
- "Where does the regrouped ten go in the algorithm? Yes — a small 1 above the hundreds column."
- "You have TWO small 1s now — one above the tens column from the ones regroup, and one above the hundreds column from the tens regroup. Check you've used both."

## Check for Understanding (3 minutes)
**Exit Ticket:**
Solve. Show all regrouping marks.

a) 468 + 374 = ____
b) 593 + 248 = ____

**Mastery = both answers correct with regrouping notation shown.**

### If Mastery Is Not Met
- Slow down to single regrouping in the tens only — choose problems where ones don't regroup (e.g., 362 + 170 where only tens regroup: 6+7=13).
- Use a color-coded algorithm: ones in one color, tens in another, hundreds in a third. Match the regrouped digit's color to the column it moves to.
- Return to base-ten blocks for the next attempt.

### If Mastery Is Met
- Pose: "Can you write a double regrouping problem where the sum is exactly 800?" (e.g., 356 + 444)
- Preview subtraction: "We've been regrouping 'up' to add. Next week, we'll regroup 'down' to subtract. What do you think that might look like?"

## Extension (Optional)
**Addition pyramid:** Fill in missing numbers in an addition pyramid (each block is the sum of the two below it):
```
         [___]
       [___][___]
     [254][___][178]
```
Given: bottom row is 254, unknown middle, 178. Can you find values for the middle row and top that work?

**Mental math challenge:** "Can you add 399 + 256 in your head? Hint: 399 is close to 400. Try 400 + 256, then adjust." (400+256=656; subtract 1 → 655.)

## Teacher/Facilitator Notes
- Double regrouping is the most error-prone operation for third graders. The most common mistake is forgetting to add the second small 1 in the tens column after having already regrouped from the ones.
- Require students to write the small 1 before they add the tens column — "Mark first, then add" — to avoid forgetting.
- Some students will make up an answer close to the estimate and not actually compute. Estimation and exact computation are both required; do not let estimation replace exact work.
- When the sum of a column is exactly 10 (e.g., 5+5), students sometimes write 0 and regroup — this is correct! Make sure they don't write "10" in the column.
