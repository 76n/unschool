# Math — Grade 3 — Unit 5, Lesson 4

## Topic
Adding Within 1,000 — No Regrouping Review; Regrouping Ones

## Learning Objectives
By the end of this lesson, the student will be able to:
- Add two three-digit numbers with no regrouping using base-ten blocks, place value drawings, and the standard algorithm.
- Identify when regrouping ones is needed (ones digit sum ≥ 10).
- Regroup 10 ones into 1 ten and add three-digit numbers with regrouping in the ones place.
- Use estimation to check whether an answer is reasonable.

## Prerequisites
- Addition within 100 with and without regrouping (G2)
- Place value understanding: hundreds, tens, ones
- Rounding and estimation (Lessons 1–3)

## Materials Needed
- Base-ten blocks: ones, tens, hundreds (Concrete phase)
- Place value mat (Hundreds | Tens | Ones), one per student
- Quick-draw reference: dot = 1 one, line = 1 ten, small square = 1 hundred
- Grid paper or lined paper for standard algorithm alignment
- Whiteboard and markers

---

## Warm-Up (5 minutes)
**Purpose:** Review addition without regrouping and estimate to prepare for the lesson.

**Estimation warm-up:** Write on the board: 214 + 153
Ask: "Estimate by rounding to the nearest 100. What is our estimate?" (200 + 200 = 400.)
"Now let's find the exact answer. This one won't need regrouping — let's see why."

Work through 214 + 153 as a class using just the algorithm:
```
  214
+ 153
-----
  367
```
Ask: "Is 367 close to our estimate of 400? Yes — reasonable!"
Tell students: "Today we'll practice addition with and without regrouping — this time we'll use blocks to really understand what 'regrouping' means."

---

## Direct Instruction (10-15 minutes)
**Purpose:** Build conceptual understanding of regrouping ones using CRA.

### Key Vocabulary
- **Regroup:** Exchange equal amounts between place values. In addition, when ones reach 10, we regroup 10 ones into 1 ten.
- **Standard algorithm:** A step-by-step written procedure for adding using column addition.
- **Ones place / tens place / hundreds place:** The positional values in a multi-digit number.

### Instruction Notes

**CRA Phase: Concrete → Representational → Abstract (this lesson introduces all three)**

**Part 1: No regrouping (review)**
Model 231 + 142 with base-ten blocks.
- Place 2 hundreds, 3 tens, 1 one on the mat.
- Add 1 hundred, 4 tens, 2 ones.
- Count: 3 hundreds, 7 tens, 3 ones = 373.
Show the standard algorithm alongside:
```
  231
+ 142
-----
  373
```
"We added ones to ones, tens to tens, hundreds to hundreds. Easy — no regrouping needed because no column exceeded 9."

**Part 2: Regrouping ones**
Model 147 + 135 with base-ten blocks.
- Place 1 hundred, 4 tens, 7 ones.
- Add 1 hundred, 3 tens, 5 ones.
- Ones: 7 + 5 = 12 ones. Show 12 unit cubes. Ask: "Can we have 12 in the ones column?" No — we regroup!
- Trade 10 ones for 1 ten rod. Now we have 2 ones left and 1 extra ten to "carry to" the tens column.
- Tens: 4 + 3 + 1 (the regrouped ten) = 8 tens.
- Hundreds: 1 + 1 = 2 hundreds.
- Total: 282.

### Worked Examples

**Example 1: No regrouping — 352 + 215**
Estimate: 400 + 200 = 600. Wait — 352 rounds to 400? No, 352 → 400 at nearest 100. Actually 352 rounds to 400 (tens digit 5 → round up). 215 → 200. Estimate: 400 + 200 = 600.
```
  352
+ 215
-----
  567
```
Ones: 2 + 5 = 7. Tens: 5 + 1 = 6. Hundreds: 3 + 2 = 5. Answer: 567. Reasonable? (Yes, close to 600.)

**Example 2: Regrouping ones — 246 + 137**
Estimate: 200 + 100 = 300.
```
    1        ← regrouped ten
  246
+ 137
-----
  383
```
Ones: 6 + 7 = 13. Write 3 in ones place, regroup 1 ten (write small 1 above tens column). Tens: 4 + 3 + 1 = 8. Hundreds: 2 + 1 = 3. Answer: 383. Reasonable? (383 is close to 300 — yes, though 300 was a rough estimate. Stress that 383 is between 300 and 400 so it's reasonable.)

**Example 3: Regrouping ones — 365 + 279**
Estimate: 400 + 300 = 700.
```
    1
  365
+ 279
-----
  644
```
Ones: 5 + 9 = 14. Write 4, regroup 1 ten. Tens: 6 + 7 + 1 = 14. Oh! The tens also regroup — but we'll focus on that in Lesson 5. For now, choose numbers where only ones regroup. Use this example only if students are ready.

*(Facilitator note: Example 3 previews Lesson 5. Skip if students are not secure with single regrouping yet.)*

## Guided Practice (10 minutes)
Complete using base-ten blocks (concrete) first, then draw (representational), then write the algorithm (abstract).

**Set A — No regrouping (practice alignment):**
1. 213 + 154 = ____
2. 421 + 307 = ____

**Set B — Regrouping ones only:**
3. 134 + 219 = ____
4. 247 + 126 = ____
5. 358 + 135 = ____

For each problem in Set B:
- Step 1: Estimate (nearest 100).
- Step 2: Use blocks or drawings to regroup the ones.
- Step 3: Write the standard algorithm, showing the regrouped 1.
- Step 4: Check reasonableness.

**Facilitator prompts:**
- "Show me with your blocks. How many ones do you have total? Is that more than 9? What do we do?"
- "When we trade 10 ones for 1 ten, where does that ten go?" (To the tens column in the algorithm — written as a small 1 above the tens column.)
- "Does your answer make sense? Compare it to your estimate."

## Check for Understanding (3 minutes)
**Exit Ticket:**
Solve. Show your work (use algorithm with regrouping mark if needed).

a) 263 + 419 = ____
b) 347 + 245 = ____

**Mastery = both correct, with regrouped tens correctly shown (small 1 above the tens column).**

### If Mastery Is Not Met
- Return to base-ten blocks and physically trade 10 ones for 1 ten before writing anything.
- Use a color-coding strategy: ones column in blue, tens in red, hundreds in green. The regrouped amount writes in the same color as its new column.
- Slow down: work only problems where ones sum to exactly 10 first (e.g., 5 + 5, 6 + 4, 7 + 3).

### If Mastery Is Met
- Preview: "What would happen if after regrouping, your tens column also adds up to more than 9? That's tomorrow's lesson!"
- Challenge: "Can you write two three-digit numbers that when added, require regrouping, and whose sum is between 700 and 800?"

## Extension (Optional)
**Two-step addition puzzle:** "I add two numbers. Both numbers have a 4 in the tens place. When I add the ones, I regroup. The sum is 583. What could the two numbers be?" (Multiple answers, e.g., 246 + 247 = oops, need to check — students explore.)

**Base-ten block building:** Using blocks, build the largest three-digit number you can with exactly 12 blocks (ones + tens + hundreds), then add another three-digit number built with 9 blocks. What is the sum?

---

## Teacher/Facilitator Notes
- The transition from concrete to abstract is critical here. Do not rush to the algorithm. If a student cannot explain WHY we write a small 1 above the tens column, return to blocks.
- Regrouping notation: the small 1 written above the tens column represents the 1 ten that was created from 10 ones. Some curricula write it above the tens column before adding; others add it as a remembered digit. Choose one consistent notation and model it every time.
- Students who already know the algorithm from G2 may skip ahead mentally — still require them to show regrouping notation in writing, which prepares them for double regrouping in Lesson 5.
- Aligned grid paper dramatically reduces errors caused by column misalignment. Require it for independent practice.
