# Math — Grade 3 — Unit 5: Multi-Digit Arithmetic
## Facilitator Guide

---

## Unit Overview

Unit 5 develops fluency with addition and subtraction within 1,000, rounding to the nearest 10 and 100, and using estimation as a checking strategy. Students build on their second-grade understanding of place value and three-digit numbers, progressing through a Concrete–Representational–Abstract (CRA) sequence: physical base-ten blocks, place value drawings, and finally the standard algorithm. The unit culminates in multi-step word problems and mixed fluency practice.

**Unit Title:** Multi-Digit Arithmetic
**Grade:** 3
**Duration:** 10 lessons (~50 minutes each)
**Standards:** 3.NBT.1, 3.NBT.2

## Prerequisites

Students entering this unit should be able to:

- Read, write, and represent numbers to 1,000 (place value: hundreds, tens, ones)
- Add and subtract within 100 with fluency (G2 mastery)
- Identify the value of digits in a three-digit number
- Locate three-digit numbers on a number line
- Apply basic multiplication and division facts (Units 1–4 of this course)
- Understand unit fractions and place fractions on a number line (Unit 4)

---

## Unit Learning Goals

By the end of this unit, students will be able to:

1. Round any whole number within 1,000 to the nearest 10 and nearest 100.
2. Use rounding to estimate sums and differences.
3. Add two three-digit numbers within 1,000, including problems requiring regrouping of ones, tens, or both.
4. Subtract two three-digit numbers, including problems requiring regrouping from the tens place, hundreds place, or across zeros.
5. Check the reasonableness of an answer using estimation.
6. Solve one- and two-step word problems involving addition and subtraction within 1,000.

## CRA Progression

This unit follows a deliberate three-phase progression:

**Concrete (Lessons 1–4 introduction)**
Students use base-ten blocks and number lines to build physical understanding of place value, rounding, and regrouping. Encourage all students to use blocks before moving on, even if they feel ready for pencil-and-paper work.

**Representational (Lessons 4–6 transition)**
Students draw quick-draw representations: small squares for hundreds, vertical lines for tens, dots for ones. Place value mats support organization. The standard algorithm is introduced alongside drawings so students can see the connection.

**Abstract (Lessons 5–10)**
Students work with numerals and the standard algorithm. Drawings remain available as a scaffold. Estimation (a mental/abstract skill) is woven throughout from Lesson 3 onward.

## Facilitation Tips

**Talking about regrouping**
Always use the word "regroup" (not "borrow" or "carry"). The language matters:
- Addition: "We regroup 10 ones into 1 ten."
- Subtraction: "We regroup 1 ten into 10 ones."
Model this language consistently and prompt students to use it when explaining their work.

**Place value mat discipline**
Before students touch pencil to paper, have them set up their place value mat and work with blocks. This slows down impulsive students who want to grab an algorithm without understanding it, and it surfaces misconceptions early.

**Number talk warm-ups**
Lessons 1–3 warm up with number lines. Lessons 4–10 warm up with mental math or "quick adds/subtracts." A good 5-minute number talk (e.g., "How would you add 398 + 215 in your head?") surfaces multiple strategies and builds number sense alongside the algorithm.

**Error analysis as instruction**
When students make systematic errors (e.g., subtracting the smaller digit from the larger digit regardless of position, or forgetting to regroup across zeros), use those errors as teaching moments. Write the error on the board and ask, "What did this person do? Where did things go wrong?" This normalizes mistakes and builds metacognition.

**Word problem scaffolds**
For Lessons 9–10 and word problems throughout, use the Read–Draw–Write (RDW) approach:
1. Read the problem carefully.
2. Draw a model (bar model, number line, or place value drawing).
3. Write a number sentence and answer with a label.

## Common Misconceptions

| Misconception | What It Looks Like | How to Address |
|---------------|-------------------|----------------|
| Rounding toward the closer digit without using the midpoint rule | Student rounds 45 "to 5 because it looks closer to 50" then rounds 45 down | Explicitly teach: if the digit is 5 or more, round up. Practice with the midpoint on the number line. |
| Subtracting smaller from larger regardless of position | 523 − 48: student writes 523 − 048, gets 5 2 5 (subtracts 0 from 5 in hundreds, 4 from 2 in tens, 8 from 3 in ones but inverts the ones) | Return to blocks: show that you cannot take 8 ones from 3 ones without regrouping. |
| Forgetting to regroup across zeros | 400 − 136: student leaves the zero unchanged | Teach the "unstack and restack" strategy: regroup 1 hundred into 10 tens, then regroup 1 ten into 10 ones. Do this with blocks first. |
| Adding/subtracting digits without aligning place values | Misaligned columns in the standard algorithm | Require grid paper or lined place value columns until alignment is automatic. |
| Treating estimation as an exact answer | After rounding 348 + 271 → 350 + 270 = 620, student writes 620 as the answer | Clarify: an estimate tells us if our exact answer is reasonable, not what the answer is. |

## Differentiation

**Support strategies**
- Provide a place value mat with labeled columns (H | T | O) for all written work.
- Allow extended use of base-ten blocks beyond the concrete phase.
- Reduce problem counts; focus on one regrouping type before moving to double regrouping.
- Pair students strategically during guided practice (stronger / developing).
- Provide a hundreds chart as a reference for rounding anchor numbers.

**Extension strategies**
- Challenge students to add and subtract across the 1,000 boundary (e.g., 987 + 45).
- Introduce open-ended problems: "Write two three-digit numbers whose sum is between 700 and 750."
- Pose estimation challenges: "Without calculating, put these sums in order: 423+318, 199+502, 350+350."
- Multi-step problems with three addends or with unknown start/change numbers.

## Assessment Guidance

**Formative (daily)**
Each lesson includes a 3-minute exit ticket. Review exit tickets before the next lesson. Students who do not meet mastery on the exit ticket should receive a brief re-teach or small-group pull at the start of the next lesson's warm-up.

**Key checkpoints**
- After Lesson 2: Can the student round to the nearest 10 and 100? (Prerequisite for Lesson 3.)
- After Lesson 5: Can the student add with regrouping in both places? (Prerequisite for Lesson 6.)
- After Lesson 7: Can the student subtract with regrouping, including across zeros? (Critical before word problems.)

**Summative**
The unit assessment (unit-assessment.md) should be administered after Lesson 10. It covers rounding, estimation, addition with regrouping, subtraction with regrouping, and a multi-step word problem. Allow approximately 40–45 minutes.

**Mastery threshold**
80% overall, with no isolated skill below 60%. Students below mastery should receive targeted review before the next unit.

## Vocabulary for the Unit

| Term | Definition |
|------|-----------|
| digit | Any of the symbols 0–9 used to write numbers |
| place value | The value of a digit based on its position in a number |
| hundreds place | The position three places to the left of the decimal point; worth 100s |
| tens place | The second position from the right; each digit is worth 10s |
| ones place | The rightmost position; each digit is worth 1s |
| round | Replace a number with a nearby number that is easier to work with |
| benchmark number | A "friendly" number used as a reference (e.g., multiples of 10 or 100) |
| estimate | A thoughtful approximation; not an exact answer |
| regroup | Exchange equal amounts between place values (10 ones = 1 ten; 10 tens = 1 hundred) |
| sum | The result of addition |
| difference | The result of subtraction |
| reasonable | An answer that makes sense given the context and an estimate |
