## Administration Instructions

Read all item prompts aloud for the student. The student may respond verbally or in writing. For computation items, the student may use any strategy (counting on, break apart, place value reasoning). ## Rubric and Mastery Determination

| Level | Score Range | Meaning | Next Steps |
|-------|-----------|---------|------------|
| **Mastered** | 18-21 (85-100%) with at least 1 correct in each section | Strong addition and subtraction within 100 | Advance to Unit 4: Measurement and Data. Continue computation practice through warm-ups. |
| **Approaching** | 15-17 (70-84%) | Most skills present; specific gaps remain | Reteach struggling sections. Provide extra practice before advancing. |
| **Developing** | Below 15 (<70%) | Significant gaps in computation strategies | Return to specific lessons. Ensure Unit 2 place value foundation is solid before reattempting. |

### Section-Specific Reteaching Guide

| If struggling in... | Focus on... |
|---|---|
| Section A (Adding/Subtracting Tens) | Return to Lessons 1-2. Use base-ten blocks: "30 + 40 means 3 tens + 4 tens. Count the tens." If the student counts by ones (31, 32, ...), they are not using tens as units. Rebuild with block bundles and skip counting. |
| Section B (10 More/10 Less) | Return to Lesson 3. Use the hundred chart: "10 more = one row down. 10 less = one row up." Practice until the student can answer instantly. The key insight is that the ones digit never changes. |
| Section C (No Regrouping) | Return to Lessons 4-5. If errors are in the addition/subtraction fact (e.g., 3 + 4 ≠ 7), revisit Unit 1 facts. If errors are in place value (adding to wrong digit), rebuild with the place value mat. |
| Section D (With Regrouping) | Return to Lessons 6-7. This is the most common area of difficulty. Use base-ten blocks for every problem. The key moments: addition — "10 or more ones? Trade for a ten." Subtraction — "Not enough ones? Break a ten." Physical manipulation must be fluent before moving to mental strategies. |
| Section E (Two-Digit + Multiple of 10) | Return to Lesson 8. If the student adds to the wrong place (34 + 20 = 36), rebuild with blocks: "20 is 2 tens, not 2 ones." Use the hundred chart to show downward jumps. |
| Section F (Word Problems) | Return to Lesson 10. If the student cannot identify the operation, act out the story with objects. "Are things being combined or removed?" Help the student build a library of key words, but emphasize understanding the situation over memorizing keywords. |

## Observation Notes

During the assessment, record the following to inform future instruction:

| Observation | Notes |
|-------------|-------|
| Does the student rely on the hundred chart or solve mentally? | □ Fully mental □ Uses chart occasionally □ Needs chart for most problems |
| For regrouping problems, does the student use a learned strategy or count by ones? | □ Place value / Make 10 strategy □ Counting on by ones □ Guesses or gets confused |
| Can the student identify addition vs. subtraction in word problems? | □ Immediately identifies operation □ Needs prompting □ Chooses wrong operation |
| Does the student check their work or verify answers? | □ Checks naturally □ Checks when asked □ Does not check |
| How does the student handle regrouping in subtraction (Section D)? | □ Breaks a ten confidently □ Hesitates but succeeds □ Reverses digits (does bigger minus smaller) □ Cannot regroup |
| Additional observations: | |

These notes help guide instruction even when the student meets the mastery threshold. A student who scores 18/21 but relies on counting by ones for every problem would benefit from strategy instruction before moving on.
