# Math — Grade 1 — Unit 3, Lesson 4

## Topic
Adding a One-Digit Number to a Two-Digit Number (No Regrouping)

## Learning Objectives
By the end of this lesson, the student will be able to:
- Add a one-digit number to a two-digit number when the ones sum is 9 or less (e.g., 34 + 5 = 39)
- Explain that only the ones digit changes when adding ones
- Use base-ten blocks and place value reasoning to solve

## Prerequisites
- Place value: tens and ones (Unit 2)
- Addition facts within 10 (Unit 1)
- Adding and subtracting tens (Lessons 1-3)

## Materials Needed
- Base-ten blocks (ten-rods and unit cubes)
- Place value mat
- Paper and pencil

---

## Warm-Up (5 minutes)
**Purpose:** Activate place value decomposition and addition facts.

1. "Break apart 46: how many tens? how many ones?" (4 tens, 6 ones)
2. "3 + 5 = ?" (8) "4 + 2 = ?" (6) "7 + 1 = ?" (8)
3. "10 more than 46 = ?" (56) — review from Lesson 3

"In Lesson 3, you added a ten. Today you'll add ones."

---

## Direct Instruction (10 minutes)
**Purpose:** Show that adding a one-digit number to a two-digit number changes only the ones place (when no regrouping is needed).

### Key Vocabulary
- **Ones place:** The rightmost digit, telling how many single units
- **No regrouping:** The ones add up to 9 or less, so no new ten is formed

### Instruction Notes

**Step 1: Build the problem with blocks.**
Build 34 on the place value mat: 3 ten-rods, 4 unit cubes. "I want to add 5." Place 5 more unit cubes in the ones column. "How many tens?" (3 — unchanged) "How many ones now?" (9) "What number?" (39)

"34 + 5 = 39. The tens stayed at 3. Only the ones changed: 4 + 5 = 9."

**Step 2: Reinforce the place value logic.**
"34 is 30 + 4. I'm adding 5 to the ones. 4 + 5 = 9. The tens are still 30. So 30 + 9 = 39."

**Step 3: Try several examples.**
- 52 + 3: Ones: 2 + 3 = 5. Tens: 5 (unchanged). Answer: 55.
- 61 + 7: Ones: 1 + 7 = 8. Tens: 6. Answer: 68.
- 45 + 0: Ones: 5 + 0 = 5. Tens: 4. Answer: 45. "Adding zero doesn't change anything."

### Worked Examples

**Example 1:** 23 + 6. Tens: 2 (stays). Ones: 3 + 6 = 9. Answer: 29.

**Example 2:** 71 + 8. Tens: 7 (stays). Ones: 1 + 8 = 9. Answer: 79.

**Example 3:** 50 + 4. Tens: 5 (stays). Ones: 0 + 4 = 4. Answer: 54.

## Guided Practice (10 minutes)
**Purpose:** Student solves with decreasing support.

**Activity 1: Build and solve (with blocks)**
- 42 + 6 = ? Student builds, adds cubes, reads answer. (48)
- 35 + 4 = ? Build and solve. (39)
- 60 + 8 = ? Build and solve. (68)

**Activity 2: Think aloud (no blocks)**
- 53 + 5 = ? "What are the tens?" (5) "What are the ones?" (3 + 5 = 8) "Answer?" (58)
- 24 + 3 = ? (27)
- 81 + 7 = ? (88)

*Facilitator prompt: Always ask: "Do the tens change?" (No — not in this lesson.) "Why not?" (Because the ones add up to less than 10.)*

## Check for Understanding (5 minutes)
**Purpose:** Confirm accurate addition of one-digit to two-digit (no regrouping).

**Exit Ticket:**

1. 45 + 4 = ___ (49)
2. 62 + 7 = ___ (69)

**Mastery = Both correct. Student adds the ones digits and keeps the tens digit unchanged.**

### If Mastery Is Not Met
- Return to base-ten blocks. Build the two-digit number, add the one-digit number to the ones column, and count the ones. Emphasize: "The tens don't move. Only the ones change."
- If the student struggles with the addition fact itself (e.g., 5 + 4), review Unit 1 facts before continuing.

### If Mastery Is Met
Move to Lesson 5 (Subtracting a One-Digit Number Without Regrouping).

## Teacher/Facilitator Notes

**"No regrouping" is a deliberate scaffold.** In this lesson, the ones always add up to 9 or less, so no new ten is formed. This keeps the focus on the key idea: when you add ones, only the ones place changes. Regrouping comes in Lesson 6.

**Students may notice:** "What if the ones add up to more than 9?" Great question! Tell them: "That's exactly what we'll learn in Lesson 6. For now, let's master these problems where the ones fit."

**Common errors:**
- Student adds to the tens digit instead of the ones: 34 + 5 = 84. Reinforce: "5 is ones, not tens. Add it to the ones column."
- Student recounts from 1. Redirect: "Start at 34. Count on 5 more: 35, 36, 37, 38, 39." Then connect to place value: "Or just add the ones: 4 + 5 = 9, so 39."
