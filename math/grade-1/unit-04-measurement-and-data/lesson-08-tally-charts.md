# Math — Grade 1 — Unit 4, Lesson 8

## Topic
Organizing Data — Tally Charts

## Learning Objectives
By the end of this lesson, the student will be able to:
- Collect data by asking a question and recording responses
- Record data using tally marks, including the diagonal fifth mark to make groups of 5
- Read a completed tally chart and count the tallies to find the total for each category
- Explain that data is information we collect to answer a question

## Prerequisites
- Tell time to the hour and half-hour (Lessons 6-7)
- Count groups of objects accurately, including counting by 5s (Unit 2)
- Add within 20 fluently (Unit 1)

## Materials Needed
- Paper and pencil
- Crayons or colored pencils
- Pre-made tally chart examples (drawn on paper or printed)
- Small objects for sorting and counting (colored cubes, crayons, buttons, or similar)
- Blank tally chart templates (or blank paper to draw charts)

## Direct Instruction (10-15 minutes)
**Purpose:** Introduce the concept of data, teach how to make and read tally marks, and model creating a tally chart.

### Key Vocabulary
- **Data:** Information we collect to answer a question — like counting how many of each kind
- **Tally mark:** A short line we draw to count one thing; every fifth mark goes across the previous four to make a group of 5
- **Tally chart:** A chart that uses tally marks to show how many are in each category
- **Category:** A group that things belong to (like "red," "blue," or "green")

### Instruction Notes

**Step 1: Introduce the idea of data.**
"Sometimes we want to find out something — like 'What is everyone's favorite color?' To answer that question, we need to ASK people and WRITE DOWN what they say. The information we collect is called data."

"Today we are going to learn a special way to keep track of data — using tally marks."

**Step 2: Teach tally marks.**
Draw on paper as you explain:

"A tally mark is a short straight line, like this: |"

"When we count one thing, we draw one line. Two things — two lines. Three — three lines. Four — four lines, all standing side by side."

Draw: | | | |

"But when we get to five, we do something special. Instead of drawing a fifth line standing up, we draw it ACROSS the other four, like this."

Draw the diagonal line through the four: ~~||||~~ (the standard tally-five symbol)

"Now I can see a group of 5 right away, without counting each line. This makes it much faster to count big numbers."

Practice together: "Let me show 7 using tally marks." Draw a group of 5 (four lines with a diagonal) and then 2 more lines. "I see one group of 5 and 2 more. 5 + 2 = 7."

"Your turn: show me 9 using tally marks." (Student draws a group of 5 and 4 more lines. 5 + 4 = 9.)

**Step 3: Model creating a tally chart.**
"Let's collect some data! I am going to sort these colored cubes by color and use a tally chart to record what we find."

Sort out a small collection (e.g., 4 red, 6 blue, 3 yellow, 2 green).

Draw a simple tally chart on paper:

| Color | Tallies | Total |
|-------|---------|-------|
| Red | | | | | | 4 |
| Blue | ~~|||||~~ | | 6 |
| Yellow | | | | | 3 |
| Green | | | | 2 |

"I write each color as a category on the left. Then I make one tally mark for each cube of that color. Finally, I count the tallies and write the total number."

"How many blue cubes? I see a group of 5 and 1 more. 5 + 1 = 6."

## Teacher Notes

**Common Errors:**
- **Forgetting the diagonal for 5:** Students may draw five vertical lines without the crossing mark. This makes counting harder. Practice the "four up, one across" pattern until it is automatic.
- **Counting the diagonal as a separate tally:** Some students count the diagonal mark as a sixth tally. Clarify: "The diagonal is the FIFTH mark — it is not an extra one. It goes across the first four to bundle them into a group of 5."
- **Losing track while tallying:** When creating tallies from a count, students may lose track and draw too many or too few. Encourage the student to cross off or touch each item as they tally it.

**Tips:**
- Use real objects whenever possible. Sorting a handful of colored cubes or crayons and tallying them is far more engaging than reading pre-made charts.
- Conduct a mini-survey as a class or family activity: "What is your favorite animal?" This makes data collection feel purposeful.
- Connect tally counting to skip counting by 5s: "I see three groups of 5. Let's count: 5, 10, 15. Then 2 more makes 17." This reinforces the skip-counting work from Unit 2.

**Look-Fors:**
- Does the student make the diagonal fifth mark correctly (across the previous four)?
- Can the student count tallies efficiently using groups of 5 rather than counting every line?
- Does the student organize data neatly with clear categories and aligned tallies?
- Can the student explain what the tally chart shows in their own words?
