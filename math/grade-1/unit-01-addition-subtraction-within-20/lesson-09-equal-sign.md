# Math — Grade 1 — Unit 1, Lesson 9

## Topic
The Equal Sign Means "The Same As"

## Learning Objectives
By the end of this lesson, the student will be able to:
- Explain that = means "is the same as," not "the answer is"
- Determine whether equations with = on either side are true or false (e.g., 5 = 3 + 2, 7 = 7, 4 + 3 = 2 + 5)
- Fill in missing numbers in equations with the = in various positions

## Prerequisites
- Addition and subtraction within 20 (Lessons 1-8)
- Reads and writes number sentences (Kindergarten)

## Materials Needed
- Paper and pencil
- Counting objects (for verification)
- Balance scale (if available) or a drawn balance image

## Direct Instruction (10 minutes)
**Purpose:** Build deep understanding of the equal sign.

### Key Vocabulary
- **Equal / Equals (=):** Means "is the same as" — both sides have the same value
- **True equation:** Both sides of the = actually are the same (e.g., 3 + 2 = 5)
- **False equation:** The sides are NOT the same (e.g., 3 + 2 = 6 is false)

### Instruction Notes

**Step 1: Challenge the misconception.**
Write: 5 = 3 + 2. Ask: "Is this true or false?"

Many students say "false" because they think the answer should be on the right side. But: "3 + 2 IS 5. And 5 IS 5. Both sides are the same. So this is TRUE!"

"The = sign doesn't mean 'the answer is.' It means 'is the same as.' The answer can be on EITHER side."

**Step 2: Balance scale analogy.**
Draw (or use) a balance scale:
```
  3 + 4  |  7
    \_______/
      balanced!
```

"Imagine a scale. If both sides weigh the same, it balances. The = sign means the scale balances."

**Step 3: Various equation formats.**
Write and evaluate each:

- 7 = 7 ✓ (True — both sides are 7)
- 3 + 4 = 7 ✓ (True — both sides are 7)
- 7 = 3 + 4 ✓ (True — same as above, just flipped)
- 4 + 3 = 3 + 4 ✓ (True — both sides are 7)
- 5 + 2 = 4 + 3 ✓ (True — both sides are 7)
- 3 + 4 = 8 ✗ (False — 7 ≠ 8)

"See? The = can go anywhere. What matters is: are both sides the same?"

**Step 4: Missing number problems.**
Write: ___ + 3 = 10. "What number makes this true?" (7, because 7 + 3 = 10.)

Write: 6 + 4 = ___ + 5. "Both sides must be the same. The left side is 10. So the right side must be 10 too. ___ + 5 = 10. The answer is 5."

### Worked Examples

**Example 1:** Is 8 = 5 + 3 true? Left side: 8. Right side: 5+3=8. Yes, true!

**Example 2:** 4 + ___ = 3 + 6. Right side: 9. So 4 + ___ = 9. Missing number: 5.

## Guided Practice (10 minutes)
**Purpose:** Practice with various equation formats.

**Activity 1: True or false? (4 minutes)**
Student evaluates each equation:
- 6 = 6 → True
- 3 + 5 = 8 → True
- 8 = 3 + 5 → True
- 4 + 2 = 5 + 2 → False (6 ≠ 7)
- 9 = 10 − 1 → True
- 3 + 4 = 4 + 3 → True

**Activity 2: Missing numbers (4 minutes)**
- 5 + ___ = 12 (7)
- ___ = 8 + 6 (14)
- 7 + 3 = ___ + 4 (6, because both sides = 10)
- 15 − ___ = 9 (6)

**Activity 3: Write your own (2 minutes)**
"Write a true equation where the = is in the middle and there are addition on BOTH sides." (e.g., 4+5 = 6+3)

## Independent Practice (10 minutes)
**Purpose:** Solidify understanding of equality.

**★ On-level:**
1. True or false: 9 = 4 + 5 (True)
2. True or false: 7 + 3 = 3 + 7 (True)
3. True or false: 6 + 2 = 9 (False)
4. 8 + ___ = 14 (6)
5. ___ − 3 = 9 (12)

**★★ Stretch:**
6. 5 + 4 = ___ + 6 (3)
7. 7 + ___ = 6 + 8 (7, since 6+8=14 and 7+7=14)
8. Write two different expressions that both equal 12.

**★★★ Challenge:**
9. 8 + ___ = ___ + 5, where both sides equal 13. (8+5=5+8... or 8+5=13, so ___+5=13, ___=8)
10. "Can 3 + 4 = 4 + 3 = 7? Is it okay to chain equals signs?" (Discuss: in math, this means all three expressions are equal. Yes, it's valid.)

## Check for Understanding (5 minutes)
**Purpose:** Assess understanding of the equal sign.

**Exit Ticket:**

1. True or false: 12 = 7 + 5 (True)
2. 6 + ___ = 5 + 8 (7, since 5+8=13 and 6+7=13)
3. "What does the = sign mean?" (Accept: "is the same as," "both sides are equal," "the scale balances")

**Mastery = All 3 correct.**

### If Mastery Is Not Met
- Use the balance scale analogy consistently. Draw it for every problem.
- Start with simple cases: 5 = 5, then 5 = 3 + 2, then 3 + 2 = 1 + 4. Build complexity gradually.
- The misconception that = means "the answer is" is deeply ingrained. It takes consistent correction over weeks.

### If Mastery Is Met
Move to Lesson 10 (Word Problems Within 20).

## Teacher/Facilitator Notes

**This lesson matters more than it looks.** Research consistently shows that misunderstanding the equal sign is one of the biggest obstacles to learning algebra. Students who think = means "put the answer here" struggle when they encounter equations like x + 3 = 7. Building correct understanding NOW saves years of confusion later.

**The balance scale is the best mental model.** Both sides must balance. If you have a physical balance scale, use it (put 5 blocks on one side, then 3+2 on the other — they balance). If not, draw one.

**Challenge "answer on the right" assumptions.** Deliberately write equations with the number on the left (5 = 3 + 2) and with expressions on both sides (3 + 4 = 2 + 5). Students need exposure to all formats to truly understand equality.
