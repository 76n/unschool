# Math — Grade 1 — Unit 1, Lesson 2

## Topic
Counting On to Add

## Learning Objectives
By the end of this lesson, the student will be able to:
- Add by counting on from the larger number (instead of counting all from 1)
- Use fingers, a number line, or mental counting to track the count-on
- Apply counting on for problems where one addend is small (1, 2, or 3)

## Prerequisites
- Addition within 10 (Lesson 1 / Kindergarten)
- Oral counting to 20

## Materials Needed
- Number line 0-20
- Counting objects (optional — available but not primary)
- Paper and pencil

1. "6 + 4 = ___?" (10) *(Make-10 review)*
2. "9 − 3 = ___?" (6) *(Subtraction review)*
3. "I say 7, you say what makes 10." (3) *(Make-10 speed)*
4. "Count from 8 to 15." (8, 9, 10, 11, 12, 13, 14, 15) *(Counting on preview)*

## Direct Instruction (10-15 minutes)
**Purpose:** Introduce counting on as a more efficient addition strategy.

### Key Vocabulary
- **Count on:** Start at one number and count forward to add the other number
- **Start from the bigger number:** Always begin counting from the larger addend — it's faster

### Instruction Notes

**Step 1: Show why counting-all is slow.**
Write: 9 + 2 = ?

"If I count ALL the objects from 1, I need to count 1, 2, 3, 4, 5, 6, 7, 8, 9 — then 10, 11. That's 11 counts! That's a lot."

"But I already KNOW there are 9. I don't need to count to 9 again. I can start at 9 and just count 2 more."

**Step 2: Model counting on.**
"Watch. 9 + 2. I start at 9." (Hold up a fist.) "Now I count on 2 more: 10..." (raise one finger) "...11." (raise second finger.) "The answer is 11."

"I only needed 2 counts instead of 11. Much faster!"

**Step 3: Model on the number line.**
Draw or point to the number line. "9 + 2. I put my finger on 9. Then I hop forward 2 times: hop to 10, hop to 11. I land on 11."

**Step 4: Start from the bigger number.**
"What about 2 + 9? That's the same as 9 + 2. I should start from 9 (the bigger number) and count on 2. Starting from the bigger number means fewer counts."

Model: "3 + 8. I could start at 3 and count on 8 — that's 8 counts. OR I start at 8 and count on 3: 9, 10, 11. Only 3 counts. Same answer!"

**Step 5: Finger tracking.**
"When you count on, use your fingers to track how many you've counted. Start at the bigger number in your head, then raise one finger for each count."

Model 7 + 3: "Start at 7. Count on: 8 (one finger), 9 (two fingers), 10 (three fingers). I raised 3 fingers. The answer is 10."

### Worked Examples

**Example 1:** 8 + 3. Start at 8. Count on 3: 9, 10, 11. Answer: 11.

**Example 2:** 2 + 7 = 7 + 2. Start at 7. Count on 2: 8, 9. Answer: 9.

## Guided Practice (10 minutes)
**Purpose:** Student practices counting on with facilitator support.

**Activity 1: Count on with fingers (5 minutes)**
Student solves using counting-on with finger tracking:

- 9 + 1 → Start at 9, count on 1: 10 ✓
- 8 + 2 → Start at 8, count on 2: 9, 10 ✓
- 7 + 3 → Start at 7, count on 3: 8, 9, 10 ✓
- 6 + 3 → Start at 6, count on 3: 7, 8, 9 ✓
- 9 + 3 → Start at 9, count on 3: 10, 11, 12 ✓

*Facilitator prompt: If the student counts on but includes the starting number (e.g., for 8+2, says "8, 9" and gets 9), correct immediately: "8 is where we START. We don't count 8 — we count AFTER 8. So: 9, 10."*

**Activity 2: Number line hops (5 minutes)**
Student uses the number line. For each problem, student points to the starting number and hops forward.

- 5 + 3 → Start at 5, hop 3: land on 8 ✓
- 12 + 2 → Start at 12, hop 2: land on 14 ✓
- 3 + 9 → "Which number should I start from?" (9.) Start at 9, hop 3: land on 12 ✓

*Facilitator prompt: Ask "Which number should I start from?" before each problem. Reinforce: start from the bigger number.*

## Independent Practice (10-15 minutes)
**Purpose:** Student uses counting-on independently.

**★ On-level:**
1. 8 + 1 = ___ (9)
2. 7 + 2 = ___ (9)
3. 9 + 3 = ___ (12)
4. 6 + 2 = ___ (8)
5. 3 + 8 = ___ (11) — "Start from the bigger number!"

**★★ Stretch:**
6. 11 + 3 = ___ (14)
7. 15 + 2 = ___ (17)
8. 1 + 13 = ___ (14)
9. "Why is counting on faster than counting all?" (Student explains in their own words)

**★★★ Challenge:**
10. "What is 18 + 2?" (20) "Did you need to count on?" (Maybe not — student may know 8+2=10, so 18+2=20)
11. "Can you count on to add 9 + 5? Try it." (14 — this is harder because 5 is not a small count-on)

### Interleaved Review
- "What makes 10 with 4?" (6)
- "10 − 7 = ___?" (3)
- "Write a number sentence for: six plus three equals nine." (6 + 3 = 9)

---

## Check for Understanding (5 minutes)
**Purpose:** Assess counting-on strategy.

**Exit Ticket:**

1. "Use counting on: 8 + 3 = ___?" (Answer: 11)
2. "For 2 + 9, which number should you start from?" (Answer: 9)
3. "Use counting on: 7 + 2 = ___?" (Answer: 9)

**Mastery = All 3 correct, using counting-on (not counting all from 1).**

### If Mastery Is Not Met
- Practice counting on with 1 first (any number + 1 = the next number). Then add +2, then +3.
- Use the number line as a concrete support. Physically hopping a finger along the line builds the concept.
- Continue to allow objects for verification, but encourage the student to try counting on first.

### If Mastery Is Met
Move to Lesson 3 (Doubles).

---

## Teacher/Facilitator Notes

**Counting on is the first major strategy shift.** Moving from counting-all to counting-on is a significant conceptual leap. It requires the student to hold a number in their head (rather than building it from objects) and count forward. Not all first graders make this transition quickly — patience and modeling are key.

**The most common error is "counting the start number."** For 8 + 3, the student says "8, 9, 10" and answers 10 (they counted 8 as one of their 3 counts). The fix: emphasize that the first count is "9" — the number AFTER the start. Using fingers helps: no fingers up = 8, first finger up = 9, second = 10, third = 11.

**Counting on works best for small addends (+1, +2, +3).** For larger addends like +5 or +6, counting on becomes tedious and error-prone. That's why Lessons 3-5 introduce doubles and Make 10 as better strategies for those cases. Don't ask students to count on by 7 or 8.
