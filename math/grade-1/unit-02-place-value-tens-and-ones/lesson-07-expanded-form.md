# Math — Grade 1 — Unit 2, Lesson 7

## Topic
Expanded Form

## Learning Objectives
By the end of this lesson, the student will be able to:
- Write two-digit numbers in expanded form (e.g., 63 = 60 + 3)
- Convert expanded form back to standard form
- Understand that the tens digit represents groups of ten (e.g., 6 in 63 means 60, not 6)

## Prerequisites
- Grouping objects into tens (Lesson 1)
- Tens and ones on a place value chart (Lesson 2)
- Representing numbers with base-ten blocks (Lessons 3-4)
- Reading and writing two-digit numbers (Lessons 5-6)

## Materials Needed
- Place value mat
- Base-ten blocks (tens rods and ones cubes)
- Paper and pencil

**Purpose:** Review place value concepts from prior lessons.

1. "How many tens in 34?" (3) "How many ones?" (4) *(Lesson 2)*
2. "Show me 52 with base-ten blocks." (5 tens rods, 2 ones cubes) *(Lesson 3)*
3. "What number has 7 tens and 1 one?" (71) *(Lesson 5)*
4. "9 + 8 = ___?" (17) *(Unit 1 review)*

## Direct Instruction (10 minutes)
**Purpose:** Introduce expanded form as a way to show the value of each digit in a two-digit number.

### Key Vocabulary
- **Expanded form:** A way of writing a number that shows the value of each digit (e.g., 47 = 40 + 7)
- **Standard form:** The regular way of writing a number (e.g., 47)

### Instruction Notes

**Step 1: Build 47 on the place value mat.**
Place 4 tens rods in the tens column and 7 ones cubes in the ones column.

"How many tens? 4. What is 4 tens worth? 40. How many ones? 7. What is 7 ones worth? 7. So 47 is the same as 40 + 7. This way of writing a number is called EXPANDED FORM."

Write on paper: **47 = 40 + 7**

**Step 2: Practice with more numbers.**

- Build 35 on the mat. "3 tens = 30. 5 ones = 5. So 35 = 30 + 5."
- Build 82 on the mat. "8 tens = 80. 2 ones = 2. So 82 = 80 + 2."
- Build 60 on the mat. "6 tens = 60. 0 ones = 0. So 60 = 60 + 0." Emphasize: "When there are no ones, we write + 0."

**Step 3: Reverse — expanded form back to standard form.**
"Now let's go the other way. 20 + 6 = what number?" Build 2 tens and 6 ones on the mat. "20 + 6 = 26."

Try another: "50 + 3 = what number?" (53)

**Step 4: Key insight about digit value.**
Point to the 4 in 47. "The 4 in 47 doesn't mean just 4 — it means 40! That's because it's in the tens place. The digit's POSITION tells you its VALUE." Point to the 7. "The 7 means just 7 because it's in the ones place."

### Worked Examples

**Example 1:** 53 in expanded form. 5 tens = 50, 3 ones = 3. So 53 = 50 + 3.

**Example 2:** 70 + 9 in standard form. 70 + 9 = 79.

## Guided Practice (10 minutes)
**Purpose:** Student writes expanded form and converts back to standard form with support.

**Activity 1: Write the expanded form (5 minutes)**
Student builds each number on the place value mat, then writes the expanded form.

- 53 = ___ + ___ (50 + 3) ✓
- 29 = ___ + ___ (20 + 9) ✓
- 70 = ___ + ___ (70 + 0) ✓
- 18 = ___ + ___ (10 + 8) ✓
- 64 = ___ + ___ (60 + 4) ✓

**Activity 2: Write the standard form from expanded form (5 minutes)**
Student reads the expanded form and writes the standard number.

- 30 + 7 = ___ (37) ✓
- 90 + 1 = ___ (91) ✓
- 40 + 0 = ___ (40) ✓

*Facilitator prompt: If the student struggles, have them build the expanded form on the mat first — place the tens, then the ones — and count the total.*

## Independent Practice (10 minutes)
**Purpose:** Apply expanded form skills independently.

**★ On-level:**
1. Write 46 in expanded form. (40 + 6)
2. Write 73 in expanded form. (70 + 3)
3. Write 85 in expanded form. (80 + 5)
4. Write 50 in expanded form. (50 + 0)
5. Write 31 in expanded form. (30 + 1)
6. Write 99 in expanded form. (90 + 9)

**★★ Stretch:**
7. 60 + 8 = ___ (68)
8. ___ + 5 = 25. What is the missing number? (20)

**★★★ Challenge:**
9. "I am 40 + 13. What number am I?" (53 — the student must recognize that 13 ones regroups to 1 ten and 3 ones, so 40 + 13 = 40 + 10 + 3 = 53)
10. "Write a number whose expanded form has 70 in it." (Any number from 70 to 79 is correct, e.g., 70 = 70 + 0, 71 = 70 + 1, 72 = 70 + 2, ... 79 = 70 + 9)

## Check for Understanding (5 minutes)
**Purpose:** Confirm the student can write expanded form and interpret digit values.

**Exit Ticket:**

1. Write 58 in expanded form. (50 + 8)
2. What number is 30 + 4? (34)
3. What does the 7 mean in 73? (70, or 7 tens)

**Mastery = All 3 correct.**

### If Mastery Is Not Met
- Return to the place value mat. Have the student build the number with blocks and say aloud: "___ tens is ___. ___ ones is ___. So the number is ___ + ___."
- Focus on the distinction between the digit (e.g., 7) and its value (e.g., 70). Use the mat columns to reinforce: "It's in the tens column, so it means 7 tens, which is 70."
- Practice 3-5 additional numbers with blocks before reattempting the exit ticket.

### If Mastery Is Met
Move to Lesson 8 (Comparing Two-Digit Numbers).

## Teacher/Facilitator Notes

**Expanded form bridges concrete and abstract.** Up to this point, students have worked with blocks and charts. Expanded form is the first step toward purely symbolic reasoning about place value — it explicitly names each digit's value without requiring physical manipulatives.

**The "digit vs. value" distinction is critical.** Many students think the 4 in 47 means "4." This lesson deliberately surfaces that misconception. Ask repeatedly: "Does the 4 mean 4 or 40? How do you know?" The place value mat provides the answer — the digit is in the tens column, so it represents tens.

**The "60 + 0" case matters.** Students often want to write 60 in expanded form as just "60." Push them to write 60 + 0 to reinforce that every two-digit number has a tens part and a ones part, even when the ones part is zero.
