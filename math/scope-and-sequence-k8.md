# Math Scope and Sequence — Grades K-8

This document maps the grade-by-grade topic progression for the math curriculum. Each grade is organized into units that build on prior knowledge. The curriculum follows a concrete → pictorial → abstract (CRA) progression within each topic.

**Status Key:** ✅ Complete | 🔨 In Progress | 📋 Planned

## Vertical Alignment: Key Concept Threads

### Number and Operations
K: Counting → 1: +/− within 20 → 2: +/− within 100 → 3: × and ÷ introduction → 4: Multi-digit ×/÷ → 5: Fraction operations → 6: Rational numbers → 7: Operations with rationals → 8: Real number system

### Fractions
3: Introduction (unit fractions, number line, comparing) → 4: Equivalence, ordering, +/− like denominators → 5: +/− unlike denominators, × fractions → 5-6: ÷ fractions → 7: Operations with all rational numbers

### Algebraic Thinking
K-2: Missing addend problems → 3-4: Patterns, properties → 5: Order of operations → 6: Expressions and one-step equations → 7: Two-step equations → 8: Multi-step equations, systems, functions

### Geometry and Measurement
K-1: Shapes, comparison → 2-3: Area, perimeter → 4: Angles, classification → 5: Volume, coordinates → 6: Area/surface area/volume → 7: Scale, circles → 8: Transformations, Pythagorean theorem
