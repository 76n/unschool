# Math — Grade 2 — Unit 3, Lesson 5

## Topic
Arrays and Repeated Addition

## Learning Objectives
By the end of this lesson, the student will be able to:
- Write a repeated addition sentence for an array (e.g., a 3×4 array → 4 + 4 + 4 = 12)
- Connect array rows to addends in a repeated addition sentence
- Discover that a rotated array gives the same total (commutative property preview)

## Prerequisites
- Arrays (Lesson 4)
- Repeated addition (Lesson 2)

## Materials Needed
- Counting objects or grid paper
- Paper and pencil

---

## Warm-Up (5 minutes)
**Purpose:** Connect arrays to prior lessons.

1. "Draw a 2 × 5 array." (2 rows of 5) "How many total?" (10)
2. "Write the repeated addition: 5 + 5 = 10."
3. "Now draw a 5 × 2 array." (5 rows of 2) "How many total?" (10) "Interesting — same total!"

---

## Direct Instruction (10 minutes)
**Purpose:** Explicitly link each row of an array to one addend in a repeated addition sentence.

### Key Vocabulary
- **Repeated addition sentence:** An addition expression where the same number is added multiple times
- **Commutative property (preview):** Changing the order doesn't change the total

### Instruction Notes

**Step 1: Array → repeated addition.**
Build a 3 × 4 array (3 rows of 4).
"Row 1 has 4. Row 2 has 4. Row 3 has 4. The addition sentence is: 4 + 4 + 4 = 12."
"3 rows of 4 gives us three 4s added together."

**Step 2: Different array, same idea.**
Build a 4 × 3 array (4 rows of 3).
"Row 1: 3. Row 2: 3. Row 3: 3. Row 4: 3. Addition: 3 + 3 + 3 + 3 = 12."
"Same total! 3 × 4 array and 4 × 3 array both have 12."

**Step 3: Rotate and compare.**
Physically rotate the 3 × 4 array 90 degrees. "Now the rows became columns and the columns became rows. But the total didn't change!"

"This is a big idea: the order of the groups doesn't change the total."

### Worked Examples

**Example 1:** 2 × 6 array. Repeated addition: 6 + 6 = 12. Also: 2 + 2 + 2 + 2 + 2 + 2 = 12 (counting by columns).

**Example 2:** 5 × 3 array. Repeated addition by rows: 3 + 3 + 3 + 3 + 3 = 15. By columns: 5 + 5 + 5 = 15.

**Example 3:** 4 × 5 array. By rows: 5 + 5 + 5 + 5 = 20. By columns: 4 + 4 + 4 + 4 + 4 = 20.

---

## Guided Practice (10 minutes)
**Purpose:** Student writes repeated addition for arrays.

**Activity 1: Array → two addition sentences**
Give the student a 3 × 5 array.
- "Write the repeated addition by rows." (5 + 5 + 5 = 15)
- "Write the repeated addition by columns." (3 + 3 + 3 + 3 + 3 = 15)
- "Same total?" (Yes!)

Give the student a 2 × 7 array.
- By rows: 7 + 7 = 14.
- By columns: 2 + 2 + 2 + 2 + 2 + 2 + 2 = 14.

**Activity 2: Addition sentence → array**
- "Draw an array for 4 + 4 + 4." (3 rows of 4, or 4 columns of 3)
- "Draw an array for 6 + 6." (2 rows of 6)

---

## Independent Practice (10 minutes)
**Purpose:** Practice connecting arrays and repeated addition.

**★ On-level:**
1. Draw a 3 × 2 array. Write the repeated addition by rows. (2 + 2 + 2 = 6)
2. Draw a 4 × 5 array. Write the repeated addition by rows. (5 + 5 + 5 + 5 = 20)
3. Write the repeated addition for a 2 × 8 array. (8 + 8 = 16)
4. Write the repeated addition for a 5 × 4 array. (4 + 4 + 4 + 4 + 4 = 20)
5. Draw an array for: 3 + 3 + 3 + 3. What is the total? (4 rows of 3 = 12)

**★★ Stretch:**
6. "A 3 × 4 array and a 4 × 3 array both have ___ objects." (12) "Why?" (Same total, just arranged differently)
7. "Write TWO different repeated addition sentences for an array with 18 objects." (Possible: 6+6+6=18, 9+9=18, 3+3+3+3+3+3=18)

**★★★ Challenge:**
8. "Without drawing, how many objects in a 6 × 5 array?" (30) "What repeated addition did you use?" (5+5+5+5+5+5 or 6+6+6+6+6)
9. "Is a 2 × 9 array the same size as a 9 × 2 array? Explain." (Yes — both have 18 objects. One has 2 rows of 9, the other has 9 rows of 2.)

### Interleaved Review
- "Count by 5s to 40." (5, 10, 15, 20, 25, 30, 35, 40) *(Lesson 3)*
- "74 + 20 = ___" (94)

---

## Check for Understanding (5 minutes)
**Purpose:** Confirm the student connects arrays to repeated addition.

**Exit Ticket:**

1. A 4 × 3 array. Write the repeated addition and find the total. (3 + 3 + 3 + 3 = 12)
2. Draw an array for 5 + 5 + 5. (3 rows of 5)

**Mastery = Both correct.**

### If Mastery Is Not Met
- Use grid paper: have the student color an array, then circle each row and write the number in each row as an addend. "Row 1: 3. Row 2: 3. Row 3: 3. Row 4: 3. So: 3 + 3 + 3 + 3."
- If the student can't draw arrays from addition sentences, reverse: build the array first, then write the sentence, then match.

### If Mastery Is Met
Move to Lesson 6 (The Multiplication Sign).

---

## Teacher/Facilitator Notes

**Two addition sentences for every array** is a powerful idea. A 3 × 4 array can be seen as 3 rows of 4 (4+4+4) or 4 columns of 3 (3+3+3+3). Both equal 12. This foreshadows the commutative property of multiplication.

**Don't require both sentences for mastery.** The student only needs to write one repeated addition sentence from an array. The "two ways" are an enrichment insight.

**Counting by rows vs. columns:** Some students naturally count by rows, others by columns. Both are valid. Encourage whichever skip-counting sequence the student finds easier.
