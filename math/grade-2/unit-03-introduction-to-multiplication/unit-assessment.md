# Unit Assessment — Grade 2 Math, Unit 3: Introduction to Multiplication

**Grade:** 2
**Unit:** 3 — Introduction to Multiplication
**Assessment Type:** Summative (unit-level)
**Administration:** One-on-one or written (prompts read aloud as needed)
**Estimated Duration:** 25-30 minutes
**Materials:** Paper, pencil, grid paper (available for drawing arrays)

## Administration Instructions

Read all item prompts aloud for the student. The student may respond verbally or in writing. For array problems, provide grid paper if requested. The student may use any strategy (skip counting, repeated addition, drawing). Do not provide multiplication hints during the assessment.

**D3.** 2 × 6 = ___ (12)

| Item | Correct Response | Score |
|------|-----------------|-------|
| D1 | 3 × 4 = 12 | ___ / 1 |
| D2 | 5 groups of 3 (or equivalent explanation) | ___ / 1 |
| D3 | 12 | ___ / 1 |
| **Section D Total** | | **___ / 3** |

**Scoring note for D1:** Accept 3 × 4 = 12 or 4 × 3 = 12 (commutative property). Award 0.5 if the multiplication sentence is correct but the product is wrong.

**Scoring note for D2:** Award 1 point for any response that conveys "5 groups of 3" or "5 times 3" with understanding. Accept: "5 groups of 3," "add 3 five times," "5 rows of 3." Award 0 for "5 + 3."

## Section F: Word Problems

Read each problem aloud. The student may draw pictures, use arrays, or write repeated addition to solve.

**F1.** "There are 4 nests. Each nest has 2 eggs. How many eggs altogether?"

Answer: 4 × 2 = 8 eggs.

**F2.** "A baker puts 5 cookies on each tray. She fills 6 trays. How many cookies?"

Answer: 6 × 5 = 30 cookies.

**F3.** "A classroom has 3 rows of desks. Each row has 10 desks. How many desks?"

Answer: 3 × 10 = 30 desks.

|------|-----------------|-------|

**Scoring note:** Award 1 point for the correct numerical answer. Award 0.5 if the student sets up the correct multiplication (e.g., 6 × 5) but makes a computation error. Award 0 if the student uses the wrong operation.

## Rubric and Mastery Determination

| Level | Score Range | Meaning | Next Steps |
|-------|-----------|---------|------------|
| **Mastered** | 18-21 (85-100%) with at least 1 correct in each section | Strong multiplication foundation | Advance to Unit 4: Place Value to 1,000. Multiplication concepts will deepen in Grade 3. |
| **Approaching** | 15-17 (70-84%) | Most skills present; specific gaps remain | Reteach struggling sections. Extra practice before advancing. |
| **Developing** | Below 15 (<70%) | Significant conceptual gaps | Return to specific lessons. Ensure addition fluency (prerequisite) is solid before reteaching. |

### Section-Specific Reteaching Guide

| If struggling in... | Focus on... |
|---|---|
| Section A (Equal Groups / Repeated Addition) | Return to Lessons 1-2. Build physical groups with cups and objects. The student must see "3 groups of 4" as three separate piles of 4, not as 3 + 4. Practice writing the repeated addition sentence for every physical model. |
| Section B (Skip Counting) | Return to Lesson 3. Practice daily: color patterns on the hundred chart, rhythmic counting, finger counting. Skip counting must be fluent before multiplication facts can develop. |
| Section C (Arrays) | Return to Lessons 4-5. Use grid paper to draw arrays. Practice the vocabulary: "rows go across, columns go down." Always connect the array to a repeated addition sentence. |
| Section D (Multiplication Notation) | Return to Lesson 6. The key connection: × means "groups of." If the student treats × as +, rebuild with physical groups every time. Pair every multiplication sentence with its physical model and repeated addition equivalent. |
| Section E (Multiplication Facts) | Return to Lessons 8-9. ×2 = doubles, ×5 = skip count by 5s, ×10 = add a zero. Practice each set separately until fluent, then mix. Use flash cards with physical models on the back. |
| Section F (Word Problems) | Return to Lesson 10. If the student cannot identify the operation, act out the story. "Are there equal groups? How many groups? How many in each?" Build the connection between real-world language and multiplication. |
