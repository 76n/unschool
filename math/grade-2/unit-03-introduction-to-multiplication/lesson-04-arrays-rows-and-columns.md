# Math — Grade 2 — Unit 3, Lesson 4

## Topic
Arrays — Rows and Columns

## Learning Objectives
By the end of this lesson, the student will be able to:
- Define an array as objects arranged in equal rows and equal columns
- Describe an array using "rows" and "columns"
- Count the total number of objects in an array
- Build arrays from a given description (e.g., "3 rows of 4")

## Prerequisites
- Equal groups (Lesson 1)
- Repeated addition (Lesson 2)

## Materials Needed
- Counting objects (cubes, buttons, or coins — at least 36)
- Grid paper or dot paper
- Paper and pencil

---

## Warm-Up (5 minutes)
**Purpose:** Activate equal groups knowledge.

1. "Make 3 groups of 5 cubes." (Student makes 3 piles of 5.)
2. "Now line each group up in a row, one below the other." (Student creates 3 rows of 5.)
3. "Look at that! You just made something new — an array."

---

## Direct Instruction (10 minutes)
**Purpose:** Introduce arrays as a structured way to organize equal groups.

### Key Vocabulary
- **Array:** Objects arranged in rows (horizontal lines) and columns (vertical lines), forming a rectangle
- **Row:** A horizontal line of objects (goes across, left to right)
- **Column:** A vertical line of objects (goes up and down)

### Instruction Notes

**Step 1: Build and name an array.**
Arrange 12 cubes in 3 rows of 4. "This is an array. How many rows?" (3) "How many in each row?" (4) "We say: 3 rows of 4."

Point across a row: "This is a row — it goes across." Point down a column: "This is a column — it goes down." "How many columns?" (4)

**Step 2: Count the array.**
"We can count by rows: 4, 8, 12. Or count by columns: 3, 6, 9, 12. Either way, 12."

**Step 3: Compare to equal groups.**
"An array IS equal groups, but organized neatly. 3 rows of 4 is the same as 3 groups of 4."

**Step 4: Build another array.**
Arrange 15 cubes in 5 rows of 3. "5 rows of 3. How many columns?" (3) "Total?" Count by 3s: 3, 6, 9, 12, 15. Or by 5s down the columns: 5, 10, 15.

### Worked Examples

**Example 1:** 2 rows of 6. Build it: ○○○○○○ / ○○○○○○. Total: 6 + 6 = 12. (Or count by 2s down columns: 2, 4, 6, 8, 10, 12.)

**Example 2:** 4 rows of 3. Build: ○○○ / ○○○ / ○○○ / ○○○. Total: 3 + 3 + 3 + 3 = 12.

**Example 3:** 1 row of 7. Build: ○○○○○○○. Total: 7. "Even 1 row is an array!"

## Guided Practice (10 minutes)
**Purpose:** Student builds and describes arrays.

**Activity 1: Build arrays**
- "Build an array with 2 rows of 5." Student arranges cubes. "How many total?" (10)
- "Build an array with 4 rows of 4." (16)
- "Build an array with 3 rows of 6." (18)

**Activity 2: Describe arrays**
Show pre-built arrays (or draw them):
- ○○○○ / ○○○○ / ○○○○. "___ rows of ___. Total: ___." (3 rows of 4. Total: 12.)
- ○○ / ○○ / ○○ / ○○ / ○○. "___ rows of ___. Total: ___." (5 rows of 2. Total: 10.)

---

## Independent Practice (10 minutes)
**Purpose:** Practice building, describing, and counting arrays.

**★ On-level:**
1. Draw an array with 2 rows of 3. How many total? (6)
2. Draw an array with 3 rows of 5. How many total? (15)
3. An array has 4 rows with 2 in each row. How many total? (8)
4. An array has 5 rows with 4 in each row. How many total? (20)
5. Look at this array: ○○○○○ / ○○○○○ / ○○○○○. How many rows? (3) How many columns? (5) Total? (15)

**★★ Stretch:**
6. "Draw two different arrays that both have 12 objects." (2×6, 3×4, 4×3, 6×2, 1×12, 12×1)
7. "A classroom has 5 rows of desks with 6 desks in each row. How many desks?" (30)

**★★★ Challenge:**
8. "If an array has 3 rows and a total of 18, how many are in each row?" (6)
9. "Can you make an array with 7 objects and more than 1 row?" (No — 7 can only be 1×7 or 7×1.)

### Interleaved Review
- "5 + 5 + 5 + 5 = ___" (20) *(Lesson 2)*
- "Count by 2s to 16." (2, 4, 6, 8, 10, 12, 14, 16) *(Lesson 3)*

---

## Check for Understanding (5 minutes)
**Purpose:** Confirm the student can build and describe arrays.

**Exit Ticket:**

1. Build (or draw) an array with 4 rows of 3. How many total? (12)
2. How many rows and columns does this array have? ○○○○○ / ○○○○○. (2 rows, 5 columns)

**Mastery = Both correct. Student builds/draws accurate arrays and correctly identifies rows and columns.**

### If Mastery Is Not Met
- Use grid paper. Have the student color squares to form the array — the grid ensures even spacing and equal rows.
- If "rows" and "columns" are confused, use hand gestures consistently: sweep hand horizontally for rows, vertically for columns.

### If Mastery Is Met
Move to Lesson 5 (Arrays and Repeated Addition).

---

## Teacher/Facilitator Notes

**Arrays are everywhere.** Point out arrays in real life: egg cartons (2×6), muffin tins (2×6 or 3×4), window panes, ice cube trays, tile floors. Making this connection helps the concept stick.

**Rows vs. columns confusion is normal.** Be patient. Use consistent gestures and labels. Some students benefit from the mnemonic: "Rows go Right" (both start with R) and "Columns go... the other way."

**Grid paper is powerful.** For students who struggle to keep objects aligned, grid paper or dot paper solves the problem immediately.
