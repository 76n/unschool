# Math — Grade 2 — Unit 4, Lesson 2

## Topic
Hundreds, Tens, and Ones

## Learning Objectives
By the end of this lesson, the student will be able to:
- Identify the hundreds, tens, and ones digits in a three-digit number
- Use base-ten blocks (flats, rods, unit cubes) to represent three-digit numbers
- Use a place value chart with H | T | O columns
- Explain the value of each digit based on its position

## Prerequisites
- Understanding that 10 tens = 1 hundred (Lesson 1)
- Counting by hundreds to 900
- Familiarity with tens and ones from Grade 1 / Grade 2 Unit 1

## Materials Needed
- Base-ten blocks: flats (hundreds), rods (tens), unit cubes (ones)
- Place value chart (three columns labeled H, T, O) — printed or drawn on paper
- Dry-erase board or paper and pencil
- Number cards 0-9 (three sets)

---

## Warm-Up (5 minutes)
**Purpose:** Review hundreds from Lesson 1 and activate tens-and-ones knowledge.

1. "Skip count by 100s to 900." (100, 200, 300, 400, 500, 600, 700, 800, 900)
2. Hold up 4 rods and 3 unit cubes. "What number is this?" (43) "How do you know?" (4 tens and 3 ones)
3. "Now I'm going to add flats to the mix. We need a new column in our place value chart — the hundreds column."

---

## Direct Instruction (10-15 minutes)
**Purpose:** Show that three-digit numbers are made of hundreds, tens, and ones.

### Key Vocabulary
- **Digit:** A single symbol (0, 1, 2, 3, 4, 5, 6, 7, 8, or 9) used to write numbers
- **Three-digit number:** A number with a hundreds digit, a tens digit, and a ones digit (100-999)
- **Place value chart:** A chart with columns that show the value of each digit

### Instruction Notes

**Step 1: Build a three-digit number with blocks.**
Place 2 flats, 3 rods, and 5 unit cubes on the table. "Let's count what we have. 2 flats — that's 2 hundreds, or 200. 3 rods — that's 3 tens, or 30. 5 unit cubes — that's 5 ones, or 5. Altogether: 200 + 30 + 5 = 235."

**Step 2: Introduce the place value chart.**
Draw a chart with three columns: H | T | O. "We write the hundreds digit under H, the tens digit under T, and the ones digit under O." Write 2 under H, 3 under T, 5 under O. "This is the number 235."

**Step 3: Stress the value of each digit.**
Point to the 2 in 235. "This 2 is not just '2.' It is in the hundreds place, so it means 2 hundreds, or 200." Point to the 3. "This 3 means 3 tens, or 30." Point to the 5. "This 5 means 5 ones, or 5. Same digit can mean very different things depending on WHERE it sits."

### Worked Examples

**Example A:** Build 174 with blocks. Place 1 flat, 7 rods, 4 cubes. "1 hundred, 7 tens, 4 ones." Fill in the chart: H = 1, T = 7, O = 4. "The number is 174. The 1 is worth 100, the 7 is worth 70, and the 4 is worth 4."

**Example B:** Build 650 with blocks. Place 6 flats, 5 rods, 0 cubes. "6 hundreds, 5 tens, 0 ones." Fill in the chart: H = 6, T = 5, O = 0. "The number is 650. Notice there are zero ones — we still write a 0 in the ones place."

## Guided Practice (10 minutes)
**Purpose:** Student builds numbers with blocks, records them on the place value chart, and identifies digit values.

**Activity 1: Build and chart**
- "Build 382 with your blocks." Student places 3 flats, 8 rods, 2 cubes. "Fill in the chart." (H = 3, T = 8, O = 2) "What is the value of the 8?" (80)
- "Build 519." (5 flats, 1 rod, 9 cubes; H = 5, T = 1, O = 9) "What is the value of the 5?" (500)
- "Build 407." (4 flats, 0 rods, 7 cubes; H = 4, T = 0, O = 7) "Why are there no rods?" (There are 0 tens.)

**Activity 2: Chart to blocks**
Write a number on the chart; student builds it with blocks.
- H = 2, T = 6, O = 1. Student builds 261.
- H = 7, T = 0, O = 3. Student builds 703. "What number is this?" (703)
- H = 8, T = 4, O = 0. Student builds 840.

## Independent Practice

### Tier 1 (Approaching)
1. Build 234 with blocks. How many hundreds? (2) Tens? (3) Ones? (4)
2. Fill in the chart for 156. H = ___ T = ___ O = ___ (1, 5, 6)
3. What is the value of the 3 in 368? (300)
4. How many flats do you need for 400? (4)

### Tier 2 (On Level)
1. Write the number: 5 hundreds, 2 tens, 8 ones = ___ (528)
2. What is the value of the 7 in 374? (70)
3. Fill in the chart for 609. H = ___ T = ___ O = ___ (6, 0, 9)
4. "I have 4 flats, 1 rod, and 6 cubes. What number am I?" (416)
5. In the number 852, which digit is in the tens place? (5)

### Tier 3 (Advanced)
1. "The digit 6 is in the hundreds place, the digit 0 is in the tens place, and the digit 4 is in the ones place. What is the number?" (604)
2. "In the number 739, what is the value of each digit?" (700, 30, 9)
3. "True or false: the 4 in 241 and the 4 in 432 have the same value." (False — 40 vs. 400)
4. "Write a three-digit number where the tens digit is 0." (Answers vary, e.g., 305, 409, 700)
5. "What is the biggest three-digit number you can make with the digits 3, 7, and 1? What is the smallest?" (731; 137)

---

## Exit Ticket (2-3 minutes)

1. What number is shown by 3 flats, 4 rods, and 7 cubes? (347)
2. In the number 582, what is the value of the 5? (500)
3. Fill in: 691 = ___ hundreds + ___ tens + ___ ones. (6, 9, 1)

**Mastery = All three correct. Student reliably identifies hundreds, tens, and ones digits and their values.**

## Teacher Notes

**The place value chart is the bridge from Concrete to Representational.** In this lesson students still handle blocks (Concrete) but also begin recording digits in the chart (Representational). Always have the student build the number with blocks first, *then* write it in the chart. Do not skip the blocks.

**Zero as a placeholder.** Numbers like 407 and 650 are important teaching moments. Students often want to skip the zero column. Emphasize: "We need the zero to hold the place. Without it, 407 would look like 47 — and that's a very different number!"

**Common errors:**
- Student reverses the order of digits (writes 234 as 432). Always point to the chart columns: "H is on the left, then T, then O."
- Student confuses the digit with its value (says the 3 in 345 is worth "3" instead of "300"). Redirect: "Where is the 3 sitting? In the hundreds column. So it means 3 hundreds, which is 300."
- Student struggles with zero in the tens place (e.g., 506). Build it with blocks: "5 flats, no rods, 6 cubes. We write 0 in the tens column to show there are no tens."

**Facilitator language tip:** Ask "What is the VALUE of this digit?" rather than "What is this digit?" The word "value" keeps attention on place value, not just the digit itself.
