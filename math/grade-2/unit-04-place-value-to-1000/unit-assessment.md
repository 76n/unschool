# Unit Assessment — Grade 2 Math, Unit 4: Place Value to 1,000

**Grade:** 2
**Unit:** 4 — Place Value to 1,000
**Assessment Type:** Summative (unit-level)
**Administration:** Written; facilitator reads item prompts aloud as needed
**Estimated Duration:** 30-40 minutes
**Total Items:** 20
**Total Points:** 50

---

## Overview

This assessment measures student understanding of three-digit place value concepts introduced in Unit 4. Students demonstrate their ability to identify the value of digits in the hundreds, tens, and ones places; read and write numbers to 1,000 in standard, word, and expanded form; compare and order three-digit numbers; and apply skip counting and place value reasoning to solve problems.

The assessment contains 20 items worth a combined 50 points across four sections. The facilitator should read all item prompts aloud as needed. Students write their answers on the assessment paper. Allow students to work at their own pace. Do not provide place value hints or strategy cues during the assessment.

---

## Materials Needed

- Student assessment paper and pencil
- Base-ten blocks (hundreds flats, tens rods, ones cubes) — available on request; note usage on observation sheet
- Blank number line from 0 to 1,000 with tick marks at every 100 (for Section 3)
- Place value chart (hundreds, tens, ones) — available on request; note usage on observation sheet

## Section 1: Place Value Understanding

**Items 1-5 | 12 points**

Tell the student: *"These questions are about hundreds, tens, and ones in three-digit numbers. Write your answers on the paper."*

---

**Item 1.** (2 pts) How many hundreds, tens, and ones are in 574?

Expected response: 5 hundreds, 7 tens, 4 ones.

---

**Item 2.** (2 pts) What is the value of the digit 3 in 831?

Expected response: 30 (or "3 tens" or "thirty").

---

**Item 3.** (3 pts) What number has 6 hundreds, 0 tens, and 9 ones? Write the number and draw the base-ten blocks that represent it.

Expected response: 609. Drawing shows 6 hundreds flats, 0 tens rods, and 9 ones cubes.

---

**Item 4.** (2 pts) A number is shown with base-ten blocks: 2 hundreds flats, 4 tens rods, and 5 ones cubes. What number is this?

Tell the student: *"Imagine you see 2 large squares for hundreds, 4 sticks for tens, and 5 small cubes for ones. What number is that?"*

Expected response: 245.

---

**Item 5.** (3 pts) Write the value of the underlined digit in each number below.

(a) **4**62 — value of 4
(b) 7**8**3 — value of 8
(c) 51**6** — value of 6

Tell the student: *"For each number, I will tell you which digit is underlined. Write the value of that digit."*

Expected responses: (a) 400, (b) 80, (c) 6.

## Reteaching Recommendations

### Section 1: Place Value Understanding (Items 1-5)

If the student struggles to identify hundreds, tens, and ones or to determine the value of a digit:

- **Return to concrete models.** Use physical base-ten blocks extensively. Have the student build numbers with hundreds flats, tens rods, and ones cubes, then state the number of hundreds, tens, and ones while touching each group.
- **Practice the "value vs. digit" distinction.** A common error is saying the digit 3 in 831 has a value of "3" rather than "30." Build 831 with blocks and physically separate the 3 tens rods: "These 3 tens rods are worth 30." Repeat with many numbers until the student consistently names the value, not the digit.
- **Zero as a placeholder.** If the student struggles with numbers like 609 (zero tens), build with blocks and show the empty tens column on a place value chart. Practice several numbers with zero in the tens or ones place: 502, 740, 308, 910.
- **Daily warm-up:** Flash a three-digit number. The student names the hundreds, tens, and ones within 5 seconds.

### Section 2: Reading and Writing Numbers (Items 6-10)

If the student struggles to convert between standard form, word form, and expanded form:

- **Standard-to-word and word-to-standard.** Use a place value chart as a bridge. Write the number, then read each place: "8 hundreds is eight hundred, 5 tens is fifty, 6 ones is six — eight hundred fifty-six." Practice daily with a mix of numbers, including those with zeros (e.g., 904, 360, 500).
- **Expanded form.** Build the number with blocks, then separate each place into its own pile: "400 ... plus 90 ... plus 3." Write the expanded form while looking at the separated piles. Common error: writing 4 + 9 + 3 instead of 400 + 90 + 3 — this indicates the student is recording the digit, not its value. Return to Section 1 reteaching.
- **Zero in expanded form.** Show that 710 = 700 + 10 + 0. The zero is real — it holds the ones place. Some students omit it; accept "700 + 10" but ensure the student understands the ones place is 0.
- **Practice activity:** Write a number in one form on a card; the student writes it in the other two forms.

### Section 3: Comparing and Ordering (Items 11-15)

If the student struggles to compare or order three-digit numbers:

- **Hundreds-first strategy.** Place two numbers side by side on a place value chart. "Which has more hundreds? That number is greater." If hundreds are the same, compare tens. If tens are the same, compare ones. Practice this systematic approach until it becomes automatic.
- **Common error: comparing only ones.** If the student says 299 > 301 because "9 is bigger than 1," the student is not comparing by place. Use blocks: build 299 and 301 side by side. "Which pile has more hundreds flats? 301 has 3 hundreds, 299 has only 2. 3 hundreds is always more than 2 hundreds, no matter what is in the tens and ones."
- **Number line placement.** Practice locating numbers between labeled hundreds on a number line. Start with multiples of 100, then multiples of 50, then arbitrary numbers. Ask: "Is 550 closer to 500 or to 600? How do you know?"
- **Ordering practice.** Give sets of 3-4 three-digit numbers. The student writes them on separate cards, arranges them on a number line, then writes the ordered sequence. Alternate between least-to-greatest and greatest-to-least to build flexibility.

### Section 4: Skip Counting and Problem Solving (Items 16-20)

If the student struggles with skip counting, 10/100 more or less, or word problems:

- **Skip counting across hundreds.** The critical skill is crossing a hundred boundary (e.g., 390, 400, 410). Use a hundreds chart or a number line. Count by 10s starting from various points: 270, 280, 290 ... the student must say 300, not "two hundred and one hundred." Practice counting by 100s from non-zero starting points (e.g., 150, 250, 350 ...).
- **10 more/less and 100 more/less.** Use base-ten blocks. "Start with 462. Add 1 tens rod. What number now?" (472). "Take away 1 tens rod." (452). "Add 1 hundreds flat." (562). "Take away 1 hundreds flat." (362). The student should see that only one digit changes each time. Practice until the student can do this mentally.
- **Number riddles.** If the student struggles with riddle Item 19, break it down: "Write down what you know: 4 hundreds — that's 4 _ _. The ones digit is 3 — that's 4 _ 3. Now the tens digit is 2 more than 3 — what is 2 more than 3?" Build the number step by step.
- **Word problems with comparison.** If the student cannot explain using place value, return to the comparison strategy from Section 3. Practice stating: "I compare the hundreds first. ___ hundreds vs. ___ hundreds. ___ is more, so ___ is the greater number."
