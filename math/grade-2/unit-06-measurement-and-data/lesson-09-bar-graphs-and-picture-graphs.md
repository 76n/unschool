# Math — Grade 2 — Unit 6, Lesson 9

## Topic
Reading and Creating Bar Graphs and Picture Graphs

## Learning Objectives
By the end of this lesson, the student will be able to:
- Read a picture graph (pictograph) and answer questions about the data
- Read a bar graph and answer questions about the data
- Create a simple bar graph from a tally chart or data set
- Use graph data to compare categories (more, fewer, difference)

## Prerequisites
- Counting to 20
- Subtraction within 20 (Unit 2)
- Understanding categories and sorting from prior experience

## Materials Needed
- Pre-made tally chart (class survey results — e.g., favorite fruit: apple, banana, orange, grape)
- Blank bar graph templates (vertical and horizontal versions)
- Colored pencils or crayons
- Sticky notes (for live class survey)
- Linking cubes in 4 colors (for building concrete bar graphs)
- Mini whiteboards
- Large graph paper or chart paper for whole-class graph

---

## Warm-Up (5 minutes)
**Purpose:** Collect real data and create genuine curiosity about organizing it.

**Class Survey:**
Ask: "What is your favorite fruit: apple, banana, orange, or grape?" Students vote by raising hands. Record tally marks on the board as a tally chart.

Ask: "Just from looking at the tally chart — which fruit is most popular? Is it easy to tell?" (It can be hard to compare tally marks quickly.)

Transition: "Today we'll learn a way to show data that makes it MUCH easier to compare — graphs!"

---

## Direct Instruction (10–15 minutes)
**Purpose:** Teach how to read and create picture graphs and bar graphs using the CRA progression.

### Key Vocabulary
- **Data:** Information we collect, often by counting
- **Picture graph (pictograph):** A graph that uses pictures or symbols to represent data; a key tells how many each picture represents
- **Bar graph:** A graph that uses bars (rectangles) to show data; the length of each bar represents the amount
- **Key (legend):** On a picture graph, this tells what each picture stands for
- **Scale:** The numbers along the side or bottom of a bar graph
- **Category:** A group in the graph (e.g., "apple" is a category)
- **Title:** The name of the graph, telling what data it shows

### Instruction Notes

**Concrete phase:**
Use linking cubes to build a physical bar graph. Give students 4 colors of cubes. Say: "Blue = apple, Red = banana, Yellow = orange, Green = grape. Take the number of cubes matching our survey results and stack them." Stand the stacks upright side by side.

Ask: "Which stack is tallest? Which is shortest? How can you tell which has more?"

**Pictorial phase — Picture Graph:**
Show a prepared picture graph. Example:
```
Favorite Fruit Survey
Apple:   🍎 🍎 🍎 🍎 🍎
Banana:  🍌 🍌 🍌
Orange:  🍊 🍊 🍊 🍊
Grape:   🍇 🍇

Key: Each picture = 1 vote
```
Read together:
- "How many students chose apple?" (5)
- "How many chose grape?" (2)
- "How many more students chose apple than grape?" (5 − 2 = 3)

**Pictorial phase — Bar Graph:**
Show the same data as a bar graph with a scale of 1 (each square = 1). Model how to shade bars to match the numbers. Emphasize:
- Title at top
- Categories labeled on one axis
- Numbers (scale) on the other axis
- Bars must touch the scale exactly (don't go between numbers)

**Abstract phase:**
Ask questions where students read and compute from the graph alone without counting pictures:
- "Total votes for banana and orange combined?"
- "Which two categories have the same number?"

### Worked Examples

**Example 1 (Reading a picture graph):**
The graph shows: cats = 4, dogs = 6, fish = 2, birds = 3.
Q: "How many more dogs than fish are there?" 6 − 2 = 4 more dogs.

**Example 2 (Reading a bar graph):**
Bar graph shows: red = 5, blue = 8, green = 3, yellow = 5.
Q: "Which color was most popular?" Blue (bar reaches 8).
Q: "How many students were surveyed?" 5 + 8 + 3 + 5 = 21.

**Example 3 (Creating a bar graph):**
Data: Soccer = 7, Basketball = 4, Swimming = 6, Tennis = 3.
Demonstrate drawing and shading bars to exactly 7, 4, 6, 3 on a scale of 0–8.

## Guided Practice (10 minutes)

Use the class fruit survey data from the warm-up.

**Together:**
1. As a class, create a bar graph on chart paper using the live data from the warm-up.
   - Title: "Our Favorite Fruit"
   - Categories: Apple, Banana, Orange, Grape
   - Scale: 0 to [number slightly above highest bar]
   - Shade each bar to match the tally chart.

**Then answer together:**
- Which fruit got the most votes?
- Which got the fewest?
- How many more votes did the most popular get than the least popular?
- How many students total voted?

Students record answers on mini whiteboards.

## Independent Practice (10–15 minutes)

### Difficulty Tiers

**On-level:**

Use this picture graph to answer questions 1–3:
```
Pets in Our Class
Dog:   🐶 🐶 🐶 🐶
Cat:   🐱 🐱 🐱 🐱 🐱 🐱
Fish:  🐟 🐟
Bird:  🐦 🐦 🐦

Key: Each picture = 1 student
```
1. How many students have a cat? ___
2. How many more students have a cat than a dog? ___
3. How many students have a pet shown in the graph? ___

For questions 4–5, use this data to create a bar graph (blank template provided):
Favorite Color: Red = 4, Blue = 7, Green = 3, Purple = 5
4. Draw and shade bars for each color.
5. Which color got the most votes? ___

**Stretch:**
Use the bar graph you created for questions 6–7:
6. How many more students chose blue than green? ___
7. How many students voted in all? ___
8. If 2 more students voted for red, how many votes would red have? How would that change the graph?

**Challenge:**
9. Create your own survey about something interesting to you. Ask at least 6 classmates (or family members). Make a tally chart. Then draw a bar graph. Write two math questions about your graph and answer them.

## Check for Understanding (3 minutes)

**Exit Ticket:**

Use this bar graph:
```
Number of Books Read
Ana:   |||||| (6)
Ben:   ||||  (4)
Cara:  ||||||||| (9)
Dan:   || (2)
```
1. Who read the most books? ___
2. How many more books did Cara read than Dan? ___ − ___ = ___

**Mastery = both correct.**

### If Mastery Is Not Met
- Practice reading picture graphs only (key = 1 symbol per item) before introducing bar graphs.
- Use physical cubes to build bar graphs first; then draw the bars to match the cube towers.
- Have students physically color over each unit on a graph paper bar before filling in a smooth bar.

### If Mastery Is Met
- Ask: "What if the key on a picture graph said 'each picture = 2 students'? How would that change how you read the graph?" Preview of scaled graphs.

## Extension (Optional)
**Two-Graph Challenge:** Take the same data and show it as BOTH a picture graph AND a bar graph. Compare: Which is easier to read quickly? Write a sentence explaining your preference.

---

## Teacher/Facilitator Notes
- The live class survey in the warm-up is important — it makes the data feel real and meaningful. Students are more engaged when the graph is "about us."
- Students often confuse the categories axis and the number axis. Reinforce: "The bars grow up (or across) toward the numbers. The categories tell us WHAT we are counting."
- When creating bar graphs, students sometimes draw bars of uneven width or leave gaps between bars. Model carefully with a ruler or on graph paper where each square = 1 unit.
- The "key" in picture graphs is a crucial reading comprehension step. If a key says each picture = 2, the student must multiply. In this lesson, all keys are "= 1" so students count directly. This sets up Grade 3 scaled graphs.
