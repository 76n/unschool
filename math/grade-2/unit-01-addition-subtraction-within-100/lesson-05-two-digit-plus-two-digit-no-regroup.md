# Math — Grade 2 — Unit 1, Lesson 5

## Topic
Adding Two Two-Digit Numbers (No Regrouping)

## Learning Objectives
By the end of this lesson, the student will be able to:
- Add two two-digit numbers when no regrouping is needed (e.g., 23 + 45 = 68)
- Use the break-apart (decomposition) strategy: add tens to tens, add ones to ones, then combine
- Model the addition with base-ten blocks on a place value mat
- Write the addition in expanded form (e.g., 23 + 45 = 20 + 40 + 3 + 5 = 60 + 8 = 68)

## Prerequisites
- Lesson 2: Adding tens (e.g., 30 + 40 = 70)
- Lesson 3: Adding a two-digit number and a one-digit number without regrouping
- Understanding of place value: tens and ones

## Materials Needed
- Base-ten blocks (tens rods and ones cubes) — at least 9 tens and 18 ones
- Place value mat (paper with "Tens" and "Ones" columns)
- Paper and pencil
- Two different colors of crayons or pencils (to color-code tens and ones)

**Standards:** 2.NBT.5, 2.NBT.6, 2.NBT.9

## Direct Instruction (15 minutes)
**Purpose:** Introduce the break-apart strategy for adding two two-digit numbers.

### Key Vocabulary
- **Break apart (decompose):** Split a number into its tens and ones (47 = 40 + 7)
- **Expanded form:** Writing a number as the sum of its place values (47 = 40 + 7)
- **Combine:** Put parts together to make the total
- **Vertical form:** Writing one number above the other, lining up the ones and tens columns

### Instruction Notes

**Step 1 — Build both numbers with blocks (5 minutes)**

Write: 23 + 45

Say: "Let's build both numbers on the place value mat."

Build 23: Place 2 tens rods and 3 ones cubes on the top half of the mat.
Build 45: Place 4 tens rods and 5 ones cubes on the bottom half of the mat.

Say: "Now we are going to combine them. Let's start with the ones."

Push the ones cubes together in the Ones column: 3 + 5 = 8 ones.
Ask: "How many ones do we have?" (8)

Now push all the tens rods together in the Tens column: 2 + 4 = 6 tens.
Ask: "How many tens do we have?" (6)

Ask: "6 tens and 8 ones — what number is that?" (68)

Write: 23 + 45 = 68

**Step 2 — The break-apart strategy on paper (5 minutes)**

Say: "Now let me show you how to write this without blocks. It is called the break-apart strategy."

Write on paper:
```
23 + 45

Step 1: Break apart both numbers.
  23 = 20 + 3
  45 = 40 + 5

Step 2: Add the tens.
  20 + 40 = 60

Step 3: Add the ones.
  3 + 5 = 8

Step 4: Combine the tens and ones.
  60 + 8 = 68

Answer: 23 + 45 = 68
```

Say: "This is the same thing we did with blocks, but now we write it on paper. Break apart, add tens, add ones, combine."

Use the two different colored pencils: write all tens values in one color and all ones values in another to make the decomposition visible.

**Step 3 — The vertical format (3 minutes)**

Say: "There is another way to write this. We can stack the numbers on top of each other."

Write:
```
  23
+ 45
----
  68
```

Say: "Line up the ones under the ones and the tens under the tens. First, add the ones column: 3 + 5 = 8. Write 8 in the ones place. Then, add the tens column: 2 + 4 = 6. Write 6 in the tens place. The answer is 68."

Say: "Both the break-apart method and the vertical method give the same answer. The vertical method is a shortcut — it keeps things neat and organized."

**Step 4 — Why no regrouping? (2 minutes)**

Ask: "In our problem, did we need to regroup? Did the ones add up to more than 9?"

- 23 + 45: 3 + 5 = 8 (no, 8 is not more than 9)
- The tens: 2 + 4 = 6 (no, 6 tens is not more than 9 tens)

Say: "Today, all of our problems will have ones that add to 9 or less — so no regrouping needed. In a future lesson, we will add two two-digit numbers where regrouping IS needed."

### Worked Examples

**Example 1:**
Problem: 23 + 45
- Step 1: Break apart. 23 = 20 + 3 and 45 = 40 + 5.
- Step 2: Add the tens. 20 + 40 = 60.
- Step 3: Add the ones. 3 + 5 = 8.
- Step 4: Combine. 60 + 8 = 68.
- Answer: 23 + 45 = 68
- Vertical check:
  ```
    23
  + 45
  ----
    68
  ```

**Example 2:**
Problem: 51 + 36
- Step 1: Break apart. 51 = 50 + 1 and 36 = 30 + 6.
- Step 2: Add the tens. 50 + 30 = 80.
- Step 3: Add the ones. 1 + 6 = 7.
- Step 4: Combine. 80 + 7 = 87.
- Answer: 51 + 36 = 87
- Vertical check:
  ```
    51
  + 36
  ----
    87
  ```

## Guided Practice (10 minutes)
**Purpose:** Practice the break-apart strategy together with facilitator support.

Have the student use base-ten blocks for problems 1-2, then transition to paper-only for problems 3-5.

1. 31 + 24 = ___
   - Ask: "Break apart 31. Break apart 24. Now add the tens. Add the ones. Combine."
   - Verify with blocks: 3 tens + 2 tens = 5 tens. 1 one + 4 ones = 5 ones. 55.

2. 42 + 35 = ___
   - Ask: "Can you build this with blocks and then check with the break-apart strategy on paper?"
   - If the student struggles to transition: work the blocks and paper side-by-side so they can see the connection.

3. 53 + 26 = ___
   - Say: "Try this one on paper only. Write out the four steps."
   - If the student struggles without blocks, let them use blocks — but encourage paper too.

4. 14 + 65 = ___
   - Ask: "Does it matter which number you start with? Is 14 + 65 the same as 65 + 14?"
   - (Yes, same answer — commutative property. The student might find it easier to think about the larger number first.)

5. 70 + 21 = ___
   - Ask: "70 has 0 ones. What happens when you add the ones?" (0 + 1 = 1)
   - This reinforces that the strategy works even when one number has 0 in a place.

**Decision check — Do NOT solve:** Write 46 + 37. Ask: "Before you solve, check the ones. 6 + 7 = ?" (13.) "Is that 10 or more?" (Yes.) "So this one WILL need regrouping. We will practice that in a future lesson! For now, just notice: you have to check the ones column first."

**Facilitator note:** By problem 3 or 4, see if the student can state the strategy in their own words. A good response: "I break both numbers into tens and ones. I add the tens together and add the ones together. Then I put them back together." If they can say this, they understand the method.

If the student adds the tens of one number to the ones of the other (e.g., 30 + 4 for 31 + 24), redirect: "Tens go with tens, and ones go with ones. The tens are 30 and 20. The ones are 1 and 4."

## Check for Understanding (5 minutes)
**Purpose:** Quick formative assessment to gauge mastery.

### Exit Ticket

1. 32 + 54 = ___
2. 25 + 43 = ___
3. Show your work for 41 + 36 using the break-apart strategy. Write out the steps.

**Mastery Criteria:** All 3 correct. For problem 3, the student must show the four steps (break apart, add tens, add ones, combine) — not just the final answer. Accept any clear format:
- "41 = 40 + 1, 36 = 30 + 6. 40 + 30 = 70. 1 + 6 = 7. 70 + 7 = 77."
- A vertical format with clear column work.
- A drawing with tens and ones grouped.

### If Mastery Is Not Met
- The student likely needs more time with base-ten blocks. Set up the place value mat and work through 5 more problems physically, labeling each group: "These are the tens from 32. These are the tens from 54. Put them together."
- Write out the break-apart steps as a fill-in template the student can complete:
  ```
  ___ + ___
  Step 1: ___ = ___ + ___ and ___ = ___ + ___
  Step 2: Tens: ___ + ___ = ___
  Step 3: Ones: ___ + ___ = ___
  Step 4: Combine: ___ + ___ = ___
  ```
- If errors are computational (e.g., 3 + 2 = 6), practice basic facts within 10 before continuing.
- Re-attempt the exit ticket after practice.

### If Mastery Is Met
Preview: "You just combined skills from Lesson 2 (adding tens) and Lesson 3 (adding ones) into one strategy! Next time, we will tackle problems where the ones DO add to more than 9 — like 36 + 47. You already know how to regroup from Lesson 4, so you will be ready."

## Extension (Optional)
**Purpose:** Enrichment for students who finish early or demonstrate advanced understanding.

**Sum Hunt:** Give the student these clues and have them find the two-digit addends.
- "I am adding two numbers. The tens add to 70. The ones add to 5. My answer is 75. What could my two numbers be?" (Many answers: 31 + 44, 42 + 33, 53 + 22, 64 + 11, etc.)
- "I am adding two numbers. Both numbers are the same. My answer is 88. What are my numbers?" (44 + 44)

**Puzzle:** "I am thinking of two two-digit numbers. They add up to 99. Neither of them has a zero in it. No regrouping is needed. What could they be?" (Ones sum to 9, tens sum to 9. Examples: 11 + 88, 12 + 87, 13 + 86, 21 + 78, 22 + 77, etc.)

**Real-World Connection:** "You read 31 pages of your book on Monday and 25 pages on Tuesday. How many pages did you read in total? Can you use the break-apart strategy to figure it out?" (31 + 25 = 56 pages.) "Is that more or less than 50 pages?"

**Expanded Form Practice:** Write these numbers in expanded form and add:
- 62 + 25: 60 + 2 + 20 + 5 = 60 + 20 + 2 + 5 = 80 + 7 = 87
- 43 + 51: 40 + 3 + 50 + 1 = 40 + 50 + 3 + 1 = 90 + 4 = 94

## Teacher/Facilitator Notes

### How This Lesson Connects
This lesson is the synthesis of Lessons 2 and 3. In Lesson 2, students learned to add tens. In Lesson 3, they learned to add ones to a two-digit number. Here, they do both steps within a single problem. The break-apart strategy makes this explicit: decompose, add like places, recombine.

### Common Misconceptions
- **Adding tens to ones (or vice versa):** The student might compute 23 + 45 as 20 + 5 = 25 and 3 + 40 = 43, then get confused. Use color-coding: write all tens in one color and all ones in another. "Red goes with red, blue goes with blue."
- **Adding all four digits together:** For example, 34 + 25 becomes 3 + 4 + 2 + 5 = 14. This means the student does not understand column alignment. Return to blocks and the place value mat to make the columns visible.
- **Forgetting to combine:** The student adds 20 + 40 = 60 and 3 + 5 = 8, then writes the answer as "60 and 8" or "608" instead of 68. Emphasize: "60 + 8 is the same as saying 6 tens and 8 ones, which is 68."
- **Trying to regroup when it is not needed:** After Lesson 4, some students may try to trade ones for tens even when the ones sum to less than 10. Remind them: "First add the ones. 3 + 5 = 8. Is 8 more than 9? No. So no regrouping needed."

### Pacing Adjustments
- Most students find this lesson manageable because it combines two skills they already know. If the student is confident after 2-3 guided practice problems, move quickly through independent practice and use the remaining time for the extension.
- If the student struggles with the multi-step nature (breaking apart, adding twice, combining), slow down and use a graphic organizer: a T-chart with "Tens" on one side and "Ones" on the other.
- The vertical format is introduced here but not required. Students should be comfortable with at least one written method (break-apart or vertical). Both will be used in later lessons.

### Discussion Questions
- "Why do we break numbers apart before adding them?"
- "Is the break-apart strategy the only way to add these numbers? Can you think of another way?" (Some students may count on by tens, then ones: 23 + 45 = 23 + 40 + 5 = 63 + 5 = 68. This is also valid!)
- "Which part of the strategy uses what you learned in Lesson 2? Which part uses Lesson 3?"
- "When you write the problem vertically, why is it important to line up the ones under ones and tens under tens?"
