# Math — Grade 2 — Unit 1, Lesson 3

## Topic
Adding a Two-Digit Number and a One-Digit Number (No Regrouping)

## Learning Objectives
By the end of this lesson, the student will be able to:
- Add a two-digit number and a one-digit number when the ones digits sum to 9 or less (e.g., 34 + 5 = 39)
- Explain that when adding ones to a two-digit number, the tens digit stays the same and only the ones digit changes
- Model the addition using base-ten blocks on a place value mat

## Prerequisites
- Lesson 2: Adding tens
- Fluent addition within 10 (e.g., 4 + 5 = 9)
- Ability to identify the tens and ones in a two-digit number

## Materials Needed
- Base-ten blocks (tens rods and ones cubes) — at least 9 tens and 15 ones
- Place value mat (paper with "Tens" and "Ones" columns)
- Hundred chart
- Paper and pencil

**Standards:** 2.NBT.5, 2.NBT.9

---

## Warm-Up (5 minutes)
**Purpose:** Activate prior knowledge and review spaced-practice items.

1. 40 + 30 = ___ (Review from Lesson 2)
2. 20 + 50 = ___ (Review from Lesson 2)
3. 4 + 3 = ___ (Single-digit fact — notice the connection to problem 1)
4. In the number 52, how many tens? ___ How many ones? ___ (Place value review)

Say: "Look at problems 1 and 3. Do you see how they are connected?" (40 + 30 is like 4 tens + 3 tens; 4 + 3 = 7, so 40 + 30 = 70.)

---

## Direct Instruction (15 minutes)
**Purpose:** Introduce adding a one-digit number to a two-digit number when no regrouping is needed.

### Key Vocabulary
- **Two-digit number:** A number with a tens digit and a ones digit (like 34, 52, 71)
- **One-digit number:** A number from 1 to 9
- **No regrouping:** When the ones add up to 9 or less, so we do not need to make a new ten

### Instruction Notes

**Step 1 — Build the problem with blocks (7 minutes)**

Write the problem: 34 + 5

Say: "Let's build 34 with base-ten blocks."
- Place 3 tens rods in the Tens column of the place value mat.
- Place 4 ones cubes in the Ones column.
- Say: "This is 34. 3 tens and 4 ones."

Say: "Now we are adding 5. Where should we put the 5?"
- Guide the student: "5 is ones, so we add 5 ones cubes to the Ones column."
- Place 5 more ones cubes in the Ones column.

Ask: "How many tens do we have now?" (Still 3.) "Did the tens change?" (No!)
Ask: "How many ones do we have now?" (4 + 5 = 9.) "What changed?" (The ones changed.)

Say: "So 34 + 5 = 39. The tens stayed at 3 and the ones went from 4 to 9."

**Step 2 — The big idea (3 minutes)**

Write on paper:
```
  34
+  5
----
  39
```

Point to the tens column: "The 3 did not change. We did not add any tens."
Point to the ones column: "4 + 5 = 9. We only added ones."

Say: "When we add a one-digit number, only the ones place changes. The tens place stays the same — as long as the ones do not add up to more than 9. We will talk about what happens when they do add to more than 9 in the next lesson."

**Step 3 — Hundred chart connection (3 minutes)**

On the hundred chart, find 34. Say: "Adding 5 means we move 5 spaces to the right."

Count: 35, 36, 37, 38, 39.

Say: "We stayed in the same row! That means we stayed in the 30s. The tens did not change."

Ask: "Why did we stay in the same row?" (Because we only added ones, not tens.)

**Step 4 — Try another together (2 minutes)**

Write: 52 + 6

Say: "Build 52. Now add 6 ones. How many tens? (5) How many ones? (2 + 6 = 8) So 52 + 6 = 58."

### Worked Examples

**Example 1:**
Problem: 34 + 5
- Step 1: Break apart 34. "34 = 3 tens + 4 ones."
- Step 2: Add the ones. "4 ones + 5 ones = 9 ones."
- Step 3: The tens stay the same. "3 tens = 30."
- Step 4: Combine. "30 + 9 = 39."
- Answer: 34 + 5 = 39

**Example 2:**
Problem: 61 + 7
- Step 1: Break apart 61. "61 = 6 tens + 1 one."
- Step 2: Add the ones. "1 one + 7 ones = 8 ones."
- Step 3: The tens stay the same. "6 tens = 60."
- Step 4: Combine. "60 + 8 = 68."
- Answer: 61 + 7 = 68

## Guided Practice (10 minutes)
**Purpose:** Practice the new skill together with facilitator support.

Have the student use base-ten blocks for problems 1-3, then try problems 4-5 without blocks.

1. 23 + 4 = ___
   - Ask: "How many tens in 23? How many ones? After you add 4 ones, how many ones now?"
2. 45 + 3 = ___
   - Ask: "Did the tens digit change? Why not?"
3. 71 + 8 = ___
   - If the student struggles: "Build 71 on the mat. Now add 8 cubes to the ones side. Count all the ones."
4. 52 + 6 = ___
   - Say: "Try this one in your head. What do you add? Which digit changes?"
5. 80 + 7 = ___
   - Ask: "80 has 0 ones. What happens when we add 7 ones?" (We go from 0 ones to 7 ones: 87.)

**Facilitator note:** By problem 4 or 5, encourage the student to try mental math. The pattern is simple: keep the tens digit, add the ones digits. If the student can articulate this rule, they understand the concept.

If the student attempts a problem like 45 + 3 and gets 75 (adding to the tens instead of ones), redirect: "The 3 is a one-digit number — it goes in the ones place. Show me with blocks."

## Check for Understanding (5 minutes)
**Purpose:** Quick formative assessment to gauge mastery.

### Exit Ticket

1. 43 + 5 = ___
2. 61 + 8 = ___
3. When you add 34 + 5, does the tens digit change? Circle: YES / NO. Explain why.

**Mastery Criteria:** All 3 correct. For problem 3, accept "No" with any explanation that mentions we are only adding ones, not tens (e.g., "No, because 5 is ones and we only change the ones place" or "No, the tens stay at 3 because we did not add any tens").

### If Mastery Is Not Met
- Return to base-ten blocks and the place value mat. Have the student build 5 more problems physically, saying aloud each time: "The tens stay the same. I only add to the ones."
- Focus on the pattern: Write several problems in a column and highlight that the tens digit never changes.
  - 21 + 3 = 24 (tens: 2, stays 2)
  - 45 + 4 = 49 (tens: 4, stays 4)
  - 70 + 6 = 76 (tens: 7, stays 7)
- Re-attempt the exit ticket after additional practice.

### If Mastery Is Met
Preview: "Today the ones always added to 9 or less, so the tens stayed the same. But what happens if the ones add to more than 9? Like 37 + 5? There are not enough ones — we will have more than 9 ones! Next lesson, you will learn how to trade 10 ones for 1 ten. It is called regrouping."

## Extension (Optional)
**Purpose:** Enrichment for students who finish early or demonstrate advanced understanding.

**Pattern Detective:** Have the student solve this series and describe the pattern:
- 31 + 1 = ___
- 31 + 2 = ___
- 31 + 3 = ___
- 31 + 4 = ___
- 31 + 5 = ___
- 31 + 6 = ___
- 31 + 7 = ___
- 31 + 8 = ___

Ask: "What pattern do you see?" (The tens stay at 3, the ones go up by 1 each time: 32, 33, 34, 35, 36, 37, 38, 39.)

Ask: "What would 31 + 9 equal?" (40.) "What happened to the tens digit?" (It changed to 4!) "Why?" (Because 1 + 9 = 10, and 10 ones becomes 1 new ten.) This is a great preview of Lesson 4.

**Real-World Connection:** "You have 42 baseball cards. Your grandparent gives you 7 more. How many do you have now? Did you get more tens of cards or just ones?"

## Teacher/Facilitator Notes

### Common Misconceptions
- **Adding to the wrong place:** A student might compute 34 + 5 as 84 (adding 5 to the tens). Redirect with base-ten blocks: "Where do 5 ones cubes go — in the tens column or the ones column?"
- **Thinking the answer must 'look different' in the tens place:** Some students expect both digits to change and may second-guess correct answers like 34 + 5 = 39 ("But the 3 did not change — is that right?"). Reassure them: "That is exactly right! You only added ones, so only the ones changed."
- **Confusing this with adding tens:** If the student computes 34 + 5 as 34 + 50 = 84, clarify: "5 is a one-digit number. It means 5 ones, not 5 tens. Five tens would be 50."

### Pacing Adjustments
- This lesson deliberately avoids regrouping. Every problem is chosen so the ones sum to 9 or less. This builds confidence before the more challenging Lesson 4.
- If the student grasps this quickly (within guided practice), you can spend more time on the extension activity, which naturally previews regrouping.
- If the student needs more time, cut the extension and add 3-4 more guided practice problems with blocks.

### Discussion Questions
- "How do you know whether to add to the tens place or the ones place?"
- "If 34 + 5 = 39, what do you think 34 + 50 would equal? Why is it different?"
- "Can you explain in your own words why the tens digit does not change when we add a small number?"
