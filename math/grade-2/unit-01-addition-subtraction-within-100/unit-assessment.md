## Section E: Word Problems

Read each aloud. Student solves and writes the number sentence.

**E1. (Result unknown)** "A library has 34 picture books and 28 chapter books. How many books does the library have in all?"
Answer: 62. Number sentence: 34 + 28 = 62.

**E2. (Change unknown)** "Tyler had 75 baseball cards. He gave some to his friend and now has 48. How many did he give away?"
Answer: 27. Number sentence: 75 − ___ = 48 (or 48 + ___ = 75).

**E3. (Two-step)** "Maria had 42 stickers. She got 25 more from her teacher. Then she gave 13 to her sister. How many stickers does Maria have now?"
Answer: 54. Number sentences: 42 + 25 = 67, then 67 − 13 = 54.

## Rubric and Mastery Determination

| Level | Score Range | Meaning | Next Steps |
|-------|-----------|---------|------------|
| **Mastered** | 18-21 (85-100%) with ≥1 per section | Solid two-digit addition and subtraction | Advance to Unit 2 (Fluency Within 20) and Unit 3 (Introduction to Multiplication). |
| **Approaching** | 15-17 (70-84%) | Most skills present, specific gaps | Reteach the section(s) with the lowest scores. Focus on regrouping if that's the gap. |
| **Developing** | Below 15 (<70%) | Significant gaps | Identify whether the issue is place value understanding, regrouping mechanics, or computation fluency. Address the root cause before advancing. |

### Section-Specific Reteaching Guide

| If struggling in... | Root cause | Focus on... |
|---|---|---|
| Section A (Fluency ≤20) | Grade 1 gap | Return to Grade 1 Unit 1 strategies. Within-20 fluency must be solid. |
| Section B (2-digit + 1-digit) | Regrouping likely | Return to Lesson 4. Use base-ten blocks for every problem until the "trade" is automatic. |
| Section C (2-digit + 2-digit) | Place value or regrouping | If no-regroup problems are correct but regrouping ones aren't → Lesson 6. If both wrong → Lesson 5 (place value decomposition). |
| Section D (Subtraction) | Regrouping in subtraction | Return to Lesson 9. Physical unbundling of tens rods. Think-addition as alternative strategy. |
| Section E (Word Problems) | Problem type comprehension | Return to Lesson 10. Use bar models. Practice identifying the unknown. |
| Section F (Conceptual) | Place value understanding | Spend extra time with base-ten blocks before computation. Build and read numbers daily. |
