# Math — Grade 2 — Unit 5, Lesson 6

## Topic
Three-Digit + Three-Digit Addition (No Regrouping)

## Learning Objectives
By the end of this lesson, the student will be able to:
- Add two three-digit numbers using the standard algorithm when no regrouping is needed
- Explain the addition process column by column using place value language
- Connect the algorithm to base-ten block models

## Prerequisites
- Lessons 1–5: All prior unit lessons
- Unit 4: Reading and writing three-digit numbers; expanded form
- Unit 1: Column addition algorithm for two-digit numbers

## Materials Needed
- Base-ten blocks: hundreds flats, tens rods, unit cubes (enough for two three-digit numbers)
- Two-color place value mats (or two separate mats side by side)
- Whiteboard and dry-erase marker
- Math journal
- Pencils

---

## Warm-Up (5 minutes)
**Purpose:** Build fluency with column-by-column addition; review place value.

**Activity — "Expanded Form Match-Up":**

Write on the board:
- 300 + 40 + 5 = ___
- 200 + 70 + 8 = ___
- 400 + 0 + 6 = ___
- 500 + 90 + 3 = ___

Students write the standard form on their whiteboards.

Then ask: "If I add 300 + 200, what do I get? (500). If I add 40 + 70? (110 — but keep this for discussion). If I add 5 + 8? (13 — same)."

"Today we're going to add numbers where the column sums are nice and easy — under 10 each time. Tomorrow and the next day we'll tackle the trickier ones."

---

## Direct Instruction (10–15 minutes)
**Purpose:** Introduce full three-digit + three-digit algorithm without regrouping, emphasizing place value structure.

### Key Vocabulary
- **Column addition:** Adding digits in the same place value position
- **Sum:** The total when you add two or more numbers

### Instruction Notes

**Concrete:**

Place two sets of base-ten blocks on the mat. Build 234 with one color (or on one side): 2 flats, 3 rods, 4 cubes. Build 152 with another marker or grouping: 1 flat, 5 rods, 2 cubes.

"To add these numbers, I bring them together column by column."

"Ones column: 4 cubes + 2 cubes = 6 cubes."
"Tens column: 3 rods + 5 rods = 8 rods."
"Hundreds column: 2 flats + 1 flat = 3 flats."

"My answer: 3 hundreds, 8 tens, 6 ones = 386."

Ask: "Did anything overflow? Did we need to trade?" (No.) "When the column totals are less than 10, we just write the digit straight down — no trades needed."

**Pictorial:**
Draw side-by-side sketches of both numbers. Combine by place and draw the result.

**Abstract:**
```
  234
+ 152
-----
  386
```
"I always start in the ones place and work left: 4+2=6, 3+5=8, 2+1=3. Answer: 386."

Walk through a second example together on the board, asking students to call out each column sum.

### Worked Examples

**Example 1:** 413 + 275 = ?
- Ones: 3 + 5 = 8
- Tens: 1 + 7 = 8
- Hundreds: 4 + 2 = 6
- **Answer: 688**

**Example 2:** 350 + 247 = ?
- Ones: 0 + 7 = 7
- Tens: 5 + 4 = 9
- Hundreds: 3 + 2 = 5
- **Answer: 597**

**Example 3:** 521 + 368 = ?
- Ones: 1 + 8 = 9
- Tens: 2 + 6 = 8
- Hundreds: 5 + 3 = 8
- **Answer: 889**

## Guided Practice (10 minutes)
**Purpose:** Students practice the column addition algorithm, verifying with blocks for the first two.

1. 312 + 245 = ___
2. 461 + 318 = ___
3. 204 + 693 = ___
4. 530 + 254 = ___
5. 123 + 456 = ___

**Facilitator guidance:** For problems 1–2, require students to first build with blocks. For 3–5, students may go straight to the algorithm. Watch for students who add left-to-right instead of right-to-left — this won't cause errors today (no regrouping), but it will in future lessons. Gently redirect to right-to-left: "It's a good habit to always start in the ones place."

## Independent Practice (10–15 minutes)

### Difficulty Tiers

**On-level:**
1. 235 + 342 = ___
2. 412 + 374 = ___
3. 601 + 297 = ___
4. 150 + 347 = ___
5. 483 + 214 = ___
6. ___ + 241 = 673 (missing addend — what three-digit number?)
7. 352 + ___ = 586 (missing addend)

**Stretch:**
8. A farmer grew 315 tomatoes and 264 cucumbers. How many vegetables in all?
9. Two trains carry passengers. Train A has 452 riders and Train B has 345 riders. How many riders are there altogether?
10. Use the digits 1, 2, 3, 4, 5, and 6 (each once) to make a three-digit + three-digit addition problem with the greatest possible sum. (No regrouping required — arrange so no column sums to 10 or more.)

**Challenge:**
11. Is it possible to add two three-digit numbers (with no regrouping) and get a sum greater than 900? Give an example or explain why not.
12. A zoo has 432 fish and 261 birds. A new shipment brings 106 more animals (all birds). How many animals does the zoo now have in total?
13. Create two different three-digit + three-digit addition problems that both have the sum 777. (No regrouping.)

## Check for Understanding (3 minutes)
**Exit Ticket:**
Solve and explain:
1. 324 + 253 = ___
2. "I added column by column starting from the ______ place. My answer is ______."

**Mastery = 577 and explanation correctly identifies ones place as starting point.**

### If Mastery Is Not Met
Have student use blocks to build both numbers separately, then combine column by column physically. Narrate each step: "I'm putting the ones together: 4 and 3 make 7. I'm putting the tens together: 2 and 5 make 7. I'm putting the hundreds together: 3 and 2 make 5. My answer is 577."

### If Mastery Is Met
Challenge: "My friend got 597 for 324 + 253. What mistake might they have made?" (Likely added ones together as 4+3=7, tens as 2+5=7, but then added hundreds as 3+2 and wrote 5 in hundreds but also 9 in tens by accident — discussion will vary. Or student may identify an unreachable answer and invent a plausible error.)

---

## Extension (Optional)
**"Secret Sum" Puzzle:**
Using only the digit cards 1, 2, 3, 4, 5, 6, 7, 8, students create two three-digit numbers that add to the largest possible sum without any column exceeding 9 (no regrouping). Then find the pair that gives the smallest sum. Discuss strategies.

---

## Teacher/Facilitator Notes
- This lesson establishes the "clean" version of the algorithm before introducing regrouping in Lesson 7. Do not introduce problems that require regrouping today — the goal is fluency with the procedure and place value language.
- The right-to-left habit for column addition is important. Reinforce it even when it doesn't matter yet, so it's automatic for when regrouping is introduced.
- Students may wonder why they need to use an algorithm at all for some of these "easy" problems. Validate this: "You're right that some are easy to do in your head! The algorithm is especially useful for harder problems — we're learning the steps now so they're automatic later."
- Connect to 2.NBT.9 throughout: "Why do we add ones first? Tens next? Hundreds last?"
