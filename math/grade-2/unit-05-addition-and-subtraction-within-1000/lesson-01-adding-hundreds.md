# Math — Grade 2 — Unit 5, Lesson 1

## Topic
Adding Hundreds to Three-Digit Numbers

## Learning Objectives
By the end of this lesson, the student will be able to:
- Add multiples of 100 to any three-digit number mentally
- Explain why only the hundreds digit changes when adding hundreds
- Use a number line and base-ten blocks to model adding hundreds

## Prerequisites
- Understanding of place value to 1,000 (hundreds, tens, ones)
- Ability to read and write three-digit numbers in standard and expanded form
- Familiarity with counting by 100s

## Materials Needed
- Base-ten blocks: hundreds flats, tens rods, unit cubes
- Place value mat (Hundreds | Tens | Ones) per student
- Number line (0–1,000 marked by hundreds) displayed at front
- Dry-erase whiteboard and marker per student
- Math journal

---

## Warm-Up (5 minutes)
**Purpose:** Activate prior knowledge of skip-counting by 100s and place value structure.

**Activity — "Count the Flats":**
Place a pile of base-ten hundreds flats on the table. Ask students to count along as you reveal them one at a time: "100, 200, 300, 400…" up to 900.

Then ask:
- "If I have 3 flats, what number is that?" (300)
- "If I have 5 flats and 2 rods, what number?" (520)
- "If I have 4 flats, 1 rod, and 3 cubes?" (413)

Keep this quick — 4–5 questions. The goal is fluency with reading base-ten representations.

---

## Direct Instruction (10–15 minutes)
**Purpose:** Build understanding that adding hundreds affects only the hundreds place.

### Key Vocabulary
- **Hundreds place:** The position in a three-digit number that shows groups of 100
- **Mental math:** Computing an answer in your head without writing it down

### Instruction Notes

**Start with the concrete (base-ten blocks):**

Build 234 on the place value mat using 2 flats, 3 rods, 4 cubes. Say: "This is 234. I can see 2 hundreds, 3 tens, and 4 ones."

"Now I want to add 300. Let me put 3 more flats in the hundreds column." (Add 3 flats to the mat.)

"What do we have now? Let's count the hundreds: 1, 2, 3, 4, 5. Five hundreds! The tens and ones didn't change — still 3 tens and 4 ones. So 234 + 300 = 534."

Ask: "What was the only thing that changed in our number?" (The hundreds digit.)

**Move to pictorial:**

Draw on the board: a quick sketch of 2 squares (hundreds), 3 lines (tens), 4 dots (ones). Then add 3 more squares. Count and write 534.

**Move to abstract:**

Write on board:
```
  234
+ 300
-----
```
"In the ones place: 4 + 0 = 4. In the tens place: 3 + 0 = 3. In the hundreds place: 2 + 3 = 5. The answer is 534."

Emphasize: "When we add a multiple of 100, only the hundreds digit changes."

### Worked Examples

**Example 1:** 450 + 300 = ?
- Concrete: Build 450 (4 flats, 5 rods, 0 cubes). Add 3 flats.
- Count: 7 flats, 5 rods, 0 cubes = 750.
- Abstract: 4 + 3 = 7 hundreds, tens and ones stay the same. **Answer: 750**

**Example 2:** 362 + 500 = ?
- Hundreds: 3 + 5 = 8. Tens: 6. Ones: 2.
- **Answer: 862**

**Example 3:** 100 + 400 = ?
- "Even though 100 looks like just a hundreds number, we can still think about it the same way."
- Hundreds: 1 + 4 = 5. **Answer: 500**

## Guided Practice (10 minutes)
**Purpose:** Students practice adding hundreds with facilitator support, using blocks first then moving to abstract.

Have students build each number on their place value mat, then add the hundreds, then write the equation.

1. 321 + 200 = ___
2. 540 + 400 = ___
3. 115 + 600 = ___
4. 700 + 200 = ___
5. 463 + 300 = ___

**Facilitator guidance:** Circulate as students work. Ask: "Which digit changed? Which stayed the same?" If a student makes an error, direct them back to the blocks: "Can you show me 321 with your blocks first?"

## Independent Practice (10–15 minutes)

### Difficulty Tiers

**On-level:**
1. 241 + 300 = ___
2. 530 + 200 = ___
3. 127 + 400 = ___
4. 600 + 300 = ___
5. 352 + 500 = ___
6. ___ + 200 = 700 (missing addend)
7. 418 + ___ = 718 (missing addend)

**Stretch:**
8. 234 + 300 + 200 = ___ (add two chunks of hundreds)
9. 149 + 400 = ___ (sum crosses through a new hundred)
10. I have 562 stickers. My friend gives me 300 more. How many do I have now?

**Challenge:**
11. Start at 327. Add 100 five times. Where do you end up? Write the equation.
12. What number + 400 = 900? How did you figure it out?
13. Maya has 236 beads. She buys 3 bags of 100 beads each. How many beads does she have now?

### Interleaved Review
*(Skills from Units 1–4)*

R1. 67 + 25 = ___ *(Unit 1: two-digit addition with regrouping)*
R2. Write 508 in expanded form. *(Unit 4: expanded form)*
R3. 14 − 8 = ___ *(Unit 2: subtraction within 20)*

## Check for Understanding (3 minutes)
**Exit Ticket:**
1. 473 + 200 = ___
2. Circle the digit that changed: **6**73 → 473 + 200 → ___**_**3

**Mastery = both answers correct AND student can identify that only the hundreds digit changes.**

### If Mastery Is Not Met
Return to base-ten blocks. Have student build the starting number, then physically add the hundreds flats, then read the new number aloud before writing it. Repeat with one more example before tomorrow's lesson.

### If Mastery Is Met
Challenge: "Can you find a three-digit number where adding 400 would give you exactly 1,000? How many are there?" (Any number from 600–609 where the tens and ones sum to zero — i.e., only 600 gives exactly 1,000. But encourage exploration.)

---

## Extension (Optional)
**"Hundreds Race" Game (partner activity):**
Shuffle digit cards 1–9. Player 1 draws two cards and makes a two-digit number for the tens and ones (e.g., draws 3 and 7 → tens digit = 3, ones = 7, so 137 starting number). Player 2 draws a card for how many hundreds to add (1–9). Both players race to find the sum. First correct answer earns a point. Play 5 rounds.

---

## Teacher/Facilitator Notes
- Students who struggled with expanded form in Unit 4 will need extra support at the concrete stage. Do not rush them to the abstract.
- Some students may try to add all digits together (e.g., 234 + 300 → 234 + 3 = 237). Redirect to place value mat.
- This lesson sets the mental math foundation for 2.NBT.8. Invest time here — the pattern (only the hundreds digit changes) must be internalized before the next lessons.
- If time allows, connect to the number line: "If I start at 234 and jump 3 hundreds forward, where do I land?"
