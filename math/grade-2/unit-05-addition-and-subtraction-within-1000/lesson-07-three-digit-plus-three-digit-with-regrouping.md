# Math — Grade 2 — Unit 5, Lesson 7

## Topic
Three-Digit + Three-Digit Addition with Regrouping

## Learning Objectives
By the end of this lesson, the student will be able to:
- Add two three-digit numbers with regrouping in the ones and/or tens place
- Correctly record regrouping in the standard algorithm
- Explain why regrouping is necessary using place value language

## Prerequisites
- Lesson 5: Three-digit + two-digit with regrouping in ones
- Lesson 6: Three-digit + three-digit, no regrouping
- Unit 4: 10 ones = 1 ten; 10 tens = 1 hundred

## Materials Needed
- Base-ten blocks: hundreds flats, tens rods, unit cubes (enough for both addends)
- Place value mat per student
- Whiteboard and dry-erase marker
- Math journal
- Anchor chart from Lesson 5: "Steps for Adding with Regrouping" (still posted)

---

## Warm-Up (5 minutes)
**Purpose:** Review ones-regrouping from Lesson 5 and column addition from Lesson 6.

**"Which needs regrouping?" (whiteboard activity):**

Show each pair of ones digits. Students circle YES or NO on their board.

- Ones: 7 + 6 = ? → YES (13)
- Tens: 4 + 3 = ? → NO (7)
- Ones: 8 + 5 = ? → YES (13)
- Tens: 5 + 8 = ? → YES (13 — includes tens regrouping)
- Ones: 3 + 4 = ? → NO (7)
- Tens: 9 + 4 = ? → YES (13)

"Today we'll use these decisions while adding full three-digit numbers — and sometimes BOTH the ones and tens will regroup!"

---

## Direct Instruction (10–15 minutes)
**Purpose:** Develop algorithm for three-digit + three-digit with regrouping in ones place only, then ones AND tens.

### Key Vocabulary
- **Double regrouping:** When both the ones column and the tens column produce a sum ≥ 10, requiring two separate trades

### Instruction Notes

**Part 1 — Regrouping Ones Only (concrete):**

Build 364 + 248 on the place value mat.

"Ones: 4 + 8 = 12. Trade 10 cubes for 1 rod. Write 2 in ones, carry 1 ten."
"Tens: 6 + 4 + 1 (carried) = 11. Wait — 11 tens is less than 10? No! 11 ≥ 10! We need to trade again!"

Pause and let students notice: the tens column also needs regrouping! This may be a surprise.

"Trade 10 rods for 1 flat. Write 1 in tens, carry 1 hundred."
"Hundreds: 3 + 2 + 1 (carried) = 6."
"Answer: 364 + 248 = 612."

Let students see this is the same process they learned, just applied twice.

**Abstract:**
```
   1 1
   364
+  248
------
   612
```

"The '1' above the tens is from regrouping ones. The '1' above the hundreds is from regrouping tens. Both carried 1s must be added."

**Part 2 — Regrouping Tens Only:**

Build 253 + 471:
"Ones: 3 + 1 = 4. No regroup."
"Tens: 5 + 7 = 12. Regroup! Write 2, carry 1."
"Hundreds: 2 + 4 + 1 = 7."
"Answer: 724."

**Abstract:**
```
    1
  253
+ 471
-----
  724
```

### Worked Examples

**Example 1 (ones regroup):** 347 + 425 = ?
- Ones: 7 + 5 = 12. Write 2, carry 1.
- Tens: 4 + 2 + 1 = 7. No regroup.
- Hundreds: 3 + 4 = 7.
- **Answer: 772**

**Example 2 (tens regroup):** 183 + 451 = ?
- Ones: 3 + 1 = 4. No regroup.
- Tens: 8 + 5 = 13. Write 3, carry 1.
- Hundreds: 1 + 4 + 1 = 6.
- **Answer: 634**

**Example 3 (both regroup):** 476 + 358 = ?
- Ones: 6 + 8 = 14. Write 4, carry 1.
- Tens: 7 + 5 + 1 = 13. Write 3, carry 1.
- Hundreds: 4 + 3 + 1 = 8.
- **Answer: 834**

## Guided Practice (10 minutes)
**Purpose:** Students practice with increasing complexity; facilitator monitors the "double carry" step.

Before solving, students predict: "Ones regroup? YES/NO. Tens regroup? YES/NO."

1. 254 + 318 = ___
2. 467 + 215 = ___
3. 385 + 247 = ___
4. 576 + 358 = ___
5. 649 + 174 = ___

**Facilitator guidance:** Problem 3 involves regrouping in both ones and tens (5+7=12; 8+4+1=13). Problem 4 also has both (6+8=14; 7+5+1=13). Problem 5: 9+4=13, 4+7+1=12. Watch for students who forget to add the carried 1 to the tens before deciding whether the tens regroup. Ask: "What's in the tens column? Don't forget the carried 1!"

## Check for Understanding (3 minutes)
**Exit Ticket:**
1. Solve: 457 + 378 = ___
2. Label each regrouping with a small arrow or circle. How many times did you need to regroup?

**Mastery = 835 with both regrouping steps identified (ones: 7+8=15; tens: 5+7+1=13).**

### If Mastery Is Not Met
Revisit with blocks. First practice a ones-only regroup (e.g., 345 + 427), then a tens-only regroup (e.g., 253 + 371), before attempting double-regroup. Each step should be verbalized.

### If Mastery Is Met
Challenge: "Can you create a problem where the hundreds column ALSO needs regrouping? What would happen then? Try 567 + 543." (Answer: 567 + 543 = 1,110; ones: 7+3=10, write 0 carry 1; tens: 6+4+1=11, write 1 carry 1; hundreds: 5+5+1=11, write 1 carry 1; thousands: 1. This previews four-digit sums.)

## Extension (Optional)
**"Sum Detectives":**
Give students a completed but partially erased addition problem (some digits replaced with blanks). Students work backward to find the missing digits, using their knowledge of the regrouping rules.

Example:
```
    1
  3_4
+ _57
-----
  861
```
(Answer: 304 + 557 = 861)

## Teacher/Facilitator Notes
- Double regrouping is the main challenge of this lesson. Students who understand single regrouping well will grasp this naturally; students who were shaky on Lesson 5 or 6 will need extra support.
- The prediction step in Guided Practice ("Does ones regroup? Does tens regroup?") builds metacognitive awareness that reduces mechanical errors.
- Emphasize that the "2" in the sum of 364 + 248 = 612 comes from two separate regroupings — this can feel magical to students. Use blocks to make it concrete.
- Connect to 2.NBT.9: "Why does it make sense that we might need to regroup twice?"
- If a student arrives at a four-digit answer (e.g., when both hundreds add to 10+), validate the observation and preview future learning rather than marking it wrong.
