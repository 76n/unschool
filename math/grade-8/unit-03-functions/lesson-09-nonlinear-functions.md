# Math — Grade 8 — Unit 3, Lesson 9

## Topic
Nonlinear Functions

## Learning Objectives
- Identify nonlinear functions from tables by recognizing a non-constant rate of change.
- Identify nonlinear functions from graphs by recognizing curves (not straight lines).
- Describe qualitative features of a graph: increasing, decreasing, linear, and nonlinear intervals.
- Sketch a graph that matches a qualitative description of a function.

## Prerequisites
- Understanding of linear functions and constant rate of change (Lesson 4)
- Ability to calculate differences between consecutive table entries (Lesson 4)
- Familiarity with graphing on the coordinate plane (Lessons 3-6)

## Materials Needed
- Whiteboard and markers (or projector).
- Graph paper or pre-printed coordinate planes.
- Student worksheet (Guided Practice and Independent Practice problems).
- Index cards or half-sheets for Exit Ticket.

**Standards:** 8.F.3 — Interpret the equation y = mx + b as defining a linear function, whose graph is a straight line; give examples of functions that are not linear. 8.F.5 — Describe qualitatively the functional relationship between two quantities by analyzing a graph (e.g., where the function is increasing or decreasing, linear or nonlinear). Sketch a graph that exhibits the qualitative features of a function that has been described verbally.

## Warm-Up (5 minutes)
**Purpose:** Contrast linear and nonlinear patterns in tables.

1. Table A:

   | x | y |
   |---|---|
   | 0 | 2 |
   | 1 | 5 |
   | 2 | 8 |
   | 3 | 11 |

   Is this linear or nonlinear? (Linear — constant change of +3.)

2. Table B:

   | x | y |
   |---|---|
   | 0 | 1 |
   | 1 | 4 |
   | 2 | 9 |
   | 3 | 16 |

   Is this linear or nonlinear? (Nonlinear — changes are +3, +5, +7, not constant.)

3. Ask: "We have focused on linear functions for several lessons. But not everything in the world follows a straight line. Today we explore functions that curve, bend, and behave in more complex ways."

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Nonlinear function** — a function whose graph is NOT a straight line; its rate of change is NOT constant.
- **Increasing** — a portion of a graph where the y-values go UP as x-values increase (the graph rises from left to right).
- **Decreasing** — a portion of a graph where the y-values go DOWN as x-values increase (the graph falls from left to right).
- **Constant** — a portion of a graph where the y-values stay the SAME as x-values increase (the graph is flat).
- **Qualitative description** — describing the overall shape and behavior of a graph without using specific numbers.

### Instruction Notes

**Step 1 — Review what makes a function nonlinear.**

Say: "A linear function has a constant rate of change — the same slope everywhere. A nonlinear function does NOT. Its rate of change varies: sometimes it grows slowly, sometimes quickly. On a graph, this shows up as a curve instead of a straight line."

**Step 2 — Show common nonlinear patterns in tables.**

Write Table 1 (quadratic pattern):

| x | y | Change |
|---|---|--------|
| 0 | 0 | — |
| 1 | 1 | +1 |
| 2 | 4 | +3 |
| 3 | 9 | +5 |
| 4 | 16 | +7 |

Say: "The changes are +1, +3, +5, +7 — they increase by 2 each time but are NOT constant. This is y = x^2, a quadratic function. Its graph is a U-shaped curve called a parabola."

Write Table 2 (exponential pattern):

| x | y | Change |
|---|---|--------|
| 0 | 1 | — |
| 1 | 2 | +1 |
| 2 | 4 | +2 |
| 3 | 8 | +4 |
| 4 | 16 | +8 |

Say: "The changes are +1, +2, +4, +8 — they DOUBLE each time. This is y = 2^x, an exponential function. Its graph curves upward, slowly at first, then very steeply."

Write Table 3 (another nonlinear pattern):

| x | y | Change |
|---|---|--------|
| 0 | 100 | — |
| 1 | 50 | -50 |
| 2 | 25 | -25 |
| 3 | 12.5 | -12.5 |
| 4 | 6.25 | -6.25 |

Say: "This function decreases, but NOT by the same amount each time. Each change is half of the previous change. This is exponential decay. The graph curves downward, dropping quickly at first, then leveling off."

**Step 3 — Describe qualitative features of graphs.**

Say: "When we describe a graph qualitatively, we talk about its general behavior without focusing on exact numbers. We use four key terms: increasing, decreasing, linear, and nonlinear."

Describe Graph A (a ball thrown upward): "Imagine a graph that starts at y = 5 (the initial height), curves upward to a peak at about y = 40, then curves back down to y = 0. This graph is INCREASING on the left side (the ball goes up), reaches a maximum, and then is DECREASING on the right side (the ball comes down). The graph is NONLINEAR because it is a curve, not a straight line."

Describe Graph B (filling a pool, then it overflows): "Imagine a graph that rises in a straight line from (0, 0) to (10, 500), then becomes flat (horizontal) at y = 500 after x = 10. The first part is LINEAR and INCREASING. The second part is LINEAR and CONSTANT (neither increasing nor decreasing)."

Describe Graph C (a runner who speeds up): "Imagine a graph that starts at (0, 0) and curves upward, getting steeper and steeper — like a skateboard ramp. The graph is always INCREASING, but it is NONLINEAR because the rate of increase changes."

**Step 4 — Sketching a graph from a verbal description.**

Say: "If I tell you: 'The temperature rose slowly at first, then rose quickly, then leveled off,' you should sketch a graph that goes up gently on the left, curves to go up steeply in the middle, and then flattens out on the right. The graph would be nonlinear and mostly increasing, becoming constant at the end."

Say: "You do not need to know exact values for a qualitative sketch. The shape and direction matter most."

### Worked Examples

**Example A: Identifying nonlinear from a table**
| x | y |
|---|---|
| 0 | 3 |
| 1 | 5 |
| 2 | 11 |
| 3 | 21 |
| 4 | 35 |

Changes: +2, +6, +10, +14. The changes increase by 4 each time but are NOT constant. **This is nonlinear.**

For comparison, if this were linear with a constant change of +8, the table would be: 3, 11, 19, 27, 35. The actual table does not match this pattern.

**Example B: Describing qualitative features**
A graph shows a line going upward from (0, 0) to (5, 20), then a curve going downward from (5, 20) to (10, 0).

Description: "The function is INCREASING and LINEAR from x = 0 to x = 5. Then it is DECREASING and NONLINEAR from x = 5 to x = 10. The maximum value occurs at x = 5."

**Example C: Sketching from a description**
"A car accelerates from rest (starts at speed 0), speeds up quickly, then gradually reaches a constant cruising speed."

Sketch description: The graph starts at (0, 0). It curves upward steeply at first (rapid acceleration), then the curve bends and becomes flatter (slowing acceleration), and eventually becomes a horizontal line (constant speed). The graph is NONLINEAR and INCREASING on the left, then LINEAR and CONSTANT on the right.

## Guided Practice (10 minutes)

Work through these problems together. The student attempts each problem first, then discusses.

1. Is this function linear or nonlinear?

   | x | y |
   |---|---|
   | 0 | 5 |
   | 1 | 10 |
   | 2 | 20 |
   | 3 | 40 |
   | 4 | 80 |

   - *Answer:* Changes: +5, +10, +20, +40. Not constant (they double each time). **Nonlinear.** This is an exponential function (y = 5 * 2^x).

2. Which equation is nonlinear: y = 7x - 3 or y = x^2 + 1? Explain.
   - *Answer:* y = x^2 + 1 is nonlinear because the variable x is squared. y = 7x - 3 is linear (in the form y = mx + b).

3. Describe the qualitative features of this graph: A straight line that goes from (0, 50) downward to (10, 0).
   - *Answer:* The function is DECREASING and LINEAR over the entire interval. It starts at 50 and decreases at a constant rate to 0.

4. Describe the qualitative features of this graph: A curve that starts at (0, 0), rises steeply to (3, 27), then continues rising but less steeply to (6, 36).
   - *Answer:* The function is INCREASING and NONLINEAR. It increases rapidly at first, then increases more slowly. The rate of increase is slowing down.

5. Sketch a graph (describe the shape) for this situation: "A population grows slowly at first, then faster and faster over time."
   - *Answer:* The graph starts near the x-axis and rises gently. As you move to the right, the curve gets steeper and steeper, curving upward dramatically. The function is always INCREASING and NONLINEAR. This is typical of exponential growth.

**Facilitator tip:** Students may confuse "nonlinear" with "not a function." Clarify: a nonlinear function IS still a function (each input has one output). It just does not have a constant rate of change. The graph curves, but it still passes the vertical line test.

## Independent Practice (10-15 minutes)

### Part A: Identifying Nonlinear Functions
Classify each function as linear or nonlinear. Explain your reasoning.

1. | x | y |
   |---|---|
   | 0 | -4 |
   | 1 | -1 |
   | 2 | 2 |
   | 3 | 5 |

2. | x | y |
   |---|---|
   | 0 | 1 |
   | 1 | 3 |
   | 2 | 9 |
   | 3 | 27 |

3. y = 2x + 8
4. y = x^2 - 5
5. y = 3^x
6. y = -4x

### Part B: Describing Qualitative Features
Describe the qualitative features of each graph (increasing/decreasing, linear/nonlinear).

7. A graph that shows a straight line rising from (0, 0) to (8, 24).
8. A graph that curves upward from (0, 1), slowly at first, then very steeply by x = 5, reaching y = 32.
9. A graph that starts at (0, 100), curves steeply downward to about (3, 20), then continues to decrease very slowly, approaching y = 0 but never quite reaching it.
10. A graph that rises linearly from (0, 0) to (3, 12), stays flat from (3, 12) to (6, 12), then drops linearly from (6, 12) to (9, 0).

### Part C: Word Problems

11. A ball is dropped from a height of 100 feet. The height at each second is: 0 sec = 100 ft, 1 sec = 84 ft, 2 sec = 36 ft, 3 sec = 0 ft. Is the height a linear or nonlinear function of time? Explain.
12. Describe a real-world scenario that would produce a graph that is increasing and nonlinear. Sketch what the graph would look like (describe the shape in words).

### Answer Key

**Part A**
1. Changes: +3, +3, +3. Constant rate of change. **Linear.** (y = 3x - 4)
2. Changes: +2, +6, +18. Not constant (tripling). **Nonlinear.** (y = 3^x)
3. **Linear.** It is in the form y = mx + b (m = 2, b = 8).
4. **Nonlinear.** The x^2 term means the rate of change is not constant.
5. **Nonlinear.** The variable x is in the exponent, which creates exponential growth.
6. **Linear.** It is in the form y = mx + b (m = -4, b = 0).

**Part B**
7. The function is INCREASING and LINEAR. It rises at a constant rate from left to right. The slope is (24 - 0)/(8 - 0) = 3.
8. The function is INCREASING and NONLINEAR. It starts with a slow increase, then the increase accelerates dramatically. This is typical of exponential growth.
9. The function is DECREASING and NONLINEAR. It starts with a steep decrease that gradually slows down. The graph approaches y = 0 but does not reach it. This is typical of exponential decay.
10. The function has three parts: (1) INCREASING and LINEAR from x = 0 to x = 3; (2) CONSTANT (neither increasing nor decreasing) and LINEAR from x = 3 to x = 6; (3) DECREASING and LINEAR from x = 6 to x = 9.

**Part C**
11. Heights: 100, 84, 36, 0. Changes: -16, -48, -36. The changes are NOT constant, so the height is a **nonlinear** function of time. (Falling objects accelerate due to gravity, so the distance fallen each second increases. The actual equation is h = -16t^2 + 100.)
12. Acceptable examples: compound interest in a savings account (the balance grows faster as the interest earns interest on interest). The graph starts low and curves upward, getting steeper over time. It is always increasing but never forms a straight line. Another example: a viral social media post — views grow slowly at first, then explode as more people share it.

## Assessment Check

### Exit Ticket
**Problem 1:** Is the function y = x^2 + 3 linear or nonlinear? Explain.
**Problem 2:** Describe the qualitative features of a graph that starts at (0, 50), drops steeply and curves to (4, 10), then drops slowly and nearly levels off near y = 2.

**Target response:**
1. Nonlinear. The x^2 term means the rate of change is not constant. When x changes from 0 to 1, y changes by 1 (from 3 to 4). When x changes from 1 to 2, y changes by 3 (from 4 to 7). The changes are not equal.
2. The function is DECREASING throughout. It is NONLINEAR because the graph curves — it drops quickly at first and then more slowly. The function appears to approach a value near y = 2 but may never reach it. This is similar to exponential decay.

## Extension

- **Linear vs. Nonlinear Data Collection:** Drop a ball from different heights (e.g., 50 cm, 100 cm, 150 cm, 200 cm) and measure how high it bounces. Record the data and plot it. Is the relationship between drop height and bounce height linear or nonlinear? (For most balls on hard surfaces, the relationship is approximately linear within a reasonable range.)
- **Qualitative Graph Storytelling:** Create a graph with at least four distinct sections (some increasing, some decreasing, some linear, some nonlinear). Then write a real-world story that matches the graph. Trade stories with the facilitator and see if you can each sketch the other person's graph from the description alone.
