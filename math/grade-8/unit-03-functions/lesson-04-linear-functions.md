# Math — Grade 8 — Unit 3, Lesson 4

## Topic
Linear Functions

## Learning Objectives
- Define a linear function as a function with a constant rate of change.
- Identify whether a function is linear from a table by checking for a constant rate of change.
- Identify whether a function is linear from a graph by checking if the graph is a straight line.
- Distinguish between linear and nonlinear functions using tables and graphs.

## Prerequisites
- Understanding of functions and multiple representations (Lessons 1-3)
- Ability to calculate the difference between consecutive values in a table
- Ability to recognize straight lines vs. curves on a graph

## Materials Needed
- Whiteboard and markers (or projector).
- Graph paper or pre-printed coordinate planes.
- Ruler or straightedge.
- Student worksheet (Guided Practice and Independent Practice problems).
- Index cards or half-sheets for Exit Ticket.

**Standards:** 8.F.3 — Interpret the equation y = mx + b as defining a linear function, whose graph is a straight line; give examples of functions that are not linear.

## Warm-Up (5 minutes)
**Purpose:** Observe patterns in tables to prepare for identifying constant vs. non-constant rates of change.

1. Look at Table A:

   | x | y |
   |---|---|
   | 1 | 5 |
   | 2 | 8 |
   | 3 | 11 |
   | 4 | 14 |

   What is the change in y each time x increases by 1? (+3 each time)

2. Look at Table B:

   | x | y |
   |---|---|
   | 1 | 2 |
   | 2 | 4 |
   | 3 | 8 |
   | 4 | 16 |

   What is the change in y each time x increases by 1? (+2, then +4, then +8 — it changes!)

3. Ask: "One of these tables shows a function that increases by the same amount each step. The other does not. Today we will learn the name for each type."

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Linear function** — a function that has a constant rate of change. Its graph is a straight line, and its equation can be written in the form y = mx + b.
- **Nonlinear function** — a function that does NOT have a constant rate of change. Its graph is a curve (not a straight line).
- **Rate of change** — how much the output (y) changes for each unit increase in the input (x). In a linear function, this rate is the same everywhere.
- **Constant rate of change** — a rate of change that does not vary; the y-values increase (or decrease) by the same amount for each equal step in x.

### Instruction Notes

**Step 1 — Define linear functions.**

Write on the board: "A linear function has a CONSTANT rate of change. Its graph is a STRAIGHT LINE."

Say: "The word 'linear' comes from 'line.' If you can draw the graph of a function with a ruler — one perfectly straight line — then the function is linear. If the graph curves, bends, or wiggles, it is nonlinear."

**Step 2 — Identify linear functions from tables.**

Write Table 1:

| x | y | Change in y |
|---|---|------------|
| 0 | 3 | — |
| 1 | 7 | +4 |
| 2 | 11 | +4 |
| 3 | 15 | +4 |
| 4 | 19 | +4 |

Say: "Every time x increases by 1, y increases by 4. The rate of change is CONSTANT at +4. This is a linear function. Its equation is y = 4x + 3."

Write Table 2:

| x | y | Change in y |
|---|---|------------|
| 0 | 1 | — |
| 1 | 3 | +2 |
| 2 | 9 | +6 |
| 3 | 27 | +18 |
| 4 | 81 | +54 |

Say: "Here the changes are +2, +6, +18, +54 — NOT constant. This is a nonlinear function. In fact, this is y = 3^x, an exponential function. You will study these more in high school."

**Step 3 — Identify linear functions from graphs.**

Describe Graph 1: "Picture a straight line that goes through (0, 2) and rises steadily to (4, 10). You could lay a ruler along it and every point would touch the ruler. This IS a linear function."

Describe Graph 2: "Picture a curve that starts at (0, 0), curves upward slowly at first, then steeper and steeper, passing through (1, 1), (2, 4), (3, 9). This is a parabola — the graph of y = x^2. It curves, so it is NOT a linear function."

Describe Graph 3: "Picture a curve that starts high at (0, 100) and drops quickly at first, then levels off, approaching but never reaching 0. This curve is NOT a straight line, so it is NOT a linear function."

**Step 4 — Connect to the equation form y = mx + b.**

Say: "Every linear function can be written in the form y = mx + b, where m and b are numbers. The m tells you the rate of change (how much y changes per step), and b tells you the starting value (the y-value when x = 0). We will study this form in detail in Lessons 5 and 6."

Give quick examples:
- y = 2x + 5 — linear (m = 2, b = 5).
- y = -3x + 1 — linear (m = -3, b = 1).
- y = x^2 — NOT linear (there is an x^2, not just x).
- y = 7 — linear! (m = 0, b = 7 — it is a horizontal line).

Say: "A quick check for equations: if x appears only to the first power (no x^2, no x^3, no square roots of x, no x in a denominator), the function is linear."

### Worked Examples

**Example A: Table — linear or nonlinear?**

| x | y |
|---|---|
| 0 | -2 |
| 1 | 1 |
| 2 | 4 |
| 3 | 7 |
| 4 | 10 |

Changes in y: +3, +3, +3, +3. The rate of change is constant at +3. **Linear.** Equation: y = 3x - 2.

**Example B: Table — linear or nonlinear?**

| x | y |
|---|---|
| 0 | 0 |
| 1 | 1 |
| 2 | 4 |
| 3 | 9 |
| 4 | 16 |

Changes in y: +1, +3, +5, +7. The rate of change is NOT constant. **Nonlinear.** (This is y = x^2.)

**Example C: Equation — linear or nonlinear?**
Is y = -5x + 12 a linear function?

Yes. It is in the form y = mx + b, with m = -5 and b = 12. The graph would be a straight line with a constant rate of change of -5. **Linear.**

## Guided Practice (10 minutes)

Work through these problems together. The student attempts each problem first, then discusses.

1. Is this function linear or nonlinear?

   | x | y |
   |---|---|
   | 0 | 10 |
   | 1 | 8 |
   | 2 | 6 |
   | 3 | 4 |
   | 4 | 2 |

   - *Answer:* Changes: -2, -2, -2, -2. Constant rate of change. **Linear.** Equation: y = -2x + 10.

2. Is this function linear or nonlinear?

   | x | y |
   |---|---|
   | 1 | 2 |
   | 2 | 6 |
   | 3 | 12 |
   | 4 | 20 |
   | 5 | 30 |

   - *Answer:* Changes: +4, +6, +8, +10. Not constant. **Nonlinear.**

3. A graph shows a perfectly straight line going from (0, -3) up to (6, 9). Is this a linear function?
   - *Answer:* Yes. A straight line indicates a linear function.

4. Is y = x^3 a linear function? Why or why not?
   - *Answer:* No. The variable x is raised to the third power. Linear functions have x raised only to the first power. A quick check: when x = 1, y = 1; when x = 2, y = 8; when x = 3, y = 27. The changes (+7, +19) are not constant.

5. Is y = 6 a linear function? Why or why not?
   - *Answer:* Yes. This can be written as y = 0x + 6, which is in the form y = mx + b with m = 0. The graph is a horizontal line. The rate of change is 0 (y never changes), which is constant.

6. A car travels at a steady 55 miles per hour. Is the distance traveled a linear function of time? Explain.
   - *Answer:* Yes. The distance increases by 55 miles for every additional hour, so the rate of change is constant at 55. The function is d(t) = 55t.

**Facilitator tip:** Students sometimes think y = 6 is not a function because "nothing happens." Clarify that a constant function IS a function and IS linear — it just has a rate of change of zero. Every input gives the same output, and that consistency is exactly what makes it a function.

### Part B: Equations — Linear or Nonlinear?
Classify each function as linear or nonlinear. For linear functions, identify the rate of change and the y-value when x = 0.

5. y = 7x - 3
6. y = x^2 + 4
7. y = -x + 9
8. y = 2/x
9. y = 0.5x

### Part C: Word Problems

11. A swimming pool is being filled at a constant rate of 50 gallons per minute. It already has 200 gallons. Is the total amount of water a linear function of time? If so, write the equation and make a table for t = 0, 1, 2, 3, 4, 5 minutes.
12. A ball is dropped from a building. In the 1st second it falls 16 feet, in the 2nd second it falls 48 feet, in the 3rd second it falls 80 feet, and in the 4th second it falls 112 feet. Are the total distances after each second (16, 64, 144, 256) a linear function of time? Explain.

### Answer Key

**Part A**
1. Changes: +4, +4, +4, +4. **Linear.** y = 4x + 5.
2. Changes: +1, +3, +5, +7. **Nonlinear.** (This is y = x^2 + 1.)
3. Changes: -15, -15, -15, -15. **Linear.** y = -15x + 100.
4. Changes: +3, +6, +12, +24. **Nonlinear.** (The outputs are doubling — this is an exponential function: y = 3 * 2^(x-1).)

**Part B**
5. **Linear.** Rate of change: 7. When x = 0, y = -3.
6. **Nonlinear.** The x^2 term makes this a quadratic function.
7. **Linear.** Rate of change: -1. When x = 0, y = 9.
8. **Nonlinear.** The x is in the denominator (division by x), which means the rate of change is not constant.
9. **Linear.** Rate of change: 0.5. When x = 0, y = 0.
10. **Nonlinear.** The x^2 term makes this a quadratic function.

**Part C**
11. Yes, it is linear because the pool fills at a constant rate of 50 gallons per minute. Equation: W(t) = 50t + 200. Table: (0, 200), (1, 250), (2, 300), (3, 350), (4, 400), (5, 450).
12. Total distances after each second: 16, 64, 144, 256. Changes: +48, +80, +112. The changes are NOT constant, so this is NOT a linear function of time. (Falling objects accelerate due to gravity, so the distance-time relationship is quadratic: d = 16t^2.)

## Assessment Check

### Exit Ticket
**Problem 1:** Is the following function linear or nonlinear? Explain how you know.

| x | y |
|---|---|
| 0 | -4 |
| 2 | 0 |
| 4 | 4 |
| 6 | 8 |

**Problem 2:** Give an example of a linear equation and a nonlinear equation.

**Target response:**
1. Linear. The changes in y are +4, +4, +4 (constant rate of change). Note: x increases by 2 each time, and y increases by 4 each time, so the rate of change is 4/2 = 2 per unit of x. Equation: y = 2x - 4.
2. Acceptable examples: Linear — y = 3x + 1 (or any equation of the form y = mx + b). Nonlinear — y = x^2 (or any equation with x^2, x^3, square roots, etc.).

## Extension

- **Linear or Not? Data Investigation:** Measure the temperature of a cup of hot water every 2 minutes for 20 minutes. Record the data in a table. Is the cooling process linear or nonlinear? Plot the data on graph paper to see the shape. (It should be nonlinear — the temperature drops faster at first, then slows down.)
- **Linear Function Challenge:** Write a linear function where the output is always negative for x = 1 through x = 5. Write another linear function where the output is always positive for x = 1 through x = 5. Can you write a linear function where the output is negative for x = 1 and positive for x = 5? What does that tell you about the graph?
