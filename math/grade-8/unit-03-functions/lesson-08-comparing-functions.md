# Math — Grade 8 — Unit 3, Lesson 8

## Topic
Comparing Functions

## Learning Objectives
- Compare properties of two functions (rate of change, initial value) when they are represented in different ways.
- Determine which of two functions has a greater rate of change.
- Determine which of two functions has a greater value at a specific input.
- Justify comparisons using mathematical reasoning.

## Prerequisites
- Understanding of slope-intercept form and how to identify slope and y-intercept (Lessons 5-6)
- Ability to write linear equations from tables, graphs, and points (Lesson 7)
- Ability to evaluate functions at specific inputs (Lesson 2)

## Materials Needed
- Whiteboard and markers (or projector).
- Graph paper or pre-printed coordinate planes.
- Student worksheet (Guided Practice and Independent Practice problems).
- Index cards or half-sheets for Exit Ticket.

**Standards:** 8.F.2 — Compare properties of two functions each represented in a different way (algebraically, graphically, numerically in tables, or by verbal descriptions). For example, given a linear function represented by a table of values and a linear function represented by an algebraic expression, determine which function has the greater rate of change.

## Warm-Up (5 minutes)
**Purpose:** Review finding slope and y-intercept from different representations.

1. Function A is given by the equation y = 4x + 1. What is the slope? What is the y-intercept? (Slope: 4, y-intercept: 1)
2. Function B is given by this table:

   | x | y |
   |---|---|
   | 0 | 3 |
   | 1 | 6 |
   | 2 | 9 |
   | 3 | 12 |

   What is the slope? What is the y-intercept? (Slope: 3, y-intercept: 3)
3. Ask: "Which function increases faster — A or B? How do you know? Today we learn to compare functions even when they are shown in completely different ways."

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Rate of change** — the slope of a function; how much the output changes per unit increase in input.
- **Initial value** — the y-intercept; the output when the input is 0.
- **Compare** — to identify similarities and differences between two functions, including which is greater, which grows faster, or where they are equal.

### Instruction Notes

**Step 1 — Explain why comparing functions matters.**

Say: "In real life, you often need to compare options that are described differently. One phone plan might show a table of costs, while another gives you a formula. One investment might show a graph, while another describes the deal in words. You need to be able to compare them even though they look different."

**Step 2 — Demonstrate comparing an equation and a table.**

Function A: y = 2x + 10 (equation).
Function B (table):

| x | y |
|---|---|
| 0 | 15 |
| 1 | 17 |
| 2 | 19 |
| 3 | 21 |

Say: "To compare, we need to find the same information about both functions. Let us find the slope and y-intercept of each."

Function A: slope = 2, y-intercept = 10.
Function B: slope = (17 - 15)/(1 - 0) = 2, y-intercept = 15.

Say: "Both functions have the SAME rate of change (slope = 2). But Function B has a HIGHER initial value (15 vs. 10). That means Function B starts higher and stays higher. At every x-value, Function B is 5 more than Function A."

Verify: At x = 3, Function A gives 2(3) + 10 = 16. Function B gives 21. Indeed, 21 - 16 = 5.

**Step 3 — Demonstrate comparing a graph description and an equation.**

Function C: A line passes through (0, 8) and (4, 0) (described from a graph).
Function D: y = -x + 5 (equation).

Say: "First, let me find the equation for Function C from the graph. The y-intercept is 8 (it crosses the y-axis at (0, 8)). The slope is (0 - 8)/(4 - 0) = -8/4 = -2. So Function C is y = -2x + 8."

Now compare:
- Function C: slope = -2, y-intercept = 8.
- Function D: slope = -1, y-intercept = 5.

Say: "Both functions are decreasing (negative slopes). Function C decreases FASTER (slope of -2 vs. -1). Function C starts higher (y-intercept of 8 vs. 5). But because Function C decreases faster, the question is: does Function D ever catch up?"

Find where they are equal: -2x + 8 = -x + 5. Then -x + 8 = 5. Then -x = -3. So x = 3.

Say: "At x = 3, both functions have the same output. Before x = 3, Function C is greater. After x = 3, Function D is greater because it decreases more slowly."

Check: At x = 3, Function C: -2(3) + 8 = 2. Function D: -(3) + 5 = 2. Both equal 2.

**Step 4 — Summary strategy for comparing functions.**

Write on the board:
1. Find the slope (rate of change) of each function.
2. Find the y-intercept (initial value) of each function.
3. Compare slopes to determine which grows faster.
4. Compare y-intercepts to determine which starts higher.
5. If needed, find where the functions are equal by setting them equal to each other and solving.

### Worked Examples

**Example A: Table vs. Equation**
Function P: y = 5x - 3.
Function Q:

| x | y |
|---|---|
| 1 | 4 |
| 2 | 7 |
| 3 | 10 |
| 4 | 13 |

Function P: slope = 5, y-intercept = -3.
Function Q: slope = (7 - 4)/(2 - 1) = 3. Using point (1, 4): 4 = 3(1) + b, b = 1. Equation: y = 3x + 1. Slope = 3, y-intercept = 1.

Comparison: Function P has a greater rate of change (5 > 3). Function Q has a greater initial value (1 > -3). At x = 0, P gives -3 and Q gives 1, so Q is greater. But P grows faster. They will be equal when 5x - 3 = 3x + 1: 2x = 4, x = 2. At x = 2, both give 7. For x > 2, P is greater.

**Example B: Verbal Description vs. Equation**
Function R: A painter charges $200 plus $25 per hour.
Function S: y = 30x + 150.

Function R: C = 25h + 200. Slope = 25, y-intercept = 200.
Function S: slope = 30, y-intercept = 150.

Comparison: Function S has a greater rate of change ($30/hour vs. $25/hour). Function R has a greater initial value ($200 vs. $150). Function R starts more expensive but grows more slowly. They will be equal when 25h + 200 = 30h + 150: 50 = 5h, h = 10 hours. After 10 hours, Function S costs more.

**Example C: Graph Description vs. Table**
Function T: A line through (0, 0) and (6, 12).
Function U:

| x | y |
|---|---|
| 0 | 4 |
| 2 | 8 |
| 4 | 12 |
| 6 | 16 |

Function T: slope = (12 - 0)/(6 - 0) = 2, y-intercept = 0. Equation: y = 2x.
Function U: slope = (8 - 4)/(2 - 0) = 2, y-intercept = 4. Equation: y = 2x + 4.

Comparison: Both have the same rate of change (slope = 2). Function U always has a value 4 greater than Function T (because it starts 4 higher and grows at the same rate). They are parallel lines that never intersect.

## Guided Practice (10 minutes)

Work through these problems together. The student attempts each problem first, then discusses.

1. Function A: y = 3x + 2. Function B: a table showing (0, 5), (1, 7), (2, 9), (3, 11). Which has the greater rate of change?
   - *Answer:* Function A slope = 3. Function B slope = 2. Function A has the greater rate of change.

2. Using the same functions from problem 1, which function has a greater value at x = 0? At x = 5?
   - *Answer:* At x = 0: A gives 2, B gives 5. Function B is greater. At x = 5: A gives 3(5) + 2 = 17, B gives 2(5) + 5 = 15. Function A is greater.

3. Function C: A tutor charges $50 plus $20 per session. Function D: y = 25x + 30. Which is cheaper for 1 session? For 10 sessions?
   - *Answer:* Function C: C = 20s + 50. At 1 session: C = 70, D = 55. Function D is cheaper. At 10 sessions: C = 250, D = 280. Function C is cheaper.

4. Function E: a line through (0, 12) and (3, 3). Function F: y = -2x + 10. Which function decreases faster?
   - *Answer:* Function E: slope = (3 - 12)/(3 - 0) = -9/3 = -3. Function F: slope = -2. Function E decreases faster (slope of -3 is steeper downward than -2).

5. For Functions E and F above, at what x-value are they equal?
   - *Answer:* E: y = -3x + 12. F: y = -2x + 10. Set equal: -3x + 12 = -2x + 10. -x = -2. x = 2. At x = 2, both equal 6.

**Facilitator tip:** When comparing functions, students sometimes only look at one property (like the y-intercept) and conclude that one function is "always bigger." Remind them that the slope determines how fast each function grows, and a function that starts lower can overtake one that starts higher if it has a steeper slope.

## Independent Practice (10-15 minutes)

### Part A: Comparing Rate of Change
For each pair, determine which function has the greater rate of change.

1. Function A: y = 6x + 1.
   Function B: a table showing (0, 10), (1, 14), (2, 18), (3, 22).

2. Function C: a table showing (1, 3), (2, 8), (3, 13), (4, 18).
   Function D: y = 4x - 1.

3. Function E: a line through (0, 0) and (5, 20).
   Function F: y = 3x + 7.

### Part B: Comparing Values at Specific Points
For each pair, determine which function has a greater value at the specified input.

4. Function G: y = 2x + 8. Function H: a table showing (0, 3), (1, 6), (2, 9), (3, 12). Compare at x = 10.
   - (Hint: find the equation for H first.)

5. Function J: a line through (0, 100) and (10, 50). Function K: y = -4x + 90. Compare at x = 5 and at x = 20.

### Part C: Word Problems

6. Two internet providers:
   - Provider A charges $30 per month plus a $60 installation fee.
   - Provider B is shown in this table:

   | Months | Total Cost |
   |--------|-----------|
   | 1 | $55 |
   | 2 | $90 |
   | 3 | $125 |
   | 4 | $160 |

   Which provider has the lower monthly rate? Which is cheaper for a 1-year (12-month) contract?

7. Two runners start a race:
   - Runner A: distance = 6t (where t is in seconds and distance is in meters).
   - Runner B starts 10 meters ahead and runs at 4 meters per second.

   Write the equation for each runner. Who is ahead at t = 3? At what time does Runner A catch Runner B?

### Answer Key

**Part A**
1. Function A: slope = 6. Function B: slope = (14 - 10)/(1 - 0) = 4. **Function A** has the greater rate of change.
2. Function C: slope = (8 - 3)/(2 - 1) = 5. Function D: slope = 4. **Function C** has the greater rate of change.
3. Function E: slope = (20 - 0)/(5 - 0) = 4. Function F: slope = 3. **Function E** has the greater rate of change.

**Part B**
4. Function G: slope = 2, y-intercept = 8. G(10) = 2(10) + 8 = 28.
   Function H: slope = (6 - 3)/(1 - 0) = 3, y-intercept = 3. H(10) = 3(10) + 3 = 33.
   At x = 10, **Function H** has the greater value.

5. Function J: slope = (50 - 100)/(10 - 0) = -50/10 = -5. Equation: y = -5x + 100.
   Function K: y = -4x + 90.
   At x = 5: J = -5(5) + 100 = 75. K = -4(5) + 90 = 70. **Function J** is greater.
   At x = 20: J = -5(20) + 100 = 0. K = -4(20) + 90 = 10. **Function K** is greater.

**Part C**
6. Provider A: C = 30m + 60. Slope = 30 (monthly rate), y-intercept = 60.
   Provider B: slope = (90 - 55)/(2 - 1) = 35. Using (1, 55): 55 = 35(1) + b, b = 20. Equation: C = 35m + 20. Slope = 35, y-intercept = 20.
   **Provider A** has the lower monthly rate ($30 vs. $35).
   For 12 months: Provider A = 30(12) + 60 = $420. Provider B = 35(12) + 20 = $440. **Provider A** is cheaper for a 1-year contract.

7. Runner A: d = 6t. Runner B: d = 4t + 10.
   At t = 3: A = 18 meters, B = 22 meters. **Runner B** is ahead.
   Equal when 6t = 4t + 10: 2t = 10, t = 5 seconds. At t = 5, both are at 30 meters. **Runner A catches Runner B at 5 seconds.**

## Assessment Check

### Exit Ticket
**Problem 1:** Function A: y = 4x + 3. Function B is given by the table (0, 7), (1, 10), (2, 13), (3, 16). Which function has the greater rate of change? Which has the greater value at x = 0?

**Target response:** Function A: slope = 4, y-intercept = 3. Function B: slope = 3, y-intercept = 7. Function A has the greater rate of change (4 > 3). Function B has the greater value at x = 0 (7 > 3).

## Extension

- **Break-Even Analysis:** Research two real phone plans, streaming services, or gym memberships. Write linear equations for each. Find the "break-even point" — the time when both cost the same. Which plan is cheaper in the short run? In the long run? Present your findings with graphs and equations.
- **Three-Way Comparison:** Given Function A (equation), Function B (table), and Function C (graph description), rank all three by rate of change and initial value. Determine at which x-value each pair of functions are equal. Example: A: y = 2x + 10. B: (0, 4), (1, 7), (2, 10). C: passes through (0, 1) and (2, 9). (Slopes: A = 2, B = 3, C = 4. By rate of change: C > B > A.)
