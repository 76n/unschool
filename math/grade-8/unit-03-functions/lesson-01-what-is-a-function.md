# Math — Grade 8 — Unit 3, Lesson 1

## Topic
What Is a Function

## Learning Objectives
- Define a function as a rule that assigns exactly one output to each input.
- Determine whether a relation is a function using input/output tables and mapping diagrams.
- Apply the vertical line test to determine whether a graph represents a function.
- Identify examples and non-examples of functions in everyday contexts.

## Prerequisites
- Ability to read and create input/output tables (Grade 6-7)
- Ability to plot and read ordered pairs on a coordinate plane (Grade 6-7)
- Understanding of ordered pairs as (input, output) or (x, y)

## Materials Needed
- Whiteboard and markers (or projector).
- Graph paper or pre-printed coordinate planes.
- Student worksheet (Guided Practice and Independent Practice problems).
- Index cards or half-sheets for Exit Ticket.

**Standards:** 8.F.1 — Understand that a function is a rule that assigns to each input exactly one output. The graph of a function is the set of ordered pairs consisting of an input and the corresponding output.

## Warm-Up (5 minutes)
**Purpose:** Activate prior knowledge of input/output relationships and ordered pairs.

1. A vending machine has buttons A1, A2, A3, and B1. Each button gives a specific snack. If you press A1, you get chips. If you press A2, you get pretzels. If you press A3, you get chips (same as A1). If you press B1, you get a cookie.
   - List the four input-output pairs. (A1 -> chips, A2 -> pretzels, A3 -> chips, B1 -> cookie)
   - Is there ever a situation where pressing one button could give you two different snacks? (No — each button always gives exactly one snack.)
2. Now imagine a broken vending machine where pressing A1 sometimes gives chips and sometimes gives pretzels. Would you trust this machine? Why or why not?
3. Ask: "In math, we want our rules to behave like the working vending machine, not the broken one. Today we will learn the name for this kind of reliable rule."

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Relation** — any set of ordered pairs; a relationship between inputs and outputs.
- **Function** — a special type of relation where each input has exactly one output.
- **Input** — the value you put into a function (also called the independent variable, or x-value).
- **Output** — the value the function produces (also called the dependent variable, or y-value).
- **Domain** — the set of all possible inputs.
- **Range** — the set of all possible outputs.
- **Mapping diagram** — a visual that shows arrows from each input to its output.
- **Vertical line test** — a test applied to a graph: if any vertical line crosses the graph more than once, the graph does NOT represent a function.

### Instruction Notes

**Step 1 — Define a function.**

Write on the board: "A function is a rule that assigns to each input exactly one output."

Say: "Think of a function like a machine. You feed in a number — that is the input. The machine does something to it and spits out a result — that is the output. The key rule is this: if you put in the SAME input, you must ALWAYS get the SAME output. The machine cannot give you different answers on different days."

**Step 2 — Show examples using input/output tables.**

Draw Table 1 on the board:

| Input (x) | Output (y) |
|-----------|-----------|
| 1 | 3 |
| 2 | 5 |
| 3 | 7 |
| 4 | 9 |

Say: "Is this a function? Let us check. Does any input appear more than once with different outputs? No — each input has exactly one output. This IS a function."

Draw Table 2 on the board:

| Input (x) | Output (y) |
|-----------|-----------|
| 1 | 4 |
| 2 | 7 |
| 1 | 6 |
| 3 | 8 |

Say: "Now look at this table. The input 1 appears twice: once with output 4 and once with output 6. That means the same input gives two different outputs. This is NOT a function."

Say: "But notice something important: it IS okay for two different inputs to give the same output. In Table 1, if I added a row where input 5 also gives output 3, that would still be a function. The rule is about inputs, not outputs."

**Step 3 — Introduce mapping diagrams.**

Draw a mapping diagram for Table 1: two ovals labeled "Input" and "Output." In the Input oval, write 1, 2, 3, 4. In the Output oval, write 3, 5, 7, 9. Draw arrows: 1 -> 3, 2 -> 5, 3 -> 7, 4 -> 9.

Say: "In a mapping diagram, each input has exactly one arrow going out. That is what makes it a function. If any input had TWO arrows going to different outputs, it would not be a function."

Draw a mapping diagram for a non-function: Input oval has 1, 2, 3. Output oval has 4, 6, 7, 8. Arrows: 1 -> 4, 1 -> 6, 2 -> 7, 3 -> 8.

Say: "See how the input 1 has two arrows — one going to 4 and one going to 6? That breaks the rule. This is NOT a function."

**Step 4 — Introduce the vertical line test.**

Say: "When a relation is shown as a graph, we can use the vertical line test. Imagine sliding a vertical line across the graph from left to right. If the vertical line ever touches the graph at MORE than one point at the same time, the graph is NOT a function."

Describe Graph A: "Picture a straight line going up from left to right, like y = 2x + 1. No matter where you place a vertical line, it crosses the graph at exactly one point. This IS a function."

Describe Graph B: "Now picture a circle centered at the origin. If you draw a vertical line through the middle of the circle, it crosses the circle at TWO points — one at the top and one at the bottom. That means a circle is NOT a function."

Say: "Why does this work? A vertical line represents a single x-value. If it hits the graph twice, that means one x-value has two y-values — two outputs for the same input. That violates the definition of a function."

### Worked Examples

**Example A: Input/output table**
Determine whether this relation is a function:

| x | y |
|---|---|
| 2 | 5 |
| 4 | 5 |
| 6 | 8 |
| 8 | 10 |

Solution: Check each input. The input 2 appears once (output 5). The input 4 appears once (output 5). The input 6 appears once (output 8). The input 8 appears once (output 10). No input is repeated with a different output. Notice that both x = 2 and x = 4 give the same output (5), but that is allowed. **This IS a function.** Domain: {2, 4, 6, 8}. Range: {5, 8, 10}.

**Example B: Mapping diagram**
Determine whether this relation is a function:
- Input set: {-1, 0, 3, 5}
- Arrows: -1 -> 2, 0 -> 4, 3 -> 2, 5 -> 7

Solution: Each input has exactly one arrow. The input -1 goes to 2 only. The input 0 goes to 4 only. The input 3 goes to 2 only (same output as -1, which is fine). The input 5 goes to 7 only. **This IS a function.** Domain: {-1, 0, 3, 5}. Range: {2, 4, 7}.

**Example C: Vertical line test**
A graph shows a set of plotted points: (1, 3), (2, 5), (3, 4), (2, 7).

Solution: The points (2, 5) and (2, 7) share the same x-value of 2 but have different y-values. A vertical line at x = 2 would pass through two points. **This is NOT a function.** The input 2 has two different outputs.

## Guided Practice (10 minutes)

Work through these problems together. The student attempts each problem first, then discusses.

1. Is this relation a function? {(1, 4), (2, 7), (3, 4), (4, 9)}
   - *Answer:* Yes. Each input (1, 2, 3, 4) has exactly one output. The fact that inputs 1 and 3 both output 4 is allowed.

2. Is this relation a function? {(5, 2), (5, 8), (6, 3), (7, 1)}
   - *Answer:* No. The input 5 has two outputs (2 and 8).

3. Draw a mapping diagram for the relation: {(0, 1), (1, 3), (2, 5), (3, 7)}. Is it a function?
   - *Answer:* Yes. Each input maps to exactly one output. The mapping diagram shows one arrow from each input.

4. A graph shows a horizontal line at y = 4 (the line extends left and right). Does it pass the vertical line test?
   - *Answer:* Yes. Any vertical line crosses a horizontal line at exactly one point. This IS a function.

5. A graph shows a vertical line at x = 3 (the line extends up and down). Does it pass the vertical line test?
   - *Answer:* No. A vertical line at x = 3 overlaps with the graph entirely — it hits infinitely many points. This is NOT a function.

6. A student says: "The set {(1, 5), (2, 5), (3, 5)} is not a function because all the outputs are the same." Is the student correct?
   - *Answer:* The student is incorrect. Each input has exactly one output. It does not matter that all outputs happen to be 5. This IS a function (a constant function).

**Facilitator tip:** The most common confusion is about repeated outputs. Reinforce: "The rule is about inputs. One input, one output. But many inputs CAN share the same output."

## Independent Practice (10-15 minutes)

### Part A: Tables and Ordered Pairs
Determine whether each relation is a function. State the domain and range.

1. {(3, 6), (4, 8), (5, 10), (6, 12)}
2. {(1, 2), (1, 3), (2, 4), (3, 5)}
3. {(-2, 4), (-1, 1), (0, 0), (1, 1), (2, 4)}
4. | x | y |
   |---|---|
   | 0 | 5 |
   | 1 | 5 |
   | 2 | 5 |
   | 3 | 5 |
5. | x | y |
   |---|---|
   | 7 | 1 |
   | 8 | 2 |
   | 7 | 3 |
   | 9 | 4 |

### Part B: Mapping Diagrams and Vertical Line Test

6. Draw a mapping diagram for {(2, 10), (3, 15), (4, 10), (5, 20)}. Is it a function?
7. Draw a mapping diagram for {(1, 3), (2, 6), (3, 9), (1, 12)}. Is it a function?
8. A graph shows a parabola opening upward (a U-shaped curve with vertex at the origin). Does it pass the vertical line test? Explain.
9. A graph shows an S-shaped curve that passes through the origin, going from lower-left to upper-right, never doubling back. Does it pass the vertical line test?
10. A graph shows a sideways parabola (a U-shape opening to the right). Does it pass the vertical line test?

### Part C: Word Problems

11. A store has a price list: apples cost $1.50, bananas cost $0.75, and oranges cost $1.25. The input is the fruit name and the output is the price. Is this a function? Explain.
12. In a classroom, the input is a student's name and the output is their birthday. Could this be a function? What if the input were a birthday and the output were a student's name — would that also be a function? Explain both cases.

### Answer Key

**Part A**
1. Function. Each input (3, 4, 5, 6) has one output. Domain: {3, 4, 5, 6}. Range: {6, 8, 10, 12}.
2. Not a function. The input 1 has two outputs (2 and 3). Domain: {1, 2, 3}. Range: {2, 3, 4, 5}.
3. Function. Each input (-2, -1, 0, 1, 2) has one output. Note: -2 and 2 both give output 4, and -1 and 1 both give output 1 — that is allowed. Domain: {-2, -1, 0, 1, 2}. Range: {0, 1, 4}.
4. Function. Each input (0, 1, 2, 3) has one output (5). This is a constant function. Domain: {0, 1, 2, 3}. Range: {5}.
5. Not a function. The input 7 has two outputs (1 and 3). Domain: {7, 8, 9}. Range: {1, 2, 3, 4}.

**Part B**
6. Function. Each input (2, 3, 4, 5) has one arrow. Domain: {2, 3, 4, 5}. Range: {10, 15, 20}.
7. Not a function. The input 1 has two arrows (to 3 and to 12). Domain: {1, 2, 3}. Range: {3, 6, 9, 12}.
8. Yes, it passes the vertical line test. Although the parabola curves, any vertical line crosses it at most once (except at points to the left and right of the vertex where it crosses once). Actually, for a standard upward parabola like y = x^2, vertical lines to the left and right of the vertex cross at exactly one point each. It IS a function.
9. Yes, it passes the vertical line test. Since the curve never doubles back (it always moves to the right as it goes up), any vertical line crosses it at most once. It IS a function.
10. No, it does not pass the vertical line test. A sideways parabola (like x = y^2) has two y-values for most x-values (one on the top half and one on the bottom half). A vertical line to the right of the vertex would cross the graph at two points. It is NOT a function.

**Part C**
11. Yes, this is a function. Each fruit (input) has exactly one price (output). You cannot have apples costing both $1.50 and $2.00 at the same time.
12. Student name -> birthday: Yes, this is a function. Each student has exactly one birthday. Two students might share a birthday (same output), but each student has only one. Birthday -> student name: This might NOT be a function if two students share the same birthday. Then one input (the shared birthday) would have two outputs (two different students).

## Assessment Check

### Exit Ticket
**Problem 1:** Determine whether the relation {(4, 7), (5, 9), (6, 7), (4, 11)} is a function. Explain your reasoning.
**Problem 2:** Describe a real-world situation that IS a function and one that is NOT a function.

**Target response:**
1. Not a function. The input 4 has two different outputs: 7 and 11. A function requires each input to have exactly one output.
2. Acceptable examples — Function: Each person has exactly one biological mother. Non-function: A parent may have multiple children, so the relation "parent -> child" is not a function if a parent has more than one child.

## Extension

- **Function Machines:** Design three "function machines" with different rules (e.g., "double and add 1," "square the input," "always output 7"). Create input/output tables for each. Then give a classmate just the tables and see if they can figure out the rule.
- **Real-World Function Hunt:** Find five examples of functions in everyday life (e.g., each zip code corresponds to one city, each item on a restaurant menu has one price). For each, identify the input, output, domain, and range. Then find one real-world example that is NOT a function and explain why.
