# Math — Grade 8 — Unit 3, Lesson 10

Review and Problem Solving

## Direct Instruction (10-15 minutes)

### Key Vocabulary
This lesson reviews all vocabulary from Lessons 1-9. Key terms:
- **Function** — a rule that assigns exactly one output to each input.
- **Function notation** — f(x), read "f of x."
- **Domain** — set of all inputs.
- **Range** — set of all outputs.
- **Slope** — rate of change; rise/run; m = (y2 - y1)/(x2 - x1).
- **Slope-intercept form** — y = mx + b.
- **Linear function** — constant rate of change; straight-line graph.
- **Nonlinear function** — non-constant rate of change; curved graph.

### Instruction Notes

**Step 1 — Concept map review.**

Say: "We have covered a lot in this unit. Let me connect the big ideas."

Write on the board and discuss each connection:
- "A FUNCTION assigns one output to each input."
- "We write it as f(x) = [rule]. The input is x, the output is f(x)."
- "We can show a function as a table, graph, equation, or verbal description."
- "If the rate of change is CONSTANT, the function is LINEAR. Its graph is a STRAIGHT LINE."
- "For a linear function, the rate of change is the SLOPE (m). The starting value is the Y-INTERCEPT (b)."
- "The equation of a linear function is y = mx + b."
- "We can WRITE this equation from a graph, table, or two points."
- "We can COMPARE functions by examining their slopes and y-intercepts."
- "If the rate of change is NOT constant, the function is NONLINEAR. Its graph is a CURVE."

**Step 2 — Walk through a comprehensive problem.**

Say: "Let me show you a problem that ties many of these ideas together."

Problem: "Two delivery services offer different pricing. Express Delivery charges $5 per mile plus $10. Speedy Delivery is described by this table:"

| Miles | Cost ($) |
|-------|---------|
| 0 | 20 |
| 2 | 28 |
| 4 | 36 |
| 6 | 44 |

"Part A: Write equations for both services."
- Express: C = 5m + 10.
- Speedy: slope = (28 - 20)/(2 - 0) = 8/2 = 4. Y-intercept = 20. Equation: C = 4m + 20.

"Part B: Which has a higher rate of change?"
- Express has a rate of $5/mile vs. Speedy's $4/mile. Express charges more per mile.

"Part C: For a 5-mile delivery, which is cheaper?"
- Express: 5(5) + 10 = $35. Speedy: 4(5) + 20 = $40. Express is cheaper.

"Part D: At how many miles are the costs equal?"
- 5m + 10 = 4m + 20. m = 10 miles. At 10 miles, both charge $60.

"Part E: Is the cost a linear function of miles for both services?"
- Yes — both have constant rates of change. Their graphs would be straight lines.

**Step 3 — Error analysis review.**

Say: "Before the assessment, let me point out the most common mistakes I see students make."

Write and discuss:
1. "f(x) means f times x." — NO! f(x) means "the function f evaluated at x."
2. "Slope is run/rise." — NO! Slope is rise/run = change in y / change in x.
3. "A line that goes down has positive slope." — NO! A line that goes down from left to right has NEGATIVE slope.
4. "In y = mx + b, the slope is b." — NO! m is the slope. b is the y-intercept.
5. "A function cannot have two inputs giving the same output." — YES IT CAN! What it cannot have is one input giving two different outputs.
6. "All curves are not functions." — NOT TRUE! A curve that passes the vertical line test IS a function. It is just a nonlinear function.

### Worked Examples

**Example A: Multi-step real-world problem**
A gym offers two membership plans. Plan A costs $40 per month with no sign-up fee. Plan B costs $25 per month with a $120 sign-up fee.

(a) Write equations: Plan A: C = 40m. Plan B: C = 25m + 120.
(b) Which plan is cheaper for 6 months? Plan A: 40(6) = $240. Plan B: 25(6) + 120 = $270. Plan A is cheaper.
(c) When are they equal? 40m = 25m + 120. 15m = 120. m = 8 months. At 8 months, both cost $320.
(d) Which plan is cheaper for 12 months? Plan A: 40(12) = $480. Plan B: 25(12) + 120 = $420. Plan B is cheaper.

**Example B: Function identification and evaluation**
A function is given: g(x) = -3x + 15.

(a) Is it a function? Yes — for each input x, there is exactly one output.
(b) Is it linear? Yes — it is in the form y = mx + b with m = -3 and b = 15.
(c) Find g(0), g(3), g(5). g(0) = 15. g(3) = -9 + 15 = 6. g(5) = -15 + 15 = 0.
(d) Domain: all real numbers. Range: all real numbers (since it is a non-horizontal linear function).
(e) What is the slope? -3. What does it mean? The output decreases by 3 for each increase of 1 in the input.
(f) At what input does g(x) = 0? -3x + 15 = 0. x = 5.

**Example C: Graph description and analysis**
A graph shows the distance from home over time for a student walking to school.
- From time 0 to 5 minutes, the graph rises steeply in a straight line from 0 to 400 meters.
- From 5 to 8 minutes, the graph is flat at 400 meters.
- From 8 to 12 minutes, the graph rises gently in a straight line from 400 to 600 meters.

Analysis:
- Segment 1 (0-5 min): linear, increasing. Slope = 400/5 = 80 meters per minute (walking fast).
- Segment 2 (5-8 min): constant (stopped — maybe waiting for a traffic light).
- Segment 3 (8-12 min): linear, increasing. Slope = 200/4 = 50 meters per minute (walking slower).
- The overall function is nonlinear (piecewise linear with different slopes in different sections).

## Guided Practice (10 minutes)

Work through these problems together. The student attempts each problem first, then discusses.

1. Determine whether each relation is a function:
   (a) {(2, 4), (3, 6), (4, 4), (5, 10)}
   (b) {(1, 3), (1, 5), (2, 7)}
   - *Answer:* (a) Yes — each input has one output. (b) No — input 1 has two outputs.

2. Given f(x) = -2x + 9, find f(-3) and solve for x when f(x) = 1.
   - *Answer:* f(-3) = -2(-3) + 9 = 6 + 9 = 15. For f(x) = 1: -2x + 9 = 1. -2x = -8. x = 4.

3. Write the equation of the line through (3, 7) and (6, 16).
   - *Answer:* m = (16 - 7)/(6 - 3) = 9/3 = 3. Substitute (3, 7): 7 = 3(3) + b. 7 = 9 + b. b = -2. Equation: y = 3x - 2.

4. Function A: y = 3x + 5. Function B: table showing (0, 8), (1, 10), (2, 12), (3, 14). Which function has a greater rate of change? Which has a greater value at x = 10?
   - *Answer:* A: slope 3, y-intercept 5. B: slope 2, y-intercept 8. A has greater rate of change (3 > 2). At x = 10: A = 35, B = 28. A has the greater value.

5. Is the function in this table linear or nonlinear?

   | x | y |
   |---|---|
   | 0 | 2 |
   | 1 | 6 |
   | 2 | 18 |
   | 3 | 54 |

   - *Answer:* Changes: +4, +12, +36. Not constant (they triple each time). **Nonlinear.** This is y = 2 * 3^x.

**Facilitator tip:** Use this review session to identify any remaining gaps. If the student struggles with a particular problem type, note it and allocate extra time before the unit assessment. Focus especially on slope calculation and writing equations from two points, as these are the most common areas of difficulty.

## Independent Practice (10-15 minutes)

### Part A: Core Skills Review

1. Is {(-1, 4), (0, 4), (1, 4), (2, 4)} a function? What is special about this function?
2. Given h(x) = 5x - 8, find h(3), h(0), and h(-2).
3. Find the slope of the line through (-2, 5) and (4, -7).
4. Write the equation in slope-intercept form: a line with slope 4 and passing through (2, 11).
5. Is y = 2x^2 + 1 linear or nonlinear? Give the value when x = 3.

### Part B: Equations and Comparisons

6. Write the equation from this table:

   | x | y |
   |---|---|
   | 1 | 1 |
   | 3 | 7 |
   | 5 | 13 |
   | 7 | 19 |

7. Function P: y = -x + 20. Function Q: passes through (0, 14) and (2, 20). Which function is greater at x = 0? At x = 4? Where are they equal?

8. A graph shows: from x = 0 to x = 4, a straight line rises from y = 0 to y = 8. From x = 4 to x = 8, a curve rises steeply from y = 8 to y = 40. Describe the qualitative features.

### Part C: Real-World Problem Solving

9. A food truck sells tacos and burritos. The profit on tacos is modeled by P(t) = 3t - 50, where t is the number of tacos sold. The profit on burritos is shown in this table:

   | Burritos sold | Profit ($) |
   |--------------|-----------|
   | 10 | -10 |
   | 20 | 30 |
   | 30 | 70 |
   | 40 | 110 |

   (a) Write the burrito profit equation.
   (b) How many of each item must be sold to break even (profit = $0)?
   (c) Which item is more profitable per item sold?

10. A student tracks the number of pages she has read over time:

    | Hours | Pages |
    |-------|-------|
    | 0 | 0 |
    | 1 | 30 |
    | 2 | 55 |
    | 3 | 75 |
    | 4 | 90 |

    (a) Is her reading rate constant? How do you know?
    (b) Is the pages-vs-hours function linear or nonlinear?
    (c) Describe the qualitative features of the graph.

### Answer Key

**Part A**
1. Yes, it is a function — each input has exactly one output. This is a **constant function** (every input gives the output 4). Its graph is a horizontal line at y = 4.
2. h(3) = 5(3) - 8 = 7. h(0) = 5(0) - 8 = -8. h(-2) = 5(-2) - 8 = -18.
3. m = (-7 - 5)/(4 - (-2)) = -12/6 = -2.
4. Substitute (2, 11): 11 = 4(2) + b. 11 = 8 + b. b = 3. Equation: y = 4x + 3.
5. Nonlinear — the x^2 term means the rate of change is not constant. When x = 3: y = 2(9) + 1 = 19.

**Part B**
6. slope = (7 - 1)/(3 - 1) = 6/2 = 3. Substitute (1, 1): 1 = 3(1) + b. b = -2. Equation: y = 3x - 2. Check: 3(7) - 2 = 19. Correct.

7. Function P: slope = -1, y-intercept = 20. Function Q: slope = (20 - 14)/(2 - 0) = 3, y-intercept = 14. Equation: y = 3x + 14.
   At x = 0: P = 20, Q = 14. **P is greater.**
   At x = 4: P = -4 + 20 = 16, Q = 12 + 14 = 26. **Q is greater.**
   Equal when: -x + 20 = 3x + 14. 6 = 4x. x = 1.5. At x = 1.5, both equal 18.5.

8. From x = 0 to x = 4: the function is INCREASING and LINEAR (constant slope of 8/4 = 2). From x = 4 to x = 8: the function is INCREASING and NONLINEAR (the curve gets steeper, so the rate of increase is accelerating).

**Part C**
9. (a) Burrito profit: slope = (30 - (-10))/(20 - 10) = 40/10 = 4. Substitute (10, -10): -10 = 4(10) + b. -10 = 40 + b. b = -50. Equation: B(b) = 4b - 50.
   (b) Taco break-even: 3t - 50 = 0. t = 50/3 = 16.67, so approximately 17 tacos. Burrito break-even: 4b - 50 = 0. b = 12.5, so 13 burritos.
   (c) Tacos: $3 profit per taco (after fixed costs). Burritos: $4 profit per burrito (after fixed costs). **Burritos are more profitable per item** ($4 vs. $3 per item).

10. (a) No, her reading rate is not constant. Changes in pages: +30, +25, +20, +15. Each hour she reads fewer pages than the previous hour.
    (b) **Nonlinear.** The rate of change decreases over time.
    (c) The graph is INCREASING (she reads more pages over time) and NONLINEAR (the curve rises quickly at first, then less steeply). The graph curves upward but is getting flatter — she is slowing down over time, perhaps from fatigue.

## Assessment Check

### Exit Ticket
**Problem 1:** Write the equation of the line through (1, 5) and (3, 11). Then evaluate f(10) using your equation.
**Problem 2:** A function is described: "A tank starts with 200 gallons and loses 15 gallons per minute." Write the equation. Is this linear or nonlinear? After how many minutes is the tank empty?

**Target response:**
1. m = (11 - 5)/(3 - 1) = 6/2 = 3. Substitute (1, 5): 5 = 3(1) + b. b = 2. Equation: y = 3x + 2. f(10) = 3(10) + 2 = 32.
2. W(t) = -15t + 200. Linear — constant rate of change of -15 gallons per minute. Tank empty when 0 = -15t + 200. 15t = 200. t = 200/15 = 40/3 = 13.33 minutes, or 13 minutes and 20 seconds.
