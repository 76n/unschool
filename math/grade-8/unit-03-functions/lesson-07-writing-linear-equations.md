# Math — Grade 8 — Unit 3, Lesson 7

## Topic
Writing Linear Equations

## Learning Objectives
- Write the equation of a line given a graph (by reading the slope and y-intercept).
- Write the equation of a line given a table of values.
- Write the equation of a line given two points.
- Apply equation-writing skills to real-world problems.

## Prerequisites
- Understanding of slope-intercept form y = mx + b (Lesson 6)
- Ability to calculate slope from two points (Lesson 5)
- Ability to solve one-step equations (Unit 2)

## Materials Needed
- Whiteboard and markers (or projector).
- Graph paper or pre-printed coordinate planes.
- Ruler or straightedge.
- Student worksheet (Guided Practice and Independent Practice problems).
- Index cards or half-sheets for Exit Ticket.

**Standards:** 8.F.4 — Construct a function to model a linear relationship between two quantities. Determine the rate of change and initial value of the function from a description of a relationship or from two (x, y) values, including reading these from a table or from a graph.

## Warm-Up (5 minutes)
**Purpose:** Review slope calculation and slope-intercept form to prepare for writing equations.

1. Find the slope of the line through (1, 3) and (4, 12). (m = 9/3 = 3)
2. If a line has slope 3 and y-intercept 5, write the equation. (y = 3x + 5)
3. If a line passes through (0, -2) and has slope 4, write the equation. (y = 4x - 2)
4. Ask: "What if I do not give you the y-intercept directly? What if I only give you two points like (2, 7) and (5, 16)? Today we learn how to find the equation from that information."

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Slope-intercept form** — y = mx + b, where m is the slope and b is the y-intercept.
- **y-intercept** — the value of y when x = 0; the point (0, b).
- **Back-substitute** — to substitute a known point into the equation to solve for an unknown value.

### Instruction Notes

**Step 1 — Writing an equation from a graph.**

Describe a graph: "A straight line crosses the y-axis at (0, 2) and passes through (3, 8)."

Say: "When you can read the y-intercept directly from the graph, the process is straightforward. Step 1: Read the y-intercept: b = 2. Step 2: Pick two clear points and find the slope: m = (8 - 2)/(3 - 0) = 6/3 = 2. Step 3: Write the equation: y = 2x + 2."

Say: "Always pick points where the line crosses grid intersections — those are the easiest to read accurately."

**Step 2 — Writing an equation from a table.**

Present this table:

| x | y |
|---|---|
| 0 | 5 |
| 1 | 8 |
| 2 | 11 |
| 3 | 14 |

Say: "Step 1: Find the slope. Each time x increases by 1, y increases by 3. So m = 3. Step 2: Find the y-intercept. Look for the row where x = 0. When x = 0, y = 5, so b = 5. Step 3: Write the equation: y = 3x + 5."

**Step 3 — Writing an equation from a table WITHOUT x = 0.**

Present this table:

| x | y |
|---|---|
| 2 | 9 |
| 4 | 15 |
| 6 | 21 |
| 8 | 27 |

Say: "This table does not include x = 0, so we cannot read b directly. Here is the process."

Say: "Step 1: Find the slope. Using (2, 9) and (4, 15): m = (15 - 9)/(4 - 2) = 6/2 = 3."

Say: "Step 2: Plug the slope and one known point into y = mx + b and solve for b. Using the point (2, 9): 9 = 3(2) + b. 9 = 6 + b. b = 3."

Say: "Step 3: Write the equation: y = 3x + 3."

Say: "Step 4: Verify with another point. Using (8, 27): y = 3(8) + 3 = 24 + 3 = 27. Correct."

**Step 4 — Writing an equation from two points.**

Say: "This is the most general case. You have just two points and nothing else."

Example: Write the equation of the line through (1, 4) and (3, 10).

Say: "Step 1: Find the slope. m = (10 - 4)/(3 - 1) = 6/2 = 3."

Say: "Step 2: Substitute the slope and one point into y = mx + b. Using (1, 4): 4 = 3(1) + b. 4 = 3 + b. b = 1."

Say: "Step 3: Write the equation: y = 3x + 1."

Say: "Step 4: Check with the other point. Using (3, 10): y = 3(3) + 1 = 10. Correct."

**Step 5 — Summary of the method.**

Write on the board:
1. Find the slope m (from the table, graph, or two points).
2. Find the y-intercept b (read it from x = 0, or substitute a point into y = mx + b and solve for b).
3. Write y = mx + b.
4. Verify with another point or the context.

### Worked Examples

**Example A: From a graph**
A line passes through (0, -3) and (4, 5).

Step 1: b = -3 (the line crosses the y-axis at (0, -3)).
Step 2: m = (5 - (-3))/(4 - 0) = 8/4 = 2.
Step 3: y = 2x - 3.
Check: When x = 4, y = 2(4) - 3 = 5. Correct.

**Example B: From two points (no y-intercept given)**
Write the equation of the line through (2, 1) and (5, 10).

Step 1: m = (10 - 1)/(5 - 2) = 9/3 = 3.
Step 2: Substitute (2, 1): 1 = 3(2) + b. 1 = 6 + b. b = -5.
Step 3: y = 3x - 5.
Check: When x = 5, y = 3(5) - 5 = 10. Correct.

**Example C: From a table**

| x | y |
|---|---|
| 3 | 2 |
| 5 | 8 |
| 7 | 14 |
| 9 | 20 |

Step 1: m = (8 - 2)/(5 - 3) = 6/2 = 3.
Step 2: Substitute (3, 2): 2 = 3(3) + b. 2 = 9 + b. b = -7.
Step 3: y = 3x - 7.
Check: When x = 9, y = 3(9) - 7 = 20. Correct.

## Guided Practice (10 minutes)

Work through these problems together. The student attempts each problem first, then discusses.

1. A line passes through (0, 4) and (2, 10). Write the equation.
   - *Answer:* m = (10 - 4)/(2 - 0) = 3. b = 4. Equation: y = 3x + 4.

2. Write the equation from this table:

   | x | y |
   |---|---|
   | 0 | -1 |
   | 1 | 2 |
   | 2 | 5 |
   | 3 | 8 |

   - *Answer:* m = 3 (y increases by 3 each time). b = -1 (when x = 0). Equation: y = 3x - 1.

3. Write the equation of the line through (2, 5) and (6, 13).
   - *Answer:* m = (13 - 5)/(6 - 2) = 8/4 = 2. Substitute (2, 5): 5 = 2(2) + b. 5 = 4 + b. b = 1. Equation: y = 2x + 1. Check with (6, 13): 2(6) + 1 = 13. Correct.

4. Write the equation of the line through (-1, 8) and (2, -1).
   - *Answer:* m = (-1 - 8)/(2 - (-1)) = -9/3 = -3. Substitute (2, -1): -1 = -3(2) + b. -1 = -6 + b. b = 5. Equation: y = -3x + 5. Check with (-1, 8): -3(-1) + 5 = 3 + 5 = 8. Correct.

5. A gym membership costs $200 after 3 months and $350 after 6 months. Write a linear equation for the cost C after m months.
   - *Answer:* m = (350 - 200)/(6 - 3) = 150/3 = 50 (dollars per month). Substitute (3, 200): 200 = 50(3) + b. 200 = 150 + b. b = 50 (the sign-up fee). Equation: C = 50m + 50.

**Facilitator tip:** The most common error is forgetting to solve for b after finding the slope. Students often write "y = 3x" and leave off the y-intercept. Reinforce the full process: slope THEN y-intercept THEN write the equation THEN verify.

## Independent Practice (10-15 minutes)

### Part A: Writing Equations from Graphs
Write the equation of each line described.

1. A line passes through (0, 7) and (3, 1).
2. A line passes through (0, -4) and (2, 2).
3. A line passes through (0, 0) and (5, 15).

### Part B: Writing Equations from Two Points
Write the equation of the line through each pair of points.

4. (1, 6) and (3, 12)
5. (2, -1) and (4, 7)
6. (-2, 10) and (3, 0)
7. (1, 1) and (4, 10)
8. (-3, -7) and (1, 5)

### Part C: Word Problems

9. A plant is 4 cm tall after 1 week and 10 cm tall after 3 weeks. Assuming the growth is linear, write an equation for the height h in terms of weeks w. How tall was the plant when it was first measured (at week 0)?
10. A pool has 320 gallons of water after 2 hours of draining and 200 gallons after 5 hours. Write a linear equation for the water level W in terms of hours h. How much water was in the pool before draining started?
11. A cell phone plan costs $68 after using 40 minutes and $86 after using 100 minutes. Write a linear equation for the cost C in terms of minutes m. What is the base fee (cost for 0 minutes)?

### Answer Key

**Part A**
1. m = (1 - 7)/(3 - 0) = -6/3 = -2. b = 7. Equation: y = -2x + 7.
2. m = (2 - (-4))/(2 - 0) = 6/2 = 3. b = -4. Equation: y = 3x - 4.
3. m = (15 - 0)/(5 - 0) = 15/5 = 3. b = 0. Equation: y = 3x.

**Part B**
4. m = (12 - 6)/(3 - 1) = 6/2 = 3. Substitute (1, 6): 6 = 3(1) + b. b = 3. Equation: y = 3x + 3. Check: 3(3) + 3 = 12. Correct.
5. m = (7 - (-1))/(4 - 2) = 8/2 = 4. Substitute (2, -1): -1 = 4(2) + b. -1 = 8 + b. b = -9. Equation: y = 4x - 9. Check: 4(4) - 9 = 7. Correct.
6. m = (0 - 10)/(3 - (-2)) = -10/5 = -2. Substitute (3, 0): 0 = -2(3) + b. 0 = -6 + b. b = 6. Equation: y = -2x + 6. Check: -2(-2) + 6 = 10. Correct.
7. m = (10 - 1)/(4 - 1) = 9/3 = 3. Substitute (1, 1): 1 = 3(1) + b. b = -2. Equation: y = 3x - 2. Check: 3(4) - 2 = 10. Correct.
8. m = (5 - (-7))/(1 - (-3)) = 12/4 = 3. Substitute (1, 5): 5 = 3(1) + b. b = 2. Equation: y = 3x + 2. Check: 3(-3) + 2 = -7. Correct.

**Part C**
9. m = (10 - 4)/(3 - 1) = 6/2 = 3 cm per week. Substitute (1, 4): 4 = 3(1) + b. b = 1. Equation: h = 3w + 1. At week 0, h = 1 cm. The plant was 1 cm tall when first measured.
10. m = (200 - 320)/(5 - 2) = -120/3 = -40 gallons per hour. Substitute (2, 320): 320 = -40(2) + b. 320 = -80 + b. b = 400. Equation: W = -40h + 400. Before draining (h = 0), there were 400 gallons.
11. m = (86 - 68)/(100 - 40) = 18/60 = 0.30 dollars per minute. Substitute (40, 68): 68 = 0.30(40) + b. 68 = 12 + b. b = 56. Equation: C = 0.30m + 56. The base fee is $56.

## Assessment Check

### Exit Ticket
**Problem 1:** Write the equation of the line through (2, 3) and (4, 9).
**Problem 2:** A table shows (1, 5), (3, 11), (5, 17). Write the equation.

**Target response:**
1. m = (9 - 3)/(4 - 2) = 6/2 = 3. Substitute (2, 3): 3 = 3(2) + b. 3 = 6 + b. b = -3. Equation: y = 3x - 3.
2. m = (11 - 5)/(3 - 1) = 6/2 = 3. Substitute (1, 5): 5 = 3(1) + b. b = 2. Equation: y = 3x + 2. Check: 3(5) + 2 = 17. Correct.

## Extension

- **Equation from Context — Design Challenge:** Make up three real-world situations that result in linear equations. For each one, provide two data points (not including x = 0). Exchange with the facilitator and solve each other's problems. Check by verifying that both original data points satisfy the equation.
- **Secret Point Challenge:** The facilitator picks a secret linear equation. The student is allowed to ask for the y-value at any two x-values of their choice. From those two points, the student must determine the equation. Try to make it work in as few questions as possible.
