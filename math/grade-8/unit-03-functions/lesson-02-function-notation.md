# Math — Grade 8 — Unit 3, Lesson 2

## Topic
Function Notation

## Learning Objectives
- Read and interpret function notation f(x) as "the output of function f when the input is x."
- Evaluate functions for given input values using function notation.
- Identify the domain and range of a function from a table, set of ordered pairs, or equation.
- Translate between function notation and verbal descriptions.

## Prerequisites
- Understanding of what a function is (Lesson 1)
- Ability to evaluate algebraic expressions by substituting values for variables (Grade 7)
- Familiarity with order of operations (Grade 6-7)

## Materials Needed
- Whiteboard and markers (or projector).
- Student worksheet (Guided Practice and Independent Practice problems).
- Index cards or half-sheets for Exit Ticket.

**Standards:** 8.F.1 — Understand that a function is a rule that assigns to each input exactly one output. The graph of a function is the set of ordered pairs consisting of an input and the corresponding output.

## Warm-Up (5 minutes)
**Purpose:** Review function concepts and practice substitution into expressions.

1. Evaluate 3x + 2 when x = 4. (14)
2. Evaluate x^2 - 1 when x = 5. (24)
3. Evaluate 2x - 7 when x = -3. (-13)
4. Is this a function? {(1, 6), (2, 8), (3, 6), (4, 10)}. (Yes — each input has one output.)
5. Ask: "Instead of writing 'evaluate 3x + 2 when x = 4,' mathematicians have a shorthand. Today we learn that shorthand."

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Function notation** — the notation f(x), read as "f of x," which represents the output of function f when the input is x.
- **Evaluate** — to find the output of a function for a specific input value.
- **Domain** — the set of all possible input values (x-values) for a function.
- **Range** — the set of all possible output values (y-values) for a function.

### Instruction Notes

**Step 1 — Introduce function notation.**

Write on the board: f(x) = 2x + 3.

Say: "This is called function notation. The letter f is the NAME of the function — like naming a pet. The x inside the parentheses is the INPUT. And the expression 2x + 3 is the RULE that tells us what to do with the input to get the output."

Say: "IMPORTANT: f(x) does NOT mean f times x. The parentheses here do not mean multiplication. They mean 'f evaluated at x.' Think of it as: f is a machine, and x is what you feed into it."

**Step 2 — Demonstrate evaluating a function.**

Write: f(x) = 2x + 3. Find f(5).

Say: "f(5) means: replace every x in the rule with 5."
- f(5) = 2(5) + 3 = 10 + 3 = 13.
- So f(5) = 13. The input is 5, the output is 13.

Write: Find f(-2).
- f(-2) = 2(-2) + 3 = -4 + 3 = -1.
- So f(-2) = -1.

Write: Find f(0).
- f(0) = 2(0) + 3 = 0 + 3 = 3.
- So f(0) = 3.

Say: "Notice that f(0) gives us the value when x = 0. On a graph, that is the y-intercept. We will use this idea a lot in later lessons."

**Step 3 — Show that functions can use different letters.**

Write: g(x) = x^2 - 4. Find g(3).

Say: "The function is named g instead of f, but the process is the same. Replace x with 3."
- g(3) = (3)^2 - 4 = 9 - 4 = 5.

Write: h(t) = 5t + 10. Find h(6).

Say: "This function is named h, and the input variable is t instead of x. Same idea — replace t with 6."
- h(6) = 5(6) + 10 = 30 + 10 = 40.

**Step 4 — Connect function notation to ordered pairs.**

Say: "When we write f(2) = 7, we are saying: input 2, output 7. As an ordered pair, that is (2, 7). So f(x) = y means the point (x, y) is on the graph of f."

Write these equivalences:
- f(2) = 7 means the point (2, 7) is on the graph.
- f(0) = 3 means the point (0, 3) is on the graph.
- f(-1) = 1 means the point (-1, 1) is on the graph.

**Step 5 — Domain and range from a function.**

Say: "The domain is all the inputs the function can accept. The range is all the outputs the function actually produces."

Example: Given f = {(1, 3), (2, 5), (3, 7), (4, 9)}.
- Domain: {1, 2, 3, 4}.
- Range: {3, 5, 7, 9}.

Say: "For an equation like f(x) = 2x + 3, with no restrictions stated, we can plug in any number for x. In later math, you will study domains more carefully, but for now, assume you can use any real number as an input unless told otherwise."

### Worked Examples

**Example A: Evaluating a linear function**
Given f(x) = 4x - 1. Find f(3), f(0), and f(-2).

- f(3) = 4(3) - 1 = 12 - 1 = 11.
- f(0) = 4(0) - 1 = 0 - 1 = -1.
- f(-2) = 4(-2) - 1 = -8 - 1 = -9.

**Example B: Evaluating a quadratic function**
Given g(x) = x^2 + 2x. Find g(4) and g(-3).

- g(4) = (4)^2 + 2(4) = 16 + 8 = 24.
- g(-3) = (-3)^2 + 2(-3) = 9 + (-6) = 3.

**Example C: Finding an input from a given output**
Given f(x) = 3x + 5. Find x when f(x) = 20.

- Set up the equation: 3x + 5 = 20.
- Subtract 5: 3x = 15.
- Divide by 3: x = 5.
- Check: f(5) = 3(5) + 5 = 15 + 5 = 20. Correct.

## Guided Practice (10 minutes)

Work through these problems together. The student attempts each problem first, then discusses.

1. Given f(x) = 5x - 3. Find f(4).
   - *Answer:* f(4) = 5(4) - 3 = 20 - 3 = 17.

2. Given g(x) = x^2 + 1. Find g(6).
   - *Answer:* g(6) = 36 + 1 = 37.

3. Given h(x) = -2x + 10. Find h(0) and h(7).
   - *Answer:* h(0) = -2(0) + 10 = 10. h(7) = -2(7) + 10 = -14 + 10 = -4.

4. Given f(x) = 3x - 8. If f(x) = 13, find x.
   - *Answer:* 3x - 8 = 13. 3x = 21. x = 7.

5. A function is given as ordered pairs: p = {(0, 2), (1, 5), (2, 8), (3, 11), (4, 14)}. State the domain and range.
   - *Answer:* Domain: {0, 1, 2, 3, 4}. Range: {2, 5, 8, 11, 14}.

6. For the function in problem 5, what is p(3)?
   - *Answer:* p(3) = 11 (the output when the input is 3).

**Facilitator tip:** If the student writes f(3) as "f times 3," stop immediately and re-explain. This is the single most common notation error. Use the analogy: "f(3) is like saying 'Room 204' — the number tells you WHICH room, not that you multiply Room by 204."

## Independent Practice (10-15 minutes)

### Part A: Evaluating Functions
Given f(x) = 2x + 7, find:

1. f(3)
2. f(0)
3. f(-4)
4. f(10)

Given g(x) = x^2 - 3x, find:

5. g(5)
6. g(-2)
7. g(0)
8. g(1)

### Part B: Finding Inputs
Solve for x.

9. f(x) = 4x + 1. If f(x) = 25, find x.
10. g(x) = 6x - 10. If g(x) = 8, find x.
11. h(x) = -3x + 15. If h(x) = 0, find x.

### Part C: Word Problems

12. A phone plan charges a monthly fee according to the function C(m) = 0.10m + 30, where m is the number of text messages and C is the total cost in dollars. Find C(100) and explain what it means.
13. The height of a ball thrown upward is modeled by h(t) = -16t^2 + 48t + 5, where t is time in seconds and h is height in feet. Find h(0), h(1), and h(2). What does h(0) represent?

### Answer Key

**Part A**
1. f(3) = 2(3) + 7 = 6 + 7 = 13.
2. f(0) = 2(0) + 7 = 0 + 7 = 7.
3. f(-4) = 2(-4) + 7 = -8 + 7 = -1.
4. f(10) = 2(10) + 7 = 20 + 7 = 27.
5. g(5) = (5)^2 - 3(5) = 25 - 15 = 10.
6. g(-2) = (-2)^2 - 3(-2) = 4 + 6 = 10.
7. g(0) = (0)^2 - 3(0) = 0 - 0 = 0.
8. g(1) = (1)^2 - 3(1) = 1 - 3 = -2.

**Part B**
9. 4x + 1 = 25. 4x = 24. x = 6. Check: f(6) = 4(6) + 1 = 25. Correct.
10. 6x - 10 = 8. 6x = 18. x = 3. Check: g(3) = 6(3) - 10 = 8. Correct.
11. -3x + 15 = 0. -3x = -15. x = 5. Check: h(5) = -3(5) + 15 = 0. Correct.

**Part C**
12. C(100) = 0.10(100) + 30 = 10 + 30 = 40. This means if you send 100 text messages, your monthly phone bill is $40.
13. h(0) = -16(0)^2 + 48(0) + 5 = 5. h(1) = -16(1) + 48(1) + 5 = -16 + 48 + 5 = 37. h(2) = -16(4) + 48(2) + 5 = -64 + 96 + 5 = 37. h(0) = 5 represents the initial height of the ball — it was thrown from 5 feet above the ground.

## Assessment Check

### Exit Ticket
**Problem 1:** Given f(x) = -3x + 11, find f(4).
**Problem 2:** Given g(x) = 2x - 5. If g(x) = 9, find x.

**Target response:**
1. f(4) = -3(4) + 11 = -12 + 11 = -1.
2. 2x - 5 = 9. 2x = 14. x = 7.

## Extension

- **Mystery Function:** A function produces these ordered pairs: (1, 1), (2, 4), (3, 9), (4, 16), (5, 25). Write the function rule using function notation. Then use your rule to predict the output when the input is 10. (The rule is f(x) = x^2. f(10) = 100.)
- **Two Functions, One Question:** Given f(x) = 2x + 3 and g(x) = x + 8. For what value of x does f(x) = g(x)? Set the two expressions equal: 2x + 3 = x + 8. Solve: x = 5. Check: f(5) = 13, g(5) = 13. Both functions give the same output when x = 5.
