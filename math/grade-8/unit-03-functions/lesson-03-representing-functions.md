# Math — Grade 8 — Unit 3, Lesson 3

## Topic
Representing Functions

## Learning Objectives
- Represent a function using four forms: table, graph, equation, and verbal description.
- Translate a function from one representation to another (e.g., table to graph, equation to table).
- Recognize that different representations describe the same function.
- Choose the most useful representation for a given context.

## Prerequisites
- Understanding of functions and function notation (Lessons 1-2)
- Ability to plot ordered pairs on a coordinate plane (Grade 6-7)
- Ability to evaluate expressions by substitution (Grade 7)

## Materials Needed
- Whiteboard and markers (or projector).
- Graph paper or pre-printed coordinate planes.
- Ruler or straightedge.
- Student worksheet (Guided Practice and Independent Practice problems).
- Index cards or half-sheets for Exit Ticket.

**Standards:** 8.F.1 — Understand that a function is a rule that assigns to each input exactly one output. The graph of a function is the set of ordered pairs consisting of an input and the corresponding output. 8.F.2 — Compare properties of two functions each represented in a different way (algebraically, graphically, numerically in tables, or by verbal descriptions).

## Warm-Up (5 minutes)
**Purpose:** Review evaluating functions and connect to building tables.

1. Given f(x) = x + 4, evaluate: f(0), f(1), f(2), f(3). (4, 5, 6, 7)
2. Write the four results as ordered pairs. ((0, 4), (1, 5), (2, 6), (3, 7))
3. Ask: "You just created a table of values and a set of ordered pairs from an equation. Today we will explore how one function can look like a table, a graph, an equation, AND a word description — and how to move between them."

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Table of values** — a list of input-output pairs organized in rows or columns.
- **Graph** — a visual representation on the coordinate plane showing the set of all input-output pairs.
- **Equation** — a symbolic rule using variables that describes the relationship between input and output.
- **Verbal description** — a description in words of the rule relating input to output.
- **Representations** — the different ways to display or describe a function.

### Instruction Notes

**Step 1 — Introduce the four representations.**

Write on the board:

"Four Ways to Show a Function: Table | Graph | Equation | Words"

Say: "Every function can be shown in all four ways. Each way has advantages. A table shows specific values clearly. A graph shows the overall shape and trend. An equation lets you calculate any output precisely. A verbal description connects the function to a real-world context."

**Step 2 — Demonstrate: From equation to table to graph.**

Write: f(x) = 2x - 1.

Say: "Let us start with an equation and build a table by choosing input values."

Build the table:

| x | f(x) = 2x - 1 | y |
|---|----------------|---|
| -1 | 2(-1) - 1 | -3 |
| 0 | 2(0) - 1 | -1 |
| 1 | 2(1) - 1 | 1 |
| 2 | 2(2) - 1 | 3 |
| 3 | 2(3) - 1 | 5 |

Say: "Now we have five ordered pairs: (-1, -3), (0, -1), (1, 1), (2, 3), (3, 5). Let us plot these on a coordinate plane."

Describe the graph: "Plot each point. The points form a straight line that rises from left to right, crossing the y-axis at (0, -1). Connect the points with a straight line and extend it in both directions with arrows."

Say: "The verbal description would be: 'Start at -1 and add 2 for each step.' Or in a real-world context: 'A taxi ride costs $2 per mile with a $1 discount coupon, so the cost is 2 times the miles minus 1.'"

**Step 3 — Demonstrate: From table to equation.**

Present this table:

| x | y |
|---|---|
| 0 | 3 |
| 1 | 5 |
| 2 | 7 |
| 3 | 9 |
| 4 | 11 |

Say: "To find the equation, look for a pattern. Each time x increases by 1, y increases by 2. That means the rate of change is 2. When x = 0, y = 3. So the equation is y = 2x + 3."

Verify: "Check: when x = 4, y = 2(4) + 3 = 11. That matches the table."

**Step 4 — Demonstrate: From graph to table and equation.**

Describe a graph: "Imagine a straight line that passes through the points (0, 5), (1, 3), (2, 1), and (3, -1). The line slopes downward from left to right."

Say: "Reading the graph, we can build a table."

| x | y |
|---|---|
| 0 | 5 |
| 1 | 3 |
| 2 | 1 |
| 3 | -1 |

Say: "Each time x increases by 1, y decreases by 2. When x = 0, y = 5. The equation is y = -2x + 5."

**Step 5 — Demonstrate: From verbal description to equation.**

Say: "A streaming service charges $8 per month plus a one-time $15 activation fee. Write a function for the total cost C after m months."

- The rate is $8 per month, so the coefficient of m is 8.
- The one-time fee of $15 is the starting amount.
- C(m) = 8m + 15.

Say: "Now you can make a table, plot a graph, or find the cost for any number of months."

### Worked Examples

**Example A: Equation to table and graph**
f(x) = -x + 4.

Table:

| x | f(x) |
|---|------|
| 0 | 4 |
| 1 | 3 |
| 2 | 2 |
| 3 | 1 |
| 4 | 0 |

Graph description: The points (0, 4), (1, 3), (2, 2), (3, 1), (4, 0) form a straight line that slopes downward from left to right. The line crosses the y-axis at (0, 4) and the x-axis at (4, 0).

Verbal description: "Start at 4 and subtract 1 each time x increases by 1." Or: "The amount of water in a 4-gallon tank that drains 1 gallon per minute."

**Example B: Table to equation**
| x | y |
|---|---|
| 1 | 6 |
| 2 | 9 |
| 3 | 12 |
| 4 | 15 |
| 5 | 18 |

The rate of change: each time x increases by 1, y increases by 3. So the multiplier is 3.
Check with x = 1: 3(1) = 3, but y = 6. The difference is 3. So y = 3x + 3.
Verify with x = 5: 3(5) + 3 = 18. Correct.

**Example C: Verbal description to equation and table**
"A plant is 2 inches tall when purchased and grows 1.5 inches per week."

Equation: h(w) = 1.5w + 2, where w = number of weeks and h = height in inches.

Table:

| w (weeks) | h (inches) |
|-----------|------------|
| 0 | 2 |
| 2 | 5 |
| 4 | 8 |
| 6 | 11 |
| 8 | 14 |

## Guided Practice (10 minutes)

Work through these problems together. The student attempts each problem first, then discusses.

1. Given f(x) = 3x - 2, build a table for x = 0, 1, 2, 3, 4 and describe what the graph would look like.
   - *Answer:* Table: (0, -2), (1, 1), (2, 4), (3, 7), (4, 10). The graph is a straight line rising from left to right, crossing the y-axis at (0, -2).

2. A table shows: (0, 10), (1, 7), (2, 4), (3, 1), (4, -2). Find the equation.
   - *Answer:* Rate of change: -3 (y decreases by 3 each time x increases by 1). When x = 0, y = 10. Equation: y = -3x + 10.

3. Write a verbal description for the function y = 5x + 20.
   - *Answer:* Possible: "A worker earns $5 per hour plus a $20 bonus" or "Start at 20 and add 5 for each unit increase in x."

4. A car rental company charges $45 per day plus a $30 insurance fee. Write the function, make a table for days 1-5, and state the cost for 7 days.
   - *Answer:* C(d) = 45d + 30. Table: (1, 75), (2, 120), (3, 165), (4, 210), (5, 255). C(7) = 45(7) + 30 = 345. The cost for 7 days is $345.

5. A graph shows a straight line through (0, 1) and (4, 9). Find the rate of change and write the equation.
   - *Answer:* Rate of change = (9 - 1)/(4 - 0) = 8/4 = 2. Y-intercept is 1. Equation: y = 2x + 1.

**Facilitator tip:** When students struggle to find equations from tables, teach them to always find the rate of change first (how much y changes when x changes by 1), then use the value of y when x = 0 as the starting point. If x = 0 is not in the table, work backward.

## Independent Practice (10-15 minutes)

2. g(x) = -2x + 8. Build a table for x = 0, 1, 2, 3, 4. Describe the graph.
3. h(x) = 4x. Build a table for x = -2, -1, 0, 1, 2. Describe the graph.

### Part C: Word Problems

7. A gym charges a one-time registration fee of $50 and a monthly fee of $25. Write a function for the total cost after m months. Build a table for months 0 through 6. How much does a one-year membership cost?
8. A candle is 12 inches tall and burns at a rate of 0.5 inches per hour. Write a function for the height h after t hours of burning. Build a table for t = 0, 2, 4, 6, 8. After how many hours will the candle be completely burned?

### Answer Key

**Part A**
1. Table: (0, 6), (1, 7), (2, 8), (3, 9), (4, 10). The graph is a straight line rising gently from left to right, crossing the y-axis at (0, 6). It has a slope of 1.
2. Table: (0, 8), (1, 6), (2, 4), (3, 2), (4, 0). The graph is a straight line falling from left to right, crossing the y-axis at (0, 8) and the x-axis at (4, 0).
3. Table: (-2, -8), (-1, -4), (0, 0), (1, 4), (2, 8). The graph is a straight line passing through the origin, rising steeply from left to right. It has a slope of 4.

**Part B**
4. Rate of change: (2 - (-1))/(1 - 0) = 3. Y-intercept: -1. Equation: y = 3x - 1. Check: 3(4) - 1 = 11. Correct.
5. Rate of change: (17 - 20)/(1 - 0) = -3. Y-intercept: 20. Equation: y = -3x + 20. Check: -3(4) + 20 = 8. Correct.
6. Rate of change: (11 - 7)/(2 - 1) = 4. Using point (1, 7): 7 = 4(1) + b, so b = 3. Equation: y = 4x + 3. Check: 4(5) + 3 = 23. Correct.

**Part C**
7. C(m) = 25m + 50. Table: (0, 50), (1, 75), (2, 100), (3, 125), (4, 150), (5, 175), (6, 200). One year (12 months): C(12) = 25(12) + 50 = 300 + 50 = $350.
8. h(t) = -0.5t + 12. Table: (0, 12), (2, 11), (4, 10), (6, 9), (8, 8). The candle is completely burned when h(t) = 0: -0.5t + 12 = 0, so t = 24 hours.

## Assessment Check

### Exit Ticket
**Problem 1:** Given the table below, find the equation of the function.

| x | y |
|---|---|
| 0 | 4 |
| 1 | 7 |
| 2 | 10 |
| 3 | 13 |

**Problem 2:** A pool contains 500 gallons of water and is being drained at 25 gallons per minute. Write a function for the amount of water W after t minutes.

**Target response:**
1. Rate of change: 3. Y-intercept: 4. Equation: y = 3x + 4.
2. W(t) = -25t + 500 (or equivalently, W(t) = 500 - 25t).

## Extension

- **Representation Challenge:** Choose any real-world situation you like. Represent it as: (1) a verbal description, (2) an equation, (3) a table with at least 5 entries, and (4) a graph. All four should describe the SAME function. Present all four to the facilitator.
- **Which Representation Is Best?** For each scenario, decide which representation would be MOST useful and explain why: (a) You need to find the exact cost after 37 months. (b) You want to see whether the function is increasing or decreasing at a glance. (c) You want to quickly look up a few specific values. (d) You need to explain the situation to someone who does not know algebra.
