## Answer Key

### Section 1: Understanding Functions

**1.1a.** {(2, 5), (3, 8), (4, 5), (5, 12)}.
- **Function.** Each input (2, 3, 4, 5) has exactly one output. The fact that inputs 2 and 4 both produce the output 5 is allowed — the rule is about inputs, not outputs.

**1.1b.** {(1, 3), (2, 7), (1, 9), (3, 4)}.
- **Not a function.** The input 1 appears twice with different outputs (3 and 9). A function requires each input to have exactly one output.

**1.2a.** f(5) = 4(5) - 3 = 20 - 3 = **17**.

**1.2b.** f(0) = 4(0) - 3 = 0 - 3 = **-3**.

**1.2c.** f(-2) = 4(-2) - 3 = -8 - 3 = **-11**.

**1.3a.** Completed table:

| x | f(x) |
|---|------|
| 0 | 1 |
| 1 | 4 |
| 2 | 7 |
| 3 | 10 |
| 4 | 13 |

**1.3b.** Range: **{1, 4, 7, 10, 13}**.

**1.3c.** 3x + 1 = 13. 3x = 12. **x = 4**.

### Section 2: Linear Functions and Slope

**2.1a.** Changes in y: +4, +4, +4, +4. The rate of change is constant.
- **Linear.** The function has a constant rate of change of 4. (Equation: y = 4x + 6.)

**2.1b.** Changes in y: +1, +3, +5, +7. The rate of change is not constant.
- **Nonlinear.** The differences between consecutive y-values increase, so the rate of change is not constant. (This is y = x^2 + 1.)

**2.2a.** Points (1, 3) and (4, 15).
- m = (15 - 3) / (4 - 1) = 12 / 3 = **4**.

**2.2b.** Points (2, 10) and (6, 2).
- m = (2 - 10) / (6 - 2) = -8 / 4 = **-2**.

**2.3a.** **Positive.**

**2.3b.** **Zero.**

**2.3c.** **Undefined** (division by zero).

**2.3d.** m = (8 - 8) / (5 - 0) = 0 / 5 = **0**. This is a **horizontal line**.

### Section 3: Slope-Intercept Form

**3.1a.** y = 3x + 7. Slope: **3**. Y-intercept: **7** (the point (0, 7)).

**3.1b.** y = -2x + 5. Slope: **-2**. Y-intercept: **5** (the point (0, 5)).

**3.1c.** y = x - 4. Slope: **1**. Y-intercept: **-4** (the point (0, -4)).

**3.1d.** y = -5x. Slope: **-5**. Y-intercept: **0** (the point (0, 0)).

**3.2.** y = 2x - 3.
- Y-intercept: (0, -3). Plot this point.
- Slope = 2 = 2/1. From (0, -3), rise 2, run 1 to (1, -1).
- From (1, -1), rise 2, run 1 to (2, 1).
- Three points: **(0, -3), (1, -1), (2, 1)**.
- Draw a straight line through all three points extending in both directions.
- The line rises from left to right, crossing the y-axis at (0, -3) and the x-axis at (1.5, 0).

**3.3.** Line through (2, 1) and (5, 10).
- Step 1: Slope: m = (10 - 1) / (5 - 2) = 9 / 3 = **3**.
- Step 2: Substitute (2, 1) into y = 3x + b: 1 = 3(2) + b. 1 = 6 + b. **b = -5**.
- Step 3: Equation: **y = 3x - 5**.
- Check: When x = 5, y = 3(5) - 5 = 10. Correct.

### Section 4: Comparing and Analyzing Functions

**4.1a.** Rate of change of Function A: **3** (the coefficient of x in y = 3x + 2).

**4.1b.** Rate of change of Function B: Using (0, 8) and (1, 10): m = (10 - 8)/(1 - 0) = **2**.

**4.1c.** **Function A** has the greater rate of change (3 > 2).

**4.1d.** At x = 0: Function A gives 3(0) + 2 = 2. Function B gives 8. **Function B** has the greater value at x = 0.

**4.1e.** Function B equation: y = 2x + 8. Set equal to Function A:
- 3x + 2 = 2x + 8.
- x + 2 = 8.
- **x = 6**.
- Check: A(6) = 3(6) + 2 = 20. B(6) = 2(6) + 8 = 20. Both equal 20.

**4.2.** The function is **increasing** throughout (the y-values always go up). It is **nonlinear** because the graph curves — it rises steeply at first and then more gradually. The rate of increase slows down as x increases.

**4.3.** Acceptable example: **y = x^2** is nonlinear because the variable x is raised to the second power. In a linear function, x appears only to the first power. When x = 1, y = 1; when x = 2, y = 4; when x = 3, y = 9. The changes (+3, +5) are not constant, confirming it is nonlinear.

(Other valid examples: y = 2^x, y = x^3, y = 1/x, etc., with appropriate explanations.)

### Section 5: Word Problems

**5.1a.** **C(m) = 8m + 12** (or equivalently, C = 8m + 12).

**5.1b.** C(6) = 8(6) + 12 = 48 + 12 = **$60**.

**5.1c.** 8m + 12 = 76. 8m = 64. m = **8 months**.

**5.2a.** Aisha: **S = 15w + 50**. Ben: **S = 5w + 110**.

**5.2b.** Set equal: 15w + 50 = 5w + 110.
- 10w + 50 = 110.
- 10w = 60.
- **w = 6 weeks**.
- Amount: 15(6) + 50 = 90 + 50 = **$140**. (Check: 5(6) + 110 = 30 + 110 = $140.)

## Rubric and Mastery Determination

| Level | Score Range | Meaning | Next Steps |
|-------|-----------|---------|------------|
| **Mastered** | 40-50 (80-100%) with at least 50% per section | Solid understanding of functions, linear relationships, and slope | Advance to Unit 4 (Geometry). Include function concepts in spaced review. |
| **Approaching** | 30-39 (60-79%) | Partial understanding; specific gaps in one or more areas | Identify weak sections and reteach. See section-specific guide below. Reassess weak sections before advancing. |
| **Developing** | Below 30 (<60%) | Significant gaps across multiple areas | Check prerequisites: Can the student plot points? Evaluate expressions? Solve equations? Address foundational gaps before reteaching unit content. |

### Section-Specific Reteaching Guide

| If struggling in... | Focus on... |
|---|---|
| Section 1 (Understanding Functions) | Return to Lessons 1-2. Use mapping diagrams with physical objects (cards and string) to reinforce the one-input-one-output rule. For function notation, practice 10 evaluations with the explicit step "replace every x with [number]" written out. The most common issue is treating f(x) as multiplication — address this directly. |
| Section 2 (Linear Functions and Slope) | Return to Lessons 4-5. For linear vs. nonlinear, practice computing differences in y-values for 8-10 tables and classifying each as constant or non-constant. For slope, use graph paper and physically count rise and run between two plotted points before using the formula. Practice with points that produce positive, negative, zero, and undefined slopes. |
| Section 3 (Slope-Intercept Form) | Return to Lessons 6-7. Start by identifying m and b from 10 equations before graphing any of them. Then practice graphing using the step-by-step method: (1) plot y-intercept, (2) use slope to find next point, (3) verify with a third point. For writing equations, use the structured template: find slope, substitute a point, solve for b, write the equation, verify. |
| Section 4 (Comparing and Analyzing Functions) | Return to Lessons 8-9. First, ensure the student can fluently extract slope and y-intercept from ANY representation (table, equation, graph description). Practice extracting these values from 6-8 representations before attempting any comparisons. For qualitative descriptions, use real-world graph scenarios (speed of a car, temperature over a day) to build intuition about increasing/decreasing and linear/nonlinear. |
| Section 5 (Word Problems) | Return to Lessons 3 and 10. Separate the translation skill from the solving skill. Give 5 word problems and ask the student to write ONLY the equation (do not solve). Then give 5 equations in context and ask the student to solve and interpret. Finally, combine both skills. Key phrase translations: "per" = slope, "starts at" or "initial" = y-intercept. |

## Error Analysis Guide

| Error Pattern | Example | Likely Cause | Intervention |
|--------------|---------|-------------|-------------|
| Treats f(x) as multiplication | Writes f(3) = f * 3 = 3f | Does not understand function notation | Re-explain: f(x) means "the function f applied to x," not "f times x." Use the machine analogy: feed in 3, get out a result. Practice 10 evaluations. |
| Confuses slope and y-intercept | In y = 5x + 2, says slope is 2 | Mixes up m and b | Use the mnemonic: m is the Multiplier of x (slope), b is the Beginning value (y-intercept). Practice identifying both from 10 equations. |
| Computes slope as run/rise | Gets 1/4 instead of 4 for points (0, 0) and (1, 4) | Reverses the fraction | Reinforce: slope = rise/run = change in y / change in x. The y-change always goes on top. Write the formula and circle the y-terms on top. |
| Gets wrong sign for slope | Computes slope as positive when line goes down | Subtraction order inconsistent | Emphasize: subtract in the SAME order for both y and x. If you do y2 - y1, you must do x2 - x1 (not x1 - x2). Show that reversing BOTH gives the same answer, but reversing only one flips the sign. |
| Forgets to solve for b | Finds slope m = 3 and writes y = 3x without finding b | Incomplete process — stops after finding slope | Use a checklist: (1) Find m. (2) Substitute a point to find b. (3) Write y = mx + b. (4) Verify with another point. Check off each step. |
| Says repeated outputs mean "not a function" | Sees {(1, 5), (2, 5), (3, 5)} and says "not a function" | Confuses the roles of inputs and outputs | Clarify: the rule is about INPUTS. One input, one output. Different inputs CAN share the same output. Show a mapping diagram where multiple arrows point to the same output — it is still a function. |
| Cannot compare functions in different forms | Stares at a table and an equation without making progress | Does not know how to extract comparable properties | Teach the extraction strategy: for EVERY function, find two things — slope and y-intercept. Once both functions are reduced to (slope, y-intercept), comparison is straightforward. |
| Describes all curves as "not a function" | Sees a parabola and says "not a function" | Confuses nonlinear with non-function | Clarify: a function can be linear OR nonlinear. A parabola (opening up or down) IS a function. Only graphs that fail the vertical line test are not functions (e.g., circles, sideways parabolas). |

## Facilitator Observations

- Does the student correctly identify functions vs. non-functions, or is there lingering confusion about repeated outputs vs. repeated inputs?
- Can the student evaluate f(x) fluently, or does each evaluation require prompting about what to substitute?
- When computing slope, does the student set up the formula correctly on the first attempt, or are there consistent sign errors?
- Can the student graph a line from y = mx + b without assistance, or does the student need reminders about which number is the slope and which is the y-intercept?
- When writing equations from two points, does the student follow all steps (find slope, substitute to find b, write equation, verify), or does the student skip steps?
- When comparing functions in different representations, can the student independently extract slope and y-intercept from a table, or does the student need the facilitator to convert it first?
- Can the student articulate the difference between linear and nonlinear in their own words?
- For word problems, can the student set up the equation independently, or does the student need prompting to identify which quantity is the slope and which is the y-intercept?
