# Math — Grade 8 — Unit 2, Lesson 7

## Topic
Solving Systems by Substitution

## Learning Objectives
- Use the substitution method to solve a system when one variable is already isolated.
- Isolate a variable in one equation when it is not already solved for, then substitute.
- Back-substitute to find the second variable.
- Verify the solution by checking the ordered pair in both original equations.

## Prerequisites
- Understanding of what a system of equations is and what constitutes a solution (Lesson 5)
- Experience solving systems by graphing (Lesson 6)
- Ability to solve multi-step equations in one variable (Lessons 1-4)
- Comfort with substituting expressions into equations

## Materials Needed
- Whiteboard and markers (or projector).
- Student worksheet (Guided Practice and Independent Practice problems).
- Index cards or half-sheets for Exit Ticket.

**Standards:** 8.EE.8b — Solve systems of two linear equations in two variables algebraically, and estimate solutions by graphing the equations. Solve simple cases by inspection.

## Warm-Up (5 minutes)

**Purpose:** Review the idea that if two expressions both equal y, then the two expressions must equal each other.

1. If y = 3x + 1 and y = 7, what is 3x + 1 equal to? (7)
2. Solve: 3x + 1 = 7. (x = 2)
3. So if y = 3x + 1 and y = 7, the solution is x = 2 and y = 7, or the ordered pair (2, 7).
4. Ask: "What if instead of y = 7, we had y = -x + 9? Could we still set the two expressions for y equal to each other?"

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Substitution** — replacing a variable with an expression that is equal to it. If y = 3x + 1, we can replace y in another equation with (3x + 1).
- **Back-substitute** — after finding the value of one variable, substitute it back into one of the original equations to find the other variable.
- **Isolate** — solve for one variable in terms of the other (e.g., rewrite 2x + y = 10 as y = -2x + 10).

### Instruction Notes

**Step 1 — When both equations are solved for y.**
Write the system:
- y = 3x + 1
- y = -x + 9

Say: "Both equations tell us what y equals. Since both right-hand sides equal y, they must equal each other."
- Set equal: 3x + 1 = -x + 9.
- Add x to both sides: 4x + 1 = 9.
- Subtract 1: 4x = 8.
- Divide by 4: x = 2.

Say: "Now we know x = 2. To find y, substitute x = 2 into either original equation."
- y = 3(2) + 1 = 7.
- Solution: (2, 7).

Check in both equations:
- y = 3(2) + 1 = 7. True.
- y = -(2) + 9 = 7. True.

**Step 2 — When one equation is solved for a variable, the other is not.**
Write the system:
- y = 2x - 1
- 3x + y = 14

Say: "The first equation tells us y = 2x - 1. We can replace y in the second equation with (2x - 1)."
- Substitute: 3x + (2x - 1) = 14.
- Combine: 5x - 1 = 14.
- Add 1: 5x = 15.
- Divide by 5: x = 3.

Back-substitute: y = 2(3) - 1 = 5.
Solution: (3, 5).

Check:
- y = 2(3) - 1 = 5. True.
- 3(3) + 5 = 14. True.

**Step 3 — When neither equation is solved for a variable.**
Write the system:
- x + 2y = 11
- 3x - y = 9

Say: "Neither equation has a variable isolated. We choose the equation and variable that is easiest to isolate. Here, the first equation is easiest to solve for x."
- From equation 1: x = 11 - 2y.
- Substitute into equation 2: 3(11 - 2y) - y = 9.
- Distribute: 33 - 6y - y = 9.
- Combine: 33 - 7y = 9.
- Subtract 33: -7y = -24.
- Divide by -7: y = 24/7.

Say: "This gives a fractional answer. Let me re-examine... Actually, let's try a cleaner system for the demonstration."

(Erase and rewrite.) Write the system:
- x + 2y = 10
- 3x - y = 5

From equation 1: x = 10 - 2y.
Substitute into equation 2: 3(10 - 2y) - y = 5.
- 30 - 6y - y = 5.
- 30 - 7y = 5.
- -7y = -25.

Say: "That still gives a fraction. Let me use: x + y = 7 and 2x - y = 5."

From equation 1: x = 7 - y.
Substitute into equation 2: 2(7 - y) - y = 5.
- 14 - 2y - y = 5.
- 14 - 3y = 5.
- -3y = -9.
- y = 3.

Back-substitute: x = 7 - 3 = 4. Solution: (4, 3).

Check: 4 + 3 = 7. True. 2(4) - 3 = 5. True.

**Step 4 — Summarize the substitution method.**
Write on the board:
1. Isolate one variable in one equation (choose the easiest one).
2. Substitute the expression into the other equation.
3. Solve the resulting one-variable equation.
4. Back-substitute to find the other variable.
5. Write the solution as an ordered pair (x, y).
6. Check in BOTH original equations.

### Worked Examples

**Example A — Both equations solved for y**
Solve: y = 4x - 5 and y = x + 4.
- Set equal: 4x - 5 = x + 4.
- Subtract x: 3x - 5 = 4.
- Add 5: 3x = 9.
- x = 3. Back-substitute: y = 3 + 4 = 7.
- Solution: (3, 7). Check: 7 = 4(3) - 5 = 7. 7 = 3 + 4. Correct.

**Example B — One equation solved for y**
Solve: y = -3x + 10 and 2x + y = 7.
- Substitute: 2x + (-3x + 10) = 7.
- Simplify: -x + 10 = 7.
- -x = -3. x = 3.
- Back-substitute: y = -3(3) + 10 = 1.
- Solution: (3, 1). Check: 1 = -9 + 10. 2(3) + 1 = 7. Correct.

**Example C — Neither solved; isolate first**
Solve: x + y = 7 and 2x - y = 5.
- Isolate y from equation 1: y = 7 - x.
- Substitute into equation 2: 2x - (7 - x) = 5.
- 2x - 7 + x = 5.
- 3x - 7 = 5.
- 3x = 12. x = 4.
- Back-substitute: y = 7 - 4 = 3.
- Solution: (4, 3). Check: 4 + 3 = 7. 2(4) - 3 = 5. Correct.

## Guided Practice (10 minutes)

Work through these problems together. The student attempts each problem first, then discusses.

1. Solve: y = 2x + 3 and y = -x + 12.
   - *Facilitator prompt:* "Both are solved for y. Set the right sides equal."

2. Solve: y = x - 4 and 3x + y = 16.
   - *Facilitator prompt:* "Replace y in the second equation with (x - 4)."

3. Solve: x = 5y - 2 and 2x + 3y = 22.
   - *Facilitator prompt:* "x is already isolated. Substitute into the second equation."

4. Solve: x + y = 10 and x - y = 4.
   - *Facilitator prompt:* "Isolate x (or y) from the first equation, then substitute."

5. Solve: 2x + y = 13 and x = y + 1.
   - *Facilitator prompt:* "Which equation already has a variable isolated?"

**Facilitator tip:** The most common errors are: (1) forgetting parentheses when substituting, leading to sign errors (e.g., writing 2x - 7 - x instead of 2x - (7 - x)); and (2) forgetting to back-substitute to find the second variable. Remind the student: "You need two values for a complete solution."

## Independent Practice (10-15 minutes)

### Part A — Both Equations Solved for y
Solve each system using substitution.

1. y = 3x - 4 and y = -2x + 11
2. y = x + 5 and y = -3x + 13
3. y = 4x and y = 2x + 6

### Part B — One Variable Isolated
Solve each system using substitution.

4. y = 2x + 1 and 4x - y = 5
5. x = 3y and 2x + y = 21
6. y = -x + 8 and 3x + 2y = 18

### Part C — Isolate First, Then Substitute

7. x + y = 9 and 3x - 2y = 8
8. 2x + y = 11 and x - y = 1
9. x + 3y = 14 and 2x - y = 7
10. A coffee shop sells lattes for $5 and teas for $3. A customer buys a total of 8 drinks and spends $30. Let x = lattes and y = teas. Write a system and solve by substitution.

### Answer Key

**Part A**
1. 3x - 4 = -2x + 11 → 5x = 15 → x = 3. y = 3(3) - 4 = 5. **Solution: (3, 5).** Check: 5 = 9 - 4, 5 = -6 + 11. Correct.
2. x + 5 = -3x + 13 → 4x = 8 → x = 2. y = 2 + 5 = 7. **Solution: (2, 7).** Check: 7 = 2 + 5, 7 = -6 + 13. Correct.
3. 4x = 2x + 6 → 2x = 6 → x = 3. y = 4(3) = 12. **Solution: (3, 12).** Check: 12 = 12, 12 = 6 + 6. Correct.

**Part B**
4. 4x - (2x + 1) = 5 → 4x - 2x - 1 = 5 → 2x = 6 → x = 3. y = 2(3) + 1 = 7. **Solution: (3, 7).** Check: 7 = 7, 12 - 7 = 5. Correct.
5. 2(3y) + y = 21 → 6y + y = 21 → 7y = 21 → y = 3. x = 3(3) = 9. **Solution: (9, 3).** Check: 9 = 9, 18 + 3 = 21. Correct.
6. 3x + 2(-x + 8) = 18 → 3x - 2x + 16 = 18 → x + 16 = 18 → x = 2. y = -2 + 8 = 6. **Solution: (2, 6).** Check: 6 = 6, 6 + 12 = 18. Correct.

**Part C**
7. From eq 1: y = 9 - x. Substitute: 3x - 2(9 - x) = 8 → 3x - 18 + 2x = 8 → 5x = 26 → x = 26/5. y = 9 - 26/5 = 19/5. **Solution: (26/5, 19/5) or (5.2, 3.8).** Check: 26/5 + 19/5 = 45/5 = 9. 3(26/5) - 2(19/5) = 78/5 - 38/5 = 40/5 = 8. Correct.
8. From eq 2: x = y + 1. Substitute: 2(y + 1) + y = 11 → 2y + 2 + y = 11 → 3y = 9 → y = 3. x = 3 + 1 = 4. **Solution: (4, 3).** Check: 8 + 3 = 11, 4 - 3 = 1. Correct.
9. From eq 1: x = 14 - 3y. Substitute: 2(14 - 3y) - y = 7 → 28 - 6y - y = 7 → -7y = -21 → y = 3. x = 14 - 9 = 5. **Solution: (5, 3).** Check: 5 + 9 = 14, 10 - 3 = 7. Correct.
10. System: x + y = 8 and 5x + 3y = 30. From eq 1: y = 8 - x. Substitute: 5x + 3(8 - x) = 30 → 5x + 24 - 3x = 30 → 2x = 6 → x = 3. y = 8 - 3 = 5. **Solution: 3 lattes and 5 teas.** Check: 3 + 5 = 8, 15 + 15 = 30. Correct.

## Assessment Check

### Exit Ticket
**Problem 1:** Solve by substitution: y = 2x + 1 and 3x + y = 16. Show all steps.
**Problem 2:** Solve by substitution: x + y = 11 and 2x - y = 7. Show all steps.

**Scoring:**
- 2 out of 2 correct (with complete work) = Mastery demonstrated.
- 1 out of 2 correct = Partial understanding; review errors.
- 0 out of 2 correct = Reteach needed.

**Exit Ticket Answer Key:**
1. Substitute: 3x + (2x + 1) = 16 → 5x + 1 = 16 → 5x = 15 → x = 3. y = 2(3) + 1 = 7. **Solution: (3, 7).** Check: 7 = 7, 9 + 7 = 16. Correct.
2. From eq 1: y = 11 - x. Substitute: 2x - (11 - x) = 7 → 2x - 11 + x = 7 → 3x = 18 → x = 6. y = 11 - 6 = 5. **Solution: (6, 5).** Check: 6 + 5 = 11, 12 - 5 = 7. Correct.

### If Mastery Is Not Met
- Slow down the procedure: write each step on a separate line and have the student explain WHY each step is valid.
- Use color-coding: write the expression being substituted in a different color so the student can see where it "lands" in the other equation.
- Provide equations where one variable is already fully isolated to reduce the number of steps.

### If Mastery Is Met
- Challenge: Solve a system with fractional coefficients: y = (1/2)x + 3 and y = -(3/2)x + 7.
- Preview: "Substitution works great when one variable is already isolated. But what if NEITHER equation has an easy variable to isolate? Next lesson, we will learn elimination — a method that works well in those cases."

## Extension

- **Comparison Problem:** Solve the system y = x + 2 and y = -x + 6 by both graphing AND substitution. Compare the two answers. Which method was faster? Which was more precise?
- **Create a System:** Write a system of equations where the solution is (5, -2). Use the substitution method to verify. Then trade with the facilitator.
