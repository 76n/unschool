# Math — Grade 8 — Unit 2, Lesson 2

## Topic
Solving Multi-Step Equations

## Learning Objectives
- Apply the distributive property to remove parentheses before solving.
- Combine like terms on the same side of an equation before isolating the variable.
- Solve equations that require both distributing and combining like terms.
- Verify solutions by substituting back into the original equation.

## Prerequisites
- Ability to solve two-step equations (Lesson 1)
- Understanding of the distributive property: a(b + c) = ab + ac (Grade 7)
- Ability to combine like terms: 3x + 5x = 8x, 4 + 7 = 11 (Grade 7)
- Fluency with integer operations, including negatives

## Materials Needed
- Whiteboard and markers (or projector).
- Student worksheet (Guided Practice and Independent Practice problems).
- Index cards or half-sheets for Exit Ticket.

**Standards:** 8.EE.7 — Solve linear equations in one variable. 8.EE.7b — Solve linear equations with rational number coefficients, including equations whose solutions require expanding expressions using the distributive property and collecting like terms.

## Warm-Up (5 minutes)

**Purpose:** Review the distributive property and combining like terms as isolated skills before applying them inside equations.

1. Expand: 4(x + 3). (4x + 12)
2. Expand: -2(3x - 5). (-6x + 10)
3. Simplify: 7x + 3 + 2x - 8. (9x - 5)
4. Ask: "Why would these skills matter when solving equations?"

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Distributive property** — the rule that a(b + c) = ab + ac. Used to remove parentheses.
- **Like terms** — terms that have the same variable raised to the same power. For example, 3x and 7x are like terms; 3x and 3x^2 are not.
- **Simplify** — combine like terms and perform operations to make an expression as compact as possible.
- **Multi-step equation** — an equation requiring more than two steps to solve, typically involving distribution and/or combining like terms.

### Instruction Notes

**Step 1 — Equations requiring combining like terms first.**
Write on the board: 3x + 5 + 2x = 30.

Say: "Before we can isolate x, we need to simplify the left side. There are two x-terms: 3x and 2x."
- Combine like terms: 5x + 5 = 30.
- Subtract 5: 5x = 25.
- Divide by 5: x = 5.
- Check: 3(5) + 5 + 2(5) = 15 + 5 + 10 = 30. Correct.

**Step 2 — Equations requiring the distributive property first.**
Write on the board: 3(x + 4) - 2 = 16.

Say: "There are parentheses, so we need to distribute first."
- Distribute: 3x + 12 - 2 = 16.
- Combine like terms on the left: 3x + 10 = 16.
- Subtract 10: 3x = 6.
- Divide by 3: x = 2.
- Check: 3(2 + 4) - 2 = 3(6) - 2 = 18 - 2 = 16. Correct.

**Step 3 — Equations with negative distribution.**
Write on the board: 5 - 2(x + 3) = 7.

Say: "Be very careful with the negative sign in front of the 2. Distribute -2 to both terms inside."
- Distribute: 5 - 2x - 6 = 7.
- Combine constants on the left: -2x - 1 = 7.
- Add 1: -2x = 8.
- Divide by -2: x = -4.
- Check: 5 - 2(-4 + 3) = 5 - 2(-1) = 5 + 2 = 7. Correct.

**Step 4 — Summarize the process.**
Write on the board:
1. Distribute (remove parentheses).
2. Combine like terms on each side.
3. Use inverse operations to isolate the variable (same as two-step equations).
4. Check your solution.

### Worked Examples

**Example A — Combining like terms then solving**
Solve: 4x + 7 + x = 32.
- Combine like terms: 5x + 7 = 32.
- Subtract 7: 5x = 25.
- Divide by 5: x = 5.
- Check: 4(5) + 7 + 5 = 20 + 7 + 5 = 32. Correct.

**Example B — Distribute then solve**
Solve: 2(3x - 1) + 4 = 18.
- Distribute: 6x - 2 + 4 = 18.
- Combine like terms: 6x + 2 = 18.
- Subtract 2: 6x = 16.
- Divide by 6: x = 16/6 = 8/3.
- Check: 2(3(8/3) - 1) + 4 = 2(8 - 1) + 4 = 2(7) + 4 = 14 + 4 = 18. Correct.

**Example C — Negative distribution**
Solve: 10 - 3(2x - 1) = 1.
- Distribute -3: 10 - 6x + 3 = 1.
- Combine constants: 13 - 6x = 1.
- Subtract 13: -6x = -12.
- Divide by -6: x = 2.
- Check: 10 - 3(2(2) - 1) = 10 - 3(3) = 10 - 9 = 1. Correct.

## Guided Practice (10 minutes)

Work through these problems together. The student attempts each problem first, then discusses.

1. Solve: 2x + 3x + 7 = 32.
   - *Facilitator prompt:* "Start by combining the x-terms on the left."

2. Solve: 4(x + 5) = 36.
   - *Facilitator prompt:* "Distribute the 4 first. What do you get?"

3. Solve: 3(2x - 3) + 5 = 20.
   - *Facilitator prompt:* "Distribute, then combine the constants."

4. Solve: 8 - 2(x - 4) = 20.
   - *Facilitator prompt:* "What does -2 times -4 equal? Be careful with signs."

5. Solve: 5(x + 1) - 3x = 17.
   - *Facilitator prompt:* "After distributing, you will have two x-terms to combine."

**Facilitator tip:** The most common error in this lesson is mishandling the negative sign during distribution (e.g., writing -2(x - 4) = -2x - 8 instead of -2x + 8). If you see this error, pause and re-derive: -2 times x = -2x, and -2 times -4 = +8. Use the sign rules explicitly each time until the student is consistent.

## Independent Practice (10-15 minutes)

### Part A — Combining Like Terms
Solve each equation and check your solution.

1. 6x + 4 + 2x = 28
2. 3x - 5 + x = 15
3. 9 + 7x - 3 = 27

### Part B — Distributive Property
Solve each equation and check your solution.

4. 5(x + 2) = 40
5. 2(4x - 3) = 26
6. -3(x + 5) = -21

### Part C — Combined Skills
Solve each equation and check your solution.

7. 4(x + 3) - 5 = 23
8. 6 - 2(3x - 1) = -10
9. 3(2x + 1) + 2(x - 4) = 19
10. 7 + 5(x - 2) - 3x = 9

### Answer Key

**Part A**
1. 6x + 4 + 2x = 28 → 8x + 4 = 28 → 8x = 24 → x = 3. Check: 6(3) + 4 + 2(3) = 18 + 4 + 6 = 28. Correct.
2. 3x - 5 + x = 15 → 4x - 5 = 15 → 4x = 20 → x = 5. Check: 3(5) - 5 + 5 = 15 - 5 + 5 = 15. Correct.
3. 9 + 7x - 3 = 27 → 7x + 6 = 27 → 7x = 21 → x = 3. Check: 9 + 7(3) - 3 = 9 + 21 - 3 = 27. Correct.

**Part B**
4. 5(x + 2) = 40 → 5x + 10 = 40 → 5x = 30 → x = 6. Check: 5(6 + 2) = 5(8) = 40. Correct.
5. 2(4x - 3) = 26 → 8x - 6 = 26 → 8x = 32 → x = 4. Check: 2(4(4) - 3) = 2(13) = 26. Correct.
6. -3(x + 5) = -21 → -3x - 15 = -21 → -3x = -6 → x = 2. Check: -3(2 + 5) = -3(7) = -21. Correct.

**Part C**
7. 4(x + 3) - 5 = 23 → 4x + 12 - 5 = 23 → 4x + 7 = 23 → 4x = 16 → x = 4. Check: 4(4 + 3) - 5 = 4(7) - 5 = 28 - 5 = 23. Correct.
8. 6 - 2(3x - 1) = -10 → 6 - 6x + 2 = -10 → 8 - 6x = -10 → -6x = -18 → x = 3. Check: 6 - 2(3(3) - 1) = 6 - 2(8) = 6 - 16 = -10. Correct.
9. 3(2x + 1) + 2(x - 4) = 19 → 6x + 3 + 2x - 8 = 19 → 8x - 5 = 19 → 8x = 24 → x = 3. Check: 3(2(3) + 1) + 2(3 - 4) = 3(7) + 2(-1) = 21 - 2 = 19. Correct.
10. 7 + 5(x - 2) - 3x = 9 → 7 + 5x - 10 - 3x = 9 → 2x - 3 = 9 → 2x = 12 → x = 6. Check: 7 + 5(6 - 2) - 3(6) = 7 + 20 - 18 = 9. Correct.

## Assessment Check

### Exit Ticket
**Problem 1:** Solve 2(x + 6) - 3 = 17. Show your work and check.
**Problem 2:** Solve 4x + 3(x - 2) = 15. Show your work and check.

**Scoring:**
- 2 out of 2 correct (with check) = Mastery demonstrated.
- 1 out of 2 correct = Partial understanding; review errors.
- 0 out of 2 correct = Reteach needed.

**Exit Ticket Answer Key:**
1. 2(x + 6) - 3 = 17 → 2x + 12 - 3 = 17 → 2x + 9 = 17 → 2x = 8 → x = 4. Check: 2(4 + 6) - 3 = 2(10) - 3 = 17. Correct.
2. 4x + 3(x - 2) = 15 → 4x + 3x - 6 = 15 → 7x - 6 = 15 → 7x = 21 → x = 3. Check: 4(3) + 3(3 - 2) = 12 + 3 = 15. Correct.

### If Mastery Is Not Met
- If the student struggles with distribution, return to the distributive property as a standalone skill. Practice expanding 5-10 expressions before embedding them in equations.
- If sign errors are the issue, have the student write out each multiplication with explicit signs: -2 * (+x) = -2x, -2 * (-4) = +8.
- Provide three additional multi-step equations with the first step (distribution) already completed so the student can focus on the remaining steps.

### If Mastery Is Met
- Challenge: Solve 3(2x + 1) - 4(x - 3) = 2(x + 5) + 5 (preview of variables on both sides with distribution).
- Ask: "If an equation has two sets of parentheses on the same side, does the order in which you distribute matter?" (No — distribution is applied independently to each set.)

## Extension

- **Error Analysis:** Present three "student solutions" with deliberate errors in distribution or combining like terms. The student identifies and corrects each error.
- **Create the Equation:** The answer is x = 3. Write a multi-step equation using the distributive property that has this solution. Then write a harder one. Trade with the facilitator for checking.
