# Math — Grade 8 — Unit 2, Lesson 8

## Topic
Solving Systems by Elimination

## Learning Objectives
- Solve a system of equations by adding or subtracting the equations to eliminate one variable.
- Multiply one or both equations by a constant to create opposite coefficients before adding.
- Back-substitute to find the second variable and verify the solution.
- Recognize when elimination is more efficient than substitution.

## Prerequisites
- Understanding of systems of equations and what a solution represents (Lessons 5-6)
- Ability to solve systems by substitution (Lesson 7)
- Fluency with combining like terms and integer operations
- Understanding that multiplying both sides of an equation by the same constant preserves equality

## Materials Needed
- Whiteboard and markers (or projector).
- Student worksheet (Guided Practice and Independent Practice problems).
- Index cards or half-sheets for Exit Ticket.

**Standards:** 8.EE.8b — Solve systems of two linear equations in two variables algebraically, and estimate solutions by graphing the equations. Solve simple cases by inspection.

## Warm-Up (5 minutes)

**Purpose:** Build intuition for adding equations by working with simple number sentences.

1. If a + b = 10 and a - b = 4, add the two equations together. What do you get? (2a = 14, so a = 7.)
2. Now find b. (7 + b = 10, so b = 3.)
3. Check: 7 + 3 = 10. True. 7 - 3 = 4. True.
4. Ask: "What happened to b when you added the equations? Why did it disappear?" (The +b and -b canceled out.)

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Elimination** — a method for solving systems in which you add or subtract the equations to remove (eliminate) one variable, leaving a single equation in one variable.
- **Opposite coefficients** — coefficients of the same variable that are additive inverses (e.g., +3y and -3y). When the equations are added, these terms cancel.
- **Multiplying an equation** — multiplying every term on both sides by the same nonzero constant. This creates an equivalent equation.

### Instruction Notes

**Step 1 — The core idea: adding equations to eliminate a variable.**
Write the system:
- x + y = 8
- x - y = 2

Say: "Look at the y-terms: +y and -y. These are opposites. If we ADD the two equations, the y-terms will cancel."

Add:
- (x + y) + (x - y) = 8 + 2
- 2x = 10
- x = 5

Back-substitute into equation 1: 5 + y = 8, so y = 3.
Solution: (5, 3). Check: 5 + 3 = 8. 5 - 3 = 2. Correct.

**Step 2 — When to subtract instead of add.**
Write the system:
- 3x + 2y = 16
- x + 2y = 10

Say: "The y-coefficients are the same (+2y in both). If we SUBTRACT the second equation from the first, the y-terms cancel."

Subtract (equation 1 minus equation 2):
- (3x + 2y) - (x + 2y) = 16 - 10
- 3x - x + 2y - 2y = 6
- 2x = 6
- x = 3

Back-substitute: 3 + 2y = 10, so 2y = 7, y = 7/2 = 3.5.

Hmm, let me use a cleaner example. Write the system:
- 3x + 2y = 16
- x + 2y = 8

Subtract: 2x = 8, so x = 4. Back-substitute: 4 + 2y = 8, so 2y = 4, y = 2.
Solution: (4, 2). Check: 3(4) + 2(2) = 16. 4 + 2(2) = 8. Correct.

**Tip for students:** Instead of subtracting an equation (which can cause sign errors), multiply the equation by -1 and then ADD. For example, multiplying x + 2y = 8 by -1 gives -x - 2y = -8. Then add to 3x + 2y = 16: the result is 2x = 8.

**Step 3 — When you need to multiply first.**
Write the system:
- 2x + 3y = 12
- 4x - y = 2

Say: "Neither the x-coefficients nor the y-coefficients are opposites or equal. We need to create opposites. Let's eliminate y."
- Multiply equation 2 by 3: 12x - 3y = 6.
- Now the y-terms are +3y and -3y — opposites.
- Add: (2x + 3y) + (12x - 3y) = 12 + 6 → 14x = 18 → x = 18/14 = 9/7.

Say: "That gives a fraction. Let me pick a system with integer solutions."

Write the system:
- 2x + 3y = 16
- 4x - 3y = 8

Say: "The y-coefficients are already opposites (+3y and -3y). Just add."
- 6x = 24 → x = 4.
- Back-substitute: 2(4) + 3y = 16 → 8 + 3y = 16 → 3y = 8... That is also a fraction.

Write the system:
- 2x + 3y = 19
- 4x - 3y = 5

Add: 6x = 24 → x = 4. Back-substitute: 2(4) + 3y = 19 → 8 + 3y = 19 → 3y = 11. Still a fraction.

Write the system:
- 3x + 2y = 14
- x - 2y = 2

Add: 4x = 16 → x = 4. Back-substitute: 4 - 2y = 2 → -2y = -2 → y = 1.
Solution: (4, 1). Check: 3(4) + 2(1) = 14. 4 - 2(1) = 2. Correct.

**Step 4 — Multiplying one equation to create opposite coefficients.**
Write the system:
- 3x + y = 11
- x + 2y = 12

Say: "The coefficients are not lined up. Let's eliminate x by multiplying equation 2 by -3."
- Equation 1: 3x + y = 11
- Equation 2 times -3: -3x - 6y = -36
- Add: -5y = -25 → y = 5.
- Back-substitute: x + 2(5) = 12 → x = 2.
- Solution: (2, 5). Check: 3(2) + 5 = 11. 2 + 2(5) = 12. Correct.

**Step 5 — Summary of the elimination method.**
Write on the board:
1. Line up the equations vertically (x-terms, y-terms, constants).
2. Look for opposite or matching coefficients.
3. If needed, multiply one or both equations by constants to create opposite coefficients for one variable.
4. Add the equations to eliminate that variable.
5. Solve for the remaining variable.
6. Back-substitute to find the other variable.
7. Check in BOTH original equations.

### Worked Examples

**Example A — Coefficients already opposite**
Solve: 5x + y = 17 and 3x - y = 7.
- The y-terms are +y and -y. Add: 8x = 24 → x = 3.
- Back-substitute: 5(3) + y = 17 → y = 2.
- Solution: (3, 2). Check: 15 + 2 = 17, 9 - 2 = 7. Correct.

**Example B — Multiply one equation**
Solve: 2x + 5y = 24 and x + 3y = 13.
- Multiply equation 2 by -2: -2x - 6y = -26.
- Add to equation 1: (2x + 5y) + (-2x - 6y) = 24 + (-26) → -y = -2 → y = 2.
- Back-substitute: x + 3(2) = 13 → x = 7.
- Solution: (7, 2). Check: 14 + 10 = 24, 7 + 6 = 13. Correct.

**Example C — Multiply both equations**
Solve: 3x + 4y = 25 and 2x + 3y = 18.
- To eliminate x: multiply eq 1 by 2, eq 2 by -3.
  - 6x + 8y = 50
  - -6x - 9y = -54
- Add: -y = -4 → y = 4.
- Back-substitute: 3x + 4(4) = 25 → 3x = 9 → x = 3.
- Solution: (3, 4). Check: 9 + 16 = 25, 6 + 12 = 18. Correct.

## Guided Practice (10 minutes)

Work through these problems together. The student attempts each problem first, then discusses.

1. Solve: x + y = 10 and x - y = 6.
   - *Facilitator prompt:* "The y-terms are +y and -y. What happens when you add?"

2. Solve: 4x + 3y = 23 and 4x - y = 11.
   - *Facilitator prompt:* "The x-coefficients are the same. Subtract the second from the first (or multiply one by -1 and add)."

3. Solve: 2x + y = 9 and x - y = 3.
   - *Facilitator prompt:* "Are the y-coefficients opposites? Add the equations."

4. Solve: 3x + 2y = 16 and x - y = 3.
   - *Facilitator prompt:* "Multiply the second equation by 2 so the y-terms become opposites."

5. Solve: 5x + 2y = 19 and 3x - 2y = 5.
   - *Facilitator prompt:* "The y-coefficients are already opposites. Just add."

**Facilitator tip:** The most common error is distributing incorrectly when multiplying an equation. If multiplying x - y = 3 by 2, students sometimes write 2x - y = 6 (forgetting to multiply the y-term). Emphasize: multiply EVERY term, including the constant.

## Independent Practice (10-15 minutes)

### Part A — Add or Subtract Directly
Solve each system by elimination.

1. x + y = 12 and x - y = 4
2. 3x + 2y = 17 and 3x - 2y = 1
3. 5x + y = 22 and 3x - y = 10

### Part B — Multiply One Equation First
Solve each system by elimination.

4. 2x + y = 8 and x + 3y = 14
5. 3x + 4y = 26 and x + 2y = 12
6. x + 5y = 23 and 2x - y = 2

### Part C — Mixed Practice

7. 4x + 3y = 21 and 2x + y = 9
8. 5x - 3y = 11 and 2x + 3y = 10
9. 3x + 2y = 20 and 5x + 3y = 32
10. A school play sold adult tickets for $8 and student tickets for $5. They sold a total of 200 tickets and collected $1,300. How many of each type were sold? (Let a = adult tickets, s = student tickets.)

### Answer Key

**Part A**
1. Add: 2x = 16 → x = 8. 8 + y = 12 → y = 4. **Solution: (8, 4).** Check: 8 + 4 = 12, 8 - 4 = 4. Correct.
2. Add: 6x = 18 → x = 3. 3(3) + 2y = 17 → 2y = 8 → y = 4. **Solution: (3, 4).** Check: 9 + 8 = 17, 9 - 8 = 1. Correct.
3. Add: 8x = 32 → x = 4. 5(4) + y = 22 → y = 2. **Solution: (4, 2).** Check: 20 + 2 = 22, 12 - 2 = 10. Correct.

**Part B**
4. Multiply eq 2 by -2: -2x - 6y = -28. Add to eq 1: -5y = -20 → y = 4. 2x + 4 = 8 → x = 2. **Solution: (2, 4).** Check: 4 + 4 = 8, 2 + 12 = 14. Correct.
5. Multiply eq 2 by -2: -2x - 4y = -24. Add to eq 1: x = 2. 2 + 2y = 12 → y = 5. **Solution: (2, 5).** Check: 6 + 20 = 26, 2 + 10 = 12. Correct.
6. Multiply eq 1 by -2: -2x - 10y = -46. Add to eq 2: -11y = -44 → y = 4. x + 20 = 23 → x = 3. **Solution: (3, 4).** Check: 3 + 20 = 23, 6 - 4 = 2. Correct.

**Part C**
7. Multiply eq 2 by -2: -4x - 2y = -18. Add to eq 1: y = 3. 2x + 3 = 9 → x = 3. **Solution: (3, 3).** Check: 12 + 9 = 21, 6 + 3 = 9. Correct.
8. Add: 7x = 21 → x = 3. 2(3) + 3y = 10 → 3y = 4 → y = 4/3. **Solution: (3, 4/3).** Check: 15 - 4 = 11, 6 + 4 = 10. Correct.
9. Multiply eq 1 by -3, eq 2 by 2: -9x - 6y = -60 and 10x + 6y = 64. Add: x = 4. 3(4) + 2y = 20 → 2y = 8 → y = 4. **Solution: (4, 4).** Check: 12 + 8 = 20, 20 + 12 = 32. Correct.
10. System: a + s = 200 and 8a + 5s = 1300. Multiply eq 1 by -5: -5a - 5s = -1000. Add to eq 2: 3a = 300 → a = 100. s = 200 - 100 = 100. **Solution: 100 adult tickets, 100 student tickets.** Check: 100 + 100 = 200, 800 + 500 = 1300. Correct.

## Assessment Check

### Exit Ticket
**Problem 1:** Solve by elimination: 2x + y = 11 and x - y = 1. Show all steps.
**Problem 2:** Solve by elimination: 3x + 2y = 20 and x - 2y = -4. Show all steps.

**Scoring:**
- 2 out of 2 correct (with work) = Mastery demonstrated.
- 1 out of 2 correct = Partial understanding; review errors.
- 0 out of 2 correct = Reteach needed.

**Exit Ticket Answer Key:**
1. Add: 3x = 12 → x = 4. 4 - y = 1 → y = 3. **Solution: (4, 3).** Check: 8 + 3 = 11, 4 - 3 = 1. Correct.
2. Add: 4x = 16 → x = 4. 4 - 2y = -4 → -2y = -8 → y = 4. **Solution: (4, 4).** Check: 12 + 8 = 20, 4 - 8 = -4. Correct.

### If Mastery Is Not Met
- Return to the Warm-Up concept: practice adding and subtracting simple equations (a + b = 10 and a - b = 4 type) until the student sees the pattern of cancellation.
- Use a structured template where the equations are pre-aligned vertically, and the student highlights which variable will be eliminated.
- Practice multiplying entire equations by constants as a standalone skill before combining it with the elimination process.

### If Mastery Is Met
- Challenge: Solve a system that requires multiplying BOTH equations: 2x + 3y = 13 and 3x + 5y = 21. (Multiply eq 1 by 3, eq 2 by -2 → 6x + 9y = 39 and -6x - 10y = -42 → -y = -3 → y = 3 → x = 2.)
- Ask: "When would elimination be better than substitution? When would substitution be better?" (Preview of Lesson 9.)

## Extension

- **Two Methods, Same Answer:** Solve the system 3x + y = 10 and x - y = 2 using BOTH elimination and substitution. Compare the amount of work. Which felt more efficient?
- **Create a System:** Design a system where the solution is (5, -1) and the elimination method requires multiplying one equation by 3. Verify by solving.
