# Math — Grade 8 — Unit 2, Lesson 4

## Topic
Special Cases: No Solution and Infinitely Many Solutions

## Learning Objectives
- Recognize equations that have no solution (contradictions) and explain why no value of the variable works.
- Recognize equations that have infinitely many solutions (identities) and explain why every value of the variable works.
- Distinguish between one solution, no solution, and infinitely many solutions.
- Create examples of each type of equation.

## Prerequisites
- Ability to solve equations with variables on both sides (Lesson 3)
- Fluency with the distributive property and combining like terms
- Understanding that a solution is a value that makes both sides of an equation equal
- Comfort with integer operations

## Materials Needed
- Whiteboard and markers (or projector).
- Student worksheet (Guided Practice and Independent Practice problems).
- Index cards or half-sheets for Exit Ticket.

**Standards:** 8.EE.7a — Give examples of linear equations in one variable with one solution, infinitely many solutions, or no solution. Show which of these possibilities is the case by successively transforming the given equation into simpler forms, until an equivalent equation of the form x = a, a = a, or a = b results (where a and b are different numbers).

## Warm-Up (5 minutes)

**Purpose:** Activate reasoning about what makes equations true or false.

1. Is x = 3 a solution to 2x + 1 = 7? (Yes: 2(3) + 1 = 7.)
2. Is x = 5 a solution to 2x + 1 = 7? (No: 2(5) + 1 = 11, not 7.)
3. Now simplify: 2x + 1 - 2x. What do you get? (1)
4. Ask: "If an equation simplifies to something like 1 = 5, can that ever be true? What about 3 = 3?"

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Contradiction** — a statement that is always false, no matter what. For example, 0 = 5. An equation that simplifies to a contradiction has no solution.
- **Identity** — a statement that is always true, no matter what. For example, 0 = 0 or 7 = 7. An equation that simplifies to an identity has infinitely many solutions.
- **No solution** — there is no value of the variable that makes the equation true.
- **Infinitely many solutions** — every value of the variable makes the equation true.

### Instruction Notes

**Step 1 — The three possible outcomes when solving a linear equation.**
Write on the board:
- **One solution:** You get x = (some number). Example: 2x + 3 = 9 gives x = 3.
- **No solution:** You get a false statement like 0 = 5. Example: 2x + 1 = 2x + 5.
- **Infinitely many solutions:** You get a true statement like 0 = 0. Example: 3(x + 2) = 3x + 6.

Say: "Until now, every equation we solved had exactly one solution. Today we explore the other two possibilities."

**Step 2 — No solution (contradiction).**
Write on the board: 2x + 1 = 2x + 5.

Say: "Let's solve this using the same process."
- Subtract 2x from both sides: 1 = 5.

Say: "We get 1 = 5. Is that true?" (No.) "Can we change it by choosing a different x?" (No — x has been eliminated. The statement 1 = 5 is always false.)

Say: "This means the original equation has NO SOLUTION. No matter what number you substitute for x, the left side and the right side will never be equal."

Demonstrate with a test: try x = 0. Left: 2(0) + 1 = 1. Right: 2(0) + 5 = 5. Not equal.
Try x = 10. Left: 2(10) + 1 = 21. Right: 2(10) + 5 = 25. Not equal.
Try x = -3. Left: 2(-3) + 1 = -5. Right: 2(-3) + 5 = -1. Not equal.

Say: "The left side is always exactly 4 less than the right side. They can never be equal."

**Step 3 — Infinitely many solutions (identity).**
Write on the board: 3(x + 2) = 3x + 6.

Say: "Let's solve this."
- Distribute: 3x + 6 = 3x + 6.
- Subtract 3x: 6 = 6.

Say: "We get 6 = 6. Is that true?" (Yes.) "Does it depend on x?" (No — x has been eliminated and we are left with a statement that is always true.)

Say: "This means the original equation is true for EVERY value of x. It has infinitely many solutions."

Demonstrate with a test: try x = 0. Left: 3(2) = 6. Right: 3(0) + 6 = 6. Equal.
Try x = 5. Left: 3(7) = 21. Right: 3(5) + 6 = 21. Equal.
Try x = -100. Left: 3(-98) = -294. Right: 3(-100) + 6 = -294. Equal.

Say: "The two sides are different-looking ways of writing the SAME expression. That is why they are always equal."

**Step 4 — How to recognize each case.**
Write on the board:
- If solving leads to **x = (number)** → ONE solution.
- If solving leads to **(number) = (different number)** like 3 = 7 → NO solution.
- If solving leads to **(number) = (same number)** like 4 = 4 or 0 = 0 → INFINITELY MANY solutions.

**Step 5 — A more complex example of each.**

No solution: 4(x - 3) = 4x + 10.
- Distribute: 4x - 12 = 4x + 10.
- Subtract 4x: -12 = 10.
- Contradiction. No solution.

Infinitely many solutions: 2(x + 5) - 4 = 2x + 6.
- Distribute: 2x + 10 - 4 = 2x + 6.
- Combine: 2x + 6 = 2x + 6.
- Subtract 2x: 6 = 6.
- Identity. Infinitely many solutions.

### Worked Examples

**Example A — No solution**
Solve: 5x + 2 = 5x - 8.
- Subtract 5x: 2 = -8.
- This is a contradiction (2 does not equal -8).
- The equation has no solution.

**Example B — Infinitely many solutions**
Solve: 6x - 3(2x - 4) = 12.
- Distribute: 6x - 6x + 12 = 12.
- Combine: 12 = 12.
- This is an identity (12 equals 12).
- The equation has infinitely many solutions.

**Example C — One solution (for comparison)**
Solve: 3x + 7 = 5x - 9.
- Subtract 3x: 7 = 2x - 9.
- Add 9: 16 = 2x.
- Divide by 2: x = 8.
- This equation has exactly one solution: x = 8.

## Guided Practice (10 minutes)

Work through these problems together. The student attempts each problem first, then discusses.

1. Solve: 4x + 3 = 4x + 3.
   - *Facilitator prompt:* "What happens when you subtract 4x from both sides?"

2. Solve: 7x - 2 = 7x + 6.
   - *Facilitator prompt:* "After collecting variable terms, what statement do you get? Is it true or false?"

3. Solve: 2(x + 3) = 2x - 1.
   - *Facilitator prompt:* "Distribute first. Then collect variable terms."

4. Solve: 5(x - 1) = 3x + 7.
   - *Facilitator prompt:* "Is this a special case, or does it have a regular solution?"

5. Without solving, predict whether this equation has one solution, no solution, or infinitely many solutions: 3x + 8 = 3(x + 2) + 2.
   - *Facilitator prompt:* "Simplify the right side. What do you notice?"

**Facilitator tip:** The most common error in this lesson is writing "x = 0" when the equation simplifies to 0 = 0. Emphasize the distinction: 0 = 0 means the equation is always true (infinitely many solutions); x = 0 means the single value x = 0 is the solution. These are very different situations.

## Independent Practice (10-15 minutes)

### Part A — Classify Each Equation
Solve each equation. State whether it has one solution, no solution, or infinitely many solutions. If there is one solution, state it.

1. 3x + 5 = 3x + 5
2. 6x - 4 = 6x + 1
3. 2x + 9 = 5x - 3
4. 4(x + 2) = 4x + 8

### Part B — Equations Requiring Simplification First
Solve and classify.

5. 3(2x + 4) = 6x - 1
6. 5x - (2x + 3) = 3x - 3
7. 2(x + 6) - 4 = 3x + 1

### Part C — Create and Analyze
8. Write an equation that has no solution. Prove it by solving.
9. Write an equation that has infinitely many solutions. Prove it by solving.
10. Challenge: For what value of k does the equation 4x + k = 4x + 7 have (a) no solution, (b) infinitely many solutions?

### Answer Key

**Part A**
1. 3x + 5 = 3x + 5 → Subtract 3x: 5 = 5. Identity. **Infinitely many solutions.**
2. 6x - 4 = 6x + 1 → Subtract 6x: -4 = 1. Contradiction. **No solution.**
3. 2x + 9 = 5x - 3 → Subtract 2x: 9 = 3x - 3 → 12 = 3x → x = 4. **One solution: x = 4.** Check: 2(4) + 9 = 17, 5(4) - 3 = 17. Correct.
4. 4(x + 2) = 4x + 8 → 4x + 8 = 4x + 8 → Subtract 4x: 8 = 8. Identity. **Infinitely many solutions.**

**Part B**
5. 3(2x + 4) = 6x - 1 → 6x + 12 = 6x - 1 → Subtract 6x: 12 = -1. Contradiction. **No solution.**
6. 5x - (2x + 3) = 3x - 3 → 5x - 2x - 3 = 3x - 3 → 3x - 3 = 3x - 3 → Subtract 3x: -3 = -3. Identity. **Infinitely many solutions.**
7. 2(x + 6) - 4 = 3x + 1 → 2x + 12 - 4 = 3x + 1 → 2x + 8 = 3x + 1 → 8 = x + 1 → x = 7. **One solution: x = 7.** Check: 2(13) - 4 = 22, 3(7) + 1 = 22. Correct.

**Part C**
8. Answers will vary. Example: 5x + 3 = 5x + 10. Solving: subtract 5x: 3 = 10. Contradiction. No solution.
9. Answers will vary. Example: 2(x + 4) = 2x + 8. Solving: 2x + 8 = 2x + 8. Subtract 2x: 8 = 8. Identity. Infinitely many solutions.
10. (a) No solution when k is NOT equal to 7 — the equation becomes k = 7, which is false. Any value such as k = 3 works. (b) Infinitely many solutions when k = 7 — the equation becomes 7 = 7, which is always true.

## Assessment Check

### Exit Ticket
**Problem 1:** Solve 3(x + 4) = 3x + 12. State whether the equation has one solution, no solution, or infinitely many solutions.
**Problem 2:** Solve 8x - 5 = 8x + 2. State whether the equation has one solution, no solution, or infinitely many solutions.

**Scoring:**
- 2 out of 2 correct (with correct classification) = Mastery demonstrated.
- 1 out of 2 correct = Partial understanding; review errors.
- 0 out of 2 correct = Reteach needed.

**Exit Ticket Answer Key:**
1. 3(x + 4) = 3x + 12 → 3x + 12 = 3x + 12 → 12 = 12. **Infinitely many solutions.**
2. 8x - 5 = 8x + 2 → -5 = 2. **No solution.**

### If Mastery Is Not Met
- Return to the fundamental idea: an equation is like a question — "For what value of x are these two sides equal?" Sometimes the answer is one value, sometimes there is no value, and sometimes every value works.
- Use substitution testing: pick three values of x and substitute them into both sides. If all three give equal results on both sides, the equation likely has infinitely many solutions. If none of them work, it likely has no solution.
- Provide three additional equations (one of each type) with the simplification steps partially completed.

### If Mastery Is Met
- Challenge: "Can a linear equation in one variable ever have exactly TWO solutions? Why or why not?" (No. A linear equation in one variable can have one, zero, or infinitely many solutions — never exactly two.)
- Preview Lesson 5: "You have mastered solving single equations. What if we had TWO equations with TWO unknowns? How would that change the problem?"

## Extension

- **Algebraic Argument:** Explain in your own words (using sentences, not just symbols) why the equation ax + b = ax + c has no solution when b is not equal to c, and infinitely many solutions when b = c.
- **Graphing Connection:** On a coordinate plane, graph y = 2x + 3 and y = 2x + 7. What do you notice about the two lines? How does this connect to the idea of "no solution" for the equation 2x + 3 = 2x + 7? (The lines are parallel — they never intersect, which means there is no x-value where the two expressions are equal.)
