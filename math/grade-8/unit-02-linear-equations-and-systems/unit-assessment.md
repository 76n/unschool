# Unit Assessment — Grade 8 Math, Unit 2: Linear Equations and Systems

**Grade:** 8
**Unit:** 2 — Linear Equations and Systems
**Assessment Type:** Summative (unit-level)
**Administration:** Written; facilitator reads word problems aloud if needed

**Materials:** Paper, pencil, graph paper, ruler, and straightedge. Calculator NOT permitted (all problems use integer or simple rational solutions).

## Answer Key

### Section A: Multi-Step Equations

**A1.** 5x + 7 = 32.
- 5x = 25.
- x = 5.
- Check: 5(5) + 7 = 32. Correct.

**A2.** 3(x + 4) - 2 = 16.
- 3x + 12 - 2 = 16.
- 3x + 10 = 16.
- 3x = 6.
- x = 2.
- Check: 3(2 + 4) - 2 = 3(6) - 2 = 16. Correct.

**A3.** 4(2x - 3) + 5 = 21.
- 8x - 12 + 5 = 21.
- 8x - 7 = 21.
- 8x = 28.
- x = 28/8 = 7/2 = 3.5.
- Check: 4(2(3.5) - 3) + 5 = 4(4) + 5 = 21. Correct.

**A4.** 2(x + 5) + 3(x - 1) = 27.
- 2x + 10 + 3x - 3 = 27.
- 5x + 7 = 27.
- 5x = 20.
- x = 4.
- Check: 2(9) + 3(3) = 18 + 9 = 27. Correct.

### Section B: Variables on Both Sides and Special Cases

**B1.** 7x - 4 = 3x + 16.
- 4x - 4 = 16.
- 4x = 20.
- x = 5.
- Check: 7(5) - 4 = 31. 3(5) + 16 = 31. Correct.

**B2.** 5(x - 2) = 3x + 4.
- 5x - 10 = 3x + 4.
- 2x - 10 = 4.
- 2x = 14.
- x = 7.
- Check: 5(5) = 25. 3(7) + 4 = 25. Correct.

**B3.** 4x + 9 = 4x + 9.
- Subtract 4x: 9 = 9.
- This is always true (identity).
- **Infinitely many solutions.** The equation is true for every value of x because both sides are identical.

**B4.** 6x + 5 = 6x - 3.
- Subtract 6x: 5 = -3.
- This is never true (contradiction).
- **No solution.** No value of x can make 5 equal to -3.

### Section C: Solving Systems by Graphing

**C1.** Check (4, 1):
- Equation 1: 4 + 1 = 5. True.
- Equation 2: 2(4) - 1 = 7. True.
- **Yes, (4, 1) is a solution to the system.**

**C2.** y = x + 1 and y = -2x + 7.
- Line 1: slope 1, y-intercept (0, 1). Points: (0, 1), (1, 2), (2, 3).
- Line 2: slope -2, y-intercept (0, 7). Points: (0, 7), (1, 5), (2, 3).
- Intersection: **(2, 3).**
- Verify: 3 = 2 + 1. True. 3 = -2(2) + 7 = 3. True.

**C3a.** y = 3x + 2 and y = 3x - 5.
- Both have slope 3 but different y-intercepts (2 and -5).
- The lines are parallel and will never intersect.
- **No solution.**

**C3b.** y = 4x - 1 and 2y = 8x - 2 → y = 4x - 1.
- Both equations simplify to y = 4x - 1.
- They are the same line (coincident).
- **Infinitely many solutions.**

### Section D: Solving Systems by Substitution and Elimination

**D1.** y = 3x - 5 and 2x + y = 10.
- Substitute: 2x + (3x - 5) = 10.
- 5x - 5 = 10.
- 5x = 15.
- x = 3.
- y = 3(3) - 5 = 4.
- **Solution: (3, 4).**
- Check: 4 = 9 - 5. True. 6 + 4 = 10. True.

**D2.** 3x + 2y = 16 and x - 2y = 0.
- Add equations: 4x = 16.
- x = 4.
- 4 - 2y = 0 → 2y = 4 → y = 2.
- **Solution: (4, 2).**
- Check: 12 + 4 = 16. True. 4 - 4 = 0. True.

**D3.** 2x + 3y = 19 and 4x - y = 3.
- Multiply equation 2 by 3: 12x - 3y = 9.
- Add to equation 1: 2x + 3y + 12x - 3y = 19 + 9 → 14x = 28 → x = 2.
- Back-substitute into equation 2: 4(2) - y = 3 → 8 - y = 3 → y = 5.
- **Solution: (2, 5).**
- Check: 2(2) + 3(5) = 4 + 15 = 19. True. 4(2) - 5 = 3. True.

### Section E: Word Problems

**E1.**
a) Let p = number of pencils purchased, e = number of erasers purchased.
b) p + e = 14 and 0.50p + 0.75e = 8.50.
c) From equation 1: p = 14 - e. Substitute: 0.50(14 - e) + 0.75e = 8.50 → 7 - 0.50e + 0.75e = 8.50 → 0.25e = 1.50 → e = 6. p = 14 - 6 = 8.
d) **The student bought 8 pencils and 6 erasers.**
Check: 8 + 6 = 14. 0.50(8) + 0.75(6) = 4.00 + 4.50 = 8.50. Correct.

**E2.**
a) Jada: J = 15w + 80. Marcus: M = 30w + 20.
b) Set equal: 15w + 80 = 30w + 20 → 60 = 15w → w = 4. Amount: 15(4) + 80 = 140.
**After 4 weeks, both have $140.**
c) At w = 3: Jada: 15(3) + 80 = 125. Marcus: 30(3) + 20 = 110. **Jada has more money ($125 vs. $110) after 3 weeks.**

## Rubric and Mastery Determination

| Level | Score Range | Meaning | Next Steps |
|-------|-----------|---------|------------|
| **Mastered** | 48-60 (80-100%) with at least 50% per section | Solid understanding of linear equations and systems | Advance to Unit 3 (Functions). Include equation-solving and systems in spaced review. |
| **Approaching** | 36-47 (60-79%) | Partial understanding; specific gaps in one or more areas | Identify weak sections and reteach. See section-specific guide below. Reassess weak sections before advancing. |
| **Developing** | Below 36 (<60%) | Significant gaps across multiple areas | Check prerequisites: Can the student solve one-step equations? Apply the distributive property? Plot points on a coordinate plane? Address foundational gaps before reteaching unit content. |

### Section-Specific Reteaching Guide

| If struggling in... | Focus on... |
|---|---|
| Section A (Multi-Step Equations) | Return to Lessons 1-2. Rebuild the solving process step by step. Practice the distributive property as an isolated skill (10 expansion problems) before embedding it in equations. Focus on the order of operations in reverse: undo addition/subtraction first, then multiplication/division. |
| Section B (Variables on Both Sides and Special Cases) | Return to Lessons 3-4. Use the balance scale model to show why the same operation must be applied to both sides. For special cases, practice classifying 10 equations as "one solution," "no solution," or "infinitely many solutions" without solving them completely — just simplify until the variable disappears or does not. |
| Section C (Solving Systems by Graphing) | Return to Lessons 5-6. Start by reviewing graphing a single line from slope-intercept form (plot y-intercept, use slope to find next points). Then practice graphing pairs of lines. Use pre-drawn graphs with one line already plotted so the student only needs to add the second line and read the intersection. |
| Section D (Solving Systems by Substitution and Elimination) | Return to Lessons 7-8. For substitution, practice with systems where one variable is already isolated. For elimination, practice with systems where coefficients are already opposite. Gradually increase complexity. Use structured templates with blanks for each step. |
| Section E (Word Problems) | Return to Lesson 10. Separate the two skills: (1) setting up the system (translating words to equations) and (2) solving the system. Practice setup only (write the equations but do not solve) for 5-8 problems. Then return to solving complete problems. Use the "define, write, solve, interpret, check" framework explicitly. |

## Error Analysis Guide

| Error Pattern | Example | Likely Cause | Intervention |
|--------------|---------|-------------|-------------|
| Incomplete distribution | Writes 3(x + 4) = 3x + 4 | Forgot to distribute to the second term | Draw arrows from the multiplier to each term: 3 * x = 3x, 3 * 4 = 12. Practice 10 distribution problems. |
| Sign error in distribution | Writes -2(x - 3) = -2x - 6 | Incorrect sign multiplication | Review sign rules: negative times negative = positive. Write out -2 * x = -2x, -2 * (-3) = +6 explicitly. |
| Writes "x = 0" for identity | Gets 0 = 0 and writes x = 0 | Confuses the trivially true statement with a specific solution | Explain: 0 = 0 is always true regardless of x. This means infinitely many solutions, NOT x = 0. Test with x = 1, x = 100 to demonstrate. |
| Checks solution in only one equation | Declares (3, 5) a solution after checking one equation | Incomplete understanding of what "solution to a system" means | Consistently require checking in both equations. Circle or highlight "Check in Eq 1" and "Check in Eq 2" on every problem. |
| Misreads intersection on graph | Reads (3, 2) when the intersection is at (2, 3) | Confuses x and y coordinates | Reinforce: the first number is the horizontal position, the second is the vertical position. Practice reading coordinates from 10 plotted points. |
| Forgets to back-substitute | Finds x = 4 and writes it as the answer | Does not realize a system needs two values | Remind: the solution to a system is an ordered pair (x, y). Finding one variable is only half the work. Put a checklist on the worksheet: "Did you find x? Did you find y?" |
| Distributes negative incorrectly during elimination | When subtracting x + 2y = 8, writes -x + 2y = -8 | Does not negate all terms when subtracting an equation | Teach the safer alternative: multiply by -1 first, then add. -1(x + 2y) = -1(8) gives -x - 2y = -8. |
| Sets up wrong equations from word problem | For "total of 20 items," writes x * y = 20 | Confuses "total" with "product" | Review key phrases: "total" = addition, "times" or "per" = multiplication. Create a phrase-to-operation reference card. |

## Facilitator Observations

- Does the student solve multi-step equations fluently, or does each step require deliberate thought?
- When encountering special cases, does the student recognize the result (0 = 0 or 0 = 5) immediately, or does the student appear confused?
- During graphing, does the student use a straightedge and plot at least three points, or do the graphs appear rushed and imprecise?
- When solving by substitution, does the student remember to use parentheses when substituting, or do sign errors frequently occur?
- When solving by elimination, does the student check that coefficients are properly aligned before adding, or does the student rush into adding mismatched equations?
- For word problems, can the student identify the two constraints and write two equations independently, or does the student need prompting at each stage?
- Does the student routinely check solutions in both original equations, or does the student skip verification?
