# Math — Grade 8 — Unit 4, Lesson 1

## Topic
Translations

## Learning Objectives
- Define a translation as a transformation that slides every point the same distance in the same direction.
- Apply the coordinate rule (x, y) -> (x + a, y + b) to translate individual points and entire figures.
- Verify that translations preserve distance, angle measure, and shape (rigid transformation).
- Describe a translation using words and coordinate notation.

## Prerequisites
- Ability to plot and read ordered pairs in all four quadrants (Grade 6-7)
- Familiarity with the coordinate plane: axes, origin, quadrants (Grade 6)
- Addition and subtraction with positive and negative integers (Grade 7)

## Materials Needed
- Graph paper (at least two sheets per student)
- Ruler or straightedge
- Colored pencils (two colors: one for pre-image, one for image)
- Tracing paper or patty paper (optional, for physical demonstration)
- Index card or half-sheet for Exit Ticket

**Standards:** 8.G.1 — Verify experimentally the properties of rotations, reflections, and translations: lines are taken to lines, and line segments to line segments of the same length; angles are taken to angles of the same measure; parallel lines are taken to parallel lines.

## Warm-Up (5 minutes)
**Purpose:** Activate prior knowledge of coordinate plane plotting and integer addition.

1. Plot these four points on a coordinate plane and connect them in order to form a quadrilateral: A(1, 2), B(4, 2), C(4, 5), D(1, 5). What shape did you draw? (Rectangle)
2. Compute: -3 + 5 = ? (2). Compute: 4 + (-6) = ? (-2).
3. If you start at the point (2, 3) and move 4 units to the right, what is your new x-coordinate? (6). If you then move 2 units down, what is your new y-coordinate? (1). What point are you at? (6, 1).

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Transformation** — an operation that changes the position, size, or orientation of a figure.
- **Translation** — a transformation that slides every point of a figure the same distance in the same direction.
- **Pre-image** — the original figure before a transformation.
- **Image** — the resulting figure after a transformation.
- **Prime notation** — we label image points with a prime symbol: A becomes A', B becomes B', etc.

### Instruction Notes

**Step 1 — Introduce translations with a physical analogy.**

Say: "Imagine you are moving a piece of furniture across a room. You slide the entire object — every part of it moves the same distance in the same direction. The furniture does not rotate, flip, or change size. It just slides. That is exactly what a translation does to a geometric figure."

**Step 2 — Define the coordinate rule.**

Write on the board: "Translation rule: (x, y) -> (x + a, y + b)"

Say: "The value 'a' tells us how far to move horizontally. If a is positive, we move right. If a is negative, we move left. The value 'b' tells us how far to move vertically. If b is positive, we move up. If b is negative, we move down."

Draw a simple example: Point P(2, 3) translated by (a, b) = (4, -1).
- New x: 2 + 4 = 6
- New y: 3 + (-1) = 2
- Image: P'(6, 2)

Say: "We moved 4 units right and 1 unit down. The point slid from (2, 3) to (6, 2)."

**Step 3 — Translate an entire figure.**

Say: "Now let us translate a whole triangle. Every vertex moves by the same amount."

Draw triangle with vertices A(1, 1), B(4, 1), C(2, 4).
Translation rule: (x, y) -> (x + 3, y + 2).
- A(1, 1) -> A'(1 + 3, 1 + 2) = A'(4, 3)
- B(4, 1) -> B'(4 + 3, 1 + 2) = B'(7, 3)
- C(2, 4) -> C'(2 + 3, 4 + 2) = C'(5, 6)

Say: "Plot the original triangle in blue and the new triangle in red. Notice that the triangles are the same shape and size — the image is an exact copy, just in a different position."

**Step 4 — Verify that translations preserve distance and shape.**

Say: "Let us check that the side lengths did not change. In the original triangle, the base AB goes from (1, 1) to (4, 1). The length is 4 - 1 = 3 units. In the image, A'B' goes from (4, 3) to (7, 3). The length is 7 - 4 = 3 units. Same length. This is true for every side and every angle. A translation is a rigid transformation — it preserves all distances and angles."

### Worked Examples

**Example A:** Translate the point M(-3, 5) using the rule (x, y) -> (x + 7, y - 4).
- New x: -3 + 7 = 4
- New y: 5 + (-4) = 1
- M'(4, 1)

**Example B:** A triangle has vertices P(0, 0), Q(3, 0), R(0, 4). Translate using (x, y) -> (x - 2, y + 3).
- P(0, 0) -> P'(0 - 2, 0 + 3) = P'(-2, 3)
- Q(3, 0) -> Q'(3 - 2, 0 + 3) = Q'(1, 3)
- R(0, 4) -> R'(0 - 2, 4 + 3) = R'(-2, 7)

Check: Original side PQ has length 3. Image side P'Q' goes from (-2, 3) to (1, 3), length = 1 - (-2) = 3. Preserved.

## Guided Practice (10 minutes)

Work through these problems together. The student attempts each problem first, then discusses.

**Activity 1: Translating Points**

1. Translate the point A(5, -2) using the rule (x, y) -> (x - 3, y + 6).
   - "What do we add to the x-coordinate?" (-3) "What do we add to the y-coordinate?" (+6)
   - A'(5 - 3, -2 + 6) = A'(2, 4)

2. Translate the point B(-4, -1) using the rule (x, y) -> (x + 5, y - 3).
   - B'(-4 + 5, -1 - 3) = B'(1, -4)

3. A point C(2, 7) was translated to C'(6, 3). What translation rule was used?
   - "How did the x-coordinate change? From 2 to 6, that is +4."
   - "How did the y-coordinate change? From 7 to 3, that is -4."
   - Rule: (x, y) -> (x + 4, y - 4)

**Activity 2: Translating Figures**

4. Plot triangle DEF with D(1, 0), E(4, 0), F(3, 3) on graph paper. Translate using (x, y) -> (x - 5, y + 1). Plot the image D'E'F'.
   - D'(1 - 5, 0 + 1) = D'(-4, 1)
   - E'(4 - 5, 0 + 1) = E'(-1, 1)
   - F'(3 - 5, 3 + 1) = F'(-2, 4)
   - Ask: "Does the translated triangle look the same shape and size as the original?" (Yes)

5. A square has vertices at (0, 0), (2, 0), (2, 2), (0, 2). After a translation, the vertex at (0, 0) moves to (3, -1). Where do the other three vertices move?
   - "The shift is +3 in x and -1 in y."
   - (2, 0) -> (5, -1); (2, 2) -> (5, 1); (0, 2) -> (3, 1)

**Facilitator tip:** If the student struggles with negative coordinates, have them plot the point on graph paper first, then physically count the units of the slide. This concrete approach builds confidence before relying solely on arithmetic.

## Independent Practice (10-15 minutes)

### Tier 1 (On-level)

1. Translate the point (3, 5) using the rule (x, y) -> (x + 2, y - 7).
2. Translate the point (-6, 1) using the rule (x, y) -> (x + 4, y + 3).
3. A triangle has vertices at (2, 1), (5, 1), (3, 4). Translate using (x, y) -> (x - 4, y - 2). List the image vertices.
4. A point was translated from (1, 8) to (7, 5). Write the translation rule.
5. Plot rectangle ABCD with A(0, 0), B(3, 0), C(3, 2), D(0, 2). Translate using (x, y) -> (x + 1, y + 4). Plot and label A'B'C'D'.

### Tier 2 (Stretch)

6. A point P(-3, -5) is translated to P'(2, -1). Write the translation rule. Then apply the same rule to Q(0, 4).
7. Triangle JKL has vertices J(1, 2), K(4, 2), L(2, 5). A translation maps J to J'(-3, 4). Find K' and L' without being told the rule.
8. True or false: A translation can change the orientation (clockwise vs. counterclockwise order of vertices) of a figure. Explain.

### Tier 3 (Challenge)

9. A figure is translated by (x, y) -> (x + 3, y - 2) and then translated again by (x, y) -> (x - 1, y + 5). What single translation rule would have the same effect as both translations combined?
10. Point A(a, b) is translated to A'(a + 5, b - 3). Point B is the midpoint of segment AA'. Find the coordinates of B.

## Exit Ticket

**Problem 1:** Translate the point (-2, 6) using the rule (x, y) -> (x + 5, y - 4). State the image coordinates.

**Problem 2:** A triangle is translated so that vertex (3, 1) moves to (0, 4). Write the translation rule in the form (x, y) -> (x + a, y + b) and explain what it means in words.

**Mastery = 2 out of 2 correct.**

## Answer Key

### Independent Practice

1. (3 + 2, 5 - 7) = **(5, -2)**
2. (-6 + 4, 1 + 3) = **(-2, 4)**
3. (2 - 4, 1 - 2) = (-2, -1); (5 - 4, 1 - 2) = (1, -1); (3 - 4, 4 - 2) = (-1, 2). Image vertices: **(-2, -1), (1, -1), (-1, 2)**
4. x changed by +6, y changed by -3. Rule: **(x, y) -> (x + 6, y - 3)**
5. A'(1, 4), B'(4, 4), C'(4, 6), D'(1, 6). [Student plots on graph paper.]
6. Rule: x changed by +5, y changed by +4. Rule: **(x, y) -> (x + 5, y + 4)**. Q'(0 + 5, 4 + 4) = **Q'(5, 8)**.
7. J(1, 2) -> J'(-3, 4): shift is (-4, +2). K'(4 - 4, 2 + 2) = **K'(0, 4)**. L'(2 - 4, 5 + 2) = **L'(-2, 7)**.
8. **False.** A translation preserves orientation. If the vertices are listed counterclockwise in the pre-image, they remain counterclockwise in the image. Translation only changes position, not the order of vertices.
9. Combined: (x + 3 - 1, y - 2 + 5) = **(x + 2, y + 3)**. The two translations combine into a single translation of 2 right and 3 up.
10. Midpoint of A(a, b) and A'(a + 5, b - 3): B = ((a + a + 5)/2, (b + b - 3)/2) = **(a + 2.5, b - 1.5)** or equivalently **((2a + 5)/2, (2b - 3)/2)**.

### Exit Ticket

1. (-2 + 5, 6 - 4) = **(3, 2)**
2. x changed from 3 to 0: shift of -3. y changed from 1 to 4: shift of +3. Rule: **(x, y) -> (x - 3, y + 3)**. In words: "Slide every point 3 units to the left and 3 units up."

## Teacher Notes

- This is the first lesson in the transformation sequence. Take time to establish the vocabulary (pre-image, image, prime notation) carefully — students will use these terms throughout the unit.
- The most common error is reversing the signs: students add when they should subtract (or vice versa) because they confuse "move left" with "subtract from y." Reinforce: a affects x (horizontal), b affects y (vertical).
- Tracing paper is a powerful tool in this lesson. Have the student trace a figure, slide the tracing paper, and read off the new coordinates. This kinesthetic experience makes the abstract rule concrete.
- The Challenge problems (Tier 3) preview the idea that translations can be composed — a concept formalized in Lesson 4. If a student successfully answers Problem 9, acknowledge that they have discovered something important that the class will study in depth later.
- Connect to real life: GPS coordinates shift when you drive north or east. A translation is like driving in a straight line without turning.
