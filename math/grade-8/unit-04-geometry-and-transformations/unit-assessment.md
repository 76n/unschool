## Answer Key

### Section 1: Transformations

**1.1.** (-3 + 7, 5 - 4) = **(4, 1)**.

**1.2a.** (4, -6) over x-axis: **(4, 6)**.

**1.2b.** (-2, 3) over y-axis: **(2, 3)**.

**1.2c.** (5, 0) over y-axis: **(-5, 0)**.

**1.2d.** (0, -7) over x-axis: **(0, 7)**.

**1.3a.** 90 CCW rule: (x, y) -> (-y, x). (3, -1) -> (-(-1), 3) = **(1, 3)**.

**1.3b.** 180 rule: (x, y) -> (-x, -y). (-4, 2) -> **(4, -2)**.

**1.4.** Step 1 — Reflect (2, -5) over x-axis: (2, -(-5)) = **(2, 5)**.
Step 2 — Translate (2, 5) by (x - 3, y + 1): (2 - 3, 5 + 1) = **(-1, 6)**.

### Section 2: Dilations

**2.1a.** (3 x 4, -5 x 4) = **(12, -20)**.

**2.1b.** (8 x 0.5, -6 x 0.5) = **(4, -3)**.

**2.2a.** A'(2 x 3, 1 x 3) = A'(6, 3). B'(6 x 3, 1 x 3) = B'(18, 3). C'(4 x 3, 5 x 3) = C'(12, 15).
**A'(6, 3), B'(18, 3), C'(12, 15).**

**2.2b.** AB = 6 - 2 = **4 units**. A'B' = 18 - 6 = **12 units**. Ratio = 12/4 = **3**. This equals the scale factor.

**2.3.** Scale factor = 2/4 = **1/2** (or equivalently, -5/-10 = 1/2). Each coordinate of the image is half the corresponding coordinate of the original, so the scale factor is 1/2.

### Section 3: Congruence and Similarity

**3.1a.** Ratios: 10/5 = 2, 24/12 = 2, 26/13 = 2. All ratios equal. **Similar but not congruent** (same shape, different size, scale factor 2).

**3.1b.** All corresponding sides are equal (4 = 4, 6 = 6, 8 = 8). **Congruent** (and therefore also similar with scale factor 1).

**3.1c.** Ratios: 3/3 = 1, 5/4 = 1.25, 7/5 = 1.4. Ratios not equal. **Neither similar nor congruent.** The side lengths are not proportional.

**3.2a.** Scale factor = XY/PQ = 10/6 = **5/3**.

**3.2b.** YZ = QR x (5/3) = 9 x (5/3) = **15**.

**3.2c.** XZ = PR x (5/3) = 12 x (5/3) = **20**.

**3.3a.** **True.** Congruent figures have the same shape and same size. Similar figures have the same shape (possibly different sizes). Since congruent figures have the same shape, they are also similar (with scale factor 1).

**3.3b.** **False.** Similar figures have the same shape but may differ in size. For example, a 3-4-5 triangle and a 6-8-10 triangle are similar but not congruent because their sizes differ.

### Section 4: Pythagorean Theorem

**4.1.** 9^2 + 40^2 = c^2. 81 + 1600 = c^2. 1681 = c^2. c = sqrt(1681) = **41**.

**4.2.** 16^2 + b^2 = 20^2. 256 + b^2 = 400. b^2 = 144. b = sqrt(144) = **12**.

**4.3.** Horizontal distance: |9 - 1| = 8. Vertical distance: |-3 - 3| = 6. d^2 = 8^2 + 6^2 = 64 + 36 = 100. d = sqrt(100) = **10 units**.

**4.4a.** 7^2 + 24^2 = 49 + 576 = 625. 25^2 = 625. 625 = 625. **Yes, right triangle.**

**4.4b.** 10^2 + 15^2 = 100 + 225 = 325. 20^2 = 400. 325 ≠ 400. **No, not a right triangle.**

**4.5.** In a right triangle with legs a and b and hypotenuse c (the side opposite the right angle), **a^2 + b^2 = c^2**.

### Section 5: Problem Solving

**5.1.** Diagram: right triangle with wall (vertical leg), ground (horizontal leg = 7), and ladder (hypotenuse = 25).
7^2 + h^2 = 25^2. 49 + h^2 = 625. h^2 = 576. h = sqrt(576) = **24 feet**.

**5.2a.** AB = 6 (horizontal, from (0,0) to (6,0)). BC = 8 (vertical, from (6,0) to (6,8)). AC: horizontal = 6, vertical = 8. AC = sqrt(36 + 64) = sqrt(100) = 10. Sides: **AB = 6, BC = 8, AC = 10**.

**5.2b.** Check: 6^2 + 8^2 = 36 + 64 = 100 = 10^2. **Yes, right triangle.** The right angle is at vertex B, where the horizontal and vertical sides meet.

**5.3a.** Reflect over y-axis: (1,1)->(-1,1), (4,1)->(-4,1), (4,3)->(-4,3), (1,3)->(-1,3).
Dilate by k = 2: (-1,1)->(-2,2), (-4,1)->(-8,2), (-4,3)->(-8,6), (-1,3)->(-2,6).
Final vertices: **(-2, 2), (-8, 2), (-8, 6), (-2, 6)**.

**5.3b.** **Similar but not congruent.** The reflection is a rigid transformation (preserves size), but the dilation with k = 2 changes the size. The final image has the same shape (a rectangle with the same proportions) but is twice as large. Scale factor = 2.

### Section-Specific Reteaching Guide

| If struggling in... | Focus on... |
|---|---|
| Section 1 (Transformations) | Return to Lessons 1-3. Use tracing paper to physically perform each transformation before applying coordinate rules. Create a reference card with all rules: translation (x+a, y+b), reflection over x-axis (x, -y), reflection over y-axis (-x, y), rotation 90 CCW (-y, x), rotation 180 (-x, -y), rotation 270 CCW (y, -x). Practice 10 problems with each rule. For combined transformations (Lesson 4), enforce the strict two-step procedure: apply first transformation and write the result, then apply second transformation. |
| Section 2 (Dilations) | Return to Lesson 5. Reinforce: dilation MULTIPLIES both coordinates by k. Practice with whole-number scale factors first (k = 2, 3, 4), then fractional scale factors (1/2, 1/3, 1/4). Common error: adding k instead of multiplying. Give 10 dilation problems and check that the student multiplies (not adds). Also practice finding the scale factor given a pre-image and image point: divide image coordinate by original coordinate. |
| Section 3 (Congruence and Similarity) | Return to Lessons 6-7. Start by reviewing the definitions: congruent = same shape and size (rigid transformations); similar = same shape, possibly different size (rigid + dilation). Practice identifying whether pairs of figures are congruent, similar, or neither by computing side ratios. For similar figures, practice the proportion-solving workflow: find scale factor from one pair of corresponding sides, then apply to find missing sides. Key distinction: all congruent figures are similar, but not all similar figures are congruent. |
| Section 4 (Pythagorean Theorem) | Return to Lessons 8-9. Ensure the student can (1) identify the hypotenuse (longest side, opposite right angle), (2) correctly set up a^2 + b^2 = c^2 with c as the hypotenuse, (3) solve for the unknown, and (4) take the square root. Common error: using a + b = c instead of a^2 + b^2 = c^2. For distance on the coordinate plane, practice drawing the right triangle connecting two points and identifying the horizontal and vertical legs. For the converse, practice testing sets of three numbers. |
| Section 5 (Problem Solving) | Return to Lesson 10. The issue is usually not a lack of knowledge but difficulty recognizing which tool to apply. Practice classification: give 10 problems and ask the student to label each as "transformation," "similarity," "Pythagorean Theorem," or "combination" BEFORE solving. For multi-step problems, enforce the strategy: read, draw, identify, apply, check. |

## Error Analysis Guide

| Error Pattern | Example | Likely Cause | Intervention |
|--------------|---------|-------------|-------------|
| Changes wrong coordinate in reflection | Reflects (3, 5) over x-axis and gets (-3, 5) instead of (3, -5) | Confuses which coordinate changes for which axis | Mnemonic: "Reflect over x? x stays. Reflect over y? y stays." The coordinate matching the axis name stays the same. Practice 10 reflections with this mnemonic. |
| Uses wrong rotation rule | Gets (1, -3) instead of (1, 3) for 90 CCW rotation of (3, -1) | Confuses 90 CCW, 90 CW, and 180 rules | Write all three rules on a card. For each problem, circle which rotation is being asked for before applying the rule. Verify by plotting: does the image look rotated the right amount? |
| Applies scale factor to only one coordinate | Dilates (3, 4) by k = 2 and gets (6, 4) | Forgets to multiply both coordinates | Emphasize: BOTH coordinates are multiplied. Write (kx, ky) and underline both k's. Check: if only one coordinate doubled, the figure would be stretched, not scaled. |
| Adds sides instead of squaring | Writes 3 + 4 = 7 instead of 3^2 + 4^2 = 25 | Confuses Pythagorean Theorem with simple addition | Circle the exponents in a^2 + b^2 = c^2. Always write the squared values first (9 + 16), not the original values. Provide a "SQUARE first" reminder at the top of the work. |
| Identifies wrong side as hypotenuse | Puts the longest side as a leg | Does not connect hypotenuse to opposite-the-right-angle | Always mark the right angle first. The side across from it is c. The two sides forming the right angle are a and b. Use color: mark the right angle in red, mark the hypotenuse in red. |
| Says similar figures must be congruent | Claims 3-4-5 and 6-8-10 triangles are "not related" | Does not understand similarity allows different sizes | Compare to real life: a photograph and an enlarged print have the same shapes but different sizes — they are similar. Same shape + different size = similar. Same shape + same size = congruent. |
| Confuses scale factor direction | Gets k = 2 instead of k = 1/2 | Divides in wrong order (original / image instead of image / original) | Clarify: scale factor = image / original. If the image is smaller, k < 1. If the image is bigger, k > 1. Always check: does the scale factor make sense given whether the figure got bigger or smaller? |

## Facilitator Observations

- Can the student apply each transformation rule (translation, reflection, rotation) without a reference card, or does the student still need the card?
- When combining transformations, does the student track intermediate steps carefully, or does the student try to skip steps and make errors?
- Can the student distinguish between enlargement (k > 1) and reduction (0 < k < 1) for dilations?
- Does the student correctly identify corresponding sides and angles in congruent and similar figures?
- When using the Pythagorean Theorem, does the student correctly identify the hypotenuse before setting up the equation?
- Can the student find the distance between two points on the coordinate plane without prompting?
- For the converse of the Pythagorean Theorem, can the student test a set of three sides and determine whether the triangle is a right triangle?
- In multi-step problems, can the student identify which concepts to apply without guidance?
- Does the student draw diagrams for word problems, or does the student try to solve without a visual aid?
- Can the student explain, in their own words, the difference between congruent and similar?
