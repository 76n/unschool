# Math — Grade 8 — Unit 1, Lesson 7

## Topic
Properties of Exponents, Part 2

## Learning Objectives
- Apply the power of a product rule: (ab)^n = a^n * b^n.
- Apply the power of a quotient rule: (a/b)^n = a^n / b^n.
- Simplify expressions that require combining multiple exponent rules in a single problem.

## Prerequisites
- Product rule, quotient rule, and power rule of exponents (Lesson 6)
- Ability to evaluate integer exponents
- Comfort with variable expressions
- Understanding of fraction operations

## Materials Needed
- Whiteboard and markers (or projector).
- Exponent rules reference card from Lesson 6 (to be updated today).
- Student worksheet (Guided Practice and Independent Practice problems).
- Index cards or half-sheets for Exit Ticket.

**Standards:** 8.EE.1 — Know and apply the properties of integer exponents to generate equivalent numerical expressions.

## Warm-Up (5 minutes)

**Purpose:** Review the three rules from Lesson 6 before adding two more.

1. Simplify: x^4 * x^6. (x^10)
2. Simplify: y^9 / y^3. (y^6)
3. Simplify: (z^2)^5. (z^10)
4. Ask: "Today we are going to learn what happens when you raise a PRODUCT or a QUOTIENT to a power. What do you think (2 x 3)^4 equals?"

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Power of a product** — raising a product to an exponent distributes the exponent to each factor: (ab)^n = a^n * b^n.
- **Power of a quotient** — raising a quotient to an exponent distributes the exponent to both the numerator and the denominator: (a/b)^n = a^n / b^n.

### Instruction Notes

**Step 1 — Discover the power of a product rule.**
Write: (2 x 3)^4.

Expand: (2 x 3)^4 = (2 x 3) x (2 x 3) x (2 x 3) x (2 x 3).

Rearrange (by the commutative property of multiplication):
= (2 x 2 x 2 x 2) x (3 x 3 x 3 x 3)
= 2^4 x 3^4
= 16 x 81
= 1,296.

Check: (2 x 3)^4 = 6^4 = 1,296. It matches.

State the rule: **(ab)^n = a^n * b^n.**
"When you raise a product to a power, raise each factor to that power."

This also works with variables: (3x)^4 = 3^4 * x^4 = 81x^4.

**Step 2 — Discover the power of a quotient rule.**
Write: (3/5)^2.

Expand: (3/5)^2 = (3/5) x (3/5) = (3 x 3) / (5 x 5) = 9/25.

This is the same as 3^2 / 5^2 = 9/25.

State the rule: **(a/b)^n = a^n / b^n (where b is not zero).**
"When you raise a quotient (fraction) to a power, raise the numerator and denominator each to that power."

Example with variables: (x/4)^3 = x^3 / 4^3 = x^3 / 64.

**Step 3 — Combine multiple rules in one expression.**
Write: (2x^3)^4.

Apply the power of a product: = 2^4 * (x^3)^4.
Apply the power rule to (x^3)^4: = 2^4 * x^(3x4) = 16 * x^12 = 16x^12.

Another example: (3a^2b)^3.
Apply power of a product: = 3^3 * (a^2)^3 * b^3.
Simplify: = 27 * a^6 * b^3 = 27a^6b^3.

**Step 4 — Summarize all five rules.**
Write the complete set on the board:

1. Product rule: a^m * a^n = a^(m+n)
2. Quotient rule: a^m / a^n = a^(m-n)
3. Power rule: (a^m)^n = a^(m*n)
4. Power of a product: (ab)^n = a^n * b^n
5. Power of a quotient: (a/b)^n = a^n / b^n

Say: "These five rules are your toolkit for all exponent work going forward."

### Worked Examples

**Example A — Power of a product with numbers**
Simplify: (5 x 2)^3.
- (5 x 2)^3 = 5^3 x 2^3 = 125 x 8 = 1,000.
- Check: (5 x 2)^3 = 10^3 = 1,000. Correct.

**Example B — Power of a quotient with variables**
Simplify: (m/n)^5.
- (m/n)^5 = m^5 / n^5.

**Example C — Combining multiple rules**
Simplify: (4x^2)^3 * x^5.
- Step 1: Apply power of a product to (4x^2)^3: = 4^3 * (x^2)^3 = 64 * x^6 = 64x^6.
- Step 2: Multiply by x^5: 64x^6 * x^5 = 64x^(6+5) = 64x^11.

## Guided Practice (10 minutes)

Work through these problems together. The student attempts each problem first, then discusses.

1. Simplify: (3 x 4)^2.
   - *Facilitator prompt:* "Distribute the exponent to each factor. Then compute."

2. Simplify: (2/7)^3.
   - *Facilitator prompt:* "Raise the numerator to the 3rd power. Raise the denominator to the 3rd power."

3. Simplify: (5y)^3.
   - *Facilitator prompt:* "Treat 5 and y as two factors being raised to the 3rd power."

4. Simplify: (a^3 / b^2)^4.
   - *Facilitator prompt:* "Apply power of a quotient, then power rule to each part."

5. Simplify: (2n^4)^3 * n^2.
   - *Facilitator prompt:* "Start with the power of a product, then combine using the product rule."

## Check for Understanding (5 minutes)

### Exit Ticket
**Problem 1:** Simplify (4x^3)^2.
**Problem 2:** Simplify (2/3)^4.

**Scoring:**
- 2 out of 2 correct = Mastery demonstrated.
- 1 out of 2 correct = Partial understanding; review errors.
- 0 out of 2 correct = Reteach needed.

### If Mastery Is Not Met
- Return to the expanded form approach. Write out (4x^3)^2 = (4x^3)(4x^3) = 4*4 * x^3*x^3 = 16x^6. The expanded form makes the rule concrete.
- Update the reference card with all five rules. Have the student label which rule applies to each problem before solving.
- Practice four additional problems focusing on power of a product before combining rules.

### If Mastery Is Met
- Challenge: "Can you simplify ((2x^2y^3)^2 * (3xy^2)^3) / (6x^3y)^2 completely?" (Answer: 4x^7 * y^6 * 27x^3 * y^6 / 36x^6y^2 = 108x^10y^12 / 36x^6y^2 = 3x^4y^10)
- Preview Lesson 8: "We know the rules for positive exponents. But what happens when the exponent is 0 or negative?"

## Extension (Optional)
- **Pattern Builder:** Compute (2x)^1, (2x)^2, (2x)^3, (2x)^4. Organize in a table. What pattern do you see in the coefficients? In the exponents on x?
- **Real-World Connection:** The volume of a cube with side s is s^3. If the side is 3r^2 centimeters, express the volume in simplified form. (27r^6 cubic centimeters.)

## Teacher/Facilitator Notes

### Common Errors
- **Raising only one factor to the power.** A student may write (3x)^4 = 3x^4, forgetting to raise 3 to the 4th power. Emphasize: the exponent applies to EVERYTHING inside the parentheses.
- **Confusing power of a product with the product rule.** The product rule (a^m * a^n = a^(m+n)) requires the same base. The power of a product rule ((ab)^n = a^n * b^n) distributes the exponent to different factors. Help the student see when each applies: "Are we multiplying two powers with the same base, or are we raising a product to a power?"
- **Errors with coefficients.** A student may write (2x^3)^4 = 2x^12, forgetting to raise 2 to the 4th power. It should be 2^4 * x^12 = 16x^12.

### Pacing Advice
- The power of a product and power of a quotient rules are relatively intuitive once students see the expanded form. Spend most of the time on Step 3 (combining rules), which is where real fluency develops.
- If the student is comfortable, jump to the multi-step problems quickly. The ability to chain rules is more important than isolated rule application.
- The Guided Practice problem 5 and Independent Practice ★★ problems are where the real learning happens — they require selecting and combining rules.

## Answer Key

### Guided Practice
1. (3 x 4)^2 = 3^2 x 4^2 = 9 x 16 = 144. (Or: 12^2 = 144.)
2. (2/7)^3 = 2^3 / 7^3 = 8/343.
3. (5y)^3 = 5^3 * y^3 = 125y^3.
4. (a^3 / b^2)^4 = (a^3)^4 / (b^2)^4 = a^12 / b^8.
5. (2n^4)^3 * n^2 = 2^3 * (n^4)^3 * n^2 = 8n^12 * n^2 = 8n^14.

### Independent Practice

**★ On-Level**
1. (6 x 7)^2 = 6^2 x 7^2 = 36 x 49 = 1,764. (Or: 42^2 = 1,764.)
2. (4/9)^2 = 16/81.
3. (3m)^4 = 3^4 * m^4 = 81m^4.
4. (x/5)^3 = x^3 / 125.

**★★ Stretch**
5. (2a^3)^5 = 2^5 * (a^3)^5 = 32a^15.
6. (3x^2y)^3 / x^4 = 27x^6y^3 / x^4 = 27x^2y^3.
7. Area = (5x^2)^2 = 25x^4 square units.

**★★★ Challenge**
8. Numerator: (2^3 x 3^2)^2 = 2^6 x 3^4. Denominator: (2^2 x 3)^3 = 2^6 x 3^3. Divide: 2^(6-6) x 3^(4-3) = 2^0 x 3^1 = 1 x 3 = 3. (Note: 2^0 = 1 — we will study this formally in Lesson 8.)
9. (ab)^4 = 1296. a = 3, so (3b)^4 = 1296. 3^4 * b^4 = 1296. 81 * b^4 = 1296. b^4 = 16. b = 2.

### Interleaved Review
10. (-5) + (-8) - (-3) = -5 + (-8) + 3 = -13 + 3 = -10.
11. (-12) / 4 x (-2) = (-3) x (-2) = 6.

### Exit Ticket
1. (4x^3)^2 = 4^2 * (x^3)^2 = 16x^6.
2. (2/3)^4 = 2^4 / 3^4 = 16/81.
