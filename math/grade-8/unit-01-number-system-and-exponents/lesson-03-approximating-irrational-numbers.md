# Math — Grade 8 — Unit 1, Lesson 3

## Topic
Approximating Irrational Numbers

## Learning Objectives
- Estimate the value of a square root by identifying the two consecutive integers it falls between.
- Use successive approximation (guess-and-check with squaring) to narrow down an irrational number to the nearest tenth and hundredth.
- Locate irrational numbers on a number line with reasonable precision.

## Prerequisites
- Understanding of rational vs. irrational numbers (Lesson 2)
- Knowledge of perfect squares through at least 15^2 = 225
- Ability to multiply decimals (e.g., 3.1 x 3.1)
- Familiarity with number line placement of decimals

## Materials Needed
- Whiteboard and markers (or projector).
- Number line (large, drawn from 0 to 10 with space for decimal precision).
- Calculator (for checking approximations).
- Graph paper (for precise number line work).
- Student worksheet (Guided Practice and Independent Practice problems).
- Index cards or half-sheets for Exit Ticket.

**Standards:** 8.NS.2 — Use rational approximations of irrational numbers to compare the size of irrational numbers, locate them approximately on a number line diagram, and estimate the value of expressions.

## Warm-Up (5 minutes)

**Purpose:** Review perfect squares and reinforce the connection between squaring and square roots.

1. Quick-fire: List the perfect squares from 1^2 through 12^2. (1, 4, 9, 16, 25, 36, 49, 64, 81, 100, 121, 144)
2. Ask: "Between which two perfect squares does 50 fall?" (49 and 64, so sqrt(50) is between 7 and 8)
3. Ask: "Is sqrt(50) closer to 7 or to 8? How can you tell?" (50 is closer to 49 than to 64, so sqrt(50) is closer to 7)

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Successive approximation** — a method of getting closer and closer to the true value of a number by making increasingly precise estimates and checking each one.
- **Perfect square** — a number that is the square of an integer (e.g., 1, 4, 9, 16, 25, ...).
- **Estimate** — an approximate value that is close to the exact answer.

### Instruction Notes

**Step 1 — Identify the two consecutive integers.**
Write sqrt(20) on the board. Ask: "What two perfect squares is 20 between?"
- 4^2 = 16 and 5^2 = 25.
- So sqrt(20) is between 4 and 5.

Say: "This is our first approximation. We know sqrt(20) is somewhere between 4 and 5."

**Step 2 — Narrow down to the nearest tenth using successive approximation.**
Say: "Now let's figure out which tenth sqrt(20) is closest to. We will test values between 4 and 5 by squaring them."

- Is sqrt(20) closer to 4 or 5? Since 20 is closer to 16 than to 25, start guessing near the lower end.
- Try 4.4: 4.4 x 4.4 = 19.36. Too low.
- Try 4.5: 4.5 x 4.5 = 20.25. Too high.
- So sqrt(20) is between 4.4 and 4.5.
- Since 20 is closer to 20.25 than to 19.36, sqrt(20) is closer to 4.5.
- Better estimate: sqrt(20) is approximately 4.5.

**Step 3 — Narrow down to the nearest hundredth.**
Say: "If we want even more precision, we can keep going."
- Try 4.47: 4.47 x 4.47 = 19.9809. Close but slightly low.
- Try 4.48: 4.48 x 4.48 = 20.0704. Slightly high.
- So sqrt(20) is between 4.47 and 4.48, closer to 4.47.
- Calculator check: sqrt(20) = 4.47213...

**Step 4 — Place the approximation on a number line.**
Draw a number line from 4 to 5, with tick marks at every tenth (4.0, 4.1, ..., 4.9, 5.0). Place a point at approximately 4.47. Label it sqrt(20).

Say: "Even though we can never write the exact decimal for sqrt(20), we can place it on the number line as precisely as we need by continuing our approximation."

**Step 5 — Use approximations to compare irrational numbers.**
Write: "Which is larger, sqrt(20) or sqrt(23)?"
- We already know sqrt(20) is approximately 4.47.
- For sqrt(23): 4^2 = 16, 5^2 = 25, so sqrt(23) is between 4 and 5. Try 4.7: 4.7 x 4.7 = 22.09. Try 4.8: 4.8 x 4.8 = 23.04. So sqrt(23) is approximately 4.8.
- sqrt(23) > sqrt(20).

### Worked Examples

**Example A — Estimating sqrt(11) to the nearest tenth**
Step 1: Identify the two integers. 3^2 = 9, 4^2 = 16. So sqrt(11) is between 3 and 4.
Step 2: Test tenths.
- 3.3^2 = 10.89 (too low)
- 3.4^2 = 11.56 (too high)
- sqrt(11) is between 3.3 and 3.4.
- Since 11 is closer to 10.89 than to 11.56, sqrt(11) is approximately 3.3.
- Calculator check: sqrt(11) = 3.31662...

**Example B — Estimating sqrt(45) to the nearest tenth**
Step 1: 6^2 = 36, 7^2 = 49. So sqrt(45) is between 6 and 7.
Step 2: Test tenths.
- 6.7^2 = 44.89 (slightly low)
- 6.8^2 = 46.24 (too high)
- sqrt(45) is between 6.7 and 6.8, very close to 6.7.
- Calculator check: sqrt(45) = 6.70820...

**Example C — Comparing two irrational numbers**
Which is larger: sqrt(8) or sqrt(12)?
- sqrt(8): 2^2 = 4, 3^2 = 9. Between 2 and 3. Try 2.8: 2.8^2 = 7.84. Try 2.9: 2.9^2 = 8.41. So sqrt(8) is approximately 2.8.
- sqrt(12): 3^2 = 9, 4^2 = 16. Between 3 and 4. Try 3.4: 3.4^2 = 11.56. Try 3.5: 3.5^2 = 12.25. So sqrt(12) is approximately 3.5.
- sqrt(12) > sqrt(8).
- This makes sense: the larger the number under the radical, the larger the square root.

## Guided Practice (10 minutes)

Work through these problems together. The student attempts each problem first, then discusses.

1. Between which two consecutive integers does sqrt(33) fall?
   - *Facilitator prompt:* "What are the perfect squares nearest to 33?"

2. Estimate sqrt(33) to the nearest tenth using successive approximation.
   - *Facilitator prompt:* "Start by trying 5.7. Square it. Is the result above or below 33? Adjust."

3. Between which two consecutive integers does sqrt(75) fall?
   - *Facilitator prompt:* "What is 8^2? What is 9^2?"

4. Estimate sqrt(75) to the nearest tenth.
   - *Facilitator prompt:* "Since 75 is much closer to 81 than to 64, start your guess closer to 9."

5. Place sqrt(33) and sqrt(75) on a number line from 0 to 10. Approximately where does each go?
   - *Facilitator prompt:* "Use your estimates. sqrt(33) is approximately 5.7 and sqrt(75) is approximately 8.7. Mark them."

## Check for Understanding (5 minutes)

### Exit Ticket
**Problem 1:** Between which two consecutive integers does sqrt(42) fall? Estimate sqrt(42) to the nearest tenth.
**Problem 2:** Place sqrt(42) on a number line between 6 and 7. Mark the approximate location.

**Scoring:**
- 2 out of 2 correct = Mastery demonstrated.
- 1 out of 2 correct = Partial understanding; review errors.
- 0 out of 2 correct = Reteach needed.

### If Mastery Is Not Met
- Review the list of perfect squares from 1^2 to 15^2. Make flashcards if needed — quick recognition of perfect squares is essential for this skill.
- Walk through the successive approximation process together with an additional example (e.g., sqrt(30)), doing each squaring step on the whiteboard.
- Provide a structured worksheet with columns: "Guess | Guess^2 | Too High or Too Low?" to scaffold the process.

### If Mastery Is Met
- Challenge: "Can you estimate sqrt(200) to the nearest tenth? How about sqrt(0.5)?"
- Preview Lesson 4: "Next, we will learn to simplify square roots — turning sqrt(50) into 5 x sqrt(2) — so we can work with them algebraically, not just as decimals."

## Extension (Optional)
- **Babylonian Method:** Introduce the ancient algorithm for approximating square roots. To find sqrt(N), start with a guess g. Compute (g + N/g) / 2 to get a better guess. Repeat. Try it for sqrt(10) starting with g = 3. How many steps does it take to get to three decimal places?
- **Real-World Application:** The period of a pendulum (in seconds) is approximately T = 2 x pi x sqrt(L/9.8), where L is the length in meters. Estimate the period for a 2-meter pendulum.

## Teacher/Facilitator Notes

### Common Errors
- **Guessing instead of systematically squaring.** Students may estimate "sqrt(50) is about 7.2" without verifying. Require them to check: 7.2^2 = 51.84 (too high), 7.0^2 = 49 (too low), 7.1^2 = 50.41 (slightly high) — so sqrt(50) is between 7.0 and 7.1, closer to 7.1.
- **Thinking the estimate should be exact.** Emphasize that we are finding approximations. The true value of an irrational number cannot be written exactly as a decimal.
- **Not knowing perfect squares.** If a student cannot quickly recall that 7^2 = 49 and 8^2 = 64, the entire process stalls. Spend time drilling perfect squares if this is an issue.

### Pacing Advice
- The successive approximation process is hands-on and can be time-consuming. For the first example, do every step together. For subsequent examples, let the student try independently, intervening only when needed.
- If the student is proficient with the two-integer estimation, spend most of the time on narrowing to the nearest tenth. The hundredth-level approximation in the Direct Instruction is optional for students who need more time.
- A calculator is useful for checking but should NOT replace the manual squaring process during instruction. The goal is understanding, not calculator dependence.
