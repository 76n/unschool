# Math — Grade 8 — Unit 1, Lesson 6

## Topic
Properties of Exponents, Part 1

## Learning Objectives
- Apply the product rule of exponents: a^m * a^n = a^(m+n).
- Apply the quotient rule of exponents: a^m / a^n = a^(m-n) (where a is not zero).
- Apply the power rule of exponents: (a^m)^n = a^(m*n).

## Prerequisites
- Understanding of exponent notation (e.g., 3^4 = 3 x 3 x 3 x 3) (Grade 6)
- Ability to multiply and divide integers
- Familiarity with variables and basic algebraic notation
- Comfort with square roots and cube roots (Lessons 4-5)

## Materials Needed
- Whiteboard and markers (or projector).
- Student worksheet (Guided Practice and Independent Practice problems).
- Index cards or half-sheets for Exit Ticket.

**Standards:** 8.EE.1 — Know and apply the properties of integer exponents to generate equivalent numerical expressions. For example, 3^2 x 3^(-5) = 3^(-3) = 1/3^3 = 1/27.

## Warm-Up (5 minutes)

**Purpose:** Review exponent basics and build toward the discovery of patterns.

1. Write out the expanded form: 2^3 = ? (2 x 2 x 2 = 8)
2. Write out the expanded form: 2^5 = ? (2 x 2 x 2 x 2 x 2 = 32)
3. Now compute: 2^3 x 2^5 by multiplying 8 x 32. (256)
4. Ask: "What power of 2 is 256?" (2^8, because 2^8 = 256)
5. Ask: "Notice that 3 + 5 = 8. Do you think that is a coincidence?"

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Base** — the number being raised to a power. In 5^3, the base is 5.
- **Exponent (power)** — the number that tells how many times the base is multiplied by itself. In 5^3, the exponent is 3.
- **Product rule** — when multiplying powers with the same base, add the exponents: a^m * a^n = a^(m+n).
- **Quotient rule** — when dividing powers with the same base, subtract the exponents: a^m / a^n = a^(m-n).
- **Power rule** — when raising a power to another power, multiply the exponents: (a^m)^n = a^(m*n).

### Instruction Notes

**Step 1 — Discover the product rule through expanded form.**
Write on the board: 3^4 x 3^2.

Expand each:
- 3^4 = 3 x 3 x 3 x 3
- 3^2 = 3 x 3

Combine: 3^4 x 3^2 = (3 x 3 x 3 x 3) x (3 x 3) = 3 x 3 x 3 x 3 x 3 x 3 = 3^6.

Count the factors of 3: there are 4 + 2 = 6. So 3^4 x 3^2 = 3^(4+2) = 3^6.

State the rule: **Product Rule — a^m * a^n = a^(m+n).**
"When you multiply powers with the SAME base, keep the base and ADD the exponents."

**Step 2 — Discover the quotient rule through expanded form.**
Write on the board: 5^6 / 5^2.

Expand: 5^6 / 5^2 = (5 x 5 x 5 x 5 x 5 x 5) / (5 x 5).

Cancel two factors of 5 from numerator and denominator: = 5 x 5 x 5 x 5 = 5^4.

Count: 6 - 2 = 4. So 5^6 / 5^2 = 5^(6-2) = 5^4.

State the rule: **Quotient Rule — a^m / a^n = a^(m-n), where a is not zero.**
"When you divide powers with the same base, keep the base and SUBTRACT the exponents."

**Step 3 — Discover the power rule through expanded form.**
Write on the board: (2^3)^4.

This means 2^3 multiplied by itself 4 times:
(2^3)^4 = 2^3 x 2^3 x 2^3 x 2^3.

Using the product rule: add the exponents: 3 + 3 + 3 + 3 = 12.
So (2^3)^4 = 2^12.

Notice: 3 x 4 = 12. So (2^3)^4 = 2^(3 x 4) = 2^12.

State the rule: **Power Rule — (a^m)^n = a^(m*n).**
"When you raise a power to another power, keep the base and MULTIPLY the exponents."

**Step 4 — Emphasize the same-base requirement.**
Say: "These rules ONLY work when the bases are the same. You cannot use the product rule on 2^3 x 5^4 because the bases (2 and 5) are different. In that case, you just compute each separately: 8 x 625 = 5000."

### Worked Examples

**Example A — Product rule**
Simplify: 7^3 x 7^5.
- Same base (7). Add exponents: 3 + 5 = 8.
- 7^3 x 7^5 = 7^8.
- (If a numerical answer is needed: 7^8 = 5,764,801.)

**Example B — Quotient rule**
Simplify: 10^9 / 10^4.
- Same base (10). Subtract exponents: 9 - 4 = 5.
- 10^9 / 10^4 = 10^5 = 100,000.

**Example C — Power rule**
Simplify: (4^2)^5.
- Multiply exponents: 2 x 5 = 10.
- (4^2)^5 = 4^10.
- (If a numerical answer is needed: 4^10 = 1,048,576.)

## Guided Practice (10 minutes)

Work through these problems together. The student attempts each problem first, then discusses.

1. Simplify: 6^4 x 6^3.
   - *Facilitator prompt:* "Are the bases the same? What rule do you use? What do you do with the exponents?"

2. Simplify: 9^7 / 9^5.
   - *Facilitator prompt:* "Same base? Subtract exponents — which way? Larger minus smaller."

3. Simplify: (5^3)^2.
   - *Facilitator prompt:* "Power to a power — what do you do with the exponents?"

4. Simplify: x^5 * x^8 (using variables).
   - *Facilitator prompt:* "The rules work the same with variables. Same base x — add the exponents."

5. Simplify: (y^4)^3 / y^6.
   - *Facilitator prompt:* "This combines two rules. First apply the power rule to (y^4)^3, then use the quotient rule."

## Independent Practice (10 minutes)

### ★ On-Level
1. Simplify: 3^5 x 3^2.
2. Simplify: 8^6 / 8^3.
3. Simplify: (2^4)^3.
4. Simplify: m^3 * m^7.

### ★★ Stretch
5. Simplify: (n^5 * n^3) / n^2.
6. Simplify: (p^2)^4 * p^3.
7. A computer processes 2^10 operations per second. How many operations does it process in 2^5 seconds? Write your answer as a single power of 2.

### ★★★ Challenge
8. Simplify: (a^3)^4 / (a^2)^5. Write with a single exponent.
9. If 4^x = 2^10, find the value of x. (Hint: Rewrite 4 as a power of 2.)

### Interleaved Review
*(Reviewing: percent problems from Grade 7)*
10. A pair of shoes costs $80. Sales tax is 7.5%. What is the total cost?
11. A population of 2,000 deer decreases by 12%. What is the new population?

## Check for Understanding (5 minutes)

### Exit Ticket
**Problem 1:** Simplify 5^6 x 5^3.
**Problem 2:** Simplify (3^4)^2 / 3^5.

**Scoring:**
- 2 out of 2 correct = Mastery demonstrated.
- 1 out of 2 correct = Partial understanding; review errors.
- 0 out of 2 correct = Reteach needed.

### If Mastery Is Not Met
- Return to the expanded form approach. Write out the factors explicitly and count them. The rules are shortcuts for counting — if the student understands the counting, the rules will follow.
- Create a reference card: "Same base? Multiply: ADD exponents. Divide: SUBTRACT exponents. Power to power: MULTIPLY exponents."
- Practice five additional problems using only the product rule before combining rules.

### If Mastery Is Met
- Challenge: Simplify (2^3 x 2^4)^2 / 2^10. (2^7)^2 / 2^10 = 2^14 / 2^10 = 2^4 = 16.
- Preview Lesson 7: "Tomorrow we extend these rules to powers of products and quotients — like (3x)^4 and (a/b)^5."

## Extension (Optional)
- **Pattern Exploration:** Create a table of powers of 2 from 2^1 to 2^20. Use the product rule to find 2^15 x 2^5 without computing 2^15 and 2^5 separately. Can you find other products that equal 2^20?
- **Computer Science Connection:** In computing, storage is measured in powers of 2. A kilobyte is 2^10 bytes, a megabyte is 2^20 bytes, and a gigabyte is 2^30 bytes. How many kilobytes are in a gigabyte? Express your answer as a power of 2 and then as a regular number.

## Teacher/Facilitator Notes

### Common Errors
- **Adding exponents when they should multiply (or vice versa).** This is the most common mix-up. Reinforce with the mnemonic: "Multiply powers → Add exponents. Power of a power → Multiply exponents." The operation on the exponents is one level "simpler" than the operation on the bases.
- **Applying rules when bases are different.** A student may write 2^3 x 3^4 = 6^7, which is incorrect. Stress: the product rule requires the SAME base.
- **Forgetting to subtract in the correct order for the quotient rule.** a^m / a^n = a^(m-n), not a^(n-m). The exponent in the numerator comes first.

### Pacing Advice
- This lesson introduces three rules. If time is tight, focus on the product and quotient rules in the first session and the power rule in the next session.
- The expanded-form approach (Steps 1-3) is essential for understanding. Do not skip it, even if the student seems to memorize the rules quickly. Understanding WHY the rules work prevents errors when combining rules later.
- If the student breezes through the Guided Practice, move directly to the ★★ and ★★★ problems, which combine rules.

## Answer Key

### Guided Practice
1. 6^4 x 6^3 = 6^(4+3) = 6^7
2. 9^7 / 9^5 = 9^(7-5) = 9^2 = 81
3. (5^3)^2 = 5^(3x2) = 5^6
4. x^5 * x^8 = x^(5+8) = x^13
5. (y^4)^3 / y^6 = y^(4x3) / y^6 = y^12 / y^6 = y^(12-6) = y^6

### Independent Practice

**★ On-Level**
1. 3^5 x 3^2 = 3^(5+2) = 3^7
2. 8^6 / 8^3 = 8^(6-3) = 8^3 = 512
3. (2^4)^3 = 2^(4x3) = 2^12
4. m^3 * m^7 = m^(3+7) = m^10

**★★ Stretch**
5. (n^5 * n^3) / n^2 = n^(5+3) / n^2 = n^8 / n^2 = n^(8-2) = n^6
6. (p^2)^4 * p^3 = p^(2x4) * p^3 = p^8 * p^3 = p^(8+3) = p^11
7. Operations = (2^10) x (2^5) = 2^(10+5) = 2^15 = 32,768 operations

**★★★ Challenge**
8. (a^3)^4 / (a^2)^5 = a^12 / a^10 = a^(12-10) = a^2
9. 4^x = 2^10. Rewrite 4 as 2^2: (2^2)^x = 2^10. Power rule: 2^(2x) = 2^10. Since the bases are equal, 2x = 10, so x = 5.

### Interleaved Review
10. Tax: $80 x 0.075 = $6.00. Total: $80 + $6 = $86.00.
11. Decrease: 2,000 x 0.12 = 240. New population: 2,000 - 240 = 1,760 deer.

### Exit Ticket
1. 5^6 x 5^3 = 5^(6+3) = 5^9
2. (3^4)^2 / 3^5 = 3^(4x2) / 3^5 = 3^8 / 3^5 = 3^(8-5) = 3^3 = 27
