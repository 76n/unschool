## Section A: Rational and Irrational Numbers (3 items)

**A1.** Classify each number as rational or irrational. Write "R" for rational or "I" for irrational.

a) 0.75 ___  (R)
b) sqrt(13) ___  (I)
c) -4/7 ___  (R)
d) pi ___  (I)

| Response | Score |
|----------|-------|
| All 4 correct | 1 point |
| 3 correct | 0.5 points |
| 2 or fewer correct | 0 points |

**A2.** Convert 7/11 to a decimal. State whether the result is terminating or repeating.

(7/11 = 0.636363... = 0.63 with a bar over 63. Repeating.)

| Response | Score |
|----------|-------|
| Correct decimal AND correct classification | 1 point |
| Correct decimal OR correct classification (not both) | 0.5 points |

**A3.** Between which two consecutive integers does sqrt(55) fall? Estimate sqrt(55) to the nearest tenth.

(7^2 = 49, 8^2 = 64. sqrt(55) is between 7 and 8. 7.4^2 = 54.76, 7.5^2 = 56.25. sqrt(55) is approximately 7.4.)

| Response | Score |
|----------|-------|
| Correct integers AND estimate within 0.1 of the actual value (7.416...) | 1 point |
| Correct integers but estimate off by more than 0.1 | 0.5 points |

## Section B: Square Roots and Cube Roots (3 items)

**B1.** Simplify: sqrt(72).

Show your work.

(72 = 36 x 2. sqrt(72) = sqrt(36) x sqrt(2) = 6*sqrt(2).)

**B2.** Simplify: sqrt(150).

Show your work.

(150 = 25 x 6. sqrt(150) = sqrt(25) x sqrt(6) = 5*sqrt(6).)

**B3.** Evaluate: cbrt(-216).

(-216 = (-6)^3. cbrt(-216) = -6.)

---

## Section C: Properties of Exponents (4 items)

**C1.** Simplify: x^5 * x^4.

(x^(5+4) = x^9)

**C2.** Simplify: (y^3)^6.

(y^(3 x 6) = y^18)

**C3.** Simplify: (2a^4)^3.

Show your work.

(2^3 * (a^4)^3 = 8 * a^12 = 8a^12)

**C4.** Simplify: (m^7 * m^2) / m^5.

(m^(7+2) / m^5 = m^9 / m^5 = m^(9-5) = m^4)

---

## Section D: Negative and Zero Exponents (3 items)

**D1.** Evaluate: 9^0 + 4^(-2).

(9^0 = 1. 4^(-2) = 1/16. 1 + 1/16 = 17/16 or 1 1/16.)

| Response | Score |
|----------|-------|
| Correct final answer (17/16 or 1.0625 or 1 1/16) | 1 point |
| Correctly evaluates one part but makes an error on the other | 0.5 points |

**D2.** Rewrite with positive exponents only: 5^(-3).

(5^(-3) = 1/5^3 = 1/125.)

**D3.** Simplify and write with positive exponents: (3x^(-2))^2.

Show your work.

(3^2 * (x^(-2))^2 = 9 * x^(-4) = 9/x^4.)

---

## Section E: Scientific Notation and Operations (3 items)

**Calculator permitted for this section.**

**E1.** Write 0.0000042 in scientific notation.

(4.2 x 10^(-6))

**E2.** Multiply: (3.0 x 10^5) x (4.0 x 10^3). Write your answer in scientific notation.

Show your work.

(Coefficients: 3.0 x 4.0 = 12.0. Exponents: 5 + 3 = 8. Preliminary: 12.0 x 10^8. Adjust: 1.2 x 10^9.)

**E3.** The distance from Earth to the Moon is approximately 3.84 x 10^5 km. A spacecraft travels at 1.2 x 10^4 km per hour. How long will the journey take? Express your answer in standard form with appropriate units.

Show your work.

(Time = Distance / Speed = (3.84 x 10^5) / (1.2 x 10^4) = (3.84 / 1.2) x 10^(5-4) = 3.2 x 10^1 = 32 hours.)

### Section-Specific Reteaching Guide

| If struggling in... | Focus on... |
|---|---|
| Section A | Return to Lessons 1-2. Rebuild the classification system (rational vs. irrational). Practice converting fractions to decimals and identifying terminating vs. repeating patterns. Use the number line extensively for approximation. |
| Section B | Return to Lesson 4 (square roots) or Lesson 5 (cube roots). Ensure the student has memorized perfect squares through 15^2 and perfect cubes through 5^3. Practice the simplification process: find the largest perfect square (or cube) factor. |
| Section C | Return to Lessons 6-7. Rebuild the rules from expanded form — do NOT just re-state the rules. If the student writes out 3^4 x 3^2 as (3x3x3x3)(3x3) = 3^6, the rule becomes obvious. Focus on one rule at a time. |
| Section D | Return to Lesson 8. Use the descending-powers pattern to re-derive the zero and negative exponent rules. Focus on the key distinction: a negative exponent means a reciprocal, NOT a negative number. |
| Section E | Return to Lessons 9-10. If notation is the issue (wrong exponent sign, coefficient out of range), focus on conversion practice. If operations are the issue, connect back to Lessons 6-8 exponent rules — scientific notation operations are just exponent rules applied to powers of 10. |

## Error Analysis Guide

| Error Pattern | Example | Likely Cause | Intervention |
|--------------|---------|-------------|-------------|
| Classifies repeating decimals as irrational | Says 0.333... is irrational | Confuses "never ends" with "irrational" | Clarify: irrational means never ends AND never repeats. 0.333... repeats "3" forever, so it is rational (= 1/3). |
| Incomplete simplification of square roots | Writes sqrt(72) = 2*sqrt(18) | Did not find the largest perfect square factor | Practice finding factor pairs and identifying the largest perfect square. Encourage checking: "Is there still a perfect square under the radical?" |
| Adds exponents during addition of same-base powers | Writes x^3 + x^5 = x^8 | Confuses the product rule with addition | Demonstrate with numbers: 2^3 + 2^5 = 8 + 32 = 40, which is NOT 2^8 = 256. The product rule applies to multiplication only. |
| Writes a^(-n) as -a^n | Writes 3^(-2) = -9 | Confuses negative exponent with negation | Return to the pattern: 3^2 = 9, 3^1 = 3, 3^0 = 1, 3^(-1) = 1/3, 3^(-2) = 1/9. The values get smaller but stay positive. |
| Coefficient not between 1 and 10 in scientific notation | Writes 35 x 10^4 | Forgets the coefficient requirement | State the rule clearly: exactly one nonzero digit before the decimal point. 35 x 10^4 = 3.5 x 10^5. |
| Adds exponents when adding in scientific notation | Writes (2 x 10^3) + (5 x 10^3) = 7 x 10^6 | Confuses multiplication and addition rules | Emphasize: when ADDING, the power of 10 stays the same — you only add the coefficients. When MULTIPLYING, you add the exponents. |

## Facilitator Observations

- Does the student distinguish between rational and irrational numbers confidently, or does the student hesitate and guess?
- When simplifying square roots, does the student identify the largest perfect square factor on the first try, or does it take multiple passes?
- Can the student state the exponent rules from memory, or does the student need to refer to expanded form each time? (Both are acceptable, but fluency is the long-term goal.)
- When working with negative exponents, does the student instinctively think "reciprocal," or does the student still confuse negative exponents with negative numbers?
- In scientific notation, does the student check that the coefficient is between 1 and 10 before writing the final answer?
