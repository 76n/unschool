# Math — Grade 8 — Unit 1, Lesson 10

## Topic
Operations with Scientific Notation

## Learning Objectives
- Multiply and divide numbers in scientific notation using exponent rules.
- Add and subtract numbers in scientific notation by adjusting to the same power of 10.
- Solve real-world problems involving operations with scientific notation.

## Prerequisites
- Writing and converting numbers in scientific notation (Lesson 9)
- Properties of exponents, including the product and quotient rules (Lessons 6-8)
- Ability to add, subtract, multiply, and divide decimals
- Understanding that the coefficient in scientific notation must be between 1 and 10

## Materials Needed
- Whiteboard and markers (or projector).
- Calculator (for checking work and real-world problems).
- Student worksheet (Guided Practice and Independent Practice problems).
- Index cards or half-sheets for Exit Ticket.

**Standards:** 8.EE.4 — Perform operations with numbers expressed in scientific notation, including problems where both decimal and scientific notation are used. Use scientific notation and choose units of appropriate size for measurements of very large or very small quantities. Interpret scientific notation that has been generated by technology.

## Warm-Up (5 minutes)

**Purpose:** Review scientific notation and exponent rules that will be used in operations.

1. Write 3.0 x 10^4 and 5.0 x 10^4 on the board. Ask: "These have the same power of 10. What is their sum?" (8.0 x 10^4)
2. Using the product rule: 10^3 x 10^5 = ? (10^8)
3. Using the quotient rule: 10^9 / 10^4 = ? (10^5)
4. Ask: "If we multiply (2 x 10^3) by (4 x 10^5), what happens to the 2 and 4? What happens to the 10^3 and 10^5?"

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Coefficient** — the decimal number part of scientific notation (the a in a x 10^n).
- **Adjust** — changing the coefficient and exponent so the power of 10 matches (needed for addition and subtraction).

### Instruction Notes

**Step 1 — Multiplication in scientific notation.**
Say: "Multiplying numbers in scientific notation is the easiest operation. You multiply the coefficients and add the exponents."

Rule: (a x 10^m) x (b x 10^n) = (a x b) x 10^(m+n).

Example: (3 x 10^4) x (2 x 10^5).
- Multiply coefficients: 3 x 2 = 6.
- Add exponents: 4 + 5 = 9.
- Result: 6 x 10^9.

What if the coefficient product is 10 or more? Then adjust.
Example: (4 x 10^3) x (5 x 10^6).
- Multiply coefficients: 4 x 5 = 20.
- Add exponents: 3 + 6 = 9.
- Preliminary result: 20 x 10^9.
- Adjust: 20 = 2.0 x 10^1. So 20 x 10^9 = 2.0 x 10^(9+1) = 2.0 x 10^10.

**Step 2 — Division in scientific notation.**
Say: "For division, divide the coefficients and subtract the exponents."

Rule: (a x 10^m) / (b x 10^n) = (a / b) x 10^(m-n).

Example: (8.4 x 10^7) / (2.1 x 10^3).
- Divide coefficients: 8.4 / 2.1 = 4.
- Subtract exponents: 7 - 3 = 4.
- Result: 4 x 10^4 = 4.0 x 10^4.

What if the coefficient quotient is less than 1? Then adjust.
Example: (3 x 10^8) / (6 x 10^5).
- Divide coefficients: 3 / 6 = 0.5.
- Subtract exponents: 8 - 5 = 3.
- Preliminary result: 0.5 x 10^3.
- Adjust: 0.5 = 5.0 x 10^(-1). So 0.5 x 10^3 = 5.0 x 10^(3-1) = 5.0 x 10^2.

**Step 3 — Addition and subtraction in scientific notation.**
Say: "Addition and subtraction are a bit harder. You can only add or subtract the coefficients if the powers of 10 are THE SAME — just like adding fractions requires the same denominator."

Rule: If the exponents are the same:
(a x 10^n) + (b x 10^n) = (a + b) x 10^n.

If the exponents are different, adjust one number so the exponents match.

Example: (5.3 x 10^6) + (2.1 x 10^5).
- The exponents are 6 and 5. Rewrite the smaller one to match the larger:
  2.1 x 10^5 = 0.21 x 10^6.
- Now add: (5.3 + 0.21) x 10^6 = 5.51 x 10^6.

Example: (7.0 x 10^4) - (3.5 x 10^3).
- Rewrite: 3.5 x 10^3 = 0.35 x 10^4.
- Subtract: (7.0 - 0.35) x 10^4 = 6.65 x 10^4.

**Step 4 — Apply to real-world contexts.**
Say: "Scientific notation is used whenever numbers are extremely large or extremely small."

Example: The distance from Earth to Mars is approximately 2.25 x 10^8 km. Light travels at approximately 3.0 x 10^5 km per second. How long does it take light to travel from Earth to Mars?

Time = Distance / Speed = (2.25 x 10^8) / (3.0 x 10^5) = (2.25 / 3.0) x 10^(8-5) = 0.75 x 10^3 = 7.5 x 10^2 seconds = 750 seconds (about 12.5 minutes).

### Worked Examples

**Example A — Multiplication**
Compute: (6.2 x 10^3) x (3.0 x 10^5).
- Coefficients: 6.2 x 3.0 = 18.6.
- Exponents: 3 + 5 = 8.
- Preliminary: 18.6 x 10^8.
- Adjust: 18.6 = 1.86 x 10^1. So 1.86 x 10^(8+1) = 1.86 x 10^9.

**Example B — Division**
Compute: (9.6 x 10^(-3)) / (4.8 x 10^(-7)).
- Coefficients: 9.6 / 4.8 = 2.0.
- Exponents: (-3) - (-7) = (-3) + 7 = 4.
- Result: 2.0 x 10^4.

**Example C — Addition**
Compute: (4.5 x 10^7) + (6.3 x 10^6).
- Rewrite: 6.3 x 10^6 = 0.63 x 10^7.
- Add: (4.5 + 0.63) x 10^7 = 5.13 x 10^7.

## Guided Practice (10 minutes)

Work through these problems together. The student attempts each problem first, then discusses.

1. Multiply: (2.5 x 10^4) x (4.0 x 10^3).
   - *Facilitator prompt:* "Multiply the coefficients. Add the exponents. Do you need to adjust?"

2. Divide: (7.2 x 10^9) / (1.8 x 10^6).
   - *Facilitator prompt:* "Divide the coefficients. Subtract the exponents."

3. Add: (3.4 x 10^5) + (8.2 x 10^4).
   - *Facilitator prompt:* "The exponents are different. Rewrite 8.2 x 10^4 so it has an exponent of 5."

4. Subtract: (9.0 x 10^(-2)) - (5.0 x 10^(-3)).
   - *Facilitator prompt:* "Rewrite 5.0 x 10^(-3) as ___ x 10^(-2) and then subtract."

5. A hard drive stores 5.0 x 10^11 bytes. A single photograph is about 2.5 x 10^6 bytes. Approximately how many photographs can the hard drive store?
   - *Facilitator prompt:* "This is a division problem. Set it up and solve."

## Check for Understanding (5 minutes)

### Exit Ticket
**Problem 1:** Multiply (5.0 x 10^6) x (3.0 x 10^(-2)). Write your answer in scientific notation.
**Problem 2:** Add (4.2 x 10^5) + (3.8 x 10^4). Write your answer in scientific notation.

**Scoring:**
- 2 out of 2 correct = Mastery demonstrated.
- 1 out of 2 correct = Partial understanding; review errors.
- 0 out of 2 correct = Reteach needed.

### If Mastery Is Not Met
- For multiplication/division: review the exponent product and quotient rules from Lesson 6. The operations in scientific notation are direct applications of these rules.
- For addition/subtraction: practice rewriting numbers to have the same exponent. Use the analogy to adding fractions (you need a common denominator; here you need a common power of 10).
- Provide a step-by-step reference card for each operation type.

### If Mastery Is Met
- Challenge: "The observable universe has a radius of about 4.4 x 10^26 meters. A hydrogen atom has a radius of about 5.3 x 10^(-11) meters. How many hydrogen atoms could you line up across the observable universe?" (8.3 x 10^36 approximately.)
- The student is ready for the unit assessment. Suggest reviewing all 10 lessons before the assessment session.

## Extension (Optional)
- **Astronomy Project:** Research the distances (in km) from the Sun to each planet in our solar system. Write each distance in scientific notation. Then calculate how many times farther Neptune is from the Sun compared to Mercury.
- **Technology Connection:** Find out how much data the internet processes per day (estimated at about 2.5 x 10^18 bytes per day). If a single email is about 7.5 x 10^4 bytes, how many emails-worth of data is that?

## Teacher/Facilitator Notes

### Common Errors
- **Adding exponents when adding numbers.** Students may write (3 x 10^4) + (2 x 10^4) = 5 x 10^8. Wrong! When adding, the power of 10 stays the same: 5 x 10^4. The exponents are only added during multiplication.
- **Forgetting to adjust after multiplying coefficients.** If the product of coefficients is 15, the result 15 x 10^n is not in proper scientific notation. The student must rewrite it as 1.5 x 10^(n+1).
- **Subtracting exponents in the wrong order.** In division, the order matters: (a x 10^m) / (b x 10^n) = (a/b) x 10^(m-n). The numerator's exponent comes first.
- **Struggling with addition of different exponents.** This is the hardest operation. If students find it confusing, encourage them to convert both numbers to standard form, perform the addition, and then convert back to scientific notation. As they gain fluency, they can use the shortcut.

### Pacing Advice
- Multiplication and division are more intuitive than addition and subtraction. If time is limited, prioritize multiplication and division (Steps 1-2, which are the most commonly tested operations).
- Addition and subtraction (Step 3) can be introduced briefly and practiced more during the review session before the unit assessment.
- The real-world applications (Step 4) are motivating for students and help them understand WHY scientific notation matters. Try to include at least one.
- Consider using two sessions: one for multiplication/division and one for addition/subtraction plus applications.
