# Math — Grade 8 — Unit 1, Lesson 8

## Topic
Negative and Zero Exponents

## Learning Objectives
- Evaluate expressions with a zero exponent: a^0 = 1 for any nonzero a.
- Evaluate expressions with negative exponents: a^(-n) = 1/a^n.
- Rewrite expressions with negative exponents using positive exponents only.

## Prerequisites
- All five properties of exponents (Lessons 6-7)
- Ability to evaluate positive integer exponents
- Understanding of reciprocals (e.g., the reciprocal of 3 is 1/3)
- Comfort with fractions and fraction operations

## Materials Needed
- Whiteboard and markers (or projector).
- Exponent rules reference card (from Lessons 6-7, to be updated).
- Student worksheet (Guided Practice and Independent Practice problems).
- Index cards or half-sheets for Exit Ticket.

**Standards:** 8.EE.1 — Know and apply the properties of integer exponents to generate equivalent numerical expressions. For example, 3^2 x 3^(-5) = 3^(-3) = 1/3^3 = 1/27.

## Warm-Up (5 minutes)

**Purpose:** Use the quotient rule to set up the discovery of zero and negative exponents.

1. Simplify using the quotient rule: 5^4 / 5^4. (5^(4-4) = 5^0)
2. But also: 5^4 / 5^4 = 625/625 = 1.
3. Ask: "So what must 5^0 equal?" (1)
4. Now simplify: 2^3 / 2^5. Using the quotient rule: 2^(3-5) = 2^(-2). But also: 8/32 = 1/4.
5. Ask: "So what must 2^(-2) equal?" (1/4 = 1/2^2)

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Zero exponent** — any nonzero number raised to the zero power equals 1: a^0 = 1 (a is not zero).
- **Negative exponent** — a^(-n) means the reciprocal of a^n: a^(-n) = 1/a^n. It does NOT mean the number is negative.
- **Reciprocal** — the multiplicative inverse of a number. The reciprocal of a is 1/a. The reciprocal of 2/3 is 3/2.

### Instruction Notes

**Step 1 — Establish the zero exponent rule through a pattern.**
Write the descending powers of 3 on the board:

- 3^4 = 81
- 3^3 = 27
- 3^2 = 9
- 3^1 = 3
- 3^0 = ?

Ask: "What pattern do you see as we go down?" (Each time we divide by 3: 81/3 = 27, 27/3 = 9, 9/3 = 3.)

So 3^0 = 3/3 = 1.

Try with another base: 10^4 = 10,000; 10^3 = 1,000; 10^2 = 100; 10^1 = 10; 10^0 = 10/10 = 1.

State the rule: **a^0 = 1 for any nonzero value of a.**

Important note: 0^0 is undefined (mathematicians debate its value in different contexts). For our purposes, the base must not be zero.

**Step 2 — Extend the pattern to discover negative exponents.**
Continue the pattern:
- 3^1 = 3
- 3^0 = 1
- 3^(-1) = ?

Following the "divide by 3" pattern: 3^(-1) = 1/3.
Continue: 3^(-2) = (1/3)/3 = 1/9 = 1/3^2.
Continue: 3^(-3) = (1/9)/3 = 1/27 = 1/3^3.

State the rule: **a^(-n) = 1/a^n.**
"A negative exponent means: take the reciprocal. The number is NOT negative — it becomes a fraction."

**Step 3 — Confirm with the quotient rule.**
Use the quotient rule on 2^3 / 2^7:
- 2^3 / 2^7 = 2^(3-7) = 2^(-4).
- Also: 8/128 = 1/16 = 1/2^4.
- So 2^(-4) = 1/2^4 = 1/16. The rules are consistent.

**Step 4 — Rewriting with positive exponents.**
Say: "In many math classes, you will be asked to write your answer with positive exponents only. This means converting any negative exponents to fractions."

Examples:
- 5^(-3) = 1/5^3 = 1/125.
- x^(-2) = 1/x^2.
- 1/a^(-4) = a^4 (a negative exponent in the denominator moves to the numerator).

**Step 5 — Combine with other exponent rules.**
Simplify: 3^2 * 3^(-5).
- Product rule: 3^(2+(-5)) = 3^(-3).
- Rewrite with positive exponent: 1/3^3 = 1/27.

Simplify: (2^(-3))^2.
- Power rule: 2^((-3)*2) = 2^(-6).
- Rewrite: 1/2^6 = 1/64.

### Worked Examples

**Example A — Zero exponent**
Evaluate: 7^0 + 12^0.
- 7^0 = 1.
- 12^0 = 1.
- 7^0 + 12^0 = 1 + 1 = 2.

**Example B — Negative exponent with a number**
Evaluate: 4^(-3).
- 4^(-3) = 1/4^3 = 1/64.

**Example C — Combining rules with negative exponents**
Simplify: (5x^(-2))^3. Write with positive exponents.
- Power of a product: 5^3 * (x^(-2))^3 = 125 * x^(-6).
- Rewrite: 125/x^6.

## Guided Practice (10 minutes)

Work through these problems together. The student attempts each problem first, then discusses.

1. Evaluate: (-8)^0.
   - *Facilitator prompt:* "Any nonzero number to the zero power is... what?"

2. Evaluate: 2^(-5).
   - *Facilitator prompt:* "Negative exponent means reciprocal. What is 1/2^5?"

3. Rewrite with positive exponents: x^3 * x^(-7).
   - *Facilitator prompt:* "First use the product rule. Then convert the negative exponent."

4. Evaluate: 10^(-4).
   - *Facilitator prompt:* "What is 1/10^4? Think about place value."

5. Simplify and write with positive exponents: (3a^(-2))^2.
   - *Facilitator prompt:* "Distribute the exponent 2 to both 3 and a^(-2). Then rewrite."

## Independent Practice (10 minutes)

### ★ On-Level
1. Evaluate: 15^0.
2. Evaluate: 6^(-2).
3. Rewrite with positive exponents: b^(-5).
4. Simplify: 4^3 * 4^(-1).

### ★★ Stretch
5. Simplify and write with positive exponents: x^5 / x^8.
6. Evaluate: (1/2)^(-3). (Hint: What is the reciprocal of 1/2?)
7. A bacterium measures 10^(-6) meters across. Express this as a fraction and as a decimal.

### ★★★ Challenge
8. Simplify completely, writing with positive exponents: (2^(-2) * 3^3) / (2^3 * 3^(-1)).
9. True or false: (-1)^0 = -1^0. Explain. (Hint: Think carefully about order of operations.)

### Interleaved Review
*(Reviewing: unit rates and proportional relationships from Grade 7)*
10. A printer prints 45 pages in 3 minutes. At that rate, how long will it take to print 120 pages?
11. If the ratio of boys to girls in a class is 3:5 and there are 24 boys, how many girls are there?

## Check for Understanding (5 minutes)

### Exit Ticket
**Problem 1:** Evaluate 3^(-4).
**Problem 2:** Simplify and write with positive exponents: (2x^(-3))^2.

**Scoring:**
- 2 out of 2 correct = Mastery demonstrated.
- 1 out of 2 correct = Partial understanding; review errors.
- 0 out of 2 correct = Reteach needed.

### If Mastery Is Not Met
- Return to the descending-powers pattern (Step 1). Rebuilding from the pattern helps students see WHY the rules work, not just memorize them.
- Create a visual: draw a number line of exponents (... 3^(-3), 3^(-2), 3^(-1), 3^0, 3^1, 3^2, 3^3 ...) with corresponding values (... 1/27, 1/9, 1/3, 1, 3, 9, 27 ...). Emphasize the symmetry around 3^0 = 1.
- Practice five problems of the form a^(-n) = 1/a^n before moving to problems that combine rules.

### If Mastery Is Met
- Challenge: "Simplify (5^(-2) * 5^7) / (5^3)^2 and express as a whole number or fraction." (5^5 / 5^6 = 5^(-1) = 1/5.)
- Preview Lesson 9: "Now that we understand negative exponents, we are ready for scientific notation — a system that uses powers of 10 to express very large and very small numbers."

## Extension (Optional)
- **Powers of 10 Investigation:** Create a table of 10^n for n from -6 to 6. Match each power to a real-world measurement: 10^(-6) = 1 micrometer (width of a bacterium), 10^(-3) = 1 millimeter, 10^0 = 1 meter, 10^3 = 1 kilometer, 10^6 = distance from a city to a suburb in meters.
- **Proof Practice:** Prove that a^(-1) * a^1 = a^0 = 1 using the product rule. Explain why this confirms that a^(-1) = 1/a.

## Teacher/Facilitator Notes

### Common Errors
- **Writing a^(-n) as a negative number.** The most common misconception. Students write 2^(-3) = -8 instead of 1/8. Emphasize repeatedly: negative exponents produce fractions (reciprocals), NOT negative values.
- **Writing 5^0 = 0.** Students associate "zero" with "nothing." Use the pattern approach: 5^3 = 125, 5^2 = 25, 5^1 = 5, 5^0 = ? Each step divides by 5. 5/5 = 1, not 0.
- **Forgetting to apply the negative exponent to the coefficient.** In (2x)^(-3), students may write 2/x^3 instead of 1/(2x)^3 = 1/(8x^3). Remind: the exponent applies to everything inside the parentheses.

### Pacing Advice
- The pattern approach (Steps 1-2) is the most important part of the lesson. Do not rush it. If the student can articulate WHY a^0 = 1 and a^(-n) = 1/a^n, the rest of the lesson flows naturally.
- If time is short, cover zero exponents and negative exponents separately — zero exponents in the first half, negative exponents in the second. Consider using two sessions.
- Evaluating negative exponents in isolation is straightforward; the difficulty comes when combining with other rules (Step 5). Make sure the student is solid on the basic conversion before attempting multi-step problems.

## Answer Key

### Guided Practice
1. (-8)^0 = 1 (any nonzero number to the zero power is 1)
2. 2^(-5) = 1/2^5 = 1/32
3. x^3 * x^(-7) = x^(3+(-7)) = x^(-4) = 1/x^4
4. 10^(-4) = 1/10^4 = 1/10,000 = 0.0001
5. (3a^(-2))^2 = 3^2 * (a^(-2))^2 = 9 * a^(-4) = 9/a^4

### Independent Practice

**★ On-Level**
1. 15^0 = 1
2. 6^(-2) = 1/6^2 = 1/36
3. b^(-5) = 1/b^5
4. 4^3 * 4^(-1) = 4^(3+(-1)) = 4^2 = 16

**★★ Stretch**
5. x^5 / x^8 = x^(5-8) = x^(-3) = 1/x^3
6. (1/2)^(-3): The reciprocal of 1/2 is 2. So (1/2)^(-3) = 2^3 = 8.
7. 10^(-6) = 1/10^6 = 1/1,000,000 = 0.000001 meters.

**★★★ Challenge**
8. (2^(-2) * 3^3) / (2^3 * 3^(-1)). Separate the bases: (2^(-2) / 2^3) * (3^3 / 3^(-1)) = 2^(-2-3) * 3^(3-(-1)) = 2^(-5) * 3^4 = (1/32) * 81 = 81/32.
9. False. (-1)^0 = 1 (the base is -1, raised to the 0 power). But -1^0 = -(1^0) = -(1) = -1 (by order of operations, the exponent applies to 1 first, then the negative sign is applied). So (-1)^0 = 1 but -1^0 = -1. They are different.

### Interleaved Review
10. Rate: 45/3 = 15 pages per minute. Time for 120: 120/15 = 8 minutes.
11. 3/5 = 24/x. Cross-multiply: 3x = 120. x = 40 girls.

### Exit Ticket
1. 3^(-4) = 1/3^4 = 1/81
2. (2x^(-3))^2 = 2^2 * (x^(-3))^2 = 4 * x^(-6) = 4/x^6
