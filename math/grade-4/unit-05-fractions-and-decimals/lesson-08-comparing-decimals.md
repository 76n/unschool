# Math — Grade 4 — Unit 5, Lesson 8

## Topic
Comparing Decimals

## Learning Objectives
By the end of this lesson, the student will be able to:
- Compare two decimals to the hundredths place using >, =, or <
- Use place value reasoning, number line placement, and fraction equivalents to justify comparisons
- Avoid the common misconception that more decimal digits means a larger value
- Order three or more decimals from least to greatest and greatest to least

## Prerequisites
- Can locate decimals on a number line (Lesson 7)
- Can convert decimals to fractions and compare fractions (Lessons 6, Unit 4)
- Understands place value (ones, tenths, hundredths)

## Materials Needed
- Number line template (0 to 1, divided into tenths)
- 10×10 grid paper (2 grids)
- Place value chart (ones | . | tenths | hundredths)
- Pencil and paper

---

## Warm-Up (5 minutes)
**Purpose:** Surface the most common misconception (more digits = larger) before it causes errors.

Present this question: "A student says 0.75 is greater than 0.8 because 75 is greater than 8. Is the student correct? Why or why not?"

Let the student respond. Do not correct immediately — gather their thinking. Then say: "We'll figure out the answer using place value during today's lesson."

Also:
1. "Write 0.6 and 0.60 as fractions. Are they equal?" (6/10 and 60/100 — yes, equal)
2. "Convert 0.8 to a fraction with denominator 100." (80/100)

---

## Direct Instruction (10–15 minutes)
**Purpose:** Establish three reliable strategies for comparing decimals and demonstrate why the "more digits = larger" misconception is incorrect.

### Key Vocabulary
- **Greater than (>):** The symbol pointing to the smaller number (the open end faces the larger number).
- **Less than (<):** The symbol pointing to the smaller number (same logic, read from left).
- **Compare:** To determine whether one number is equal to, greater than, or less than another.
- **Place value comparison:** Comparing digits in matching place positions, starting from the highest place value.

### Instruction Notes

**Strategy 1 — Place value comparison:**
"To compare two decimals, first make sure they have the same number of decimal places by writing a trailing zero if needed. Then compare digit by digit, left to right."

Compare 0.8 and 0.75:
- Write: 0.80 and 0.75
- Ones place: both 0 — tied.
- Tenths place: 8 vs. 7. Since 8 > 7, we already know 0.80 > 0.75.
- We don't even need to look at the hundredths place.

"This resolves the warm-up question: 0.8 > 0.75, NOT the other way around. The student forgot to compare place by place."

Compare 0.53 and 0.57:
- Ones: tied (0). Tenths: tied (5). Hundredths: 3 vs. 7. Since 3 < 7: 0.53 < 0.57.

**Strategy 2 — Convert to fractions with the same denominator:**
"0.8 = 80/100 and 0.75 = 75/100. Same denominator → compare numerators: 80 > 75, so 0.8 > 0.75."

This strategy is slower but provides conceptual proof. Use it when verifying place value comparisons or when students are confused.

**Strategy 3 — Number line:**
"Plot both decimals on the number line. The one to the right is greater."

Plot 0.8 and 0.75: 0.8 is further right. 0.8 > 0.75. ✓

"All three strategies give the same answer. Choose the one that helps you most — but place value comparison is usually fastest."

**Ordering three or more decimals:**
"To order several decimals, compare them two at a time using place value. Or convert all to hundredths fractions and compare numerators."

Order 0.5, 0.47, 0.52, 0.4 from least to greatest:
- Convert to hundredths: 50/100, 47/100, 52/100, 40/100
- Order numerators: 40 < 47 < 50 < 52
- Result: 0.4 < 0.47 < 0.5 < 0.52

**Equal decimals:**
"When are two decimals equal? When they represent the same amount."
0.50 = 0.5 because 50/100 = 5/10.
0.70 = 0.7 because 70/100 = 7/10.

### Worked Examples

**Example 1:** Compare 0.6 and 0.59.
- Place value: 0.60 vs. 0.59. Tenths: 6 vs. 5. Since 6 > 5, 0.60 > 0.59.
- So 0.6 > 0.59.

**Example 2:** Compare 0.3 and 0.30.
- 0.3 = 3/10 = 30/100 = 0.30. Equal.
- 0.3 = 0.30.

**Example 3:** Order from least to greatest: 0.7, 0.17, 0.71, 0.07.
- Convert to hundredths: 70/100, 17/100, 71/100, 7/100.
- Order numerators: 7 < 17 < 70 < 71.
- Result: 0.07 < 0.17 < 0.7 < 0.71.

- "Which place value do you check first? What if those digits are equal?"

   c) 0.34 ___ 0.43
   d) 0.08 ___ 0.80

   b) 0.05, 0.5, 0.55, 0.50

**Stretch:**

**Challenge:**
8. Three decimals are placed on a number line: P is at 0.4, Q is at 0.04, R is at 0.40. Which two are at the same point? Explain.
9. Using digits 3, 7, and a decimal point, write the greatest decimal less than 1.0 possible using all three digits. Then write the least decimal greater than 0.
10. Create a comparison problem: write two decimals where the one with more digits is actually SMALLER. Show why using the place value method.

## Check for Understanding (3 minutes)
**Exit Ticket:**
1. Compare: 0.9 ___ 0.09 (use >, <, or =)
2. Order from least to greatest: 0.72, 0.27, 0.7, 0.2
3. Jake says 0.35 > 0.4 because 35 > 4. Write two sentences explaining the error using place value.

**Mastery = all 3 correct**

### If Mastery Is Not Met
- Return to the "same number of digits" fix: "Before comparing, write both with two decimal places. 0.9 becomes 0.90. Now compare digit by digit."
- Use the 10×10 grid: shade 0.9 (90 cells) and 0.09 (9 cells). Ask: "Which shaded region is larger?"
- Number line: plot both on the line together. "Which is to the right?"

### If Mastery Is Met
- Ask: "Can you compare 0.8 and 0.800? What about 0.8 and 8/10?" (All equal — reinforce multiple representations)
- Preview Lesson 9: "Now we'll use the /10 and /100 equivalence to add fractions with those denominators."

## Teacher/Facilitator Notes

- The misconception "more digits = larger value" is the central challenge of this lesson. Address it head-on in the warm-up and return to it multiple times. The fix is always: compare place by place, not the decimal as a whole number.
- Three strategies are presented. Students should know all three but use whichever helps them most. For most comparison problems, place value is fastest. For conceptual verification, the fraction/same-denominator method is best. For estimation, the number line is most intuitive.
- Emphasize writing trailing zeros to make decimal comparison easier. "0.6 and 0.57 → write 0.60 and 0.57, then compare."
- The ordering problems are where students who have the misconception will make errors. Watch for reversals in ordering.
- Students who grasp this quickly can begin to generalize: in any decimal, the digit in the tenths place matters most; then hundredths. This is the same left-to-right priority as whole-number place value comparison.
