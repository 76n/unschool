### Section F: Challenge (Unscored)

**C1.** Example thinking: "two digits after decimal = hundredths fraction n/100. Numerator = twice the denominator of the tenths version." If original tenths fraction is k/10, the 'denominator' of that fraction is 10. So n = 2 × 10 = 20. The decimal is 20/100 = 0.20. Another reading: "numerator of the hundredths fraction is twice the numerator of the tenths fraction." If tenths fraction = k/10, hundredths numerator = 2k. So the decimal is 2k/100. For k=1: 2/100=0.02; for k=2: 4/100=0.04; for k=3: 0.06; etc. Accept any reasonable interpretation with valid examples.

**C2.** Pairs where a/10 + b/100 = 100/100 = 1. Convert: 10a/100 + b/100 = 100/100 → 10a + b = 100. Both a/10 < 1 → a ≤ 9; b/100 < 1 → b ≤ 99.
- a=1: b=90 → 1/10 + 90/100 ✓
- a=2: b=80 → 2/10 + 80/100 ✓
- a=3: b=70 ✓
- a=4: b=60 ✓
- a=5: b=50 ✓
- a=6: b=40 ✓
- a=7: b=30 ✓
- a=8: b=20 ✓
- a=9: b=10 ✓
Accept any three of these nine pairs.

**C3.** Digits 2, 5, 8 with decimal point. Largest decimal less than 1.0: 0.85 (tenths digit 8, hundredths digit 5, and 2 must go somewhere — so actually we have three digits to place after decimal: 0.852? If only two decimal places with all three digits used differently... the decimal must use all three digits 2, 5, 8. So it's a three-decimal-place number: 0.852 (tenths=8, hundredths=5, thousandths=2) is largest less than 1. Smallest greater than 0: 0.258.
