# Math — Grade 4 — Unit 5, Lesson 5

## Topic
Decimal Notation for Hundredths

## Learning Objectives
By the end of this lesson, the student will be able to:
- Read and write decimal notation for hundredths (e.g., 25/100 = 0.25)
- Identify the tenths and hundredths places in a decimal number
- Translate fluently between fraction form (n/100) and decimal form (0.0n or 0.nn)
- Represent hundredths on a 10×10 grid using decimal labels
- Recognize that 0.50 = 0.5 (trailing zeros do not change value)

## Prerequisites
- Can write and read decimal notation for tenths (Lesson 4)
- Can represent fractions with denominator 100 on a 10×10 grid (Lesson 2)
- Understands the tenths place in a decimal number

## Materials Needed
- 10×10 grid paper (4–5 grids)
- Place value chart (ones | . | tenths | hundredths) — hand-drawn
- Play money: dimes and pennies (or printed cutouts); also a "dollar" card
- Pencil and paper
- (Optional) Dry-erase board

---

## Warm-Up (5 minutes)
**Purpose:** Review tenths as decimals; preview the need for a second decimal place.

1. "Write 7/10 as a decimal." (0.7)
2. "Write 0.4 as a fraction." (4/10)
3. "How many individual cells are in 7 rows of a 10×10 grid?" (70)
4. "If each individual cell is 1/100, how would you write 1/100 as a decimal? What new digit do we need?" (Let the student think — this leads into the lesson.)

Say: "Today we extend the decimal place value chart one more step to the right — to the hundredths place."

---

## Direct Instruction (10–15 minutes)
**Purpose:** Build the hundredths place through the place value chart and money context; establish that hundredths require two digits after the decimal point.

### Key Vocabulary
- **Hundredths place:** The second digit to the right of the decimal point; tells how many hundredths.
- **0.01:** One hundredth. One penny out of 100 pennies (one dollar).
- **0.25:** Twenty-five hundredths. Same as 25/100.
- **Trailing zero:** A zero after the last non-zero digit in the decimal part (e.g., 0.50 = 0.5). It does not change the value.

### Instruction Notes

**Extending the place value chart:**
Draw the extended place value chart:

```
Ones  |  .  |  Tenths  |  Hundredths
  0   |  .  |    2     |      5
```

"We already know the tenths place. Now there's a second place after the decimal point — the hundredths place. The number above is 0.25. We read it as 'twenty-five hundredths.'"

Write: 0.25 = 25/100.

"To write a hundredths decimal, we need exactly two digits after the decimal point. The first is the tenths digit; the second is the hundredths digit."

**Single hundredths — the challenge of 0.0n:**
"How do we write 1/100? There is 1 in the hundredths place and nothing in the tenths place — so we write a 0 in the tenths place as a placeholder."

Place value chart:
```
Ones  |  .  |  Tenths  |  Hundredths
  0   |  .  |    0     |      1
```
→ 0.01

"0.01 = 1/100. The first 0 after the decimal point is a placeholder in the tenths position."

Work through: 3/100 → 0.03; 9/100 → 0.09.

**Multiples of 10 hundredths (connection to tenths):**
"What about 30/100? The tenths digit is 3, hundredths digit is 0."
```
Ones  |  .  |  Tenths  |  Hundredths
  0   |  .  |    3     |      0
```
→ 0.30 = 0.3 = 3/10 (the trailing zero does not change the value)

**Money as hundredths:**
"Think of 1 dollar = 1 whole. A penny = 1/100 of a dollar = $0.01. A dime = 1/10 = 10/100 = $0.10 = $0.1."

Show examples:
- 3 dimes and 5 pennies = 35 cents = 35/100 of a dollar = $0.35
- 4 pennies = 4/100 = $0.04
- 2 dimes = 20/100 = $0.20 = $0.2

**10×10 grid labeling:**
Shade 47 cells. Write: 47/100 = 0.47.
Shade 5 cells. Write: 5/100 = 0.05.
Shade 70 cells (7 full rows). Write: 70/100 = 0.70 = 0.7.

### Worked Examples

**Example 1:** Write 63/100 as a decimal.
- 6 is in the tenths place; 3 is in the hundredths place.
- 0.63
- Read: "sixty-three hundredths"

**Example 2:** Write 0.08 as a fraction.
- 0 tenths, 8 hundredths = 8/100
- Fraction: 8/100

**Example 3:** A jar of quarters: you have $0.75 saved. Write this as a fraction of a dollar.
- 0.75 = 75/100 of a dollar = 75 pennies
- Fraction: 75/100

**Example 4:** Is 0.50 the same as 0.5?
- 0.50: tenths digit 5, hundredths digit 0 → 50/100
- 0.5: tenths digit 5 → 5/10
- 50/100 = 5/10 (divide both by 10), so yes: 0.50 = 0.5.

---

## Guided Practice (10 minutes)

Work through together:

1. Write as a decimal: a) 73/100  b) 8/100  c) 50/100  d) 100/100
2. Write as a fraction: a) 0.37  b) 0.09  c) 0.60  d) 0.01
3. Shade a 10×10 grid for 0.34 and label it with the decimal and fraction.
4. A parking meter shows $0.45 has been paid. Write this as a fraction of a dollar.
5. Are 0.60 and 0.6 the same? Use a grid or place value chart to explain.

**Facilitation questions:**
- "Why do we put a 0 in the tenths place when writing 0.07? What would happen if we left it out?" (0.7 ≠ 0.07)
- "How is writing 0.25 similar to writing 25/100? What are the connections between the digits?"
- "If I see $0.30, how many dimes and pennies is that?"

---

## Independent Practice (10–15 minutes)

### Difficulty Tiers

**On-level:**
1. Write each fraction as a decimal:
   a) 48/100     b) 6/100     c) 90/100     d) 25/100     e) 100/100
2. Write each decimal as a fraction with denominator 100:
   a) 0.52     b) 0.04     c) 0.80     d) 0.17     e) 0.99
3. Shade a 10×10 grid for 0.72. Write the matching fraction.
4. You have 3 dimes and 7 pennies. Write the amount as a decimal and as a fraction of a dollar.
5. Circle the equivalent pairs:
   a) 0.30 and 30/100
   b) 0.3 and 3/100
   c) 0.70 and 7/10
   d) 0.09 and 9/10

**Stretch:**
6. Order from least to greatest: 0.45, 0.09, 0.50, 0.90, 0.04
7. In a bag of 100 marbles, 35 are red, 40 are blue, and the rest are green. Write the fraction and decimal for each color.
8. How many pennies make $0.68? Write as a fraction of a dollar.

**Challenge:**
9. A student writes: "0.7 and 0.70 are different because one has two digits and one has one digit." Is this correct? Write a convincing explanation for the student using place value.
10. Write 0.05 + 0.03 = ___ without a calculator. (Hint: think in hundredths.) Can you write the answer as a fraction?
11. I spent $0.48 at the store. How much change do I get from $1.00? Write the change as a decimal and as a fraction of a dollar.

### Interleaved Review
R1. *(Unit 4 — Adding Fractions)* 3/8 + 2/8 = ___
R2. *(Unit 1 — Multiplication)* 36 × 25 = ___ (use any method)
R3. *(Unit 3 — Factors)* Find all factor pairs of 24.

## Check for Understanding (3 minutes)
**Exit Ticket:**
1. Write 39/100 as a decimal.
2. Write 0.06 as a fraction with denominator 100.
3. A cashier gives back $0.50 in change. Another cashier gives $0.5. Did they give the same amount? Write both as fractions and explain.

**Mastery = all 3 correct**

### If Mastery Is Not Met
- Use the place value chart as a scaffold: have the student fill in digits one at a time. "What is the tenths digit? [Write it.] What is the hundredths digit? [Write it.] Now read the decimal."
- For the placeholder 0: "If there are 0 tenths and 6 hundredths, what goes in the tenths box? [0] Write 0.06."
- Money is often the most intuitive context: "6 pennies out of 100 = $0.06."

### If Mastery Is Met
- Ask: "Can you explain why 0.7 = 0.70 using what you know about equivalent fractions?"
- Preview Lesson 6: "Now that we can write fractions as decimals and decimals as fractions, we'll practice converting in both directions fluently."

## Extension (Optional)
**Money challenges:** Use play money or real coins. Make different amounts using dimes and pennies. For each amount, write the decimal, the fraction with denominator 100, and the fraction with denominator 10 (if possible).

## Teacher/Facilitator Notes

- The most critical error in this lesson is writing 0.7 when the student means 0.07 (omitting the tenths placeholder). Be very attentive to this. The fix is always: "Write each digit in its place — tenths first, then hundredths."
- Consistently model reading "0.07 — zero tenths and seven hundredths" to make the placeholder explicit.
- Money is the best anchor for this lesson. Students who have handled coins have already internalized the structure of hundredths. Use it frequently.
- 0.50 = 0.5 is a source of confusion (or insight). Treat it as a learning opportunity: "trailing zeros after the last non-zero digit in the decimal part do not change the value." This also connects back to 3/10 = 30/100 from Lesson 3.
- Do not move on to Lesson 6 if the student cannot write 0.07 correctly. The tenths placeholder is not negotiable.
