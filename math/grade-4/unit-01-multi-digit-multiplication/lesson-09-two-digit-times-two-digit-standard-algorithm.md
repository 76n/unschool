# Math — Grade 4 — Unit 1, Lesson 9

## Topic

Multiplying 2-Digit x 2-Digit: Standard Algorithm

## Learning Objectives

- Carry out the standard (vertical/compressed) algorithm for two-digit by two-digit multiplication.
- Explain each line of the standard algorithm in terms of partial products and place value.
- Use estimation or the partial-products method to verify an answer obtained with the standard algorithm.
- Connect the standard algorithm to the area model and partial-products method from Lessons 7-8.

## Prerequisites

- Multiplying a multi-digit number by a one-digit number with regrouping (Lessons 3-5).
- The area model for two-digit by two-digit multiplication (Lesson 7).
- The partial-products method for two-digit by two-digit multiplication (Lesson 8).
- Estimating products by rounding (Lesson 6).

## Materials Needed

- Whiteboard and markers (teacher).
- Personal whiteboards or lined/graph paper (students).
- Place-value chart (ones, tens, hundreds, thousands) — displayed or individual copies.
- Colored markers or pencils (two colors: one for the "ones row" and one for the "tens row").

**Standards:** 4.NBT.5

## Warm-Up (5 minutes)

**Purpose:** Review partial products so students can see how the standard algorithm compresses those same steps.

1. Find 23 x 15 using partial products (from Lesson 8):
   - 20x10=200, 20x5=100, 3x10=30, 3x5=15. Total: 345.
2. "Today we will learn a faster way to write the same work. The standard algorithm combines partial products into just two lines instead of four."
3. Quick mental math: 7 x 5 = ? (35), 2 x 5 = ? (10), 3 x 1 = ? (3), 2 x 1 = ? (2). "You will use all of these multiplications in today's lesson."

## Direct Instruction (10-15 minutes)

### Key Vocabulary

- **Standard algorithm** — the traditional step-by-step method for multiplying, written vertically with regrouping.
- **Regroup (carry)** — when a product in one place-value column is 10 or more, write the ones digit and carry the tens digit to the next column.
- **Partial product (row)** — each line of work in the standard algorithm; the first row comes from multiplying by the ones digit, the second row from multiplying by the tens digit.
- **Placeholder zero** — the zero written in the ones place of the second row, because you are multiplying by tens.

### Instruction Notes

**Step 1 — Set up the problem vertically.**
Write on the board:
```
      2 3
    x 1 5
    -----
```
- "We write the larger number on top. We will multiply 23 by each digit of 15, starting with the ones digit."

**Step 2 — Multiply by the ones digit (5).**
- "5 x 3 = 15. Write 5 in the ones column, carry 1 to the tens column."
- "5 x 2 = 10, plus the carried 1 = 11. Write 11."
- First partial product row: 115.
```
        1
      2 3
    x 1 5
    -----
    1 1 5     (23 x 5)
```
- "This 115 represents 23 x 5 = 115. Check: does that match our partial products? 3x5=15 and 20x5=100, total 115. Yes!"

**Step 3 — Multiply by the tens digit (1 ten = 10).**
- "Now multiply 23 by the 1 in the tens place. Because it means 1 ten, we start by writing a 0 in the ones column as a placeholder."
- "1 x 3 = 3. Write 3 in the tens column."
- "1 x 2 = 2. Write 2 in the hundreds column."
- Second partial product row: 230.
```
      2 3
    x 1 5
    -----
    1 1 5     (23 x 5)
  + 2 3 0     (23 x 10)
    -----
```
- "This 230 represents 23 x 10 = 230. Check with partial products: 3x10=30 and 20x10=200, total 230. Yes!"

**Step 4 — Add the two rows.**
- 115 + 230 = 345.
```
      2 3
    x 1 5
    -----
    1 1 5
  + 2 3 0
    -----
    3 4 5
```
- "23 x 15 = 345. This matches our partial-products answer and our area-model answer from earlier lessons!"

**Step 5 — Estimate to check.**
- "23 rounds to 20, 15 rounds to 15. 20 x 15 = 300. Our answer 345 is close — reasonable!"

### Worked Examples

**Example A:** 14 x 12
```
      1 4
    x 1 2
    -----
      2 8     (14 x 2)
  + 1 4 0     (14 x 10)
    -----
    1 6 8
```
Check: 14 x 2 = 28. 14 x 10 = 140. 28 + 140 = 168.

**Example B:** 36 x 25
```
        3
      3 6
    x 2 5
    -----
    1 8 0     (36 x 5: 5x6=30, write 0 carry 3; 5x3=15, +3=18)
  + 7 2 0     (36 x 20: 2x6=12, write 2 carry 1; 2x3=6, +1=7; placeholder 0)
    -----
    9 0 0
```
Check: Estimate 40 x 25 = 1,000. Answer 900 is close. Exact verification with partial products: 30x20=600, 30x5=150, 6x20=120, 6x5=30. Total: 600+150+120+30 = 900.

**Example C:** 47 x 33
```
      2
      4 7
    x 3 3
    -----
    1 4 1     (47 x 3: 3x7=21, write 1 carry 2; 3x4=12, +2=14)
+ 1 4 1 0     (47 x 30: 3x7=21, write 1 carry 2; 3x4=12, +2=14; placeholder 0)
    -----
  1 5 5 1
```
Check: Estimate 50 x 30 = 1,500. Answer 1,551 is close. Exact verification: 40x30=1,200, 40x3=120, 7x30=210, 7x3=21. Total: 1,200+120+210+21 = 1,551.

## Guided Practice (10 minutes)

Students solve on whiteboards using the standard algorithm. After each problem, one student shows their work under the document camera (or on the class board).

1. Use the standard algorithm to find 22 x 13.
   - *Facilitator prompt:* "Start with the ones digit of 13. What is 3 x 2? What is 3 x 2 (the tens digit of 22)? Now move to the tens digit — don't forget the placeholder zero."

2. Use the standard algorithm to find 31 x 24.
   - *Facilitator prompt:* "Multiply 31 by 4 first. Then multiply 31 by 20. Add the two rows."

3. Use the standard algorithm to find 46 x 18.
   - *Facilitator prompt:* "This one requires regrouping. Watch your carries! After you get your answer, estimate to check."

4. Tyler used the standard algorithm for 27 x 14 and got 918. Use estimation to explain why his answer cannot be correct. Then find the right answer.
   - *Facilitator prompt:* "Estimate: 30 x 14 = 420. Is 918 close to 420? What might Tyler have done wrong?"

## Check for Understanding (5 minutes)

### Exit Ticket

**Problem 1:** Use the standard algorithm to find 35 x 17. Show all your work.

**Problem 2:** Circle the partial product row in your work that came from multiplying 35 by the tens digit of 17. Explain why there is a zero at the end of that row.

**Scoring:**
- Problem 1 correct with work shown (two partial product rows and final sum) = Mastery of computation.
- Problem 2: Student correctly identifies the row (350) and explains the zero is a placeholder because they are multiplying by 1 ten (10), not 1 = Mastery of understanding.
- Both mastery = Full mastery.
- One of two = Approaching.
- Neither = Not yet.

### If Mastery Is Not Met

- Have the student solve the same problem side-by-side using partial products (four lines) and the standard algorithm (two lines), and draw arrows connecting corresponding parts.
- Provide graph paper to help with column alignment, which is a common source of errors.
- Focus on single-digit times two-digit problems with regrouping (e.g., 36 x 7) if the student is struggling with the mechanics of carrying.

### If Mastery Is Met

- Student moves to Extension activity.
- Student may begin practicing mixed problems where they choose the most efficient method (area model, partial products, or standard algorithm).

## Extension (Optional)

**Algorithm Detective:** Give students three worked-out standard-algorithm problems, each containing one deliberate error (a carrying mistake, a missing placeholder zero, or an addition error). Students identify the mistake, explain what went wrong, and correct the work. This builds error-analysis skills and deepens understanding of why each step matters.

Example error problem:
```
      4 6
    x 2 3
    -----
    1 3 8     (46 x 3 = 138 -- correct)
  + 9 2       (46 x 2 = 92 -- forgot the placeholder zero!)
    -----
    2 3 0     (incorrect total)
```
Corrected: The second row should be 920 (not 92). Correct total: 138 + 920 = 1,058.

## Teacher/Facilitator Notes

### Common Errors

- **Forgetting the placeholder zero.** This is the single most common error. When multiplying by the tens digit, students must write a 0 in the ones column first. Emphasize: "You are multiplying by tens, so your answer must end in zero."
- **Carrying errors.** Students may forget to add the carried digit, or they may carry the wrong digit. Encourage writing the carried digit small and clearly above the correct column, and crossing it out after using it.
- **Misaligning columns.** If digits are not lined up by place value, the final addition will be wrong. Graph paper or place-value charts help enormously.
- **Mixing up which digit to multiply by.** Students sometimes multiply both rows by the same digit. Use two different colored pencils — one color for the ones-digit row and one for the tens-digit row — to keep the steps visually separate.
- **Not connecting to partial products.** Students who learn the algorithm mechanically without understanding may not be able to catch their own errors. Frequently ask: "Which partial products does this row represent?"

### Pacing Advice

- Spend extra time on Step 2 and Step 3 if needed. The transition from partial products to the compressed algorithm is the conceptual heart of this lesson.
- Guided Practice problem 4 (Tyler's error) is essential — it reinforces the habit of estimating to check. Do not skip it.
- If students grasp the algorithm quickly, use the remaining time for one or two additional practice problems rather than moving on. Fluency with the standard algorithm requires repetition.
- Students who are not yet comfortable should continue using partial products alongside the standard algorithm — there is no rush to abandon the expanded method.

7. 38 x 26 using both methods:
   - Standard algorithm: 38 x 6 = 228. (6x8=48, write 8 carry 4; 6x3=18, +4=22.) 38 x 20 = 760. (2x8=16, write 6 carry 1; 2x3=6, +1=7; placeholder 0.) Total: 228 + 760 = 988.
   - Partial products: 30x20=600, 30x6=180, 8x20=160, 8x6=48. Total: 600+180+160+48 = 988.
