# Math — Grade 4 — Unit 1, Lesson 3

## Topic

Multiplying 2-Digit x 1-Digit (No Regrouping)

## Learning Objectives

- Students will multiply a two-digit number by a one-digit number using partial products when no regrouping is needed.
- Students will set up and solve multiplication problems in vertical format using partial products.
- Students will connect the distributive property (Lesson 2) to the vertical written method.

## Prerequisites

- Fluency with single-digit multiplication facts (3.OA.7)
- Multiplying by multiples of 10 (Lesson 1)
- Using the distributive property to break apart two-digit factors (Lesson 2)

## Materials Needed

- Whiteboard and markers (teacher)
- Student dry-erase boards or scratch paper
- Grid paper (optional, helps students align digits in vertical format)
- Place-value chart handout (ones, tens)

**Standards:** 4.NBT.5 — Multiply a whole number of up to four digits by a one-digit whole number using strategies based on place value and the properties of operations.

## Warm-Up (5 minutes)

**Purpose:** Review the distributive property from Lesson 2 and check multiplication-fact fluency.

1. Use the distributive property to solve:
   - 21 x 4 = (20 x 4) + (1 x 4) = ?
   - 32 x 3 = (30 x 3) + (2 x 3) = ?
2. Quick facts:
   - 3 x 3 = ?
   - 4 x 2 = ?
   - 2 x 1 = ?

## Direct Instruction (10-15 minutes)

### Key Vocabulary

- **Vertical format:** Writing a multiplication problem with one number above the other, aligned by place value.
- **Partial products:** The results of multiplying by each place-value part separately, then adding.
- **No regrouping:** When the product of the digits in any place-value column is 9 or less (no carrying needed).

### Instruction Notes

**Step 1 — Review the distributive-property approach.**
Write on the board: 23 x 3 = ?
Say: "From Lesson 2, we know we can break this apart: (20 x 3) + (3 x 3) = 60 + 9 = 69."

**Step 2 — Introduce the vertical format.**
Write the same problem vertically:
```
    2 3
  x   3
  -----
```
Say: "Now we'll learn a written method that organizes the same work. We start by multiplying the ones, then the tens."

**Step 3 — Multiply the ones.**
- 3 (ones digit of 23) x 3 = 9. Write 9 in the ones column.

**Step 4 — Multiply the tens.**
- 2 (tens digit of 23) x 3 = 6. Write 6 in the tens column.
```
    2 3
  x   3
  -----
    6 9
```

**Step 5 — Read the answer: 69.**
Say: "Notice this matches our distributive-property answer: 60 + 9 = 69. The vertical format is just a neat way to organize the same thinking."

**Step 6 — Emphasize the "no regrouping" feature.**
Say: "In this problem, 3 x 3 = 9 (a single digit) and 2 x 3 = 6 (a single digit). Neither product is 10 or more, so we don't need to carry anything. We call this 'no regrouping.' In our next lesson, we'll tackle problems where the products are 10 or more."

### Worked Examples

**Example A:** 12 x 4
```
    1 2
  x   4
  -----
    4 8
```
- Ones: 2 x 4 = 8
- Tens: 1 x 4 = 4
- Answer: 12 x 4 = 48

**Example B:** 31 x 3
```
    3 1
  x   3
  -----
    9 3
```
- Ones: 1 x 3 = 3
- Tens: 3 x 3 = 9
- Answer: 31 x 3 = 93

**Example C:** 22 x 4
```
    2 2
  x   4
  -----
    8 8
```
- Ones: 2 x 4 = 8
- Tens: 2 x 4 = 8
- Answer: 22 x 4 = 88

## Guided Practice (10 minutes)

Work through these problems as a class. Students solve on their boards using the vertical format.

1. **11 x 7 = ?**
   *Facilitator prompt:* "Multiply the ones first: 1 x 7 = ?" (7) "Now the tens: 1 x 7 = ?" (7) "Your answer?" (77)

2. **23 x 2 = ?**
   *Facilitator prompt:* "Set it up vertically. Ones: 3 x 2 = ?" (6) "Tens: 2 x 2 = ?" (4) "Answer?" (46)

3. **34 x 2 = ?**
   *Facilitator prompt:* "Ones: 4 x 2 = ?" (8) "Tens: 3 x 2 = ?" (6) "Answer?" (68)

4. **13 x 3 = ?**
   *Facilitator prompt:* "Try this one on your own first, then show your partner." (Ones: 3 x 3 = 9, Tens: 1 x 3 = 3, Answer: 39)

5. **41 x 2 = ?**
   *Facilitator prompt:* "Ones: 1 x 2 = ?" (2) "Tens: 4 x 2 = ?" (8) "Answer?" (82)

6. **32 x 3 = ?**
   *Facilitator prompt:* "Verify your answer with the distributive property: (30 x 3) + (2 x 3) = 90 + 6 = 96. Does your vertical format match?" (96)

## Check for Understanding (5 minutes)

### Exit Ticket

Solve using the vertical format. Show your work.

1. 24 x 2 = ___
2. 31 x 3 = ___

**Scoring:** Each problem is worth 1 point (2 points total). Students must get both correct to demonstrate mastery.

### If Mastery Is Not Met

- Return to the distributive-property method (Lesson 2) side-by-side with the vertical format so the student can see the connection between the two approaches.
- Have the student use grid paper to keep digits aligned in the correct columns.
- Assign three additional no-regrouping problems with a partially completed template (ones product filled in, student completes tens product and total).

### If Mastery Is Met

- Students move to the Extension activity below.
- Students may attempt a regrouping problem as a preview of Lesson 4 (e.g., 16 x 4).

## Extension (Optional)

- **Backward Problems:** Give students the product and one factor, and ask them to find the missing two-digit factor (e.g., ___ x 3 = 63). Students must use reasoning about place value to work backward.
- **Vertical vs. Distributive Race:** In pairs, one student solves using vertical format while the other uses the distributive property. They compare answers and see who finishes first. Switch roles for the next problem.

## Teacher/Facilitator Notes

**Common Errors:**
- Students reverse the order of digits in the answer (e.g., writing 84 instead of 48 for 12 x 4) because they multiply the tens digit first and write it in the ones place. Stress: always start with the ones column.
- Students confuse this with addition and add the digits instead of multiplying (e.g., writing 2 + 4 = 6 instead of 2 x 4 = 8). Watch for this during guided practice.
- Some students may try to apply regrouping when it is not needed, adding a carried digit that doesn't exist. Reassure them: if the product is a single digit, just write it down.

**Pacing Advice:**
- This lesson should feel like a smooth bridge from Lesson 2. If students mastered the distributive property well, they will pick up the vertical format quickly.
- Spend most of the instructional time on making the connection between the two methods (Steps 1-2 and Step 5). The vertical format is just a more organized way to do the same thing.
- If the class is moving quickly, you can introduce one regrouping example at the very end as a teaser for Lesson 4, but do not expect students to master it today.
