# Math — Grade 4 — Unit 1, Lesson 5

## Topic

Multiplying 3-Digit x 1-Digit

## Learning Objectives

- Students will extend the standard algorithm to multiply a three-digit number by a one-digit number, including regrouping across multiple place-value columns.
- Students will use the distributive property to decompose a three-digit factor into hundreds, tens, and ones for verification.
- Students will solve real-world problems involving 3-digit by 1-digit multiplication.

## Prerequisites

- Fluency with single-digit multiplication facts (3.OA.7)
- Multiplying by multiples of 10 and 100 (Lesson 1)
- The distributive property (Lesson 2)
- Multiplying 2-digit x 1-digit without regrouping (Lesson 3)
- Multiplying 2-digit x 1-digit with regrouping (Lesson 4)

## Materials Needed

- Whiteboard and markers (teacher)
- Student dry-erase boards or scratch paper
- Grid paper (strongly recommended for digit alignment)
- Place-value chart handout (ones, tens, hundreds, thousands)

**Standards:** 4.NBT.5 — Multiply a whole number of up to four digits by a one-digit whole number using strategies based on place value and the properties of operations.

## Warm-Up (5 minutes)

**Purpose:** Review 2-digit x 1-digit multiplication with regrouping (Lesson 4) and prepare students to add a third column.

1. Solve using the standard algorithm:
   - 67 x 4 = ?
   - 85 x 3 = ?
2. Decompose this number by place value:
   - 234 = ___ hundreds + ___ tens + ___ ones
   - 509 = ___ hundreds + ___ tens + ___ ones

## Direct Instruction (10-15 minutes)

### Key Vocabulary

- **Hundreds place:** The third digit from the right in a whole number, representing groups of 100.
- **Multiple regroupings:** When carrying is needed in more than one column during multiplication.
- **Expanded form:** Writing a number as the sum of each digit's place value (e.g., 234 = 200 + 30 + 4).

### Instruction Notes

**Step 1 — Pose the problem.**
Write on the board vertically:
```
    2 3 4
  x     5
  -------
```
Say: "This is just like what we did in Lesson 4, but now we have three digits to multiply instead of two. We use the exact same process — start at the ones and work left."

**Step 2 — Multiply the ones.**
- 4 x 5 = 20
- Write 0 in the ones column. Carry the 2 above the tens column.
```
        2
    2 3 4
  x     5
  -------
        0
```

**Step 3 — Multiply the tens.**
- 3 x 5 = 15
- Add the carry: 15 + 2 = 17
- Write 7 in the tens column. Carry the 1 above the hundreds column.
```
      1 2
    2 3 4
  x     5
  -------
      7 0
```

**Step 4 — Multiply the hundreds.**
- 2 x 5 = 10
- Add the carry: 10 + 1 = 11
- Write 11 (since this is the last column, write both digits).
```
      1 2
    2 3 4
  x     5
  -------
  1 1 7 0
```

**Step 5 — Read the answer: 1,170.**

**Step 6 — Verify with the distributive property.**
234 x 5 = (200 x 5) + (30 x 5) + (4 x 5) = 1,000 + 150 + 20 = 1,170. It matches!

### Worked Examples

**Example A:** 312 x 3 (no regrouping needed)
```
    3 1 2
  x     3
  -------
    9 3 6
```
- Ones: 2 x 3 = 6
- Tens: 1 x 3 = 3
- Hundreds: 3 x 3 = 9
- Answer: 312 x 3 = 936
- Check: (300 x 3) + (10 x 3) + (2 x 3) = 900 + 30 + 6 = 936

**Example B:** 156 x 4 (regrouping in ones and tens)
```
      2 2
    1 5 6
  x     4
  -------
    6 2 4
```
- Ones: 6 x 4 = 24. Write 4, carry 2.
- Tens: 5 x 4 = 20, + 2 = 22. Write 2, carry 2.
- Hundreds: 1 x 4 = 4, + 2 = 6. Write 6.
- Answer: 156 x 4 = 624
- Check: (100 x 4) + (50 x 4) + (6 x 4) = 400 + 200 + 24 = 624

**Example C:** 487 x 6 (regrouping in every column)
```
      5 4
    4 8 7
  x     6
  -------
  2 9 2 2
```
- Ones: 7 x 6 = 42. Write 2, carry 4.
- Tens: 8 x 6 = 48, + 4 = 52. Write 2, carry 5.
- Hundreds: 4 x 6 = 24, + 5 = 29. Write 29.
- Answer: 487 x 6 = 2,922
- Check: (400 x 6) + (80 x 6) + (7 x 6) = 2,400 + 480 + 42 = 2,922

## Guided Practice (10 minutes)

Work through these problems as a class. Students solve on their boards using the standard algorithm.

1. **213 x 3 = ?**
   *Facilitator prompt:* "Start with the ones: 3 x 3 = ?" (9) "Tens: 1 x 3 = ?" (3) "Hundreds: 2 x 3 = ?" (6) "No carrying needed. Answer?" (639)

2. **145 x 5 = ?**
   *Facilitator prompt:* "Ones: 5 x 5 = ?" (25) "Write 5, carry ?" (2) "Tens: 4 x 5 = 20, + 2 = ?" (22) "Write 2, carry ?" (2) "Hundreds: 1 x 5 = 5, + 2 = ?" (7) "Answer?" (725)

3. **362 x 4 = ?**
   *Facilitator prompt:* "Ones: 2 x 4 = ?" (8) "Any carry?" (No) "Tens: 6 x 4 = ?" (24) "Write 4, carry ?" (2) "Hundreds: 3 x 4 = 12, + 2 = ?" (14) "Answer?" (1,448)

4. **578 x 3 = ?**
   *Facilitator prompt:* "Try this one on your own first. Then verify with the distributive property." (Ones: 8 x 3 = 24, write 4 carry 2. Tens: 7 x 3 = 21 + 2 = 23, write 3 carry 2. Hundreds: 5 x 3 = 15 + 2 = 17. Answer: 1,734)

5. **209 x 8 = ?**
   *Facilitator prompt:* "Be careful with the zero in the tens place! Ones: 9 x 8 = ?" (72) "Write 2, carry ?" (7) "Tens: 0 x 8 = 0, + 7 = ?" (7) "Hundreds: 2 x 8 = ?" (16) "Answer?" (1,672)

## Check for Understanding (5 minutes)

### Exit Ticket

Solve using the standard algorithm. Show all carries.

1. 246 x 3 = ___
2. 385 x 4 = ___

**Scoring:** Each problem is worth 2 points — 1 point for correct carrying at each step, 1 point for the correct final answer (4 points total). Mastery = 3 out of 4 points.

### If Mastery Is Not Met

- Have the student use a place-value chart with labeled columns (ones, tens, hundreds, thousands) and work through the problem one column at a time, physically writing the carry above the correct column.
- Return to a 2-digit x 1-digit regrouping problem (Lesson 4) to rebuild confidence, then try the 3-digit problem again.
- Provide partially completed standard-algorithm problems where some carries are filled in, and the student only needs to finish.

### If Mastery Is Met

- Students move to the Extension activity below.
- Students may challenge themselves with four-digit by one-digit multiplication (e.g., 1,234 x 5) as a preview of upcoming work.

## Extension (Optional)

- **Estimate First:** Before solving, students round the three-digit number to the nearest hundred and estimate the product (e.g., 487 x 6: round 487 to 500, estimate 500 x 6 = 3,000, actual answer 2,922). Compare estimate to exact answer. Is the estimate close?
- **Error Analysis Gallery Walk:** Post six completed 3-digit x 1-digit problems around the room — three are correct and three have errors. Students circulate with a recording sheet, identifying which are correct and fixing the errors.
- **Four-Digit Stretch:** Students who are ready try 1,234 x 5 or 2,106 x 4, extending the algorithm by one more column.

## Teacher/Facilitator Notes

**Common Errors:**
- Forgetting a carry when there are multiple regroupings. Students may remember the first carry but lose track of the second. Encourage them to always write the carry digit clearly above the next column.
- When the tens digit is 0 (as in 307 x 6), students sometimes skip the tens column entirely, writing 187 x 6 instead. Remind them: 0 x 6 = 0, but they still need to add any carry to that 0.
- Writing the final hundreds-place product incorrectly when it exceeds a single digit (e.g., for 487 x 6, the hundreds column yields 29 — students must write both digits, giving a four-digit answer).
- Mixing up which carry goes where when regrouping happens in consecutive columns.

**Pacing Advice:**
- Begin with Example A (no regrouping) to show students that the 3-digit process is the same as 2-digit — just one more column. This builds confidence before tackling regrouping.
- Guided Practice problem 5 (209 x 8) is critical because of the zero in the tens place. Do not skip it. Many students find zeros confusing during the algorithm.
- If time runs short, prioritize problems 1-5 from Independent Practice and assign the rest as homework. The Stretch and Challenge problems are valuable but can be done outside of class.
- This is the culminating lesson of the unit. If students demonstrate mastery here, they are well prepared for multi-digit multiplication in subsequent units.
