# Math — Kindergarten — Unit 2, Lesson 4

## Topic
The + and = Signs

## Learning Objectives
By the end of this lesson, the student will be able to:
- Recognize the + sign as meaning "add" or "put together"
- Recognize the = sign as meaning "is the same as" or "makes"
- Read a number sentence like 3 + 2 = 5 and explain what it means
- Write simple addition number sentences for sums to 5

## Prerequisites
- Solves addition problems with objects for sums to 10 (Lessons 1-3)
- Recognizes and writes numerals 0-10 (Unit 1, Lessons 4-5)

## Materials Needed
- Sign cards: large + and = written on index cards
- Number cards 0-10
- Counting objects
- Pencil and paper
- Ten-frame

---

## Warm-Up (5 minutes)
**Purpose:** Review addition with objects.

1. "5 and 4 makes ___?" (Answer: 9) *(Lesson 3 review)*
2. "3 and 3 makes ___?" (Answer: 6) *(Lesson 3 review)*
3. "Name a pair that makes 10." (Any valid pair) *(Lesson 3 review)*
4. "Write the number 7." *(Unit 1 review)*

---

## Direct Instruction (10 minutes)
**Purpose:** Connect the physical act of addition to written symbols.

### Key Vocabulary
- **Plus (+):** The symbol that means "add" or "and" — put the groups together
- **Equals (=):** The symbol that means "is the same as" — both sides match
- **Number sentence:** A way to write addition using numbers and symbols (e.g., 2 + 3 = 5)

### Instruction Notes

**Step 1: Bridge from words to symbols.**
Place 2 red blocks and 3 blue blocks. Combine them: "2 and 3 makes 5."

"We've been saying 'and' and 'makes.' Now I'm going to show you the math way to write that."

Lay out: [2 card] [+ card] [3 card] [= card] [5 card].

Point to each: "Two... PLUS... three... EQUALS... five. The plus sign means 'add' or 'put together.' The equals sign means 'is the same as.'"

**Step 2: Emphasize the meaning of =.**
"The equals sign is very important. It means 'is the same as.' 2 + 3 is the same as 5. If I have 2 blocks and 3 blocks together, that IS 5 blocks. They're the same amount."

Hold up both sides like a balance scale (hands level): "Both sides balance."

**Step 3: Build several number sentences with cards.**
Let the student watch you build each sentence, using objects to verify:

- [3] [+] [1] [=] [4] — "Three plus one equals four." Verify with 3 + 1 objects = 4.
- [4] [+] [1] [=] [5] — "Four plus one equals five."
- [2] [+] [2] [=] [4] — "Two plus two equals four."

**Step 4: Write a number sentence.**
On paper, write: 3 + 2 = 5.

"This is called a number sentence. It tells a math story using numbers and symbols instead of words. Can you read it with me? Three plus two equals five."

### Worked Examples

**Example 1:** Place 1 block and 4 blocks. "One and four makes five. Let's write that: 1 + 4 = 5."

**Example 2:** Write 2 + 3 = ___. "Can you figure out what goes in the blank?" Student uses objects: 2 and 3 makes 5. Write 5.

## Guided Practice (10 minutes)
**Purpose:** Student practices reading, building, and writing number sentences.

**Activity 1: Read the sentence (3 minutes)**
Write these number sentences. Student reads each aloud:

- 1 + 2 = 3 → "One plus two equals three."
- 4 + 1 = 5 → "Four plus one equals five."
- 3 + 0 = 3 → "Three plus zero equals three."

*Facilitator prompt: If the student reads + as "and" or = as "makes," that's fine! They understand. Gently model: "You can also say 'plus' and 'equals.'" Both forms are acceptable.*

**Activity 2: Build the sentence with cards (4 minutes)**
Set out number cards and sign cards. Say: "I put together 2 objects and 3 objects. Can you build the number sentence?"

Student arranges: [2] [+] [3] [=] [5].

Repeat:
- 1 and 4 → [1] [+] [4] [=] [5]
- 3 and 2 → [3] [+] [2] [=] [5]
- 4 and 0 → [4] [+] [0] [=] [4]

**Activity 3: Write the sentence (3 minutes)**
Student writes number sentences on paper:
- Show 2 objects and 1 object. "Write the number sentence." → 2 + 1 = 3
- Show 3 objects and 2 objects. → 3 + 2 = 5

*Facilitator prompt: Guide numeral formation if needed, but prioritize getting the structure right (number, plus, number, equals, number). Messy writing is fine.*

## Independent Practice (10 minutes)
**Purpose:** Student reads and writes number sentences.

**★ On-level:**
1. Write the number sentence: 1 + 3 = ___  (4)
2. Write the number sentence: 2 + 2 = ___  (4)
3. Read aloud: 4 + 1 = 5. Use objects to check.
4. Show 3 objects and 1 object. Write the number sentence. (3 + 1 = 4)

**★★ Stretch:**
5. Write the number sentence: 5 + 3 = ___  (8)
6. Write a number sentence that equals 5. (Any valid sentence)
7. What does the = sign mean? (Accept "is the same as," "equals," or "makes")

**★★★ Challenge:**
8. Write: ___ + 2 = 5. What goes in the blank? (3)
9. "Is 2 + 3 the same as 3 + 2?" Use objects to check. (Yes — both equal 5)

### Interleaved Review
- "6 and 4 makes ___?" (10) *(Lesson 3 review)*
- Place 5 objects and 8 objects. "Which group has fewer?" (5) *(Unit 1 review)*

---

## Check for Understanding (3 minutes)
**Purpose:** Assess understanding of + and = notation.

**Exit Ticket:**

1. Read aloud: 2 + 3 = 5. (Student reads correctly)
2. Write the number sentence for "four plus one equals five." (4 + 1 = 5)
3. "What does the plus sign mean?" (Accept: "add," "put together," "and")

**Mastery = Correct on at least 2 of 3 items.**

### If Mastery Is Not Met
- The symbols are just notation for something the student already understands. If they can add with objects but struggle with symbols, focus on the translation between physical action and written form.
- Use cards (number + sign cards) as an intermediate step before writing.
- Don't delay subtraction (Lesson 5) for symbol fluency — subtraction is a concept lesson.

### If Mastery Is Met
Move to Lesson 5 (Taking Away — Subtraction Concept).

## Extension (Optional)
- **Number sentence stories:** Write 2 + 1 = 3. Student makes up a story: "I had 2 dogs. I got 1 more dog. Now I have 3 dogs."
- **Equation building station:** Lay out all number and sign cards. Student builds as many true number sentences as they can in 3 minutes.

---

## Teacher/Facilitator Notes

**The = sign does NOT mean "the answer is."** This is one of the most persistent misconceptions in math education. Children often think = means "write the answer here." In reality, it means "is the same as" — both sides are equal. Emphasize this consistently. A student who understands = correctly will have an easier time with algebra years later.

**Don't rush written notation.** Some students will take to symbols immediately. Others will prefer "2 and 3 makes 5" for weeks. Both are fine. The concept matters more than the notation.

**Left-to-right reading of number sentences.** Model reading each number sentence from left to right, touching each symbol as you say it. This builds the convention of reading math notation in order.
