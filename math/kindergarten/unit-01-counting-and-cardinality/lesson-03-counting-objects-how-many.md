# Math — Kindergarten — Unit 1, Lesson 3

## Topic
Counting Objects — How Many? (Cardinality)

## Learning Objectives
By the end of this lesson, the student will be able to:
- Count a set of up to 10 objects and state how many there are without recounting
- Understand that the last number counted represents the total quantity (cardinality principle)
- Understand that the number of objects stays the same regardless of arrangement

## Prerequisites
- Can count orally from 1 to 10 (Lesson 1)
- Can use one-to-one correspondence when counting objects (Lesson 2)

## Materials Needed
- 10-15 counting objects (blocks, buttons, beans)
- Two small bowls or cups
- Number cards 1-10
- Number line strip (1-10)

---

## Warm-Up (5 minutes)
**Purpose:** Review counting sequence and one-to-one correspondence from Lessons 1-2.

1. Count from 1 to 10 together with claps. (Spaced review — Lesson 1)
2. Place 6 objects in a row. "Count these using touch-and-say." (Review — Lesson 2)
3. "What number comes after 7?" (Answer: 8) (Spaced review — Lesson 1)

---

## Direct Instruction (10 minutes)
**Purpose:** Build understanding that the last number counted tells "how many" — and the count doesn't change when you rearrange.

### Key Vocabulary
- **How many:** The total number of things in a group
- **Cardinality:** The last number you say when counting tells you how many there are (use with facilitator only — the student just needs the concept, not the word)

### Instruction Notes

**Step 1: The "how many?" connection.**
Place 4 objects in a row. Count them with touch-and-say: "1, 2, 3, 4."

Say: "The last number I said was 4. That means there are 4 objects. The last number is the answer to 'how many?'"

Hold up 4 fingers. "Four. I don't need to count again — I already know."

**Step 2: Repeat with different quantities.**
Place 7 objects in a row. Count: "1, 2, 3, 4, 5, 6, 7. How many? Seven. The last number is the total."

Place 3 objects. Count: "1, 2, 3. How many? Three."

Each time, emphasize: "The last number I said IS the answer."

**Step 3: The rearrangement challenge.**
Place 5 objects in a straight row. Count: "1, 2, 3, 4, 5. There are 5."

Now push them into a cluster. Ask: "Did I add any? Did I take any away?" (No.)
"So how many are there now?" (Still 5.)

Now spread them far apart. "How many now?" (Still 5!)

Say: "The number of things doesn't change just because we moved them. There are still 5 no matter how we arrange them."

### Worked Examples

**Example 1:** Place 6 beans in a row. Count: "1, 2, 3, 4, 5, 6. How many beans? 6." Push them into a circle. "How many now? Still 6 — we didn't add or remove any."

**Example 2:** Place 8 blocks in two stacks of 4. Count all of them: "1, 2, 3, 4, 5, 6, 7, 8. How many blocks in total? 8."

## Guided Practice (10 minutes)
**Purpose:** Student practices answering "how many?" and recognizing that arrangement doesn't change quantity.

**Activity 1: Count and Tell (4 minutes)**
Place sets of objects and have the student count and report the total:
- 5 objects in a row → "How many?" (5)
- 9 objects in a row → "How many?" (9)
- 4 objects in a circle → "How many?" (4)

After each count, ask: "How did you know?" The student should say something like "because the last number was ___."

*Facilitator prompt: If the student starts recounting when asked "how many?", gently stop them: "You just counted — the last number you said was the answer. What was the last number?" This habit takes time to build — be patient and consistent.*

**Activity 2: Rearrange Challenge (3 minutes)**
Place 6 objects in a row. Student counts them. Then rearrange into a different pattern (circle, two rows, scattered). Ask: "How many now? Do you need to recount?"

Goal: Student says "still 6" without recounting. If they do recount, that's okay — they'll get the same answer, and you can say, "See? It was still 6, just like before."

**Activity 3: Match the Number Card (3 minutes)**
Spread number cards 1-5 face up. Place a set of objects (e.g., 3 objects). Student counts and then picks the matching number card.

Repeat with 5 objects, then 2 objects.

*Facilitator prompt: If the student counts correctly but picks the wrong card, they may not recognize the numeral yet. That's fine — numeral recognition comes in Lessons 4-5. For now, help them: "You counted 3. This is the number 3. See? It looks like this."*

## Independent Practice (10 minutes)
**Purpose:** Student counts various sets and answers "how many?" on their own.

Arrange the following and have the student count each set and state the total:

**★ On-level:**
1. 4 objects in a row. How many? ___
2. 6 objects in a row. How many? ___
3. 5 objects in a circle. How many? ___

**★★ Stretch:**
4. 8 objects scattered on the table. How many? ___
5. Count out 7 objects from a pile. Then push them together. How many now? ___

**★★★ Challenge:**
6. 10 objects in two rows of 5. How many in total? ___
7. Count out 9 objects. Rearrange them three times. "Is it still 9?" (Yes.)

### Interleaved Review
- "Count from 1 to 10 backward." (New challenge based on Lesson 1 — it's okay if they need help.)
- Place 3 objects. "Count these with touch-and-say." (Lesson 2 review)

---

## Check for Understanding (5 minutes)
**Purpose:** Assess cardinality understanding.

**Exit Ticket:**

1. Place 7 objects in a row. "Count these and tell me how many." (Answer: 7)
2. Without changing the objects, scatter them. "How many now?" (Answer: 7 — and ideally the student does NOT recount)
3. Place 5 objects. Student counts. Take away the objects and ask: "How many were there?" (Answer: 5 — tests if the student retained the count)

**Mastery = Student answers "how many?" correctly for at least 2 of 3 items AND does not need to recount for item 2.**

### If Mastery Is Not Met
- Continue practicing with smaller sets (3-5 objects). Cardinality is easier to grasp with smaller numbers.
- After every counting activity in daily life, ask "how many?" and if the student starts to recount, gently redirect: "Remember — the last number you said is the answer."
- Repeat this lesson next session, mixing in practice from Lessons 1-2.

### If Mastery Is Met
Move to Lesson 4 (Reading and Writing Numerals 0-5). Continue asking "how many?" in every warm-up and daily activity.

---

## Extension (Optional)
- **Estimation game:** Place a small group of objects under a cloth. Show them briefly (2 seconds). Ask: "About how many do you think?" Then count to check. Builds number sense beyond one-to-one counting.
- **"I have ___ " statements:** Student counts a set and says "I have 6 buttons" — practicing the verbal statement of quantity.
- **Count and draw:** Student counts a set of objects, then draws that many dots on paper.

---

## Teacher/Facilitator Notes

**Cardinality is a conceptual leap.** It may seem obvious to adults, but understanding that "the last number is the total" is a genuine insight for young children. Some children grasp it immediately; others need weeks of reinforcement. Both paths are normal.

**The rearrangement task tests conservation of number.** This is a Piagetian concept — some kindergarteners haven't developed conservation yet, meaning they genuinely believe spreading objects apart creates "more." If your student consistently thinks a spread-out group has more, don't argue — just continue providing experiences where they count and get the same number regardless of arrangement. The understanding will develop.

**Don't rush to numeral writing.** This lesson is about counting and quantity. Numeral recognition is introduced via the number cards, but the student does not need to read or write numerals yet.

**Celebrate the "how many?" moment.** When the student counts and immediately says "there are 6" without needing to recount, that is a milestone worth celebrating. They've made the connection between the counting process and the concept of quantity.
