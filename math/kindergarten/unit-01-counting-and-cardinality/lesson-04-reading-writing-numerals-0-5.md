# Math — Kindergarten — Unit 1, Lesson 4

## Topic
Reading and Writing Numerals 0-5

## Learning Objectives
By the end of this lesson, the student will be able to:
- Recognize and name the numerals 0, 1, 2, 3, 4, and 5
- Write the numerals 1-5 (recognizable, not necessarily perfect)
- Connect each numeral to its corresponding quantity

## Prerequisites
- Can count orally from 1 to 10 (Lesson 1)
- Can count objects using one-to-one correspondence (Lesson 2)
- Understands cardinality — the last number counted tells "how many" (Lesson 3)

## Materials Needed
- Number cards 0-5 (large, clear numerals)
- Counting objects (10+)
- Pencil or crayon and paper
- Optional: sand, salt tray, or finger paint for tactile numeral formation
- Number line strip (1-10)

---

## Warm-Up (5 minutes)
**Purpose:** Review counting skills from Lessons 1-3.

1. Place 8 objects on the table. "Count these and tell me how many." (Answer: 8) *(Review: Lessons 2-3)*
2. Scatter the 8 objects. "How many now?" (Answer: still 8) *(Review: Lesson 3 — conservation)*
3. "What number comes after 4?" (Answer: 5) "After 9?" (Answer: 10) *(Review: Lesson 1)*

---

## Direct Instruction (10 minutes)
**Purpose:** Connect numerals (the written symbols) to the quantities they represent.

### Key Vocabulary
- **Numeral:** The written symbol for a number (e.g., "5" is the numeral, "five" is the word, and five objects is the quantity)
- **Zero:** The number that means "none" — no objects at all

### Instruction Notes

**Step 1: Introduce zero.**
Hold up an empty hand. "How many objects am I holding? None! Zero means none. When there is nothing to count, the answer is zero."

Show the number card for 0. "This is how we write zero. It looks like a circle — or the letter O."

**Step 2: Connect numerals to quantities (1-5).**
For each numeral from 1 to 5:
1. Show the number card.
2. Say: "This is the number [X]. It means [X] things."
3. Count out [X] objects and place them next to the card.
4. Point from the objects to the numeral: "[X] objects — the number [X]."

Go slowly. Let the student hold each number card and the matching objects together.

**Step 3: Model writing each numeral.**
Write each numeral 1-5 on paper while the student watches. Describe the strokes as you write:

- **1:** "Straight line down."
- **2:** "Curve around at the top, slide down to the left, line across the bottom."
- **3:** "Curve around at the top right, curve around again at the bottom right."
- **4:** "Line down, line across, then a tall line down."
- **5:** "Line across the top, line straight down, curve around the bottom."

Keep descriptions simple and consistent. Use the same words each time.

**Step 4: Tactile practice (recommended).**
If available, let the student trace each numeral in sand, salt, or finger paint. The large motor movement helps encode the shape before writing with a pencil.

### Worked Examples

**Example 1:** Show the numeral 3. Place 3 beans next to it. "This says 3. Let's check — 1, 2, 3. Yes, three beans match the number 3."

**Example 2:** Show the numeral 0. Show an empty plate. "This says 0. Zero means none. The plate is empty — that's zero."

## Guided Practice (10 minutes)
**Purpose:** Student practices recognizing numerals and connecting them to quantities.

**Activity 1: Match the Card (4 minutes)**
Spread number cards 0-5 face up. Place a set of objects (e.g., 4 blocks). Say: "Count the blocks. Now find the number card that matches."

Repeat with different quantities: 2 objects, 5 objects, 0 objects (empty hand), 1 object, 3 objects.

*Facilitator prompt: If the student counts correctly but picks the wrong card, point to the correct card and say: "You counted 4. This is the number 4. Let's look at it carefully." Give them a moment to study the numeral.*

**Activity 2: Show Me (3 minutes)**
Hold up a number card (e.g., 3). Say: "This number says 3. Can you count out 3 objects?"

Repeat for each numeral 0-5 in random order. Zero is important — the student should show empty hands or an empty space.

**Activity 3: Writing Practice (3 minutes)**
Give the student paper and a pencil. Write a large dotted or light numeral for each number 1-5. The student traces over it, then tries to write it independently next to the model.

*Facilitator prompt: Focus on recognition, not perfection. Reversed or messy numerals are completely normal. Say: "I can tell that's a 3 — nice work!" If the student gets frustrated with writing, switch back to tracing or tactile practice.*

---

## Independent Practice (10 minutes)
**Purpose:** Student identifies numerals and practices writing them.

**★ On-level:**
1. Lay out number cards 0-5 face up. Point to each one (in random order). Student names the numeral. (All 6 cards)
2. Write the numeral 1 three times.
3. Write the numeral 3 three times.
4. Count 5 objects. Write the number 5 next to them.

**★★ Stretch:**
5. Write each numeral 0-5 once without looking at a model.
6. Show the student 4 objects. "Write the number that tells how many."

**★★★ Challenge:**
7. Shuffle the number cards 0-5. Student puts them in order from 0 to 5.
8. Draw 3 circles on paper. Write the number next to them. Repeat for 5 circles, then 1 circle.

### Interleaved Review
- "Count from 1 to 10 for me." (Lesson 1)
- Place 7 objects in a scattered group. "How many?" (Lessons 2-3)

---

## Check for Understanding (5 minutes)
**Purpose:** Assess numeral recognition and numeral-quantity connection.

**Exit Ticket:**

1. Show the numeral 4. "What number is this?" (Answer: 4)
2. Show the numeral 2. "Count out this many objects." (Student counts out 2)
3. "Write the number 5." (Student writes 5 — recognizable, not necessarily perfect)

**Mastery = Student correctly identifies the numeral in item 1, counts the right quantity in item 2, AND writes a recognizable numeral in item 3.**

### If Mastery Is Not Met
- Focus on recognition before writing. Use flash-card style practice with number cards 0-5 daily.
- Pair each numeral with a quantity every time: "This is 3" + show 3 objects.
- For writing difficulties specifically, continue with tactile practice (sand, finger paint) and tracing. Do not delay Lesson 5 if the student recognizes numerals but struggles to write them — writing fluency develops over months.

### If Mastery Is Met
Move to Lesson 5 (Numerals 6-10). Continue reviewing 0-5 recognition in warm-ups.

---

## Extension (Optional)
- **Numeral hunt:** Find numerals 0-5 in the environment (on clocks, books, signs, remote controls). "Can you find a 3 somewhere in this room?"
- **Play "store":** Label items with number cards showing their "price" (1-5). The student reads the price and counts out that many objects to "pay."
- **Numeral art:** Decorate each numeral and hang it on the wall with the matching quantity of stickers.

---

## Teacher/Facilitator Notes

**Zero is important.** Many children learn 1-5 easily but are confused by 0. Spend extra time making zero concrete: an empty plate, an empty box, zero objects in your hand. Zero is a real number that means "none."

**Writing develops slowly.** Kindergarten-age children are still developing fine motor control. Numeral formation will be imperfect and that is entirely expected. The goal is recognizable, not beautiful. Reversed numerals (especially 3 and 5) are developmentally typical through age 6-7.

**Recognition is more important than writing at this stage.** If a child can point to "4" and say "four" but can't write it neatly yet, they are on track. Don't let writing difficulty stall their mathematical understanding.

**Multisensory approaches help.** Writing in sand, forming numerals with play-dough, tracing large numerals on the floor — all of these build the motor memory for numeral formation. They are not "extras" — they are effective instruction.

## Answer Key

**Independent Practice:**
1. Student names: 0 (zero), 1 (one), 2 (two), 3 (three), 4 (four), 5 (five)
2-3. Student produces recognizable numerals (accept reversed or imperfect forms)
4. Student writes 5
5. Student writes 0, 1, 2, 3, 4, 5
6. Student writes 4
7. Cards in order: 0, 1, 2, 3, 4, 5
8. 3 circles → writes 3; 5 circles → writes 5; 1 circle → writes 1

**Exit Ticket:**
1. Four (4)
2. Student counts out 2 objects
3. Student writes a recognizable 5
