# Math — Kindergarten — Unit 4, Lesson 8

## Topic
Sorting and Classifying Objects

## Learning Objectives
By the end of this lesson, the student will be able to:
- Sort a collection of objects by one attribute (shape, size, color, or another property)
- Explain the sorting rule used in their own words
- Re-sort the same collection of objects using a different attribute
- Identify the sorting rule someone else used (by examining pre-sorted groups)

## Prerequisites
- Identifies and names circles, squares, triangles, and rectangles (Lessons 1-2)
- Describes shapes by attributes such as number of sides, number of corners, and curved vs. straight (Lesson 3)
- Compares objects by length and weight (Lessons 6-7)

## Materials Needed
- A mixed collection of at least 15-20 small objects that vary by multiple attributes: shape blocks in different colors and sizes (red square, blue square, big triangle, small triangle, green circle, yellow circle, etc.)
- Buttons of different sizes, colors, and number of holes (if available)
- Paper plates, bowls, or sorting mats (at least 3) for making groups
- Index cards or sticky notes for labeling groups
- Crayons and paper for drawing
- A bag or box to hold the mixed collection

## Warm-Up (5 minutes)
**Purpose:** Review shape names and measurement vocabulary from the unit.

1. "Name the four shapes we learned." (Circle, square, triangle, rectangle.) *(Lessons 1-2 review)*
2. Hold up two crayons. "Which is longer? Which is shorter?" (Student identifies correctly.) *(Lesson 6 review)*
3. "If I put a rock on one side of a balance scale and a cotton ball on the other, which side goes down?" (The rock side — because the rock is heavier.) *(Lesson 7 review)*

## Direct Instruction (10-15 minutes)
**Purpose:** Introduce sorting as grouping objects by a shared attribute, and demonstrate that the same objects can be sorted in different ways depending on the rule chosen.

### Key Vocabulary
- **Sort:** To put things into groups based on something they have in common
- **Attribute:** A feature or quality of an object, such as its color, shape, or size
- **Sorting rule:** The reason you put objects in a particular group (e.g., "all the red ones go here")
- **Classify:** Another word for sorting — putting things in groups by what they are like

### Instruction Notes

**Step 1: Model sorting by color.**
Pour out a mixed pile of shape blocks (or buttons) onto the table. Include red, blue, and yellow objects of various shapes and sizes.

"Look at all these objects! They are all mixed up. I want to ORGANIZE them. I am going to SORT them into groups."

"My SORTING RULE is: I am sorting by COLOR. All the RED ones go on this plate." (Begin placing red objects on one plate.) "All the BLUE ones go on this plate." (Place blue objects on the second plate.) "All the YELLOW ones go here." (Place yellow objects on the third plate.)

Point to each group. "This group is all RED. This group is all BLUE. This group is all YELLOW. They are sorted by COLOR."

"My sorting rule was: same color goes together. Everything in this group SHARES the same attribute — they are all red."

**Step 2: Re-sort by shape.**
Scoop all the objects back into a pile. "Now I am going to sort the SAME objects a DIFFERENT way. This time, my sorting rule is: SHAPE."

"All the CIRCLES go here. All the SQUARES go here. All the TRIANGLES go here."

Sort the objects by shape. "Now look at this group." Point to the circles plate. "What do they all have in common?" (They are all circles.) "But are they all the same color?" (No — there is a red circle, a blue circle, a yellow circle.) "That is okay! My rule was SHAPE, not color."

"We sorted the SAME objects two different ways — first by color, then by shape. We can always RE-SORT!"

**Step 3: Sort by size.**
Scoop the objects back together. "One more way! This time my rule is SIZE: big objects and small objects."

Sort into two groups: big and small. "This group has all the BIG shapes. This group has all the SMALL shapes. My sorting rule was SIZE."

**Step 4: Sorting rule summary.**
"To sort, you need:
1. A COLLECTION of objects.
2. A SORTING RULE — pick one attribute: color, shape, size, or something else.
3. GROUPS — put the objects that share that attribute together.

And remember — you can always re-sort the same collection by choosing a different rule!"

### Worked Examples

**Example A:** Sort 6 buttons by color.
- Red buttons go in one group. Blue buttons go in another. Green buttons go in a third.
- "My sorting rule was COLOR. All the buttons in this group are red."

**Example B:** Sort the same 6 buttons by number of holes.
- Buttons with 2 holes go in one group. Buttons with 4 holes go in another.
- "My sorting rule was NUMBER OF HOLES. All the buttons in this group have 2 holes."

## Guided Practice (10 minutes)
**Purpose:** Student sorts objects and articulates the sorting rule.

**Activity 1: Sort and explain (5 minutes)**
Give the student the mixed collection of shape blocks. Place three plates on the table.

"Sort these by SHAPE. Put each shape on its own plate."

Student sorts. When finished, ask:
- "Tell me your sorting rule." ("I sorted by shape.")
- "What do all the objects on this plate have in common?" ("They are all triangles.")
- "Are they all the same color?" ("No.") "That is okay — your rule was shape, not color."

Now say: "Mix them all up again. This time, sort by COLOR."

Student re-sorts. When finished, ask:
- "What is your new sorting rule?" ("Color.")
- "What do all the objects on this plate have in common?" ("They are all blue.")
- "Are they all the same shape?" ("No — there is a blue circle, a blue square, and a blue triangle.")

*Facilitator prompt: If the student has trouble choosing a sorting rule, offer a choice: "Do you want to sort by color, by shape, or by size? Pick one." Once the student picks, say: "Great! That is your sorting rule. Now find ALL the objects that match and put them together."*

**Activity 2: Guess my sorting rule (5 minutes)**
Pre-sort the objects into groups while the student watches (or close their eyes for a surprise).

Round 1: Sort by size (big vs. small). "I sorted these into two groups. Can you guess my sorting rule?" (Size — big and small.)

Round 2: Sort by shape but mix colors within each group. "What is my rule this time?" (Shape.)

Round 3: Sort by an unusual attribute — for example, "has corners" vs. "has no corners" (circles go in one group; squares, triangles, and rectangles go in the other). "What is my sorting rule?" This one is harder. Give hints if needed: "Look at this group. What do they all have?" ("Corners!") "And this group?" ("No corners — they are all round!")

*Facilitator prompt: If the student cannot guess the rule, point to one group and ask: "What do you notice about ALL of these? What is the same about them?" Guide the student to find the common attribute.*

## Independent Practice

### Tier 1 (Approaching)
1. Here are 6 blocks: 3 red and 3 blue. "Sort them by color." (Student puts red blocks together and blue blocks together.)
2. "What is your sorting rule?" ("Color" or "I put the reds together and the blues together.")
3. Here are 4 shapes: 2 circles and 2 squares. "Sort them by shape." (Student puts circles together and squares together.)
4. Look at this group: circle, circle, circle. "What do they all have in common?" (They are all circles.)

### Tier 2 (On Level)
1. Sort 10 mixed objects by SHAPE. "How many groups did you make? What is in each group?" (Student sorts into 3-4 groups and explains.)
2. Now re-sort the SAME 10 objects by COLOR. "How did your groups change?" (Different objects are together now because the rule changed.)
3. Look at two pre-sorted groups: Group A has big triangle, big square, big circle. Group B has small triangle, small square, small circle. "What is the sorting rule?" (Size — big vs. small.)
4. "Sort these objects by SIZE: big, medium, small." Give 6 objects of 3 different sizes. (Student sorts into 3 groups.)
5. "Can you think of a sorting rule that has NOT been used yet?" (Accept creative answers: smooth vs. rough, has holes vs. no holes, flat vs. not flat, etc.)

### Tier 3 (Advanced)
1. Sort 15 objects by one attribute. Then sort them by a SECOND attribute. "Which sorting made MORE groups? Why?" (Answers vary — student explains.)
2. "I sorted these into two groups: {circle, square, rectangle} and {triangle}. What could my rule be?" (This is tricky — one rule could be: "3 or more sides that are the same length" vs. "not," or "has at least one pair of parallel sides" vs. "does not." Accept any rule the student can defend. The intended answer is simpler: "shapes with 4 sides or round" vs. "shapes with 3 sides," but creative thinking is welcome.)
3. "Sort the buttons by TWO attributes at once: find all the RED buttons with 2 holes." (Student identifies the subset that matches both criteria.)
4. Create your own collection of drawn shapes (draw 8 shapes on paper). "Make a sorting rule and sort them. Then tell me your rule." (Student draws, sorts, and explains.)
5. "If I add a new object to the collection — a purple hexagon — which group does it go in if we sort by color? What if we sort by number of sides?" (Student applies the existing sorting rule to a new object.)

---

## Exit Ticket (2-3 minutes)

1. Give the student 6 mixed objects (3 circles and 3 triangles in mixed colors). "Sort these by shape." (Student separates circles from triangles.)
2. "What is your sorting rule?" ("Shape" — or "circles go together, triangles go together.")
3. "Can you sort these same objects a different way?" (Yes — by color, or by size, or another attribute. Student re-sorts and explains.)

---

## Answer Key

**Tier 1 (Approaching):**
1. Red blocks in one group, blue blocks in another
2. "Color" (or equivalent explanation)
3. Circles in one group, squares in another
4. They are all circles

**Tier 2 (On Level):**
1. Student sorts into groups by shape and explains; number of groups depends on shapes present (typically 3-4)
2. Groups change because different objects share colors vs. shapes; student explains the difference
3. Size (big vs. small)
4. Student creates 3 groups: big, medium, small
5. Accept any valid new attribute (texture, material, function, etc.)

**Tier 3 (Advanced):**
1. Answers vary; student compares number of groups and explains why (e.g., sorting by color made 4 groups, sorting by shape made 3)
2. Accept any defensible rule (e.g., "shapes with 4 sides or 0 sides" vs. "shapes with 3 sides"; or "has a right angle" vs. "does not")
3. Student correctly identifies only the red buttons that also have 2 holes
4. Student draws shapes, sorts them, and articulates the rule
5. Purple hexagon: by color it goes in a new "purple" group (or with other purples if present); by number of sides it goes in a new "6 sides" group

**Exit Ticket:**
1. Circles in one group, triangles in another
2. "Shape" or equivalent
3. Student re-sorts by color, size, or another attribute and explains the new rule

## Teacher Notes

**Common Errors:**
- **Sorting by multiple attributes at once without realizing it:** A student might put all the "big red circles" together and call that a group, but leave out small red circles. Ask: "Is your rule COLOR, or SIZE, or SHAPE? Pick just one for now." Sorting by two attributes simultaneously is an advanced skill (Tier 3).
- **Not knowing what "sorting rule" means:** If the student can sort the objects but cannot articulate the rule, scaffold with: "Look at this group you made. What is the SAME about all of these?" Then help the student form the sentence: "My sorting rule is ___."
- **Thinking there is only one right way to sort:** Students may believe there is one "correct" answer. Emphasize: "There are MANY ways to sort the same objects! Sorting by color is right. Sorting by shape is also right. It depends on what RULE you pick." This is an important metacognitive insight.

**Tips for Success:**
- Use the CRA progression: start with Concrete sorting of real objects, move to Representational sorting (drawing shapes and circling groups), and finish with Abstract description of sorting rules in words.
- For the "Guess My Sorting Rule" game, start with obvious rules (color, shape) and progress to less obvious ones (size, number of corners, curved vs. straight sides). This game is highly engaging and builds reasoning skills.
- If the student finishes quickly, challenge them to find as many different sorting rules as possible for the same collection. Can they sort by color, shape, size, texture, weight, number of sides, and number of corners? Each new rule shows flexible thinking.
- Use real-world connections: "When you put away your toys, you are SORTING — cars go in one bin, stuffed animals in another. What is your sorting rule at home?"

**Look-Fors:**
- Can the student sort a collection into clear groups with no leftover "unsorted" items?
- Can the student state the sorting rule in their own words?
- Can the student re-sort the same collection using a different attribute?
- Can the student look at a pre-sorted collection and identify the rule used?
- Does the student understand that there are multiple valid ways to sort the same objects?

**Connection to Future Learning:**
Sorting and classifying is foundational to data analysis and statistics. In Grade 1, students will organize data into categories and represent it in tally charts and bar graphs. The ability to choose an attribute and group by it is also critical in science (classifying living things, materials, weather patterns). In later math, sorting by attributes connects to understanding properties of geometric figures (e.g., all quadrilaterals have 4 sides) and algebraic thinking (e.g., grouping expressions by type).
