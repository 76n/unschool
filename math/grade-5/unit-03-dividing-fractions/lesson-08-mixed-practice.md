# Math — Grade 5 — Unit 3, Lesson 8

## Topic
Mixed Practice: Distinguishing Between the Two Types

## Learning Objectives
- Classify fraction division problems as Type 1 (whole number / unit fraction) or Type 2 (unit fraction / whole number).
- Select and apply the correct procedure for each type.
- Explain the reasoning behind choosing a particular approach.
- Solve both types fluently and check answers using multiplication.

## Prerequisites
- Dividing a whole number by a unit fraction: visual models and procedure (Lessons 2-4).
- Dividing a unit fraction by a whole number: visual models and procedure (Lessons 5-7).
- Checking division with multiplication.

## Materials Needed
- Whiteboard and markers (or projector).
- Index cards (for sorting activity) -- write one problem per card.
- Paper and pencil.
- Two-column organizer handout (optional).

**Standards:** 5.NF.7 — Apply and extend previous understandings of division to divide unit fractions by whole numbers and whole numbers by unit fractions.

## Warm-Up (5 minutes)
**Purpose:** Highlight the dramatic difference between the two types.

1. Write on the board, side by side:
   - 6 / 1/3 = ?
   - 1/3 / 6 = ?
2. Ask: "These two problems look almost the same. Solve both."
3. Give students 1-2 minutes.
4. Reveal: 6 / 1/3 = 18 and 1/3 / 6 = 1/18.
5. Say: "The same numbers give VERY different answers depending on the order. 18 vs. 1/18! Today we will practice telling the two types apart and solving both correctly."

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Type 1 (measurement):** whole number / unit fraction — asks "how many [unit fractions] fit in [whole number]?" Answer is large.
- **Type 2 (sharing):** unit fraction / whole number — asks "what is [unit fraction] shared among [whole number]?" Answer is small.
- **Dividend:** the first number in a division expression (what you start with).
- **Divisor:** the second number (what you divide by).

### Instruction Notes

**Step 1 — Side-by-side comparison.**

Write a two-column chart on the board:

| Type 1: Whole Number / Unit Fraction | Type 2: Unit Fraction / Whole Number |
|--------------------------------------|--------------------------------------|
| 6 / 1/3 = ? | 1/3 / 6 = ? |
| "How many 1/3s fit in 6?" | "1/3 shared among 6" |
| Answer: 6 x 3 = 18 | Answer: 1/(3 x 6) = 1/18 |
| Answer is BIGGER than 6 | Answer is SMALLER than 1/3 |

Say: "Here is the most important question to ask yourself: what am I starting with? If I start with a whole number and divide it into fractional pieces, that is Type 1. If I start with a fraction and share it among people, that is Type 2."

**Step 2 — Decision-making questions.**

Say: "Before you solve any problem, ask yourself these three questions."

Write on the board:
1. "What is the dividend (what am I starting with)?"
2. "What is the divisor (what am I dividing by)?"
3. "Should the answer be bigger or smaller than the dividend?"

Work through an example:
- Problem: 4 / 1/5 = ?
- Dividend: 4 (a whole number). Divisor: 1/5 (a unit fraction).
- Type 1: whole number / unit fraction. Answer should be bigger than 4.
- Solve: 4 x 5 = 20. Check: 20 x 1/5 = 4.

Another example:
- Problem: 1/4 / 7 = ?
- Dividend: 1/4 (a unit fraction). Divisor: 7 (a whole number).
- Type 2: unit fraction / whole number. Answer should be smaller than 1/4.
- Solve: 1/(4 x 7) = 1/28. Check: 1/28 x 7 = 7/28 = 1/4.

**Step 3 — Sorting activity introduction.**

Say: "Now we are going to sort problems into two groups. I will show you a problem, and you hold up one finger for Type 1 or two fingers for Type 2. Then we will solve."

Present these problems one at a time (have students signal before solving):
- 3 / 1/6 (Type 1, answer: 18)
- 1/5 / 4 (Type 2, answer: 1/20)
- 1/2 / 9 (Type 2, answer: 1/18)
- 8 / 1/3 (Type 1, answer: 24)
- 1/8 / 5 (Type 2, answer: 1/40)

**Step 4 — Word problem sorting.**

Say: "Word problems can be trickier. Let's read two problems and decide which type each one is."

Write:
- Problem A: "A rope is 5 feet long. It is cut into pieces that are each 1/4 foot. How many pieces?" (Type 1: 5 / 1/4 = 20)
- Problem B: "A piece of tape is 1/4 foot long. It is cut into 5 equal pieces. How long is each piece?" (Type 2: 1/4 / 5 = 1/20)

Say: "See how both problems mention 5 and 1/4, but they are different types? In Problem A, we start with 5 feet and count pieces. In Problem B, we start with 1/4 foot and share it."

### Worked Examples

**Example A: 7 / 1/4**
Type: 1 (whole number / unit fraction). Answer should be bigger than 7.
Solve: 7 x 4 = 28. Check: 28 x 1/4 = 7.
**Answer: 28**

**Example B: 1/6 / 5**
Type: 2 (unit fraction / whole number). Answer should be smaller than 1/6.
Solve: 1/(6 x 5) = 1/30. Check: 1/30 x 5 = 5/30 = 1/6.
**Answer: 1/30**

**Example C: 10 / 1/2**
Type: 1 (whole number / unit fraction). Answer should be bigger than 10.
Solve: 10 x 2 = 20. Check: 20 x 1/2 = 10.
**Answer: 20**

## Guided Practice (10 minutes)

For each problem: (a) identify the type, (b) predict whether the answer is bigger or smaller than the dividend, (c) solve, (d) check.

1. 1/3 / 8 = ?
   - Type 2. Answer smaller than 1/3.
   - 1/(3 x 8) = 1/24. Check: 1/24 x 8 = 8/24 = 1/3.
   - **Answer: 1/24**

2. 9 / 1/5 = ?
   - Type 1. Answer bigger than 9.
   - 9 x 5 = 45. Check: 45 x 1/5 = 9.
   - **Answer: 45**

3. 1/4 / 10 = ?
   - Type 2. Answer smaller than 1/4.
   - 1/(4 x 10) = 1/40. Check: 1/40 x 10 = 10/40 = 1/4.
   - **Answer: 1/40**

4. 5 / 1/8 = ?
   - Type 1. Answer bigger than 5.
   - 5 x 8 = 40. Check: 40 x 1/8 = 5.
   - **Answer: 40**

5. 1/10 / 3 = ?
   - Type 2. Answer smaller than 1/10.
   - 1/(10 x 3) = 1/30. Check: 1/30 x 3 = 3/30 = 1/10.
   - **Answer: 1/30**

6. 12 / 1/4 = ?
   - Type 1. Answer bigger than 12.
   - 12 x 4 = 48. Check: 48 x 1/4 = 12.
   - **Answer: 48**

**Facilitator tip:** If students consistently confuse the types, have them underline the dividend and circle the divisor before classifying.

## Independent Practice (10-15 minutes)

### Part A: Sort and Solve
Classify each problem as Type 1 or Type 2. Then solve and check.

1. 4 / 1/6 = ?
2. 1/5 / 7 = ?
3. 1/2 / 8 = ?
4. 6 / 1/5 = ?
5. 1/8 / 3 = ?
6. 11 / 1/3 = ?
7. 1/4 / 9 = ?
8. 7 / 1/6 = ?
9. 1/3 / 10 = ?
10. 3 / 1/8 = ?

### Part B: Word Problem Sorting
For each problem, write the equation, identify the type, and solve.

11. A nature trail is 4 miles long. Rest stops are placed every 1/3 of a mile. How many rest stops are there?
12. A jar holds 1/4 of a gallon of honey. The honey is divided equally among 6 jars. How much honey is in each jar?
13. Marcus has 1/6 of a pizza. He shares it equally with 2 friends (3 people total). How much pizza does each person get?
14. A farmer has 8 acres. Each plot is 1/4 of an acre. How many plots are there?

### Part C: Compare and Explain
15. Without computing, determine which is greater: 5 / 1/3 or 1/3 / 5. Explain your reasoning.
16. Sarah got an answer of 1/24 for the problem 8 / 1/3. Is her answer reasonable? What might she have done wrong?

### Answer Key

**Part A**
1. Type 1: 4 / 1/6 = 4 x 6 = 24. Check: 24 x 1/6 = 4.
2. Type 2: 1/5 / 7 = 1/35. Check: 1/35 x 7 = 7/35 = 1/5.
3. Type 2: 1/2 / 8 = 1/16. Check: 1/16 x 8 = 8/16 = 1/2.
4. Type 1: 6 / 1/5 = 6 x 5 = 30. Check: 30 x 1/5 = 6.
5. Type 2: 1/8 / 3 = 1/24. Check: 1/24 x 3 = 3/24 = 1/8.
6. Type 1: 11 / 1/3 = 11 x 3 = 33. Check: 33 x 1/3 = 11.
7. Type 2: 1/4 / 9 = 1/36. Check: 1/36 x 9 = 9/36 = 1/4.
8. Type 1: 7 / 1/6 = 7 x 6 = 42. Check: 42 x 1/6 = 7.
9. Type 2: 1/3 / 10 = 1/30. Check: 1/30 x 10 = 10/30 = 1/3.
10. Type 1: 3 / 1/8 = 3 x 8 = 24. Check: 24 x 1/8 = 3.

**Part B**
11. Type 1: 4 / 1/3 = 12 rest stops.
12. Type 2: 1/4 / 6 = 1/24 of a gallon per jar.
13. Type 2: 1/6 / 3 = 1/18 of the pizza per person.
14. Type 1: 8 / 1/4 = 32 plots.

**Part C**
15. 5 / 1/3 is much greater. It equals 15 (a whole number bigger than 5). Meanwhile, 1/3 / 5 = 1/15 (a tiny fraction). Dividing a large number by a small fraction gives a large answer; dividing a small fraction by a large number gives a tiny answer.
16. Sarah's answer of 1/24 is not reasonable for 8 / 1/3. The answer should be bigger than 8, not a small fraction. She likely confused the types and solved 1/3 / 8 = 1/24 instead. The correct answer is 8 / 1/3 = 8 x 3 = 24.

## Assessment Check

A bakery has 6 pounds of flour. Each loaf of bread uses 1/4 pound of flour.
A customer bought 1/4 of a pound of cheese and shared it equally among 6 sandwiches.

Write two different equations using the numbers 6 and 1/4. Solve both. Explain the difference.

**Target response:**
Flour problem: 6 / 1/4 = 24 loaves. This is Type 1 (how many 1/4-pound portions fit in 6 pounds).
Cheese problem: 1/4 / 6 = 1/24 pound per sandwich. This is Type 2 (1/4 pound shared among 6).
The same numbers give very different answers (24 vs. 1/24) because the roles of dividend and divisor are reversed.

## Extension

- **Create a Matching Game:** Write 8 word problems on cards and 8 equations on separate cards. Mix them up and match each word problem to its equation. Include both types.
- **What If:** What is 1/2 / 1/2? Is it Type 1 or Type 2? Neither type exactly fits, but you can think of it as "how many 1/2s fit into 1/2?" The answer is 1. Explore: 1/3 / 1/3, 1/4 / 1/4. What pattern do you see? (A number divided by itself always equals 1.)
