# Math — Grade 5 — Unit 3, Lesson 6

## Topic
Unit Fraction / Whole Number: Developing the Procedure

## Learning Objectives
- Identify and describe the pattern: 1/n / w = 1/(n x w).
- Apply the procedure to compute unit fraction / whole number without drawing a model.
- Explain why the procedure works by connecting it to the partitioning models from Lesson 5.
- Verify answers using the inverse relationship between multiplication and division.

## Prerequisites
- Using partitioning diagrams to divide a unit fraction by a whole number (Lesson 5).
- Understanding that dividing a unit fraction by a whole number asks "If this fraction is shared among this many people, how much does each get?" (Lessons 1, 5).
- Whole-number multiplication fluency.

## Materials Needed
- Whiteboard and markers (or projector).
- Fraction strips (available for students who need concrete support).
- Paper and pencil.
- Index cards or half-sheets for exit ticket.

**Standards:** 5.NF.7b — Interpret division of a unit fraction by a non-zero whole number, and compute such quotients.

## Warm-Up (5 minutes)
**Purpose:** Surface the pattern from Lesson 5 data.

1. Write these completed problems from Lesson 5 on the board:
   - 1/2 / 3 = 1/6
   - 1/3 / 2 = 1/6
   - 1/4 / 5 = 1/20
   - 1/3 / 4 = 1/12
   - 1/4 / 2 = 1/8
   - 1/5 / 3 = 1/15
2. Ask: "Look at the denominator of the answer. How does it relate to the original fraction and the whole number?"
3. Give students 1-2 minutes to discuss with a partner.
4. Gather responses. Guide toward: "The denominator of the answer is the original denominator times the whole number."
5. Say: "Today we are going to turn that pattern into a procedure, understand why it works, and practice using it."

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Procedure:** a step-by-step method for solving a type of problem.
- **Inverse operations:** multiplication and division undo each other.
- **Reciprocal:** the fraction you get by flipping numerator and denominator (reciprocal of 3 is 1/3).

### Instruction Notes

**Step 1 — Confirm the pattern with a new example.**

Write on the board: 1/6 / 5 = ?

Say: "Let's think about this with our model first. We have 1/6 of a whole. We share it among 5 people. From Lesson 5, we know that if we draw the rectangle with 6 rows and 5 columns, we get 30 total pieces. Each person gets 1 of the 5 pieces in the shaded row, so each person gets 1/30."

Write: 1/6 / 5 = 1/30 = 1/(6 x 5).

Say: "The pattern holds. The denominator of the answer is 6 x 5 = 30."

**Step 2 — State the rule.**

Write on the board:
- **1/n / w = 1/(n x w)**
- "To divide a unit fraction by a whole number, multiply the denominator by the whole number."

Say: "This makes sense because sharing means making pieces smaller. Smaller pieces have bigger denominators."

**Step 3 — Connect to multiply-by-the-reciprocal.**

Say: "There is another way to think about this. Dividing by a whole number w is the same as multiplying by 1/w."

Write: 1/n / w = 1/n x 1/w = 1/(n x w).

Say: "For example, 1/4 / 3 = 1/4 x 1/3 = 1/12. This is the same as multiplying two unit fractions, which you learned in Unit 2!"

**Step 4 — The checking step: multiply to verify.**

Say: "Just like with the other type, we check by multiplying. If 1/6 / 5 = 1/30, then 1/30 x 5 should equal 1/6."

Write: 1/30 x 5 = 5/30 = 1/6. Correct!

Write the checking rule:
- If a / b = c, then c x b = a.
- Example: 1/6 / 5 = 1/30, so 1/30 x 5 = 5/30 = 1/6.

**Step 5 — Procedure steps.**

Write on the board:
1. Identify the unit fraction (dividend) and the whole number (divisor).
2. Multiply the denominator of the unit fraction by the whole number. That is the new denominator. The numerator stays 1.
3. Write the answer as 1/(original denominator x whole number).
4. Check: multiply the answer by the whole number. You should get the original unit fraction.

### Worked Examples

**Example A: 1/3 / 7**
Step 1: Unit fraction = 1/3, whole number = 7.
Step 2: New denominator: 3 x 7 = 21.
Step 3: 1/3 / 7 = 1/21.
Step 4: Check: 1/21 x 7 = 7/21 = 1/3. Correct.
**Answer: 1/21**

**Example B: 1/5 / 4**
Step 1: Unit fraction = 1/5, whole number = 4.
Step 2: New denominator: 5 x 4 = 20.
Step 3: 1/5 / 4 = 1/20.
Step 4: Check: 1/20 x 4 = 4/20 = 1/5. Correct.
**Answer: 1/20**

**Example C: 1/8 / 3**
Step 1: Unit fraction = 1/8, whole number = 3.
Step 2: New denominator: 8 x 3 = 24.
Step 3: 1/8 / 3 = 1/24.
Step 4: Check: 1/24 x 3 = 3/24 = 1/8. Correct.
**Answer: 1/24**

## Guided Practice (10 minutes)

Solve each problem using the procedure. Show the check step.

1. 1/4 / 6 = ?
   - 4 x 6 = 24. Answer: 1/24. Check: 1/24 x 6 = 6/24 = 1/4.
   - **Answer: 1/24**

2. 1/2 / 7 = ?
   - 2 x 7 = 14. Answer: 1/14. Check: 1/14 x 7 = 7/14 = 1/2.
   - **Answer: 1/14**

3. 1/6 / 3 = ?
   - 6 x 3 = 18. Answer: 1/18. Check: 1/18 x 3 = 3/18 = 1/6.
   - **Answer: 1/18**

4. 1/10 / 2 = ?
   - 10 x 2 = 20. Answer: 1/20. Check: 1/20 x 2 = 2/20 = 1/10.
   - **Answer: 1/20**

5. 1/3 / 8 = ?
   - 3 x 8 = 24. Answer: 1/24. Check: 1/24 x 8 = 8/24 = 1/3.
   - **Answer: 1/24**

6. 1/5 / 6 = ?
   - 5 x 6 = 30. Answer: 1/30. Check: 1/30 x 6 = 6/30 = 1/5.
   - **Answer: 1/30**

**Facilitator tip:** For problems 1-3, after computing, ask students to quickly sketch the partitioning diagram to confirm. This reinforces the connection between the procedure and the model.

## Independent Practice (10-15 minutes)

### Part A: Computation
Solve using the procedure. Show the check step.

1. 1/3 / 6 = ?
2. 1/4 / 5 = ?
3. 1/2 / 9 = ?
4. 1/8 / 4 = ?
5. 1/6 / 7 = ?
6. 1/5 / 8 = ?
7. 1/10 / 5 = ?
8. 1/7 / 3 = ?

### Part B: Explain the Connection
9. Kenji says "1/4 / 3 = 3/4 because you multiply the numerator by 3." Is he correct? What is the correct answer and what mistake did he make?
10. Show that 1/3 / 5 gives the same answer as 1/3 x 1/5. Explain why this works.
11. Fill in the blank: 1/6 / ___ = 1/42. Explain how you found your answer.

### Part C: Word Problems
12. A piece of string is 1/4 of a meter long. It is cut into 3 equal pieces. How long is each piece?
13. There is 1/3 of a pie left. It is shared equally among 5 friends. What fraction of the whole pie does each friend get?

### Answer Key

**Part A**
1. 1/3 / 6 = 1/18. Check: 1/18 x 6 = 6/18 = 1/3.
2. 1/4 / 5 = 1/20. Check: 1/20 x 5 = 5/20 = 1/4.
3. 1/2 / 9 = 1/18. Check: 1/18 x 9 = 9/18 = 1/2.
4. 1/8 / 4 = 1/32. Check: 1/32 x 4 = 4/32 = 1/8.
5. 1/6 / 7 = 1/42. Check: 1/42 x 7 = 7/42 = 1/6.
6. 1/5 / 8 = 1/40. Check: 1/40 x 8 = 8/40 = 1/5.
7. 1/10 / 5 = 1/50. Check: 1/50 x 5 = 5/50 = 1/10.
8. 1/7 / 3 = 1/21. Check: 1/21 x 3 = 3/21 = 1/7.

**Part B**
9. Kenji is not correct. The correct answer is 1/4 / 3 = 1/12. Kenji multiplied the numerator by 3 (getting 3/4), but he should have multiplied the denominator by 3. Dividing by 3 makes the fraction smaller, not larger. 3/4 is bigger than 1/4, which does not make sense for sharing 1/4 among 3 people.
10. 1/3 / 5 = 1/15. Also, 1/3 x 1/5 = (1 x 1)/(3 x 5) = 1/15. They give the same answer because dividing by 5 is the same as multiplying by 1/5 (the reciprocal of 5).
11. 1/6 / 7 = 1/42, because 6 x 7 = 42. So the blank is 7.

**Part C**
12. 1/4 / 3 = 1/12 of a meter per piece.
13. 1/3 / 5 = 1/15 of the whole pie per friend.

## Assessment Check

Solve: 1/5 / 6 = ?
Show the procedure AND explain in words why the answer makes sense.

**Target response:** 1/5 / 6 = 1/30. Procedure: denominator 5 x 6 = 30, so the answer is 1/30. This makes sense because we are sharing 1/5 among 6 people. Each person gets a very small piece. 1/30 is much smaller than 1/5, which is what we expect when sharing among many people. Check: 1/30 x 6 = 6/30 = 1/5.

## Extension

- **Tiny Fractions:** Solve 1/2 / 100. What is the answer? Can you explain what this would look like in real life? (Answer: 1/200. Example: if you have half a dollar (50 cents) and split it among 100 people, each person gets 1/200 of a dollar, which is half a cent.)
- **Missing Number Challenge:** Find the missing number in each equation.
  - 1/? / 4 = 1/20 (Answer: 5, because 5 x 4 = 20)
  - 1/3 / ? = 1/24 (Answer: 8, because 3 x 8 = 24)
  - 1/? / ? = 1/36 -- find at least 3 different pairs (Answers: 1/4 / 9, 1/6 / 6, 1/9 / 4, 1/12 / 3, 1/18 / 2, 1/36 / 1, etc.)
