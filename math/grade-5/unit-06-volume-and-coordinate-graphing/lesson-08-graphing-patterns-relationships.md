# Math — Grade 5 — Unit 6, Lesson 8

## Topic
Graphing Patterns and Relationships on the Coordinate Plane

## Learning Objectives
By the end of this lesson, the student will be able to:
- Generate coordinate pairs from a rule or pattern table and plot them on the coordinate plane
- Describe the visual pattern formed by a set of plotted points
- Identify the relationship between x and y values in a plotted pattern
- Use the graph to predict coordinates for values not explicitly given

## Prerequisites
- Plotting and reading ordered pairs (Lessons 6–7)
- Understanding of rules and input/output tables (Grade 4 patterns)
- Skip-counting and multiplication patterns

## Materials Needed
- Graph paper (2 sheets per student)
- Rulers
- Colored pencils
- Whiteboard

---

## Warm-Up (5 minutes)
**Purpose:** Activate understanding of rules and input/output tables as a precursor to graphing them.

Write this table on the board:

| x | y |
|---|---|
| 1 | 3 |
| 2 | 6 |
| 3 | 9 |
| 4 | 12 |

Ask: "What is the rule that connects x and y?" (y = 3 × x, or y = 3x)
"What would y be when x = 5?" (15)
"What would y be when x = 10?" (30)

Say: "Today we're going to take tables like this and turn them into pictures on the coordinate plane."

---

## Direct Instruction (12 minutes)
**Purpose:** Show how a rule (or table) generates coordinate pairs; demonstrate graphing the pairs and reading the resulting pattern.

### Key Vocabulary
- **Rule:** a mathematical relationship that determines the output (y) from any input (x)
- **Pattern:** a predictable arrangement or sequence — visually, plotted points may form a recognizable pattern
- **Table of values:** an organized list of x-values and corresponding y-values for a given rule

### Instruction Notes

**Step 1 — From rule to table to graph**
Write the rule: y = x + 2.

Create a table:

| x | y = x + 2 |
|---|-----------|
| 0 | 2 |
| 1 | 3 |
| 2 | 4 |
| 3 | 5 |
| 4 | 6 |

Plot each point: (0,2), (1,3), (2,4), (3,5), (4,6). Ask: "What do you notice?" (The points form a straight line going diagonally upward.)

Connect the points with a ruler. Say: "When a rule connects x and y by adding or subtracting a constant, the graph is a straight line. This is called a linear pattern."

**Step 2 — Predict from the graph**
Ask: "Using the graph, what would y be when x = 6?" (8) Have students extend the line and read the value. Then verify: y = 6 + 2 = 8. ✓

**Step 3 — Compare two patterns**
Rule A: y = x (every y equals x)
Rule B: y = 2x (every y equals 2 times x)

Plot both on the same grid (use different colors). Ask:
- "Which graph is steeper?" (Rule B — it goes up faster.)
- "Do they share any points?" (Yes: at (0, 0) both y-values are 0.)

### Worked Examples

**Example 1:** Generate a table and graph for y = x + 4 using x = 0, 1, 2, 3, 4.

| x | y |
|---|---|
| 0 | 4 |
| 1 | 5 |
| 2 | 6 |
| 3 | 7 |
| 4 | 8 |

Points: (0,4), (1,5), (2,6), (3,7), (4,8) — straight diagonal line.

**Example 2:** Generate a table for y = 2x using x = 0, 1, 2, 3, 4, 5.

| x | y |
|---|---|
| 0 | 0 |
| 1 | 2 |
| 2 | 4 |
| 3 | 6 |
| 4 | 8 |
| 5 | 10 |

Points: (0,0), (1,2), (2,4), (3,6), (4,8), (5,10) — straight line through origin.

**Example 3:** Given the graph of y = 3x, predict y when x = 4.
- Extend the line past (3, 9). The next point should be at (4, 12). y = 12.

## Guided Practice (10 minutes)
Students work through these together; compare tables and graphs with a partner.

**Problem 1:** Complete the table for y = x + 1 using x = 0, 1, 2, 3, 4. Plot the points on graph paper. What pattern do you see?

| x | y = x + 1 |
|---|-----------|
| 0 | 1 |
| 1 | 2 |
| 2 | 3 |
| 3 | 4 |
| 4 | 5 |

Points: (0,1), (1,2), (2,3), (3,4), (4,5) — straight diagonal line.

**Problem 2:** Two friends are saving money. Luis saves $3 each week. Sofia saves $2 each week. They both start with $0.
- Complete tables for both:
  - Luis: Week 0 = $0, Week 1 = $3, Week 2 = $6, Week 3 = $9, Week 4 = $12 → y = 3x
  - Sofia: Week 0 = $0, Week 1 = $2, Week 2 = $4, Week 3 = $6, Week 4 = $8 → y = 2x
- Plot both on the same grid. Who has more money after 4 weeks? Who has a steeper graph?
  - Luis has more ($12 vs. $8); Luis's graph is steeper.

**Discussion:** "What does the steepness of the line tell us about the situation?"
- Steeper = grows faster = saves more per week.

## Independent Practice (13 minutes)

### Difficulty Tiers

**On-level:**
1. Complete the table for y = x + 3 (x = 0, 1, 2, 3, 4, 5) and plot the points.

   | x | 0 | 1 | 2 | 3 | 4 | 5 |
   |---|---|---|---|---|---|---|
   | y | 3 | 4 | 5 | 6 | 7 | 8 |

   What is the pattern? Points form a straight line.

2. Complete the table for y = 4x (x = 0, 1, 2, 3) and plot.

   | x | 0 | 1 | 2 | 3 |
   |---|---|---|---|---|
   | y | 0 | 4 | 8 | 12|

   Where does this line start? At the origin (0, 0).

3. Look at the graph of a rule (teacher provides graph with plotted points at (0,2), (1,4), (2,6), (3,8)). What is the rule?
   - y = 2x + 2, OR y = 2(x + 1); check: 2×0+2=2 ✓, 2×1+2=4 ✓, 2×2+2=6 ✓, 2×3+2=8 ✓

**Stretch:**
4. A faucet drips 5 mL of water every minute.
   a. Complete a table for minutes 0–5.
   b. Write the rule: y = ___
   c. Plot the relationship.
   d. How many mL will drip in 8 minutes?

   - a. (0,0), (1,5), (2,10), (3,15), (4,20), (5,25)
   - b. y = 5x
   - d. y = 5 × 8 = 40 mL

5. Two graphs: Line A passes through (0,0), (1,5), (2,10). Line B passes through (0,1), (1,3), (2,5).
   - a. What is the rule for each line?
   - b. At what value of x do they have the same y-value? (Find the intersection point.)

   - a. Line A: y = 5x; Line B: y = 2x + 1
   - b. 5x = 2x + 1 → 3x = 1 → x = 1/3 (this is beyond most 5th graders; acceptable to leave as "they don't intersect at a whole-number x" or "between x=0 and x=1" with visual estimate)

6. A pattern rule gives these coordinates: (1, 4), (2, 8), (3, 12). Predict the coordinate when x = 7.
   - Rule: y = 4x; y = 4 × 7 = 28; point = (7, 28)

**Challenge:**
7. A plant grows 3 cm every 2 days. It starts at 0 cm height.
   - a. Fill in a table for every 2 days up to day 10 (x = days, y = height in cm)
   - b. What is the rule?
   - c. On what day will the plant be exactly 15 cm tall?

   - a. (0,0), (2,3), (4,6), (6,9), (8,12), (10,15)
   - b. y = 1.5x (or: y = 3x/2; or: every 2 days adds 3 cm)
   - c. Day 10 (y = 15 when x = 10 using the table)

### Interleaved Review
R1. Find the volume of a composite shape: Prism A is 4 × 3 × 2 and Prism B is 2 × 3 × 5. *(Lesson 5 — additive volume)*
   - 24 + 30 = 54 cubic units

R2. Calculate: 5/6 × 3/4. *(Unit 2 — fraction multiplication)*
   - 15/24 = 5/8

R3. Write 4.3 million in standard form. *(Unit 5 — place value)*
   - 4,300,000

## Check for Understanding (3 minutes)

**Exit Ticket:**
1. Complete the table for y = x + 5 using x = 0, 1, 2, 3.
2. Plot the points on the mini-grid provided.
3. Predict: what would y be when x = 8?

**Mastery = Correctly fills in the table (5, 6, 7, 8), plots all 4 points accurately, and predicts y = 13 when x = 8.**

### If Mastery Is Not Met
- Return to tables: ensure student can fill in a table before expecting graphing
- Check whether the student understands that each row of the table becomes one plotted point (x, y)
- Practice: "If x = 3 and the rule is y = x + 5, what is y? Now write that as an ordered pair."

### If Mastery Is Met
- Ask: "If the rule were y = x + 100, would the graph still be a straight line? What would be different?"

## Extension (Optional)
**Design a Graph Story:** Create a table of values that tells a story. For example: "A car travels 60 miles every hour. Make a table for 0–5 hours and graph the relationship." Then write 3 questions someone could answer by reading the graph.

## Teacher/Facilitator Notes
- The primary 5.G.2 standard is about graphing and interpreting points in real-world contexts. Ensure you connect the abstract pattern (y = 2x) to a concrete context (saving $2 per week) whenever possible.
- This lesson does NOT require students to write equations using formal algebra notation — "y = 2x" is used descriptively, not as an algebraic topic to be assessed.
- Emphasize that each row in the table = one point on the graph. Students sometimes think the table and graph are separate tasks rather than two representations of the same data.
- "What does the steepness tell us?" is a powerful conceptual question. Students may not use the word "slope" yet, but the intuition that a steeper line = faster change is valuable.
- Keep all x and y values non-negative in the first quadrant (both axes 0–10 or 0–12).
