# Math — Grade 5 — Unit 6, Lesson 6

## Topic
Introduction to the Coordinate Plane — Axes, Origin, and Ordered Pairs

## Learning Objectives
By the end of this lesson, the student will be able to:
- Identify the x-axis, y-axis, origin, and first quadrant of the coordinate plane
- Understand that a point on the coordinate plane is named by an ordered pair (x, y)
- Explain what each number in an ordered pair represents
- Locate a given point on the coordinate plane by starting at the origin and moving right, then up

## Prerequisites
- Whole-number number lines (Grade 2–3)
- Understanding of horizontal and vertical directions
- Basic multiplication facts (for labeling axes)

## Materials Needed
- Large grid paper posted on the board (or projected)
- Individual graph paper (1 per student, ideally 10 × 10 first-quadrant grid)
- Rulers
- Colored pencils (at least 2 colors per student)
- Optional: masking tape on the floor to create a life-size coordinate grid

---

## Warm-Up (5 minutes)
**Purpose:** Connect the idea of "two-number location" to students' existing experience.

Ask: "Has anyone ever played Battleship? Or used a map with a grid?" Take responses.

Show a simple street map grid (or draw one) with labeled columns (A, B, C...) and rows (1, 2, 3...). Point to a square. Ask: "How would I tell someone exactly where this square is?"

Expected: "You say the letter and the number." or "It's at B-3."

Say: "In math, we do the same thing — but both labels are numbers, and the order matters. Today we learn the system mathematicians use."

---

## Direct Instruction (14 minutes)
**Purpose:** Build the coordinate plane from scratch; establish vocabulary and conventions with precision.

### Key Vocabulary
- **Coordinate plane:** a flat surface formed by two perpendicular number lines that intersect at a point called the origin
- **x-axis:** the horizontal number line on the coordinate plane
- **y-axis:** the vertical number line on the coordinate plane
- **Origin:** the point where the x-axis and y-axis intersect; labeled (0, 0)
- **Ordered pair:** a pair of numbers (x, y) that names the location of a point on the coordinate plane; the x-coordinate comes first, the y-coordinate comes second
- **x-coordinate:** the first number in an ordered pair; tells how far to move right from the origin along the x-axis
- **y-coordinate:** the second number in an ordered pair; tells how far to move up from the origin along the y-axis
- **First quadrant:** the region of the coordinate plane where both the x-coordinate and y-coordinate are greater than or equal to 0

### Instruction Notes

**Step 1 — Build the coordinate plane**
On large grid paper, draw a horizontal number line (0–10). Label it "x-axis." Draw a vertical number line (0–10) from the same starting point (0). Label it "y-axis." Label the intersection "(0, 0)" — the origin.

Say: "The x-axis goes left and right — it's horizontal. The y-axis goes up and down — it's vertical. Where they cross is called the origin. The origin is always (0, 0)."

**Step 2 — Name an ordered pair**
Point to a dot at 3 units right and 5 units up. Ask: "How far did we go right?" (3) "How far did we go up?" (5) Write (3, 5).

Say: "We always write the x-coordinate first — how far right. Then the y-coordinate — how far up. The parentheses and comma show these two numbers belong together as an ordered pair."

Write on the board as a memory aid:
> (x, y) — x comes first, just like x comes before y in the alphabet.

**Step 3 — The "right then up" procedure**
Model plotting a point:
1. Start at the origin (0, 0)
2. Move RIGHT by the x-coordinate
3. From that position, move UP by the y-coordinate
4. Mark the point with a dot
5. Label the dot with its ordered pair

Plot (4, 2) together. Have students trace with their finger. Plot (0, 6). Note: "We don't move right at all; we just go up 6."
Plot (7, 0). Note: "We go right 7, but we don't go up; we stay on the x-axis."

**Step 4 — Reading a point**
Point to a plotted dot. Ask: "How far right from the origin is this point?" (4) "How far up?" (3) "What is the ordered pair?" (4, 3)

Emphasize: counting grid lines from the origin (not spaces).

### Worked Examples

**Example 1:** Plot the point (5, 3).
- Start at origin. Move right 5. Move up 3. Place dot. Label (5, 3).

**Example 2:** Plot the point (0, 4).
- Start at origin. Do not move right. Move up 4. Place dot. Label (0, 4).

**Example 3:** Point A is plotted on the grid. It appears to be 2 units to the right of the origin and 7 units up. What is its ordered pair?
- (2, 7)

**Example 4:** What is the ordered pair for the origin?
- (0, 0)

## Guided Practice (10 minutes)
Students use individual graph paper throughout.

**Task 1:** Label your graph paper with x-axis, y-axis, origin (0,0), and number both axes from 0 to 10. (Teacher models; students replicate.)

**Task 2:** Plot and label each point:
- A = (3, 5)
- B = (7, 2)
- C = (0, 8)
- D = (6, 0)
- E = (1, 1)

After plotting: ask students to describe in words where each point is (e.g., "B is 7 units to the right and 2 units up from the origin").

**Task 3:** Teacher points to unlabeled dots on the large board grid. Students call out the ordered pair.
- Dot at 4 right, 4 up: (4, 4)
- Dot at 9 right, 1 up: (9, 1)
- Dot at 0 right, 0 up: (0, 0)

**Discussion check:** "Why do we say ordered pair? What would happen if we switched the two numbers in (3, 5) to (5, 3)? Would we end up in the same place?"
- No! (3,5) and (5,3) are different points. This is why the order matters.

## Independent Practice (12 minutes)

### Difficulty Tiers

**On-level:**
Use the coordinate plane on your graph paper (labeled 0–10 on each axis).

1. Plot and label each point:
   - F = (2, 6)
   - G = (8, 3)
   - H = (5, 5)
   - J = (0, 3)
   - K = (4, 0)

2. Write the ordered pair for each labeled point below (teacher provides a grid with pre-plotted points):
   - Point P is 3 right, 7 up: (3, 7)
   - Point Q is 10 right, 0 up: (10, 0)
   - Point R is 6 right, 6 up: (6, 6)

3. True or False: The point (2, 5) is the same as the point (5, 2). Explain.
   - False: (2, 5) is 2 right and 5 up; (5, 2) is 5 right and 2 up — different locations.

4. What is the x-coordinate of the origin? What is the y-coordinate?
   - Both are 0; origin = (0, 0).

**Stretch:**
5. Point M is 3 units to the right of point (4, 5). What are M's coordinates?
   - (7, 5) — same y-coordinate, x increases by 3

6. Point N is 4 units above point (2, 3). What are N's coordinates?
   - (2, 7) — same x-coordinate, y increases by 4

7. Two students both start at the origin. Anaya moves right 5 then up 2. Bao moves up 5 then right 2. Do they end at the same point? Explain.
   - No. Anaya ends at (5, 2); Bao ends at (2, 5). Different points.

**Challenge:**
8. Point A is at (3, 8). Point B is at (7, 8). Point C is at (7, 2). These three points are corners of a rectangle. What is the fourth corner D?
   - The rectangle must have a corner at (3, 2): D = (3, 2)

9. If you move from (2, 3) to (2, 9), which coordinate changed? By how much?
   - The y-coordinate increased by 6; x-coordinate stayed the same.

### Interleaved Review
R1. Find the volume of a box: 8 in × 3 in × 5 in. *(Lesson 3 review)*
   - 120 in³

R2. Order from least to greatest: 3/8, 1/2, 1/4, 5/8. *(Unit 1 — fraction comparison)*
   - 1/4, 3/8, 1/2, 5/8

R3. 10² × 3 = ? *(Unit 5 — powers of 10)*
   - 300

## Check for Understanding (3 minutes)

**Exit Ticket:**
1. Label the parts of the coordinate plane: Which axis is horizontal? Which is vertical? What is the name of the point (0,0)?
2. Plot the point (6, 2) on the grid provided. Label it with its ordered pair.
3. What does the "4" in the ordered pair (4, 9) tell you?

**Mastery = Correctly identifies all parts, plots the point at the right location (6 right, 2 up), and explains that the "4" is the x-coordinate telling how far right from the origin.**

### If Mastery Is Not Met
- Return to the physical walk activity if available (tape grid on floor)
- Have student trace the path from origin to point with a finger, naming "right" then "up"
- Focus on the distinction: x tells how far RIGHT, y tells how far UP

### If Mastery Is Met
- Ask: "In the ordered pair (x, y), what would happen if one of the values were 0? What would the point look like on the grid?"

## Extension (Optional)
**Coordinate Riddle:** Create your own set of 5 coordinate "clues" that spell a letter when plotted and connected. For example, plotting (1, 5), (1, 1), (3, 1), (3, 3), (3, 5) connected in order might sketch a shape. Share your riddle with a partner.

---

## Teacher/Facilitator Notes
- If you have space, consider making a floor grid with masking tape before this lesson. Students physically walking the "right then up" procedure dramatically reduces reversal errors.
- The "x before y in the alphabet" memory trick is useful but not sufficient — pair it with the physical action of moving right first, then up.
- The most important error to prevent: students who go UP first, then RIGHT. Correct this immediately and consistently.
- Reinforce that we are ONLY in the first quadrant this unit (both coordinates ≥ 0). Do not go past 0 on either axis.
- Keep graph paper organized: axes labeled, numbers clearly marked. Sloppy grids cause unnecessary errors.
- Challenge problem 8 (rectangle completion) is an excellent spatial reasoning task; it previews work with geometric shapes on the coordinate plane.
