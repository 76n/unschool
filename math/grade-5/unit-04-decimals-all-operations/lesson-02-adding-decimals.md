# Math — Grade 5 — Unit 4, Lesson 2

## Topic
Adding Decimals

## Learning Objectives
By the end of this lesson, the student will be able to:
- Add decimals to hundredths using the standard algorithm with proper decimal-point alignment.
- Annex zeros to create like decimal places before adding.
- Model decimal addition using base-ten blocks or decimal grids.
- Verify the reasonableness of a sum using estimation.

## Prerequisites
- Decimal place value through thousandths (Lesson 1).
- Fluent addition of multi-digit whole numbers with regrouping.
- Understanding that 0.5 = 0.50 = 0.500 (equivalent decimals).

## Materials Needed
- Base-ten blocks (flat = 1 whole, rod = 0.1, unit cube = 0.01).
- Decimal grid paper (10x10 grids).
- Graph paper (for vertical alignment).
- Whiteboard and markers.
- Index cards for exit ticket.

**Standards:** 5.NBT.7

---

## Warm-Up (5 minutes)
**Purpose:** Review place value and activate whole-number addition skills.

1. Add without a calculator: 347 + 268 = ?
   - **Answer: 615**
2. Write 3.4 with two decimal places: ___
   - **Answer: 3.40**
3. Round 6.78 to the nearest whole number: ___
   - **Answer: 7**

Say: "You already know how to add whole numbers. Today we are going to add decimals. The big idea is simple: line up the decimal points, then add exactly like you do with whole numbers."

---

## Direct Instruction (10-15 minutes)

### Key Vocabulary
- **Align:** Line up numbers so that digits with the same place value are in the same column.
- **Regroup (carry):** When a column adds to 10 or more, carry to the next column to the left.
- **Annex zeros:** Add zeros to the right of a decimal so both numbers have the same number of decimal places.

### Instruction Notes

**Step 1 — Start with a concrete model.**

Say: "Let's add 1.3 + 0.45 using base-ten blocks."

Build 1.3: one flat (1 whole) and 3 rods (3 tenths).
Build 0.45: 4 rods (4 tenths) and 5 unit cubes (5 hundredths).

Say: "Now combine them. Put the wholes together: 1 flat. Put the tenths together: 3 rods + 4 rods = 7 rods. The hundredths: 5 unit cubes. So we have 1 whole, 7 tenths, and 5 hundredths. That is 1.75."

**Step 2 — Transition to the algorithm.**

Write on the board vertically:
```
  1.30
+ 0.45
------
```

Say: "Notice I wrote 1.3 as 1.30. I annexed a zero so both numbers have two decimal places. This makes it easier to line everything up."

Say: "Now I add column by column from right to left, just like with whole numbers."
- Hundredths: 0 + 5 = 5
- Tenths: 3 + 4 = 7
- Ones: 1 + 0 = 1
- Decimal point goes straight down.

Write the answer: 1.75.

Say: "The key rule: always line up the decimal points. Then add normally."

**Step 3 — An example with regrouping.**

Write: 3.68 + 2.47

```
  3.68
+ 2.47
------
```

- Hundredths: 8 + 7 = 15. Write 5, carry 1.
- Tenths: 6 + 4 + 1 (carried) = 11. Write 1, carry 1.
- Ones: 3 + 2 + 1 (carried) = 6.
- Decimal point straight down.

**Answer: 6.15**

Say: "Check with estimation: 3.68 is about 4, and 2.47 is about 2. So the sum should be about 6. Our answer of 6.15 is close to 6. That makes sense."

**Step 4 — Adding numbers with different numbers of decimal places.**

Write: 12.5 + 3.274

Say: "First, annex zeros: 12.500 + 3.274."

```
  12.500
+  3.274
--------
```

- Thousandths: 0 + 4 = 4
- Hundredths: 0 + 7 = 7
- Tenths: 5 + 2 = 7
- Ones: 2 + 3 = 5
- Tens: 1 + 0 = 1

**Answer: 15.774**

Estimate check: 12.5 is about 13, and 3.274 is about 3. 13 + 3 = 16. Our answer of 15.774 is close to 16.

### Worked Examples

**Example A:** 0.6 + 0.38
- Annex zero: 0.60 + 0.38
- Hundredths: 0 + 8 = 8
- Tenths: 6 + 3 = 9
- **Answer: 0.98**

**Example B:** 4.95 + 3.7
- Annex zero: 4.95 + 3.70
- Hundredths: 5 + 0 = 5
- Tenths: 9 + 7 = 16. Write 6, carry 1.
- Ones: 4 + 3 + 1 = 8.
- **Answer: 8.65**

## Guided Practice (10 minutes)

Solve together. For each problem, first annex zeros, then add vertically.

1. 2.4 + 1.35 = ?
   - 2.40 + 1.35
   - **Answer: 3.75**

2. 0.08 + 0.9 = ?
   - 0.08 + 0.90
   - **Answer: 0.98**

3. 5.67 + 3.48 = ?
   - **Answer: 9.15** (regrouping in hundredths: 7 + 8 = 15; tenths: 6 + 4 + 1 = 11)

4. 14.3 + 6.725 = ?
   - 14.300 + 6.725
   - **Answer: 21.025**

5. $7.50 + $3.85 = ?
   - **Answer: $11.35** (regrouping: 0 + 5 = 5; 5 + 8 = 13; 7 + 3 + 1 = 11)

**Facilitator tip:** If the student forgets to align the decimal point, have them use graph paper with one digit per square and a highlighted column for the decimal point.

5. Is 0.5 + 0.5 = 0.10? Explain why or why not.

## Teacher Notes

- The most common error is misalignment. Students who add 3.4 + 2.17 may write it as 3.4 + 2.17 and add 4 + 7 in the rightmost column, getting 3.4 + 2.17 = 5.57 instead of the correct 5.57. Actually that happens to work in this case, but consider 3.4 + 2.17 with misalignment: students might write 34 + 217 = 251, then not know where to put the decimal. Always enforce vertical alignment with the decimal points lined up.
- Graph paper is your best friend in this lesson. One digit per square, with the decimal point occupying its own column.
- Money is the most natural context for decimal addition. Use it liberally.
- Some students benefit from saying the problem aloud: "Three and forty hundredths plus two and seventeen hundredths."
- Preview: "Tomorrow we will subtract decimals. The same alignment rule applies -- line up the decimal points first."
