# English Language Arts Scope and Sequence — Grades K-8

**Subject:** English Language Arts
**Version:** 1.0
**Date:** 2026-04-08
**Status:** Complete (K-8)

This document maps the grade-by-grade topic progression for the English Language Arts curriculum. Each grade is organized into units that build systematically from foundational literacy skills toward sophisticated reading, writing, and language competencies. The curriculum follows the progression outlined in the Teaching Methodology Framework (Section 2.3).

## Vertical Alignment: Key Concept Threads

### Reading Foundations: Decoding to Fluency to Analysis
K: Phonemic awareness, letter-sound correspondences --> 1: Phonics patterns, decoding one-syllable words --> 2: Advanced phonics, oral fluency with expression --> 3-5: Fluent reading with comprehension focus --> 6-8: Close reading with textual evidence

### Comprehension: Retelling to Critical Analysis
K: Retell familiar stories, identify characters/settings/events --> 1: Key details, main topic, text connections --> 2: Central message, who/what/where/when/why/how --> 3: Explicit text reference, character analysis --> 4: Theme, point of view, depth of character/setting --> 5: Quoting accurately, theme + summary, comparison across texts --> 6: Citing evidence, theme development, structural analysis --> 7: Multiple evidence, theme analysis, contrasting viewpoints --> 8: Strongest evidence, theme-character-setting-plot relationships, point of view effects

### Informational Text: Features to Argument Evaluation
K-1: Key details, main topic --> 2: How reasons support points --> 3: Main idea, text features, text structure --> 4: Main idea + details, firsthand/secondhand accounts, charts/graphs --> 5: Multiple main ideas, integrating multiple texts --> 6: Central idea, author's purpose, multimedia --> 7: Multiple central ideas, evaluating arguments and claims --> 8: Central idea development, argument evaluation, conflicting sources

### Writing: Drawing to Argumentation
K: Drawing/dictating/writing to compose --> 1: Opinion/informative/narrative with structure (introduction, details, closure) --> 2: Focused writing with organization and development; revision and editing --> 3: Opinion with reasons, informative with facts, narrative with dialogue --> 4: Sophisticated opinion/informative/narrative, transitions, typing fluency --> 5: Clear topics, evidence-based writing, varied transitions, task-appropriate --> 6: Arguments with claims/reasons/evidence, informative examination, narrative with descriptive detail --> 7: Arguments acknowledging opposing claims, informative with relevant facts, narrative techniques (dialogue, pacing) --> 8: Claims with evidence, counterclaim distinction, varied evidence types, logical narrative sequencing

### Grammar & Language: Conventions to Style
K: Nouns/verbs, capitalization, end punctuation --> 1: Noun types, conventional spelling, end punctuation --> 2: Collective nouns, irregular plurals, possessives --> 3: Verb forms, adjective comparison, commas/quotation marks, dictionary skills --> 4: Relative pronouns/adverbs, progressive tenses, word choice for effect --> 5: Correlative conjunctions, verb tense precision, sentence combining --> 6: Subject-verb agreement, nonrestrictive elements, sentence variety --> 7: Phrases/clauses, sentence types, coordinate adjectives, spelling --> 8: Verbals, active/passive voice, verb moods, voice/mood shifts
